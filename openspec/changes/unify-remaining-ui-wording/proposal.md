# Proposal

## Why

2026-11-13のWeb UIの監査（U-14、#207）で、#121で直した範囲の外に、同じ種類の操作の名前の食い違いが残っていた。やり直しと続きの読み込み、すぐ始める操作の名前が、画面によって分かれている。トピックの追加、保存の知らせ、入力をやめるボタンも同じである。設定の区画「トークン」はアプリを接続するQRコードも含み、区画の名前からアプリの接続を探せない。PRODUCT.mdは、検索のあるいまの画面と合わない「検索はまだない」を書いている。

## What Changes

- 読み込みの失敗の表示のやり直しのボタンを、「再試行」から「もう一度試す」にする。
- すぐ始める操作を「いま〜」の形にそろえる。カテゴリの「いますぐ実行」を「いま実行」に、ダイジェストの「今すぐ作る」を「いま作る」にする。購読フィードの「いま取得」は変えない。
- フィルターの画面の隠している記事の一覧の「さらに表示」を、記事の一覧と同じ「さらに読み込む」にする。
- 読む画面の「トピックを足す…」を「トピックを追加…」に、そのダイアログの見出しを「トピックを追加」にする。
- カテゴリの設定を保存したときの知らせを「カテゴリを保存しました」にする。
- 読む画面の購読フィードを追加するダイアログの「閉じる」を「やめる」にする。
- 設定の画面に区画「アプリの接続」を「利用量」と「トークン」の間に足し、QRコードの説明と表示のボタンを移す。「トークン」の区画には、トークンを消す操作だけを残す。上部の区画のリンクにも「アプリの接続」を足す。
- PRODUCT.mdの「検索はまだない」の文を消し、できることの一覧に検索を足す。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-shell`：「失敗の表示」の「サーバーに届かない」の場面で、表示するボタンを「もう一度試す」にする。
- `web-settings`：区画「アプリの接続」に接続用のQRコードを置く要件を足す。

## Impact

- `apps/web/src`の画面の文言と、それを名前で探すテスト。
- 進行中の変更`add-digests`の「今すぐ作る」と、`add-topic-from-reader`の「トピックを足す」。
- 進行中の変更`add-settings-shortcuts`の区画のリンクの一覧と、`add-feed-from-category`の追加のダイアログの「閉じるボタン」。
- `README.md`、`README.ja.md`、`docs/providers.md`の「今すぐ作る」と、`PRODUCT.md`。
- サーバー、API、Androidアプリには影響しない。
