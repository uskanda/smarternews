# grilling 記録: unify-remaining-ui-wording

Issue #207（監査ID U-14の残り）のコメントで、8つの質問と推奨の答えを出した。Issueのオーナーは、Q1をB、ほかの7つを推奨のAで答えた。そのあと計画を `/ok` で承認した。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| すぐ始める操作の呼び方 | B：「いま実行」「いま作る」「いま取得」にする。カテゴリの「いますぐ実行」とダイジェストの「今すぐ作る」を直し、「いま取得」は残す | 第1ラウンド Q1 |
| 設定の区画「トークン」 | A：区画を2つに分ける。「アプリの接続」を足してQRコードを移し、「トークン」には消す操作だけを残す。「トークン」の名前と `#tokens` は変えない | 第1ラウンド Q2 |
| やり直しの操作の名前 | A：「もう一度試す」にそろえる。読み込みの失敗の表示の「再試行」と、web-shellの要件の「再試行のボタン」を直す | 第1ラウンド Q3 |
| 続きの読み込みの名前 | A：「さらに読み込む」にそろえる。フィルターの画面の「さらに表示」を直す | 第1ラウンド Q4 |
| トピックの追加の名前 | A：「トピックを追加…」（ダイアログの見出しは「トピックを追加」）にそろえる。進行中の変更add-topic-from-readerも、grilling.mdを除いて直す | 第1ラウンド Q5 |
| カテゴリの保存の知らせ | A：「カテゴリを保存しました」にする | 第1ラウンド Q6 |
| 購読フィードの追加の「閉じる」 | A：「やめる」にする。入力のないダイアログの「閉じる」は変えない | 第1ラウンド Q7 |
| PRODUCT.mdの「検索はまだない」 | A：消して、できることの行に「検索」を足す | 第1ラウンド Q8 |
| 計画 | 承認。追加の変更の指示はなし | 会話中に確認（Issueのコメントの `/ok`） |
