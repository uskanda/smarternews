# Spec Delta

## ADDED Requirements

### Requirement: 区画「アプリの接続」

設定の画面は、区画「アプリの接続」を「利用量」のすぐあと、「トークン」のすぐ前に表示しなければならない（MUST）。
接続用のQRコードの説明と表示するためのボタンは、この区画に置き、「トークン」の区画には置かない。
「トークン」の区画には、このブラウザーからトークンを消す操作を置く。
画面の上部の区画のリンクにも「アプリの接続」を置く。

#### Scenario: QRコードの置き場所

- **WHEN** 設定の画面を開く
- **THEN** 接続用のQRコードを表示するボタンは区画「アプリの接続」にあり、区画「トークン」にはない

#### Scenario: リンクからアプリの接続へ移る

- **WHEN** 上部の区画のリンクの「アプリの接続」を選ぶ
- **THEN** 画面は「アプリの接続」の区画までスクロールする
