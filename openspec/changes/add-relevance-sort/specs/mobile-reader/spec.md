# Spec Delta

## MODIFIED Requirements

### Requirement: 並び順のメニュー

記事の一覧を表示している間、アプリは、一覧の画面の上部に並び順のメニューを表示しなければならない（MUST）。
メニューの選択肢は「新しい順」「古い順」「関連度順」の3つで、メニューを開く前から、いまの並び順が分かるようにする。

#### Scenario: 購読フィードの一覧を開く

- **WHEN** 並び順を変えていない購読フィードXを引き出しで選ぶ
- **THEN** 一覧の画面の上部に並び順のメニューが表示され、いまの並び順は新しい順と読み取れる

## ADDED Requirements

### Requirement: 関連度順の表示

並び順のメニューで「関連度順」を選んだとき、アプリは、表示中の項目の一覧を関連度順で先頭から表示し直さなければならない（MUST）。
アプリは、記事の関連度の値と、その理由を表示しない。一覧の行の見た目は、新しい順のときと変えない。

#### Scenario: 関連度順に変える

- **WHEN** カテゴリBの一覧で、並び順のメニューから「関連度順」を選ぶ
- **THEN** 一覧は関連度順で先頭から表示され、いまの並び順が関連度順と読み取れる
