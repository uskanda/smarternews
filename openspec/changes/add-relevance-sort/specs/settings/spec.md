# Spec Delta

## ADDED Requirements

### Requirement: 関連度順の並び順の保持

サーバーは、項目ごとの並び順として、新しい順と古い順に加えて関連度順を保存しなければならない（MUST）。
既定は新しい順のままである。保存した関連度順は、Webとアプリで共有する。

#### Scenario: 再起動のあとも残る

- **WHEN** 「未読」の並び順を関連度順にしてから、サーバーを再起動する
- **THEN** 「未読」の並び順は関連度順のままである

### Requirement: 設定ファイルでの関連度順

設定ファイルの書き出しは、関連度順にした項目を `sort: relevance` として含めなければならない（MUST）。
設定ファイルの読み込みを受けたとき、サーバーは、`sort: relevance` と書かれた項目の並び順を関連度順として保存する。

#### Scenario: 関連度順にした項目を書き出す

- **WHEN** カテゴリ `tools` を関連度順にした状態で書き出す
- **THEN** 返されたYAMLには、識別名 `tools` のカテゴリが `sort: relevance` として含まれる

#### Scenario: 別のサーバーへ移す

- **WHEN** 「すべて」を関連度順にしたサーバーから書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーでも、「すべて」は関連度順である
