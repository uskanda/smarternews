# Spec Delta

## MODIFIED Requirements

### Requirement: 並び順のメニュー

記事の一覧を表示している間、画面は、一覧のペインの上部に並び順のメニューを表示しなければならない（MUST）。
メニューの選択肢は「新しい順」「古い順」「関連度順」の3つで、メニューを開く前から、いまの並び順が分かるようにする。

#### Scenario: 購読フィードの一覧を開く

- **WHEN** 並び順を変えていない購読フィードXを左のペインで選ぶ
- **THEN** 一覧のペインの上部に並び順のメニューが表示され、いまの並び順は新しい順と読み取れる

#### Scenario: キーボードだけで選ぶ

- **WHEN** 並び順のメニューへキーボードでフォーカスを移し、キーの操作だけで「古い順」を選ぶ
- **THEN** 一覧は古い順に表示される

## ADDED Requirements

### Requirement: 関連度順の表示

並び順のメニューで「関連度順」を選んだとき、画面は、表示中の項目の一覧を関連度順で先頭から表示し直さなければならない（MUST）。
画面は、記事の関連度の値と、その理由を表示しない。一覧の行の見た目は、新しい順のときと変えない。

#### Scenario: 関連度順に変える

- **WHEN** 一覧「未読」で、並び順のメニューから「関連度順」を選ぶ
- **THEN** 一覧は関連度順で先頭から表示され、メニューのボタンからいまの並び順が関連度順と読み取れる

#### Scenario: 読んだ記事を残す

- **WHEN** 関連度順の「未読」の一覧で、2件目の記事を開いて既読にし、一覧が取得し直される
- **THEN** 既読にした記事は、関連度順の並びの同じ位置に残る
