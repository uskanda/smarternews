# Spec Delta

## MODIFIED Requirements

### Requirement: 記事を変えない色付け

サーバーは、色付けの語の登録、変更、削除によって、記事の内容、既読、スター、一覧に含まれるかどうかを変えてはならない（MUST NOT）。
変わってよいのは、関連度順の一覧での並びだけである。

#### Scenario: 語を足す

- **WHEN** 未読の配信記事3件のタイトルに含まれる語を、色付けの語として登録する
- **THEN** 3件は未読のまま記事の一覧に含まれ、未読数は変わらない

## ADDED Requirements

### Requirement: 並びのための語の照合

サーバーは、配信記事ごとに、見出し、翻訳した見出し、要約のどれかに色付けの語が1つでも一致するかどうかを保存しなければならない（MUST）。
照合の方法は、画面とアプリの色付けと同じである。
サーバーは、配信記事を保存したとき、見出しを書き換えたとき、翻訳した見出しを保存したときにその記事を照合し、色付けの語またはまとまりを足すか消したときにすべての配信記事を照合し直す。

#### Scenario: 翻訳した見出しに一致する

- **WHEN** 色付けの語「半導体」を登録したあとで、英語の見出しの配信記事を保存し、翻訳した見出し「半導体の新工場」を保存する
- **THEN** その記事は、色付けの語に一致する記事として関連度順の一覧に並ぶ

#### Scenario: 全角と半角を区別しない

- **WHEN** 色付けの語「ＧＰＵ」を登録し、見出しに「gpu」を含む配信記事がある
- **THEN** その記事は、色付けの語に一致する記事として扱われる

#### Scenario: 語を消す

- **WHEN** 配信記事Aの見出しに一致していた色付けの語を消す
- **THEN** 記事Aは、色付けの語に一致しない記事として扱われる
