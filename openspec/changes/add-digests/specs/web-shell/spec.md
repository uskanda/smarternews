# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストの画面のURL

画面は、ダイジェストの画面を `/digests` で、識別子を指定したダイジェストを `/digests/<識別子>` で開かなければならない（MUST）。
ブラウザーを再読み込みしたとき、画面は同じダイジェストを表示し直す。

#### Scenario: 再読み込み

- **WHEN** 過去のダイジェストを選んだ状態で、ブラウザーを再読み込みする
- **THEN** 同じダイジェストが表示される

### Requirement: 「ダイジェスト」を動かせないこと

画面は、左のペインの「ダイジェスト」をドラッグで動かせるようにしてはならない（MUST NOT）。

#### Scenario: 「ダイジェスト」をドラッグしようとする

- **WHEN** 左のペインの「ダイジェスト」の上でマウスのボタンを押したまま動かす
- **THEN** ドラッグは始まらず、「ダイジェスト」は「注釈」の下にとどまる
