# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストを作る時刻の欄

設定の画面は、全体設定の区画に、ダイジェストを作る時刻の欄を表示しなければならない（MUST）。
欄には `HH:MM` の時刻を「,」か空白で区切って書く。空にすると、時刻ではダイジェストを作らない。
サーバーが値を拒否したとき、画面はその欄に誤りを表示する。

#### Scenario: 時刻を変える

- **WHEN** ダイジェストを作る時刻の欄に「6:30, 18:30」の形で `06:30, 18:30` と書いて保存する
- **THEN** 全体設定のダイジェストを作る時刻は6:30と18:30になる

#### Scenario: 不正な時刻

- **WHEN** ダイジェストを作る時刻の欄に `25:00` と書いて保存する
- **THEN** その欄に誤りが表示され、ダイジェストを作る時刻は変わらない
