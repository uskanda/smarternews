# Spec Delta

## ADDED Requirements

### Requirement: アプリのダイジェストの画面

引き出しの「ダイジェスト」が選ばれたとき、アプリは、最新のダイジェストと、過去のダイジェストの一覧を表示しなければならない（MUST）。
ダイジェストは、期間、エグゼクティブサマリー、カテゴリの区画の順に表示する。区画には、カテゴリの名前を見出しとして付ける。
過去の一覧の項目が押されたとき、アプリはそのダイジェストを表示する。

#### Scenario: 引き出しで選ぶ

- **WHEN** 7:00と19:00のダイジェストがある状態で、引き出しの「ダイジェスト」を押す
- **THEN** 19:00のダイジェストが表示され、過去の一覧に2件が並ぶ

### Requirement: アプリの根拠の記事へのリンク

アプリは、カテゴリの区画の各行に、まだ保存されている根拠の記事のタイトルを、押せる項目として表示しなければならない（MUST）。
押されたとき、アプリはその記事の本文の画面を開く。

#### Scenario: 根拠の記事を押す

- **WHEN** 区画の1行の根拠の記事を押す
- **THEN** その記事の本文の画面が開く

### Requirement: アプリのダイジェストがないときの表示

ダイジェストが1つもないとき、アプリは、ダイジェストがまだないことを表示しなければならない（MUST）。

#### Scenario: 初めて開く

- **WHEN** ダイジェストが1つもない状態で、引き出しの「ダイジェスト」を押す
- **THEN** アプリは、ダイジェストがまだないことを表示する
