# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストの一覧の操作

APIは、ダイジェストを作った時刻の新しい順に並べた一覧と、ダイジェストを作っている最中かどうかを返す操作を提供しなければならない（MUST）。
一覧の各項目は、識別子、作った時刻、期間、きっかけ、入力にした記事の数、エグゼクティブサマリーを持つ。
件数は既定で30件とし、指定で200件まで増やせる。

#### Scenario: 2つのダイジェスト

- **WHEN** 7:00と19:00にダイジェストを作ったあとで、一覧を取得する
- **THEN** 19:00のダイジェスト、7:00のダイジェストの順に2件が返る

#### Scenario: 作っている最中

- **WHEN** 今すぐ作ることを求めた直後で、LLMの応答を待っている間に一覧を取得する
- **THEN** 応答は、作っている最中であることを示す

### Requirement: ダイジェストの取得の操作

APIは、識別子を指定したダイジェスト1件を、カテゴリの区画と各行の根拠の記事の識別子とともに返す操作を提供しなければならない（MUST）。
応答には、根拠の記事のうちまだ保存されている記事のタイトルと由来を含める。削除された記事は、行の識別子に残し、タイトルの一覧には含めない。

#### Scenario: 根拠の記事の1件が削除されている

- **WHEN** 根拠の記事が記事10と記事11の行があり、記事11が削除されたあとで、そのダイジェストを取得する
- **THEN** その行の根拠の記事の識別子は10と11で、タイトルの一覧には記事10だけがある

#### Scenario: 存在しない識別子

- **WHEN** 存在しない識別子のダイジェストを取得する
- **THEN** APIはHTTPステータス404を返す

### Requirement: 今すぐ作る操作

APIは、ダイジェストを今すぐ作る操作を提供しなければならない（MUST）。
作成を始めたとき、APIはHTTPステータス202を返し、作成の終わりを待たない。
ダイジェストを作っている最中なら、APIはHTTPステータス409を返す。
ダイジェストの1日の上限か月の予算に達しているとき、または期間内に記事がないとき、APIは作成を始めず、その理由を返す。

#### Scenario: 作っている最中に求める

- **WHEN** ダイジェストを作っている最中に、今すぐ作ることを求める
- **THEN** APIはHTTPステータス409を返し、新しい作成は始まらない

#### Scenario: 上限に達している

- **WHEN** ダイジェストの1日の上限に達した状態で、今すぐ作ることを求める
- **THEN** APIは、上限に達したことを理由として返し、LLMは呼び出されない

#### Scenario: 記事がない

- **WHEN** 期間内に記事がない状態で、今すぐ作ることを求める
- **THEN** APIは、記事がないことを理由として返し、LLMは呼び出されない

### Requirement: ダイジェストの呼び出し回数の提供

APIは、プロバイダーの状態に、その日のダイジェストの呼び出し回数と、ダイジェストの1日の上限を含めなければならない（MUST）。

#### Scenario: 1回作った日

- **WHEN** その日にダイジェストを1回作ったあとで、プロバイダーの状態を取得する
- **THEN** ダイジェストの呼び出し回数は1で、記事を書く実行の呼び出し回数には数えられていない
