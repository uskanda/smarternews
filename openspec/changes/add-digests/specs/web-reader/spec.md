# Spec Delta

## ADDED Requirements

### Requirement: 「ダイジェスト」の項目

画面は、左のペインの「注釈」の下に、「ダイジェスト」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 左のペインを見る

- **WHEN** 画面を開く
- **THEN** 左のペインの上部に「未読」「すべて」「スター」「AI生成」「最近読んだ記事」「注釈」「ダイジェスト」の順で項目が並び、「ダイジェスト」の横に数字はない

### Requirement: ダイジェストの画面

左のペインの「ダイジェスト」が選ばれたとき、画面は、最新のダイジェストと、過去のダイジェストの一覧を表示しなければならない（MUST）。
ダイジェストは、期間、エグゼクティブサマリー、カテゴリの区画の順に表示する。区画には、カテゴリの名前を見出しとして付ける。
一覧の項目が選ばれたとき、画面はそのダイジェストを表示する。

#### Scenario: 2つのダイジェストがある

- **WHEN** 7:00と19:00のダイジェストがある状態で、「ダイジェスト」を選ぶ
- **THEN** 19:00のダイジェストが表示され、過去の一覧に2件が並ぶ

#### Scenario: 過去のダイジェストを選ぶ

- **WHEN** ダイジェストの画面で、過去の一覧の7:00のダイジェストを選ぶ
- **THEN** 7:00のダイジェストのエグゼクティブサマリーと区画が表示される

### Requirement: 根拠の記事へのリンク

画面は、カテゴリの区画の各行に、まだ保存されている根拠の記事へのリンクを、記事のタイトルで表示しなければならない（MUST）。
リンクが選ばれたとき、画面はその記事の本文を表示する。削除された根拠の記事のリンクは表示しない。

#### Scenario: 根拠の記事を開く

- **WHEN** 区画の1行の根拠の記事のリンクを選ぶ
- **THEN** その記事の本文が表示される

### Requirement: 画面からの今すぐ作る操作

画面は、ダイジェストの画面に「今すぐ作る」の操作を表示しなければならない（MUST）。
作っている間は、その操作を押せなくし、作っていることを表示する。作り終えたら、新しいダイジェストを表示する。
作らなかったときは、上限、予算、記事のないことのうち、当たる理由を表示する。

#### Scenario: 今すぐ作る

- **WHEN** 期間内に記事がある状態で、「今すぐ作る」を押す
- **THEN** 作っていることが表示され、作り終えると新しいダイジェストが表示される

#### Scenario: 記事がない

- **WHEN** 期間内に記事がない状態で、「今すぐ作る」を押す
- **THEN** 画面は、期間内に記事がないことを表示する

### Requirement: ダイジェストがないときの表示

ダイジェストが1つもないとき、画面は、ダイジェストがまだないことと、作る時刻を表示しなければならない（MUST）。
作る時刻の一覧が空のときは、時刻では作らないことを表示する。

#### Scenario: 初めて開く

- **WHEN** ダイジェストが1つもなく、作る時刻が7:00と19:00の状態で、「ダイジェスト」を選ぶ
- **THEN** ダイジェストがまだないことと、7:00と19:00に作ることが表示される
