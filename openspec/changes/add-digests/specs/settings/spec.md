# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストを作る時刻の保持

サーバーは、全体設定に、ダイジェストを作る時刻の一覧を保持しなければならない（MUST）。
時刻は `HH:MM` の形で、全体設定のタイムゾーンで解釈する。既定は7:00と19:00で、空の一覧も保持できる。

#### Scenario: 初めて起動した

- **WHEN** 新しいデータで起動し、全体設定を読む
- **THEN** ダイジェストを作る時刻の一覧は7:00と19:00である

#### Scenario: 一覧を空にする

- **WHEN** ダイジェストを作る時刻の一覧を空にして保存し、全体設定を読み直す
- **THEN** 一覧は空である

### Requirement: ダイジェストを作る時刻の検証

ダイジェストを作る時刻の一覧に `HH:MM` の形でない値があるとき、サーバーは全体設定の変更を拒否し、誤っている項目を示さなければならない（MUST）。
一覧は24個までとする。

#### Scenario: 25時

- **WHEN** ダイジェストを作る時刻に `25:00` を指定して全体設定を変える
- **THEN** 変更は拒否され、ダイジェストを作る時刻の項目の誤りが示される

### Requirement: 設定ファイルでのダイジェストを作る時刻の扱い

サーバーは、設定ファイルの書き出しに、ダイジェストを作る時刻の一覧を含めなければならない（MUST）。
読み込んだ設定ファイルにダイジェストを作る時刻の一覧がないとき、サーバーは保存されている一覧を変えない。

#### Scenario: 書き出して読み込む

- **WHEN** ダイジェストを作る時刻を6:30だけにして設定ファイルを書き出し、別のデータで読み込む
- **THEN** 読み込んだ側のダイジェストを作る時刻の一覧は6:30だけである

#### Scenario: 一覧のない設定ファイル

- **WHEN** ダイジェストを作る時刻が6:30だけの状態で、その項目のない設定ファイルを読み込む
- **THEN** ダイジェストを作る時刻の一覧は6:30だけのままである
