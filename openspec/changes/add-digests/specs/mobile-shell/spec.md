# Spec Delta

## ADDED Requirements

### Requirement: 引き出しの「ダイジェスト」の項目

アプリは、引き出しの「最近読んだ記事」の下に、「ダイジェスト」の項目を、数字を付けずに常に表示しなければならない（MUST）。
アプリは、引き出しの「ダイジェスト」をドラッグで動かせるようにしてはならない。

#### Scenario: 引き出しを開く

- **WHEN** 引き出しを開く
- **THEN** 上部に「未読」「すべて」「スター」「AI生成」「最近読んだ記事」「ダイジェスト」の順で項目が並び、「ダイジェスト」の横に数字はない

#### Scenario: 「ダイジェスト」を長押しする

- **WHEN** 引き出しの「ダイジェスト」を長押しする
- **THEN** ドラッグは始まらない
