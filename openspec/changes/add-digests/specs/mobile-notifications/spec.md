# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストの通知

通知の設定が「出さない」でない間、確認の結果に、前回知らせたダイジェストより新しいダイジェストがあるとき、アプリはその通知を1つ出さなければならない（MUST）。
通知には「ダイジェスト」の題と、エグゼクティブサマリーの先頭を表示する。
新しいダイジェストが2つ以上あるときは、最も新しいダイジェストの通知だけを出す。

#### Scenario: 朝のダイジェスト

- **WHEN** 通知の設定が「重要度5だけ」で、前回の確認のあとに7:00のダイジェストができる
- **THEN** 通知が1つ出て、題は「ダイジェスト」、内容はそのエグゼクティブサマリーの先頭である

#### Scenario: 出さない設定

- **WHEN** 通知の設定が「出さない」で、ダイジェストができる
- **THEN** ダイジェストの通知は出ない

### Requirement: 同じダイジェストを繰り返し通知しないこと

アプリは、通知を出したダイジェストの通知を再び出してはならない（MUST NOT）。

#### Scenario: 次の確認

- **WHEN** ダイジェストの通知を出したあとで、新しいダイジェストがないまま次の確認が走る
- **THEN** ダイジェストの通知は増えない

### Requirement: 有効にする前からあるダイジェスト

通知の設定を「出さない」からほかの値へ変えたとき、アプリは、その時点より前からあるダイジェストの通知を出してはならない（MUST NOT）。
ダイジェストの通知を1度も確かめていない端末も同じく、最初の確認では通知を出さない。

#### Scenario: 有効にした直後

- **WHEN** ダイジェストが3つある状態で、通知の設定を「出さない」から「重要度5だけ」に変え、確認が走る
- **THEN** ダイジェストの通知は出ない

### Requirement: 記事の通知のまとめとの区別

アプリは、ダイジェストの通知を、記事の通知をまとめる件数に数えてはならない（MUST NOT）。

#### Scenario: 記事が3件とダイジェスト

- **WHEN** 1回の確認で、通知する記事が3件あり、新しいダイジェストが1つある
- **THEN** 記事ごとの3つの通知と、ダイジェストの通知の1つが出る

### Requirement: ダイジェストの通知を押したときの動き

ダイジェストの通知が押されたとき、アプリはそのダイジェストを表示しなければならない（MUST）。

#### Scenario: 通知を押す

- **WHEN** 7:00のダイジェストの通知を押す
- **THEN** アプリが開き、7:00のダイジェストが表示される
