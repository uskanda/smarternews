# Proposal

## Why

いまのsmarternewsでは、1日に何十件もの生成記事と数百件の配信記事が届く。利用者は、どれが重要かを一覧を順に読んで判断するしかない。
GitHubのissueの68番は、1日2回ほど、期間内の記事のうち重要なものをLLMでまとめた文章を求めている。全体をまとめたエグゼクティブサマリーと、カテゴリごとに3行程度のまとめである。

## What Changes

- 新しいLLMのタスク「ダイジェスト」を足す。タスクの限定を9つにする。
- 全体設定に、ダイジェストを作る時刻の一覧を足す。既定は7:00と19:00である。サーバーは、その時刻ごとにダイジェストを1つ作る。止まっていた間に過ぎた時刻は、6時間以内なら起動のときに1回だけ補う。
- ダイジェストの期間は、前回のダイジェストの期間の終わりから今までとし、長さは最大24時間とする。期間内に作られたか更新された生成記事と、期間内に保存された配信記事を入力にする。
- 入力は200件までとする。生成記事は重要度の高い順に選び、配信記事はそのあとに新しい順で選ぶ。配信記事には、タイトルと、自動の要約か配信された内容の先頭300文字だけを渡す。
- 1回のダイジェストのLLMの呼び出しは1回とする。出力は、800文字以内のエグゼクティブサマリーと、カテゴリの区画である。カテゴリの区画は1区画3行程度で、各行が根拠の記事の識別子を持つ。
- カテゴリのない購読フィードの配信記事は、エグゼクティブサマリーの入力にだけ使う。
- ダイジェストの呼び出しには、専用の1日の上限（既定4回）を置く。実行の1日の上限には数えない。月の予算はほかのタスクと同じく守る。
- ダイジェストは専用の表に保存し、180日で削除する。RSSには出さない。
- APIに、ダイジェストの一覧、1件の取得、今すぐ作る操作を足す。
- Webの左のペインとアプリの引き出しに「ダイジェスト」の項目を足し、ダイジェストの画面を足す。Webの画面には「今すぐ作る」を置く。
- Webの設定の画面で、作る時刻の一覧を編集できるようにする。設定ファイルの書き出しと読み込みにも含める。
- アプリは、新しいダイジェストができたら通知を1つ出す。押すと、そのダイジェストを開く。

## Capabilities

### New Capabilities

- `digests`: ダイジェストを作る時刻、停止中の補完、期間、入力の選び方、カテゴリの区画の規則、根拠の記事の確かめ方、保存期間、RSSに出さないことを定める

### Modified Capabilities

- `llm-tasks`: タスクの限定を9つにし、ダイジェストのタスクの入出力、割り当て、1日の上限、呼び出しの記録を足す
- `settings`: 全体設定のダイジェストを作る時刻の一覧と、その検証、設定ファイルでの扱いを足す
- `http-api`: ダイジェストの一覧、1件の取得、今すぐ作る操作を足す
- `web-reader`: 左のペインの「ダイジェスト」の項目と、ダイジェストの画面を足す
- `web-shell`: ダイジェストの画面のURLと、「ダイジェスト」を動かせないことを足す
- `web-settings`: 設定の画面の、ダイジェストを作る時刻の欄を足す
- `mobile-shell`: 引き出しの「ダイジェスト」の項目を足す
- `mobile-reader`: アプリのダイジェストの画面を足す
- `mobile-notifications`: ダイジェストの通知を足す

## Impact

- `packages/core`: 移行で、ダイジェストの表と、全体設定の時刻の列を足す。ダイジェストのタスク、入力の集め方、保存、作る処理（`DigestWorker`）、保存期間での削除を足す。設定に `limits.digestsPerDay` と、`tasks` の `digest` を足す。
- `apps/server`: `DigestWorker` の組み立てと起動、ダイジェストのAPIのルートを足す。
- `packages/client`: ダイジェストのAPIの呼び出しと、ダイジェストの通知を出すかどうかの判断を足す。
- `apps/web`: 左のペインの項目、ダイジェストの画面、設定の画面の時刻の欄を足す。
- `apps/mobile`: 引き出しの項目、ダイジェストの画面、通知の確認への組み込みを足す。
- `docs/`、`examples/config.example.yaml`、README: ダイジェストと新しい設定を書く。
- LLMの呼び出しは、既定の設定で1日2回増える。入力は最大200件の短い文章で、1回あたり数万トークンまでである。
