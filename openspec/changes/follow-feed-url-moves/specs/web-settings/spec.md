# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードのURLの変更の操作

購読フィードの編集の欄は、先頭に「URL」の欄を表示しなければならない（MUST）。
利用者がURLを変えて保存を選んだとき、画面は、ほかの変更と一緒にURLを送る。URLを変えていないときは、URLを送らない。
サーバーが確かめている間、保存のボタンは「確かめています…」と表示する。
検査に通らなかったとき、画面は編集の欄を閉じず、理由をURLの欄の下に表示する。

#### Scenario: URLを変えて保存する

- **WHEN** 購読フィードの編集の欄で、URLをフィードを返す別のURLに変えて保存する
- **THEN** 一覧のその行に新しいURLが表示される

#### Scenario: フィードでないURL

- **WHEN** 購読フィードの編集の欄で、URLをフィードの指定を持たないページのURLに変えて保存する
- **THEN** 編集の欄は開いたままで、URLの欄の下に理由が表示され、一覧のURLは変わらない

### Requirement: 転送によるURLの書き換えの表示

恒久的な転送でURLを書き換えた購読フィードについて、設定の購読フィードの画面は、行の取得の状況に書き換えを文で表示しなければならない（MUST）。
表示するのは、「転送によりURLを変更」の文言と、書き換えた日時と、書き換える前のURLである。
この表示は、次にURLが変わるまで出し続ける。この表示は、問題のある購読フィードの判定に入れない。

#### Scenario: 転送で書き換わった購読フィード

- **WHEN** 恒久的な転送でURLを書き換えた購読フィードのある状態で、設定の購読フィードの画面を開く
- **THEN** その行に「転送によりURLを変更」と日時と元のURLが表示され、「取得に失敗」の印は表示されない
