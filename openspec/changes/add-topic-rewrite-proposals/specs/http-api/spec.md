# Spec Delta

## ADDED Requirements

### Requirement: トピックの書き直しの案の操作

APIは、トピックを受けて、その書き直しの案を返す操作を提供しなければならない（MUST）。
操作は本文をとらず、案が出るまで待って答える。案を出したときは、案の一覧と案を出したことを示す状態を返す。
専用の1日の上限、1日あたりの呼び出し回数の上限、予算のどれかに達しているときは、LLMを呼ばずに、その理由を状態として返す。トピックが未解釈のときも同じである。
タスクが失敗したときと時間切れのときは、今は使えないことを示す応答を返す。存在しないトピックには、存在しないことを示す応答を返す。
この操作は、案とトピックのどちらも保存してはならない（MUST NOT）。

#### Scenario: 案を得る

- **WHEN** 解釈済みのトピックで、書き直しの案の操作を呼ぶ
- **THEN** APIは案を出したことを示す状態と、1つか2つの案を返す。トピックは呼ぶ前と同じである

#### Scenario: 上限に達している

- **WHEN** 書き直しの案の1日の上限を0にした状態で、操作を呼ぶ
- **THEN** APIはLLMを呼ばず、上限を理由に返し、案の一覧は空である

#### Scenario: タスクが失敗する

- **WHEN** 書き直しの案のタスクが2回とも不正な出力を返す
- **THEN** APIは、今は使えないことを示す応答を返す

#### Scenario: 存在しないトピック

- **WHEN** 存在しないトピックで、操作を呼ぶ
- **THEN** APIは、存在しないことを示す応答を返す
