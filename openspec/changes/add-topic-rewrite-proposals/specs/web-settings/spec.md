# Spec Delta

## ADDED Requirements

### Requirement: トピックの書き直しの案

トピックの編集は、「書き直しの案を出す」の操作を持たなければならない（MUST）。
利用者がそれを選ぶと、画面は保存済みの文章と判定基準での案を求め、1つか2つの案を、変えた点の説明と一緒に並べる。
案ごとに「この案を使う」を置く。選ぶと編集欄の文章が案の文章に置き換わる。トピックは保存しない。保存は利用者が保存の操作でする。
編集欄に保存していない変更があるとき、または案を求めている間は、「書き直しの案を出す」を選べない。保存していない変更があるときは、選べない理由を表示する。
上限か予算に達したとき、トピックが未解釈のとき、求めが失敗したときは、案を出せない理由を操作のそばに表示する。

#### Scenario: 案を使う

- **WHEN** 案を求め、表示された案の「この案を使う」を選ぶ
- **THEN** 編集欄の文章が案の文章に置き換わり、トピックの保存は求められない

#### Scenario: 保存していない変更がある

- **WHEN** トピックの文章を書き換え、まだ保存していない
- **THEN** 画面は「書き直しの案を出す」を選べなくし、保存してから求めるよう表示する

#### Scenario: 上限で断られる

- **WHEN** 書き直しの案の1日の上限に達した状態で、案を求める
- **THEN** 画面は、上限に達したため案を出せないことを表示する

#### Scenario: 未解釈のトピック

- **WHEN** 未解釈のトピックで案を求める
- **THEN** 画面は、解釈が済むまで案を出せないことを表示する
