# grilling 記録: add-list-digests

GitHubのissueの233番のコメントで、1ラウンドの質問（Q1〜Q5）に答えた記録である。
issueは、名前の記事の一覧、検索の結果、スターの一覧に「この一覧をまとめる」を足し、その一覧の記事から既存のダイジェストのタスクでダイジェストを作るという要望である。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 一覧のダイジェストの1日の上限 | 時刻のダイジェストと同じ上限 `limits.digestsPerDay`（既定4回）で数える。設定は増やさない（A） | 第1ラウンド Q1 |
| 一覧のダイジェストの通知 | 出さない。アプリの通知の判断は、一覧のダイジェスト以外の最新のダイジェストだけを見る（A） | 第1ラウンド Q2 |
| アプリでの扱い | 操作はWebだけに足す。アプリは表示だけ対応する（A） | 第1ラウンド Q3 |
| まとめる記事の決め方 | サーバーが対象（名前、検索語と絞り込み、スター）の記事を引き直し、画面と同じ条件で新しい順に200件までをまとめる（A） | 第1ラウンド Q4 |
| ダイジェストの画面での並べ方 | 時刻のダイジェストと同じ一覧に作った順で並べる。ラベルは「一覧」とし、期間の代わりに対象の説明を出す（A） | 第1ラウンド Q5 |

## 計画で決めたこと

承認を求めた計画（issueのコメント）で、次を決めた。利用者は変更なしで承認した。

| 決定 | 選択 |
|---|---|
| 保存 | `digests` に対象の列 `target`（JSON、NULL可）を足し、`trigger` に `list` を足す。期間の列には入力の記事の時刻の最古と最新を入れる |
| 期間の計算 | 次の時刻のダイジェストの期間の始めは、`target` のないダイジェストの終わりだけから決める |
| タスクの入力 | ダイジェストのタスクの入力に任意の `scope`（対象の説明）を足す。あるときは、プロンプトの「期間の記事」の文を「この対象の記事」に置き換え、期間の行は出さない |
| API | `POST /digests` の本文に任意の `target` を足す。`GET /digests` に一覧のダイジェストを外す絞り込み `kind=period` を足す |
| 作っている最中 | 時刻のダイジェストと同じ列で1つずつ作る。作っている最中に頼むと409を返す |
