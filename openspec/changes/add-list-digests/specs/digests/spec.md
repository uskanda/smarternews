# Spec Delta

## ADDED Requirements

### Requirement: 一覧のダイジェストの作成

利用者がWebの名前の記事の一覧、検索の結果、スターの一覧で「この一覧をまとめる」を選んだとき、サーバーはその一覧の記事からダイジェストを1つ作らなければならない（MUST）。
サーバーは、受け取った対象の記事を画面と同じ条件で引き直し、新しい順に200件までを入力にする。配信記事に渡す内容は、時刻のダイジェストと同じく、タイトルと、自動の要約か配信された内容の先頭300文字だけである。
保存するダイジェストのきっかけは「一覧」とし、対象の説明を持つ。期間には、入力の記事の時刻の最古と最新を入れる。
対象の記事が0件のときは、LLMを呼ばず、ダイジェストも作らない。ダイジェストを作っている最中に求められたときは、作らずに断る。

#### Scenario: 検索の結果をまとめる

- **WHEN** 検索語「半導体」で未読だけに絞り込んだ結果が30件あり、利用者が「この一覧をまとめる」を選ぶ
- **THEN** その30件を入力にしたダイジェストが1つ保存され、きっかけは「一覧」、対象の説明は「検索：半導体（未読だけ）」である

#### Scenario: 200件を超える名前

- **WHEN** ある名前を含む記事が250件あり、その名前の一覧をまとめる
- **THEN** 入力は、そのうち新しい順の200件である

#### Scenario: 記事のない一覧

- **WHEN** スターを付けた記事が1件もない状態で、スターの一覧をまとめる
- **THEN** ダイジェストは作られず、サーバーは記事がないことを返す

#### Scenario: 作っている最中

- **WHEN** ダイジェストを作っている最中に、一覧をまとめるよう求める
- **THEN** 新しいダイジェストは作られず、作っている最中であることが返る

### Requirement: 一覧のダイジェストの上限

一覧のダイジェストは、時刻のダイジェストと同じ1日の上限 `limits.digestsPerDay` で数えなければならない（MUST）。上限か月の予算に達しているときは、一覧のダイジェストを作らず、その理由を返す。

#### Scenario: 上限に達した日

- **WHEN** 上限が4回で、その日に時刻のダイジェストを2回、一覧のダイジェストを2回作ったあと、もう1つ一覧をまとめる
- **THEN** ダイジェストは作られず、上限に達したことが返る

### Requirement: 一覧のダイジェストと期間の計算

時刻のダイジェストと手動のダイジェストの期間の始めを決めるとき、サーバーは一覧のダイジェストを除いて、最後に保存したダイジェストの期間の終わりを求めなければならない（MUST）。

#### Scenario: 昼に一覧をまとめた日

- **WHEN** 7:00のダイジェストのあと、12:00に一覧のダイジェストを作り、その入力の記事の最新が11:50で、19:00に次のダイジェストを作る
- **THEN** 19:00のダイジェストの期間は7:00から19:00である

### Requirement: 一覧のダイジェストの通知

アプリは、一覧のダイジェストができたことを通知してはならない（MUST NOT）。新しいダイジェストの通知は、一覧のダイジェスト以外の最新のダイジェストで判断する。

#### Scenario: 一覧のダイジェストだけが新しい

- **WHEN** 前回の確認のあとに一覧のダイジェストだけが作られた
- **THEN** アプリはダイジェストの通知を出さない

### Requirement: ダイジェストのタスクの対象の入力

ダイジェストのタスクの入力は、任意の `scope`（対象の説明）を持たなければならない（MUST）。`scope` があるとき、プロンプトは記事を期間の記事ではなくその対象の記事として示し、期間の行を出さない。

#### Scenario: 名前の一覧のプロンプト

- **WHEN** 対象の説明 `名前：OpenAI` を `scope` としてダイジェストのタスクを呼ぶ
- **THEN** プロンプトはその対象を示し、期間の行を含まない

### Requirement: 一覧のダイジェストの表示

Webとアプリのダイジェストの画面は、一覧のダイジェストを時刻のダイジェストと同じ一覧に作った順で並べ、ラベル「一覧」と、期間の代わりに対象の説明を出さなければならない（MUST）。

#### Scenario: スターのダイジェスト

- **WHEN** スターの一覧から作ったダイジェストを開く
- **THEN** 画面はラベル「一覧」と対象の説明「スター」を出し、期間を出さない
