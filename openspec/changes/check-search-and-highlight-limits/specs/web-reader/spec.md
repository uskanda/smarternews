# Spec Delta

## ADDED Requirements

### Requirement: 長すぎる検索の語の結果の画面

検索の語が前後の空白を除いて200文字を超える結果の画面のURLが開かれたとき、画面は検索を送ってはならない（MUST NOT）。
代わりに、中央のペインに文言 `検索の語は200文字以内にしてください。` を表示する。試し直しても結果は変わらないため、「再試行」は表示しない。

#### Scenario: 201文字の語のURLを開く

- **WHEN** 検索の語が201文字の結果の画面のURLを開く
- **THEN** 検索は送られず、文言 `検索の語は200文字以内にしてください。` が表示され、「再試行」は表示されない

### Requirement: 長すぎる範囲のハイライト

本文の原文で5000文字を超える範囲を選んでいる間、ハイライトを付ける操作が使われたとき、画面はハイライトを保存してはならない（MUST NOT）。
代わりに、画面下部の知らせで文言 `ハイライトする文字列は5000文字以内にしてください。選ぶ範囲を狭めてください。` を表示する。
文字を選んだときのメニュー、右クリックのメニュー、`h` のキーのどれから使っても、同じように振る舞う。
メモを書く操作が使われたときは、メモを書くダイアログを開かずに、同じ理由を表示する。

#### Scenario: メニューのハイライトを押す

- **WHEN** 本文の5001文字を選び、文字を選んだときのメニューのハイライトを付ける操作を押す
- **THEN** ハイライトは増えず、画面下部の知らせに文言 `ハイライトする文字列は5000文字以内にしてください。選ぶ範囲を狭めてください。` が表示される

#### Scenario: `h` を押す

- **WHEN** 本文の5001文字を選んだ状態で `h` を押す
- **THEN** ハイライトは増えず、画面下部の知らせに同じ理由が表示される

#### Scenario: 右クリックのメニューのハイライトを押す

- **WHEN** 本文の5001文字を選び、右クリックのメニューのハイライトを付ける操作を押す
- **THEN** ハイライトは増えず、画面下部の知らせに同じ理由が表示される

#### Scenario: メモを書く操作を押す

- **WHEN** 本文の5001文字を選び、文字を選んだときのメニューのメモを書く操作を押す
- **THEN** メモを書くダイアログは開かず、画面下部の知らせに同じ理由が表示される

#### Scenario: ちょうど5000文字を選ぶ

- **WHEN** 本文のちょうど5000文字を選び、ハイライトを付ける操作を押す
- **THEN** その範囲がハイライトされる
