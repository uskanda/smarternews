# Spec Delta

## ADDED Requirements

### Requirement: 長すぎる検索の語

検索欄の語が、前後の空白を除いて200文字を超える間、Enterキーが押されたとき、画面は検索の結果の画面へ移ってはならない（MUST NOT）。
代わりに、検索欄の下に文言 `検索の語は200文字以内にしてください。` を表示し、入力は残す。
文字は、サーバーと同じく、絵文字のような文字も1文字に数える。
理由は、検索欄の語を変えたときに消す。

#### Scenario: 201文字の語で押す

- **WHEN** 検索欄に201文字の語を入れてEnterキーを押す
- **THEN** 表示中の画面は変わらず、検索欄の下に文言 `検索の語は200文字以内にしてください。` が表示され、検索欄の語はそのまま残る

#### Scenario: ちょうど200文字の語で押す

- **WHEN** 検索欄に、前後に空白のある200文字の語を入れてEnterキーを押す
- **THEN** 検索の結果の画面へ移る

#### Scenario: 直して押し直す

- **WHEN** 201文字の語で理由が表示されたあと、語を短く直してEnterキーを押す
- **THEN** 理由は消え、検索の結果の画面へ移る
