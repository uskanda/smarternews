# Spec Delta

## ADDED Requirements

### Requirement: 文字の大きさの設定への追従

画面の文字は、ブラウザーの文字の大きさの設定に比例した大きさで表示されなければならない（MUST）。
既定の文字の大きさ（16px）では、文字はDESIGN.mdの書体の大きさで表示されなければならない（MUST）。

#### Scenario: 既定の文字の大きさ

- **WHEN** ブラウザーの文字の大きさが既定のまま、記事を表示する
- **THEN** 本文はDESIGN.mdの `body-lg` の大きさ（17px）で表示される

#### Scenario: 文字を200%にする

- **WHEN** ブラウザーの文字の大きさを200%にして、記事を表示する
- **THEN** 本文は34pxで表示され、Spaceで送ったあとも、直前の画面の最後の1行が見えている

### Requirement: 文字の大きさに応じたペインの数

画面は、ペインの数を、文字の大きさを単位に測った画面の幅で決めなければならない（MUST）。
既定の文字の大きさでは、幅1100px以上で3ペイン、720pxから1099pxで2ペイン、それより狭いと1ペインでなければならない（MUST）。

#### Scenario: 文字を拡大した広い画面

- **WHEN** 幅1600pxの画面で、ブラウザーの文字の大きさを200%にする
- **THEN** 画面は記事の一覧と本文の2ペインで表示され、項目の一覧はボタンで開く

#### Scenario: 文字を拡大した中くらいの画面

- **WHEN** 幅1280pxの画面で、ブラウザーの文字の大きさを200%にする
- **THEN** 画面は1ペインで表示される。ページを200%に拡大したときと同じである

#### Scenario: 既定の文字の広い画面

- **WHEN** 幅1280pxの画面で、ブラウザーの文字の大きさが既定のままである
- **THEN** 画面は3ペインで表示される

### Requirement: 記事の一覧の見出しの行の折り返し

記事の一覧の見出しと操作のボタンが1行に収まらず、見出しに6文字ほどの幅が残らないとき、画面はボタンを見出しの次の行へ送らなければならない（MUST）。
見出しとボタンが1行に収まるとき、画面は両方を1行に並べなければならない（MUST）。
どちらの場合も、画面は横方向にスクロールしてはならない（MUST NOT）。

#### Scenario: 狭い幅で文字を拡大する

- **WHEN** 幅390pxの画面で、ブラウザーの文字の大きさを200%にして記事の一覧を表示する
- **THEN** 見出しが読める幅で表示され、「すべて既読にする」と「読み直す」は見出しの下の行にあり、画面は横方向にスクロールしない

#### Scenario: 既定の幅の一覧

- **WHEN** 幅1280pxの画面で、既定の文字の大きさのまま記事の一覧を表示する
- **THEN** 見出しとボタンは1行に並ぶ

### Requirement: 引き出しの幅

1ペインと2ペインの画面で開く項目の一覧の引き出しは、画面の幅の80%と、文字の大きさに比例する幅（既定の文字で200px）の小さいほうの幅で表示されなければならない（MUST）。

#### Scenario: 既定の文字で引き出しを開く

- **WHEN** 幅390pxの画面で、既定の文字の大きさのまま項目の一覧を開く
- **THEN** 引き出しの幅は200pxである

#### Scenario: 文字を拡大して引き出しを開く

- **WHEN** 幅390pxの画面で、ブラウザーの文字の大きさを200%にして項目の一覧を開く
- **THEN** 引き出しの幅は画面の幅の80%（312px）である
