# Spec Delta

## MODIFIED Requirements

### Requirement: 読んだ記事を一覧に残す動き

本文から未読の一覧へ戻ったとき、アプリは、利用者が一覧を更新するまで、読んだ記事を既読の表示で一覧に残さなければならない（MUST）。一覧に残した行は、サーバーとアプリが知っている記事の最新の内容と、既読とスターの状態を表示しなければならない（MUST）。

#### Scenario: 読んで戻る

- **WHEN** 未読の一覧で記事を開き、一覧へ戻る
- **THEN** その記事は、既読の表示で同じ位置に残っている

#### Scenario: 残した行に続報が届く

- **WHEN** 未読の一覧で記事を既読にしたあと、その記事が続報で書き直され、一覧が取り直される
- **THEN** その行は新しい見出しで、未読の表示で表示される

#### Scenario: 残した行に翻訳の見出しが届く

- **WHEN** 翻訳する購読フィードの未読の一覧で記事を開いて既読にし、そのあと翻訳の見出しが届いてから一覧へ戻る
- **THEN** 一覧に残した行の見出しは、翻訳の見出しになっている

#### Scenario: 残した行の変更が失敗する

- **WHEN** 未読の一覧の行で、払う操作や長押しのメニューから既読やスターを変え、その変更をサーバーが保存できない
- **THEN** その行の既読とスターは、本文を開いていない行でも、変更の前の状態に戻る
