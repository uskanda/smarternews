# Spec Delta

## MODIFIED Requirements

### Requirement: 読んだ記事の一覧への残留

未読の一覧で記事が既読になったとき、画面は、利用者が別の項目へ移るか更新を選ぶまで、その行を一覧から消してはならない（MUST NOT）。一覧に残した行は、サーバーと画面が知っている記事の最新の内容と、既読とスターの状態を表示しなければならない（MUST）。

#### Scenario: 読んだ記事に戻る

- **WHEN** 未読の一覧で1件目を開き、続けて2件目を開く
- **THEN** 1件目は既読の見た目で一覧に残り、選び直すと本文を読める

#### Scenario: 残した行に続報が届く

- **WHEN** 未読の一覧で記事を開いて既読にしたあと、その記事が続報で書き直され、一覧が取り直される
- **THEN** その行は新しい見出しで、未読の見た目で表示される

#### Scenario: 残した行に翻訳の見出しが届く

- **WHEN** 翻訳する購読フィードの未読の一覧で記事を開いて既読にし、そのあと翻訳の見出しが届く
- **THEN** 一覧に残した行の見出しは、翻訳の見出しに変わる

#### Scenario: 残した行の変更が失敗する

- **WHEN** 未読の一覧に残した行で既読やスターを変え、その変更をサーバーが保存できない
- **THEN** その行の既読とスターは、変更の前の状態に戻る
