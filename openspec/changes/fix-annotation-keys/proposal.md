# Proposal

## Why

Webの「注釈」の画面でキーを押すと、「すべて」の一覧で最後に開いた記事のスターや既読が、画面に何も出ないまま変わる。
`Space` を押すと、「すべて」の並びの次の記事が開き、既読になる。
注釈の一覧は記事の一覧の絞り込みを持たず、「すべて」の一覧と同じキャッシュの行を記事の一覧として扱うためである。
2026-11-13のWeb UIの監査で見つけた項目である（issue #183、監査ID B-01）。

## What Changes

- 注釈の画面では、記事の一覧を空として扱う。キャッシュの行も、既読にしたあと残しておいた行も入れない。
- 存在しない購読フィードやカテゴリのパスと、それらを読み込んでいる間も、記事の一覧を空として扱う。
- これで、記事を開いていない注釈の画面では、`s`・`m`・`o` は何もしない。記事を開いているときは、これまでどおりその記事に働く。
- 注釈の画面では、本文の端と本文がないときの `Space`・`Shift+Space` が、注釈の一覧の次と前の行へ移る。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-shell`: 本文の端での移動に、注釈の画面では注釈の一覧の行へ移ることを足す
- `web-reader`: 注釈の一覧で記事のキーが働かないことと、存在しない購読フィードやカテゴリのパスで、ほかの一覧の記事にキーが働かないことを足す

## Impact

- `apps/web/src/reader/ReaderPage.tsx`：記事の一覧を空として扱う条件を足し、注釈の画面の `Space` を注釈の一覧の移動へ渡す。
- `apps/web/src/reader/AnnotationList.tsx`：注釈の一覧の移動を、外から呼べるようにする。
- APIとAndroidアプリに変更はない。
