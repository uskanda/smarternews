# Spec Delta

## MODIFIED Requirements

### Requirement: 注釈の一覧で出さない操作

注釈の一覧を表示している間、画面は、一括の既読、既読を含める切り替え、重要度4以上の切り替えを表示してはならない（MUST NOT）。
注釈の一覧を表示していて記事を開いていない間、`s`・`m`・`o` のキーが押されたとき、画面はどの記事のスター、既読、出典も変えたり開いたりしてはならない（MUST NOT）。記事を開いている間は、これらのキーは開いている記事に働く。

#### Scenario: 一覧の上部を見る

- **WHEN** 左のペインで「注釈」を選ぶ
- **THEN** 一覧の上部に、一括の既読、既読を含める切り替え、重要度4以上の切り替えは表示されない

#### Scenario: 「すべて」の記事を読んでから注釈へ移る

- **WHEN** 記事を「すべて」で開いたあと、左のペインで「注釈」を選び、`s`・`m`・`o` を押す
- **THEN** その記事のスターと既読は変わらず、出典も開かれない

## ADDED Requirements

### Requirement: 存在しない一覧のパスでの記事のキー

存在しない購読フィードやカテゴリのパスを表示している間と、パスの購読フィードやカテゴリを読み込んでいる間、画面は記事の一覧を空として扱わなければならない（MUST）。
このとき、`s`・`m`・`o`・`Space`・`Shift+Space` のキーが押されても、画面はほかの一覧の記事のスターや既読を変えたり、その記事を開いたりしてはならない（MUST NOT）。

#### Scenario: 存在しない購読フィードのパスへ移る

- **WHEN** 記事を「すべて」で開いたあと、存在しない購読フィードのパスへ移り、`s`・`m`・`Space` を押す
- **THEN** その記事のスターと既読は変わらず、どの記事も開かれない
