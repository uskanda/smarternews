# Spec Delta

## MODIFIED Requirements

### Requirement: 本文の端での記事の移動

本文の末尾が表示されている状態で `Space` が押されたとき、画面は `j` を押したときと同じく次の記事へ移らなければならない（MUST）。
本文の先頭が表示されている状態で `Shift+Space` が押されたとき、画面は `k` を押したときと同じく前の記事へ移らなければならない（MUST）。
本文が表示されていないとき、`Space` は `j` を押したときと同じ記事を選ぶ。`Shift+Space` は `k` を押したときと同じ記事を選ぶ。
注釈の一覧を表示している間、これらの `Space` と `Shift+Space` は、注釈の一覧の次と前の行へ移らなければならない（MUST）。このとき、画面はほかの一覧の記事を開いてはならない（MUST NOT）。

#### Scenario: 末尾で次の記事へ移る

- **WHEN** 一覧の1件目の本文を末尾までスクロールした状態で `Space` を押す
- **THEN** 2件目が選ばれ、その本文が先頭から表示される

#### Scenario: 短い本文

- **WHEN** 本文のペインに全体が収まる記事を表示した状態で `Space` を押す
- **THEN** 次の記事が選ばれる

#### Scenario: 先頭で前の記事へ戻る

- **WHEN** 一覧の2件目の本文を先頭から表示した状態で `Shift+Space` を押す
- **THEN** 1件目が選ばれる

#### Scenario: 注釈の一覧で次の注釈へ移る

- **WHEN** 「すべて」で記事を開いたあと「注釈」を選び、注釈を選んでいない状態で `Space` を押し、その本文の末尾が表示された状態でもう一度 `Space` を押す
- **THEN** 注釈の一覧の1件目、2件目の順に選ばれ、「すべて」の記事は開かれない

#### Scenario: 注釈の一覧で前の注釈へ戻る

- **WHEN** 注釈の一覧の2件目を選び、本文の先頭が表示された状態で `Shift+Space` を押す
- **THEN** 注釈の一覧の1件目が選ばれる
