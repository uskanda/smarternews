# Spec Delta

## ADDED Requirements

### Requirement: 記事の詳細の添付

記事の詳細の要求を受けたとき、APIは、配信記事の添付を、配信元が並べた順の配列として返さなければならない（MUST）。
各要素は、元のURL、種類（画像、音声、動画、その他）、MIMEの型、大きさ、題、サムネイルのときのリンク先、画像を読み込むためのURLを持つ。サムネイルのときのリンク先は記事のページのURLで、サムネイルでない添付では空にする。
添付のない配信記事と生成記事には、空の配列を返す。添付は本文に混ぜず、記事の一覧の項目にも含めない。

#### Scenario: 動画のサムネイル

- **WHEN** ページのURLが `https://video.example.org/watch/1` で、サムネイルの添付を持つ配信記事の詳細を要求する
- **THEN** その添付のリンク先は `https://video.example.org/watch/1` になる

#### Scenario: 保存した添付を読めない

- **WHEN** 保存した添付のJSONを読めない配信記事の詳細を要求する
- **THEN** 添付は空の配列で返り、ほかの項目はいつもどおり返る
