# Spec Delta

## ADDED Requirements

### Requirement: アプリの本文の下の添付の一覧

添付のある配信記事の本文の画面で、アプリは、本文の下に「添付」の見出しの区画を表示しなければならない（MUST）。区画の位置は、表示している本文が全文、配信された内容、訳のどれであっても変えない。
画像の添付は、接続しているサーバーの中継のURLから読み込んだ画像として出す。サムネイルの添付は、押すと記事のページを開く画像として出す。音声、動画、その他の添付は押すとそのファイルを開く部品とし、その横に種類と大きさを書く。大きさは分かるときだけ書く。
アプリは、添付を再生してはならず、埋め込んで表示してもならない（MUST NOT）。添付のない記事では、区画とその見出しを表示しない。

#### Scenario: 音声の添付を押す

- **WHEN** 大きさが2048バイトの音声の添付を持つ配信記事を開き、その添付を押す
- **THEN** 添付は「音声、2 KB」とともに読み上げられ、その音声のURLがアプリ内のブラウザーで開く

#### Scenario: 動画のサムネイルを押す

- **WHEN** サムネイルの添付を持つ動画の配信記事を開き、サムネイルを押す
- **THEN** サムネイルの画像は中継のURLから読み込まれていて、記事のページがアプリ内のブラウザーで開く

#### Scenario: 添付のない記事

- **WHEN** 添付のない配信記事を開く
- **THEN** 添付の区画は表示されない
