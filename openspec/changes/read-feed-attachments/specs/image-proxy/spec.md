# Spec Delta

## ADDED Requirements

### Requirement: 画像の添付の中継

配信記事の詳細を返すとき、APIは、画像の添付ごとに、その画像を読み込むための中継のURLを返さなければならない（MUST）。`http:` の画像も中継を通す。
APIは、画像でない添付と、配信記事でない記事に、読み込むためのURLを返してはならない（MUST NOT）。保存した添付は元のURLのままにする。

#### Scenario: 暗号化されていない画像の添付

- **WHEN** `http:` の画像の添付を持つ配信記事の詳細を要求する
- **THEN** その添付の読み込むためのURLは中継のURLで、元のURLは添付のURLとして返る

#### Scenario: 音声の添付

- **WHEN** 音声の添付を持つ配信記事の詳細を要求する
- **THEN** その添付の読み込むためのURLは空で、元のURLだけが返る
