# Spec Delta

## ADDED Requirements

### Requirement: 本文の下の添付の一覧

添付のある配信記事の本文の画面で、画面は、本文の下に「添付」の見出しの区画を表示しなければならない（MUST）。区画の位置は、表示している本文が全文、配信された内容、訳のどれであっても変えない。
画像の添付は、中継のURLから読み込んだ画像として出す。サムネイルの添付は、記事のページへのリンクにした画像として出す。音声、動画、その他の添付は元のURLへのリンクとし、その横に種類と大きさを書く。大きさは分かるときだけ書く。
添付のない記事では、区画とその見出しを表示しない。

#### Scenario: 音声の添付

- **WHEN** 大きさが12345678バイトの音声の添付を持つ配信記事を開く
- **THEN** 本文の下の「添付」の区画に、その音声へのリンクと「音声、11.8 MB」が表示される

#### Scenario: 動画のサムネイル

- **WHEN** サムネイルの添付を持つ動画の配信記事を開く
- **THEN** サムネイルの画像は中継のURLから読み込まれ、選ぶと記事のページが別のタブで開く

#### Scenario: 添付のない記事

- **WHEN** 添付のない配信記事を開く
- **THEN** 添付の区画は表示されない

### Requirement: 添付を再生しないこと

画面は、添付を再生してはならず、埋め込んで表示してもならない（MUST NOT）。画像の添付の元のURLを読み込んではならない（MUST NOT）。

#### Scenario: 動画と音声の添付

- **WHEN** 動画と音声の添付を持つ配信記事を開く
- **THEN** 区画には再生の部品と埋め込みの枠がなく、リンクだけが並ぶ
