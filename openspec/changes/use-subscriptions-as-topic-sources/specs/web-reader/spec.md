## ADDED Requirements

### Requirement: まとめた先の生成記事へのリンク

生成記事にまとめられた配信記事が選ばれたとき、画面は、本文のペインに「この記事をまとめた生成記事」として、その生成記事のタイトルを表示しなければならない（MUST）。
タイトルが押されたとき、画面はその生成記事を本文のペインに表示する。

#### Scenario: まとめられた配信記事を選ぶ

- **WHEN** 生成記事Gにまとめられた配信記事を選び、「この記事をまとめた生成記事」のGのタイトルを押す
- **THEN** 本文のペインにGが表示される

#### Scenario: まとめられていない配信記事

- **WHEN** どの生成記事にもまとめられていない配信記事を選ぶ
- **THEN** 本文のペインに「この記事をまとめた生成記事」は表示されない

### Requirement: まとめた配信記事へのリンク

配信記事をまとめた生成記事が選ばれたとき、画面は、本文のペインに「まとめた配信記事」として、各配信記事のタイトルと購読フィードの名前を並べなければならない（MUST）。
タイトルが押されたとき、画面は、左のペインでその購読フィードを選び、その配信記事を本文のペインに表示する。

#### Scenario: まとめた配信記事を開く

- **WHEN** 購読フィードAの配信記事をまとめた生成記事を選び、「まとめた配信記事」のその記事のタイトルを押す
- **THEN** 左のペインで購読フィードAが選ばれ、本文のペインにその配信記事が表示される

#### Scenario: 配信記事をまとめていない生成記事

- **WHEN** 配信記事をまとめていない生成記事を選ぶ
- **THEN** 本文のペインに「まとめた配信記事」は表示されない
