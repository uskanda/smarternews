## ADDED Requirements

### Requirement: トピックの取得元にする設定の受け付け

APIは、購読フィードの登録と変更で「トピックの取得元にする」の設定を受け付け、購読フィードの一覧と詳細でその値を返さなければならない（MUST）。

#### Scenario: 変更で有効にする

- **WHEN** ニュースのカテゴリに属する購読フィードの変更で、`topicSource`に`true`を送る
- **THEN** APIは変更した購読フィードを`topicSource`が`true`の状態で返す

### Requirement: まとめた先の生成記事の提供

配信記事の詳細の要求を受けたとき、APIは、その配信記事をまとめた生成記事の識別子とタイトルを返さなければならない（MUST）。
まとめた生成記事がないときは、値のないことを返す。

#### Scenario: まとめられた配信記事

- **WHEN** 生成記事Gにまとめられた配信記事の詳細を要求する
- **THEN** まとめた先として、Gの識別子とタイトルが返る

#### Scenario: まとめられていない配信記事

- **WHEN** どの生成記事にもまとめられていない配信記事の詳細を要求する
- **THEN** まとめた先は値のないことが返る

### Requirement: まとめた配信記事の提供

生成記事の詳細の要求を受けたとき、APIは、その生成記事にまとめた配信記事を、識別子、購読フィードの識別子と名前、タイトルとともに返さなければならない（MUST）。
フィルターで隠した配信記事は含めない。まとめた配信記事がないときは、空の並びを返す。

#### Scenario: 2件をまとめた生成記事

- **WHEN** 購読フィードAとBの配信記事を1件ずつまとめた生成記事の詳細を要求する
- **THEN** まとめた配信記事として、2件がそれぞれの購読フィードの名前とともに返る
