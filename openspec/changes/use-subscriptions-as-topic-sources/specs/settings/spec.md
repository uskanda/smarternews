## ADDED Requirements

### Requirement: 設定ファイルでのトピックの取得元にする設定の扱い

設定ファイルの書き出しは、「トピックの取得元にする」が有効な購読フィードに、その設定を書かなければならない（MUST）。
設定ファイルの読み込みは、購読フィードに書かれた「トピックの取得元にする」の設定を保存しなければならない（MUST）。
設定が書かれていない購読フィードは、新しく登録するときは無効とし、すでにあるときは保存済みの値を保つ。

#### Scenario: 往復

- **WHEN** 「トピックの取得元にする」が有効な購読フィードを持つサーバーから設定ファイルを書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーの購読フィードは、「トピックの取得元にする」が有効である

#### Scenario: 書かれていない設定

- **WHEN** 「トピックの取得元にする」が有効な購読フィードを持つサーバーへ、その購読フィードの設定を書いていない設定ファイルを読み込む
- **THEN** その購読フィードの「トピックの取得元にする」は有効のままである
