## ADDED Requirements

### Requirement: トピックの取得元にする切り替え

ニュースのカテゴリに属する購読フィードの編集の画面は、「トピックの取得元にする」の切り替えを表示し、保存できるようにしなければならない（MUST）。
切り替えのそばに、配信記事をカテゴリのトピックの候補にすることと、判定にLLMを使うことを説明する。

#### Scenario: 編集で有効にする

- **WHEN** ニュースのカテゴリに属する購読フィードの編集で、「トピックの取得元にする」を入れて保存する
- **THEN** もう一度編集を開くと、「トピックの取得元にする」が入っている

#### Scenario: カテゴリのない購読フィード

- **WHEN** カテゴリに属さない購読フィードの編集を開く
- **THEN** 「トピックの取得元にする」の切り替えは表示されない
