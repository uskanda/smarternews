## ADDED Requirements

### Requirement: 購読フィードから来た候補の表示

除外した候補の一覧で、購読フィードの配信記事から来た候補について、画面は「購読フィード」の印を表示しなければならない（MUST）。

#### Scenario: 購読フィードの候補を除外した実行

- **WHEN** 購読フィードの配信記事から来た候補を除外した実行の詳細を開く
- **THEN** その候補のサイト名のそばに「購読フィード」が表示される

### Requirement: トピックの集計での購読フィード

トピックの集計で、画面は、購読フィードの配信記事から集めた候補の数を「購読フィード」として表示しなければならない（MUST）。

#### Scenario: 購読フィードから集めた候補のあるトピック

- **WHEN** 購読フィードの配信記事から候補を3件集めたトピックの集計を開く
- **THEN** 集めた候補の内訳に「購読フィード」の3件が表示される
