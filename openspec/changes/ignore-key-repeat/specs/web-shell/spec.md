# Spec Delta

## ADDED Requirements

### Requirement: 押し続けたキーの扱い

キーを押し続けて繰り返しの入力が来たとき、画面は `j`、`k`、`Space`、`Shift+Space` のキーだけを繰り返し受け付けなければならない（MUST）。
ほかのキーでは、画面は最初の1回だけ操作をし、繰り返しの入力で操作をしてはならない（MUST NOT）。
ほかのキーには、`Shift+A`、`Shift+J`、`Shift+K`、`m`、`s`、`h`、`o`、`r`、`u`、`x`、`w`、`z`、`?`、`/`、`g` とその2打目がある。
無視した繰り返しの入力は、`g` の2打目の待ちを消してはならない（MUST NOT）。

#### Scenario: `Shift+A` を押し続ける

- **WHEN** 未読のある一覧で `Shift+A` を押し続ける
- **THEN** 画面は一括の既読を1回だけし、移った先の一覧を既読にしない

#### Scenario: `j` を押し続ける

- **WHEN** 記事の一覧で `j` を押し続ける
- **THEN** 繰り返しの入力ごとに、次の記事へ移る

#### Scenario: `g` を押し続ける

- **WHEN** `g` を押し続けてから、1秒以内に2打目のキーを押す
- **THEN** 画面は `g` と2打目の組み合わせの操作をする
