## ADDED Requirements

### Requirement: 重複の除去の切り替え

全体設定の画面は、購読フィードをまたぐ配信記事の重複の除去を、切り替えとして表示し、保存できるようにしなければならない（MUST）。

#### Scenario: 無効にして保存する

- **WHEN** 全体設定の画面で、重複の除去の切り替えを切って保存する
- **THEN** 記録済みの重複も、そのあとに取得した配信記事も、全体の一覧に並ぶ

#### Scenario: 既定の表示

- **WHEN** 重複の除去の設定を変えたことのないサーバーで、全体設定の画面を開く
- **THEN** 重複の除去の切り替えは入っている
