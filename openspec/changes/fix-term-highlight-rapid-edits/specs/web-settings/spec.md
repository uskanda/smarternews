## MODIFIED Requirements

### Requirement: 色付けの語の削除の操作

利用者が色付けの語の削除を選んだとき、画面はその語を削除し、まとまりの語から外さなければならない（MUST）。
応答の前に続けて同じまとまりの語を削除しても、先に削除した語を画面に戻してはならない（MUST NOT）。

#### Scenario: 語を外す

- **WHEN** まとまり「通商」の語「関税」の削除を選ぶ
- **THEN** まとまり「通商」の語から「関税」が消える

#### Scenario: 応答の前に続けて語を外す

- **WHEN** まとまり「通商」の語「関税」の削除を選び、その応答の前に語「輸出」の削除を選ぶ
- **THEN** 2つの応答のあと、まとまり「通商」の語から「関税」と「輸出」が消えたままになり、サーバーにも残らない

### Requirement: 語のまとまりの並べ替えの操作

画面は、語のまとまりごとに、1つ上へ動かす操作と1つ下へ動かす操作を表示しなければならない（MUST）。
先頭のまとまりは上へ動かせず、末尾のまとまりは下へ動かせない。
画面は、操作を選ぶたびに一覧をすぐに1つ動かし、応答の前に続けて選んだ回数だけ動かさなければならない（MUST）。
並べ替えに失敗したときは、一覧をサーバーの並びに戻し、失敗を知らせなければならない（MUST）。

#### Scenario: 上へ動かす

- **WHEN** まとまりA、Bの順に並んだ状態で、Bの上へ動かす操作を選ぶ
- **THEN** 一覧はB、Aの順になる

#### Scenario: キーボードで動かす

- **WHEN** キーボードだけで、まとまりBの上へ動かす操作にフォーカスして押す
- **THEN** BはAの前へ動き、フォーカスはBの操作に残る

#### Scenario: 応答の前に続けて動かす

- **WHEN** まとまりA、B、Cの順に並んだ状態で、応答の前にCの上へ動かす操作を2回選ぶ
- **THEN** 一覧はすぐにC、A、Bの順になり、応答のあともその順のままで、サーバーの並びも同じになる

#### Scenario: 並べ替えに失敗する

- **WHEN** まとまりA、B、Cの順に並んだ状態で、Cの上へ動かす操作を2回選び、1回目の並べ替えが失敗する
- **THEN** 一覧はA、B、Cの順に戻り、`並べ替えられませんでした。もう一度試してください。`と1回知らせ、2回目の並べ替えは送らない
