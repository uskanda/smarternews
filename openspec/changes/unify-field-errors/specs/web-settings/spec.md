# Spec Delta

## ADDED Requirements

### Requirement: 入力の誤りの日本語の表示

サーバーが入力を拒んだとき、設定の画面は、欄の名前と誤りの種類から作った日本語の理由を、その入力欄の近くに表示しなければならない（MUST）。
サーバーが返した英語の理由の文は、画面に出さない。種類のない誤りと、画面の知らない種類の誤りには、その欄の値は保存できないことを表示する。一覧の要素の誤りは、何番目の要素かを理由に含める。

#### Scenario: 存在しないタイムゾーン

- **WHEN** 全体設定のタイムゾーンに存在しない名前を入力して保存を選ぶ
- **THEN** タイムゾーンの入力欄の近くに、`Asia/Tokyo` のような名前にすることが日本語で表示され、英語の理由は表示されない

#### Scenario: 知らない種類の誤り

- **WHEN** サーバーが、画面の知らない種類の誤りで読み手情報を拒む
- **THEN** 読み手情報の入力欄の近くに、その値は保存できないことが日本語で表示される

### Requirement: 送る前の自前の検査

設定の画面のフォームと購読フィードのオプションのダイアログは、ブラウザー既定の検査の吹き出しを出してはならない（MUST NOT）。
フォームは、送る前に値を自分で確かめ、誤りがあれば送らずに、日本語の理由を入力欄の近くに表示する。理由の文は、同じ誤りをサーバーが拒んだときの文と同じにする。

#### Scenario: 件数上限に51を入れる

- **WHEN** カテゴリの編集で件数上限に51を入れて保存を選ぶ
- **THEN** 変更は送られず、件数上限の入力欄の近くに「件数上限は1から50までの数にしてください」という文が表示され、ブラウザー既定の吹き出しは出ない

#### Scenario: 形の違う実行時刻

- **WHEN** カテゴリの編集で実行時刻に「05:00, 5時」と入れて保存を選ぶ
- **THEN** 変更は送られず、実行時刻の2つ目の形が正しくないことと、24時間表記で書くことが表示される

### Requirement: カテゴリの範囲の表示

カテゴリの編集の画面は、件数上限と対象期間の入力欄の説明に、入れられる範囲を表示しなければならない（MUST）。
範囲は、件数上限が1から50、時間単位の対象期間が1から720、日単位の対象期間が1から90である。

#### Scenario: 件数上限の説明

- **WHEN** 種別がニュースのカテゴリの編集の画面を開く
- **THEN** 件数上限の説明に「1から50まで」、対象期間の説明に「1から720まで」と表示される

## MODIFIED Requirements

### Requirement: 設定ファイルの読み込み

利用者が設定ファイルを選んで読み込みを選んだとき、画面はそのファイルを読み込み、作成と更新の件数を表示しなければならない（MUST）。
ファイルが形式に合わないとき、画面は、誤っている箇所ごとに、ファイルの中のキーの並びと日本語の理由を表示する。理由は、ファイルのキーの名前を欄の名前として使う。

#### Scenario: 別のサーバーの設定を読み込む

- **WHEN** カテゴリ2つを含む設定ファイルを選んで読み込む
- **THEN** カテゴリ2つとトピックの作成の件数が表示され、カテゴリの一覧に反映される

#### Scenario: 形式に合わないファイル

- **WHEN** 種別が不正な設定ファイルを選んで読み込む
- **THEN** 誤っている箇所のキーの並び（`categories.0.kind`）と、選べる値から選ぶことが日本語で表示され、設定は何も変わらない

### Requirement: 更新が止まったとみなす日数の編集

全体設定の画面は、更新が止まったとみなす日数を入力欄として表示し、保存できるようにしなければならない（MUST）。

#### Scenario: 日数を変えて保存する

- **WHEN** 全体設定の画面で、更新が止まったとみなす日数を90にして保存する
- **THEN** 購読フィードの一覧で、最後に新しい項目が現れた時刻から61日たった購読フィードの印が消える

#### Scenario: 範囲の外の日数

- **WHEN** 全体設定の画面で、更新が止まったとみなす日数に0を入力して保存を選ぶ
- **THEN** 入力欄の近くに、1から365までの数にすることが表示され、保存済みの値は変わらない

#### Scenario: 既定の表示

- **WHEN** 日数を変えたことのないサーバーで、全体設定の画面を開く
- **THEN** 更新が止まったとみなす日数の入力欄は60である
