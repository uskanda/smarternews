# Spec Delta

## ADDED Requirements

### Requirement: 誤りの種類の表示

入力の誤りで400を返すとき、APIは、誤っている項目ごとに、機械が読める誤りの種類を返さなければならない（MUST）。
種類は次の10個で、どれにも当たらない誤りには種類を付けない。英語の理由の文は、ログとCLIのためにそのまま返す。

- 値がない
- 範囲より小さい
- 範囲より大きい
- 形が違う
- 選べる値でない
- 時刻帯の名前が違う
- 指すものがない
- 組み合わせが許されない
- 取得できない
- 記事を抜き出せない

#### Scenario: 件数上限の上限を超える

- **WHEN** 件数上限に51を指定してカテゴリを変更する
- **THEN** APIはHTTPステータス400と、件数上限の項目に、範囲より大きいという種類を返し、カテゴリは変わらない

#### Scenario: 知らない時刻帯

- **WHEN** タイムゾーンに存在しない名前を指定して全体設定を変更する
- **THEN** APIはHTTPステータス400と、タイムゾーンの項目に、時刻帯の名前が違うという種類を返す

### Requirement: 範囲の境界の表示

範囲を外れた値で400を返すとき、APIは、破られた境界の値と、その境界が数えるもの（文字数、数、要素の数）を返さなければならない（MUST）。

#### Scenario: 名前が長すぎる

- **WHEN** 101文字の名前を指定してカテゴリを変更する
- **THEN** APIは、名前の項目に、境界の100と、文字数を数えることを返す

#### Scenario: 件数上限の境界

- **WHEN** 件数上限に51を指定してカテゴリを変更する
- **THEN** APIは、件数上限の項目に、境界の50と、数を数えることを返す
