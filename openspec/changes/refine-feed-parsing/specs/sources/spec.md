# Spec Delta

## ADDED Requirements

### Requirement: フィードの項目の日時の読み取り

クローラーは、トピックのフィードの項目の公開日時を、購読フィードと同じ規則で読み取らなければならない（MUST）。
地域の略称は時差に置き換え、`IST` は読まず、時差のない日時は全体設定のタイムゾーンで読む。

#### Scenario: 略称つきの日時で対象期間を絞る

- **WHEN** 対象期間が24時間のカテゴリで、日時が3日前の `JST` で書かれた項目を含むフィードを取得する
- **THEN** その項目は候補にならない

### Requirement: フィードの応答の大きさの上限の適用

クローラーは、トピックのフィードとニュース検索の取得に、ページの上限ではなくフィードの応答の大きさの上限を適用しなければならない（MUST）。

#### Scenario: ページの上限より大きいトピックのフィード

- **WHEN** ページの上限が2MB、フィードの上限が10MBの設定で、トピックに登録した5MBのフィードを取得する
- **THEN** そのフィードの項目が候補になる
