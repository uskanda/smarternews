# Spec Delta

## ADDED Requirements

### Requirement: スターの一覧でのスターの切り替え

スターの一覧で利用者が記事のスターを外したとき、画面は、利用者が別の項目へ移るか更新を選ぶまで、その行をスターのない見た目で一覧に残さなければならない（MUST）。
残った行でスターを付け直したとき、画面はその行にスターを表示し、行を重ねずに1つだけ表示しなければならない（MUST）。

#### Scenario: 外した行が残る

- **WHEN** スターの一覧で2件目の記事を開いてスターを外し、続けて `j` を押す
- **THEN** 2件目の行はスターのない見た目で一覧に残り、3件目の記事が開く

#### Scenario: 更新すると消える

- **WHEN** スターの一覧でスターを外したあと、更新を選ぶ
- **THEN** その行は一覧に表示されない

#### Scenario: 別の項目から戻ると消える

- **WHEN** スターの一覧でスターを外したあと、別の項目へ移ってからスターの一覧に戻る
- **THEN** その行は一覧に表示されない

#### Scenario: 残った行でスターを付け直す

- **WHEN** スターの一覧でスターを外して残った行で、もう一度スターを付ける
- **THEN** その行にスターが表示され、行は1つだけ表示される
