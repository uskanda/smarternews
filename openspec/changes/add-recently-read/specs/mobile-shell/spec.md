# Spec Delta

## ADDED Requirements

### Requirement: 引き出しの「最近読んだ記事」の項目

アプリは、引き出しの「AI生成」の下に、「最近読んだ記事」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 引き出しを開く

- **WHEN** 引き出しを開く
- **THEN** 上部に「未読」「すべて」「スター」「AI生成」「最近読んだ記事」の順で項目が並び、「最近読んだ記事」の横に数字はない

### Requirement: 「最近読んだ記事」を動かせないこと

アプリは、引き出しの「最近読んだ記事」をドラッグで動かせるようにしてはならない（MUST NOT）。

#### Scenario: 「最近読んだ記事」を長押しする

- **WHEN** 引き出しの「最近読んだ記事」を長押しする
- **THEN** ドラッグは始まらない
