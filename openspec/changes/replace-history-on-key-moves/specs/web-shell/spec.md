# Spec Delta

## MODIFIED Requirements

### Requirement: キーボードでの記事の移動

記事の一覧が表示されている間、`j` と `k` のキーが押されたとき、画面は次または前の記事を選んで本文を表示しなければならない（MUST）。
記事が開いている間、キーで記事を移るとき、画面はブラウザーの履歴を足さずに置き換えなければならない（MUST）。
記事が開いていない間、キーで記事を開くとき、画面はブラウザーの履歴を1つ足さなければならない（MUST）。
本文の端での `Space` と `Shift+Space` による記事の移動と、注釈の一覧での `j` と `k` による移動も、キーでの移動として同じに扱わなければならない（MUST）。

#### Scenario: 次の記事へ進む

- **WHEN** 一覧の1件目を選んだ状態で `j` を押す
- **THEN** 2件目が選ばれ、その本文が表示される

#### Scenario: キーで移ったあとに戻る

- **WHEN** 一覧の記事を押して開き、`j` を3回押してから、ブラウザーの戻る操作をする
- **THEN** 記事を開く前の一覧に戻る

#### Scenario: キーで最初の記事を開いてから戻る

- **WHEN** 記事を開いていない状態で `j` を押して1件目を開き、ブラウザーの戻る操作をする
- **THEN** 記事を開いていない一覧に戻る

#### Scenario: 記事を開いたまま行を押してから戻る

- **WHEN** 記事を開いたまま、一覧の別の行を押してから、ブラウザーの戻る操作をする
- **THEN** 前に開いていた記事に戻る
