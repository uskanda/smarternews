# Spec Delta

## ADDED Requirements

### Requirement: 配信元の分類の表示

配信元の分類のある配信記事の本文の画面で、アプリは、本文の上の行の著者の横に配信元の分類を表示しなければならない（MUST）。
複数の値は読点でつなぐ。
配信元の分類のない配信記事と生成記事では、何も表示しない。

#### Scenario: 分類を持つ配信記事

- **WHEN** 著者が「山田」で、配信元の分類が「Tech」「AI」の配信記事を開く
- **THEN** 本文の上の行に、「山田」と「Tech、AI」が並んで表示される

#### Scenario: 分類のない配信記事

- **WHEN** 配信元の分類のない配信記事を開く
- **THEN** 本文の上の行には、購読フィードの名前、著者、公開の日時だけが表示される
