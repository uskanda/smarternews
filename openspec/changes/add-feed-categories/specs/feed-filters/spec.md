# Spec Delta

## MODIFIED Requirements

### Requirement: 条件の形

フィルターの条件は、照合する欄、照合の方法、値からなる。
照合する欄は、タイトル、内容、著者、URL、分類から1つ以上を選ぶ。照合の方法は、部分一致か正規表現である。
サーバーは、選んだ欄のどれかが値に合うとき、配信記事がその条件に合うと判定しなければならない（MUST）。

#### Scenario: タイトルと内容を選んだ条件

- **WHEN** 欄にタイトルと内容を選び、値を「提供」とした隠すフィルターがあり、内容にだけ「提供」を含む項目を取得する
- **THEN** その配信記事は記事の一覧に含まれない

#### Scenario: タイトルだけを選んだ条件

- **WHEN** 欄にタイトルだけを選び、値を「提供」とした隠すフィルターがあり、内容にだけ「提供」を含む項目を取得する
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: 分類を選んだ条件

- **WHEN** 欄に分類だけを選び、値を「Sports」とした隠すフィルターがあり、配信元の分類に「Sports」を持つ項目を取得する
- **THEN** その配信記事は記事の一覧に含まれない

### Requirement: 照合する文章

サーバーは、条件の欄ごとに、次の文章を照合しなければならない（MUST）。

- タイトルは、購読フィードが配信した原文のタイトルに照合する
- 内容は、購読フィードが配信した原文の内容から、Markdownの記号とリンクのURLを除いた文章に照合する
- 著者は、配信記事の著者に照合する。著者のない配信記事は、著者の条件に合わない
- URLは、配信記事のリンク先のURLに照合する
- 分類は、配信記事の配信元の分類の値に1つずつ照合する。配信元の分類のない配信記事は、分類の条件に合わない

#### Scenario: リンクのURLは内容として照合しない

- **WHEN** 内容の部分一致の値が `campaign` の隠すフィルターがあり、内容のリンクのURLにだけ `campaign` を含む項目を取得する
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: URLの条件

- **WHEN** URLの部分一致の値が `/sponsored/` の隠すフィルターがあり、リンク先のURLのパスに `/sponsored/` を含む項目を取得する
- **THEN** その配信記事は記事の一覧に含まれない

#### Scenario: 著者のない記事

- **WHEN** 著者の正規表現が `.*` の隠すフィルターがあり、著者のない項目を取得する
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: 分類のない記事

- **WHEN** 分類の正規表現が `.*` の隠すフィルターがあり、配信元の分類のない項目を取得する
- **THEN** その配信記事は記事の一覧に含まれる

## ADDED Requirements

### Requirement: 分類の値ごとの照合

分類の欄を選んだ条件について、サーバーは、配信元の分類の値を1つずつ照合し、どれか1つが合えば欄が合ったと判定しなければならない（MUST）。
正規表現の `^` と `$` は、1つの値の始まりと終わりを指す。

#### Scenario: 1つの値に完全一致する正規表現

- **WHEN** 分類の正規表現が `^Tech$` の隠すフィルターがあり、配信元の分類が「Science」「Tech」の項目と、「FinTech」の項目を取得する
- **THEN** 分類が「Science」「Tech」の配信記事は一覧に含まれず、分類が「FinTech」の配信記事は一覧に含まれる

#### Scenario: 値をまたぐ部分一致

- **WHEN** 分類の部分一致の値が `ab` の隠すフィルターがあり、配信元の分類が「a」「b」の項目を取得する
- **THEN** その配信記事は記事の一覧に含まれる
