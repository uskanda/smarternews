# Spec Delta

## ADDED Requirements

### Requirement: 実行ごとの金額の提供

実行履歴を返すとき、APIは、各実行のLLMの呼び出しの金額の合計と、金額のわからない呼び出しの件数を返さなければならない（MUST）。
金額は、金額のかかるプロバイダーの呼び出しのうち、金額のわかるものの合計とする。金額のかかる呼び出しが1件もない実行では、金額を空で返す。

#### Scenario: 金額のかかる呼び出しのある実行

- **WHEN** 判定で0.10米ドル、本文の生成で0.30米ドルを使い、1回が時間切れになった実行の実行履歴を要求する
- **THEN** その実行の金額は0.40で、金額のわからない呼び出しの件数は1である

#### Scenario: 金額のかからない実行

- **WHEN** 金額のかからないプロバイダーだけを呼んだ実行の実行履歴を要求する
- **THEN** その実行の金額は空で、金額のわからない呼び出しの件数は0である

### Requirement: 実行ごとのタスクごとの呼び出しの提供

実行履歴を返すとき、APIは、各実行のLLMの呼び出しの回数と金額を、タスクごとに返さなければならない（MUST）。
回数は、金額のかからない呼び出しも含めて数える。呼び出しのなかったタスクは返さない。

#### Scenario: 判定と本文の生成

- **WHEN** 判定を3回、本文の生成を1回呼んだ実行の詳細を要求する
- **THEN** タスクごとの呼び出しとして、判定の3回と本文の生成の1回が、それぞれの金額とともに返り、ほかのタスクは返らない

### Requirement: 利用量の内訳の提供

利用量の要求を受けたとき、APIは、今の予算の期間の初日から今までのLLMの呼び出しの内訳を返さなければならない（MUST）。
内訳は、期間の初日と最終日、カテゴリごとの行、実行に属さない呼び出しの行、日ごとの行、期末の見込みからなる。
金額は、金額のかかるプロバイダーの呼び出しのうち、金額のわかるものの合計とする。回数は、金額のかからない呼び出しも含めて数える。

#### Scenario: 期間の途中で要求する

- **WHEN** 締め日が10日の状態で、2026年10月25日に利用量を要求する
- **THEN** 期間の初日の2026年10月10日、最終日の2026年11月9日と、各内訳が返る

### Requirement: カテゴリごとの利用量の提供

利用量の要求を受けたとき、APIは、カテゴリごとに、そのカテゴリの実行の呼び出しの回数、金額、金額のわからない呼び出しの件数を返さなければならない（MUST）。
カテゴリごとの行は、作った記事の数、開いた記事の数、開いた記事1件あたりの金額も持つ。作った記事は、そのカテゴリの生成記事のうち、作った日時が期間内のものである。開いた記事は、そのうち開いた時刻のあるものである。
開いた記事1件あたりの金額は、カテゴリの金額を開いた記事の数で割った値とし、開いた記事が0件のときは空で返す。

#### Scenario: 記事を作って開いた

- **WHEN** 期間内にカテゴリAの実行が2米ドルを使い、生成記事を4件作り、利用者がそのうち2件を開いた状態で利用量を要求する
- **THEN** カテゴリAの行は、金額が2、作った記事が4、開いた記事が2、開いた記事1件あたりの金額が1である

#### Scenario: 開いた記事がない

- **WHEN** 期間内にカテゴリBの実行が金額を使ったが、作った記事を1件も開いていない状態で利用量を要求する
- **THEN** カテゴリBの行の、開いた記事1件あたりの金額は空である

### Requirement: 実行に属さない呼び出しの利用量の提供

利用量の要求を受けたとき、APIは、実行に属さない呼び出しの回数、金額、金額のわからない呼び出しの件数を1つの行にまとめて返さなければならない（MUST）。
実行に属さない呼び出しは、配信記事の要約、翻訳、セレクターの提案、ダイジェストのように、実行の外で呼んだものと、実行履歴が先に消えたものである。

#### Scenario: 要約と翻訳

- **WHEN** 期間内に、配信記事の要約を2回、本文の翻訳を1回呼んだ状態で利用量を要求する
- **THEN** 実行に属さない呼び出しの行の回数は3である

### Requirement: 日ごとの利用量の提供

利用量の要求を受けたとき、APIは、期間の初日から今日まで、UTCの日ごとに、呼び出しの回数と金額を返さなければならない（MUST）。
呼び出しのない日も、回数と金額を0として返す。日ごとの金額の和は、プロバイダーの状況の期間の合計と一致する。

#### Scenario: 日をまたぐ呼び出し

- **WHEN** 締め日が10日で、10月12日のUTCの23時59分と、10月13日のUTCの0時1分に呼び出しがあった状態で、10月14日に利用量を要求する
- **THEN** 10月10日から10月14日までの5日が返り、10月12日と10月13日の回数はそれぞれ1、ほかの日は0である

### Requirement: 期末の見込みの提供

利用量の要求を受けたとき、APIは、期末の見込みの金額と、それが月の予算を超えるかどうかを返さなければならない（MUST）。
見込みの金額は、期間の初日から今までに使った金額を、経った時間で割り、期間の長さを掛けた値とする。

#### Scenario: 期間の3分の1で40米ドル

- **WHEN** 30日の予算の期間の10日目の終わりに、期間に40米ドルを使い、月の予算が100米ドルの状態で利用量を要求する
- **THEN** 見込みの金額は120で、月の予算を超えると返る
