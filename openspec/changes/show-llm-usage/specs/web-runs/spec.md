# Spec Delta

## MODIFIED Requirements

### Requirement: 実行履歴の一覧

実行履歴の画面が開かれたとき、画面は実行を新しい順に表示しなければならない（MUST）。各行には、カテゴリ、契機、開始の日時、状態、集めた候補の数、除外した数、作った記事と更新した記事の数、LLMの呼び出し回数、金額を出す。
金額のかかる呼び出しがない実行では、金額の列に「—」を出す。

#### Scenario: 今朝の実行を確かめる

- **WHEN** 今朝のスケジュールで3つのカテゴリが実行されたあとに実行履歴を開く
- **THEN** 3つの実行が新しい順に表示され、それぞれの契機は「スケジュール」である

#### Scenario: 金額のある実行とない実行

- **WHEN** 0.40米ドルを使った実行と、金額のかからないプロバイダーだけを呼んだ実行のある実行履歴を開く
- **THEN** 前者の行の金額の列に$0.40が、後者の行の金額の列に「—」が表示される

## ADDED Requirements

### Requirement: 実行の詳細の金額の表示

実行の詳細で、画面は、その実行の金額と、金額のわからない呼び出しの件数を表示しなければならない（MUST）。
金額のかかる呼び出しがない実行では、金額に「—」を出す。金額のわからない呼び出しがない実行では、その件数を表示しない。

#### Scenario: 時間切れのあった実行

- **WHEN** 0.40米ドルを使い、1回が時間切れになった実行の詳細を開く
- **THEN** 金額の$0.40と、金額のわからない呼び出しの1件が表示される

### Requirement: 実行の詳細のタスクごとの呼び出しの表示

実行の詳細で、画面は、LLMの呼び出しの回数と金額をタスクごとに表で表示しなければならない（MUST）。
表には、呼び出しのあったタスクだけを出す。金額のかかる呼び出しがないタスクの金額には「—」を出す。呼び出しのない実行では、表を出さない。

#### Scenario: 判定と本文の生成

- **WHEN** 判定を3回、本文の生成を1回呼んだ実行の詳細を開く
- **THEN** タスクごとの呼び出しの表に、判定の3回と本文の生成の1回が、それぞれの金額とともに表示される
