# Spec Delta

## ADDED Requirements

### Requirement: 「利用量」の区画

設定の画面は、「プロバイダー」の区画のすぐあとに「利用量」の区画を表示しなければならない（MUST）。
画面の上部の区画のリンクにも「利用量」を置く。区画は、数える期間が今の予算の期間の初日から今までであることを、UTCであることとともに表示する。

#### Scenario: 設定の画面を開く

- **WHEN** 設定の画面を開く
- **THEN** 「プロバイダー」の区画のすぐあとに「利用量」の区画があり、上部の区画のリンクから移れる

### Requirement: 期末の見込みの表示

金額のかかるプロバイダーがあるとき、設定の画面は、「利用量」の区画に、期末の見込みの金額を文で表示しなければならない（MUST）。
文は、見込みであることと、期間の平均の速さで期末まで進んだときの金額であることを伝える。見込みが月の予算を超えるときは、そのことも同じ文の並びで伝える。画面の上部の警告の帯は増やさない。

#### Scenario: 予算を超えそうな期間

- **WHEN** 月の予算が100米ドルで、期末の見込みが120米ドルの状態で設定の画面を開く
- **THEN** 「利用量」の区画に、期末の見込みの$120.00と、月の予算を超えそうなことが表示される

#### Scenario: 予算に収まりそうな期間

- **WHEN** 月の予算が100米ドルで、期末の見込みが30米ドルの状態で設定の画面を開く
- **THEN** 「利用量」の区画に、期末の見込みの$30.00が表示され、予算を超えそうなことは表示されない

### Requirement: カテゴリごとの利用量の表示

設定の画面は、「利用量」の区画に、カテゴリごとの利用量を表で表示しなければならない（MUST）。
各行には、カテゴリの名前、回数、金額、作った記事の数、開いた記事の数、開いた記事1件あたりの金額を出す。開いた記事が0件のカテゴリの1件あたりの金額には「—」を出す。
表の最後の行には、実行に属さない呼び出しを1行にまとめて出す。この行の記事の数の列は空にする。

#### Scenario: 記事を開いたカテゴリ

- **WHEN** 期間内にカテゴリAの実行が2米ドルを使い、生成記事を4件作り、そのうち2件を開いた状態で設定の画面を開く
- **THEN** カテゴリごとの利用量の表のカテゴリAの行に、$2.00、作った記事の4、開いた記事の2、1件あたりの$1.00が表示される

#### Scenario: 要約と翻訳の呼び出し

- **WHEN** 期間内に、配信記事の要約を2回、本文の翻訳を1回呼んだ状態で設定の画面を開く
- **THEN** カテゴリごとの利用量の表の最後に「実行に属さない呼び出し」の行があり、回数の3が表示される

### Requirement: 日ごとの利用量の表示

設定の画面は、「利用量」の区画に、期間の初日から今日までの日ごとの利用量を表で表示しなければならない（MUST）。
各行には、UTCの日、金額、回数を出す。金額の列には、期間の中で最も多い日の金額を全幅とした横棒を添える。横棒は読み上げから外し、金額は文字で読めるようにする。

#### Scenario: 期間の5日目に開く

- **WHEN** 締め日が10日の状態で、10月14日に設定の画面を開く
- **THEN** 日ごとの利用量の表に、10月10日から10月14日までの5行が表示される

### Requirement: 金額のかからない構成での利用量の表示

金額のかかるプロバイダーがないとき、設定の画面は、「利用量」の区画の金額を「かからない」と表示し、回数で利用量を見せなければならない（MUST）。
このとき、期末の見込みの文は表示しない。

#### Scenario: 金額のかからないプロバイダーだけで動かす

- **WHEN** すべてのプロバイダーが金額のかからないアダプターの状態で設定の画面を開く
- **THEN** カテゴリごとの利用量の表の金額の列は「かからない」と表示され、回数は数で表示され、期末の見込みは表示されない
