# Spec Delta

## ADDED Requirements

### Requirement: LLMの呼び出しの記録の保存期間

LLMの呼び出しの記録が、30日前と今の予算の期間の初日のどちらよりも古くなったとき、サーバーはその記録を削除しなければならない（MUST）。
予算の期間の合計、予算の判定、期末の見込みが、期間のすべての呼び出しを数えられるようにするためである。
実行履歴は、呼び出しの記録とは別に、30日で削除する。実行履歴が先に消えた呼び出しは、実行に属さない呼び出しとして残る。

#### Scenario: 31日ある予算の期間の最後の日

- **WHEN** 締め日が10日で、10月10日に記録した呼び出しがあり、11月9日の正午に古い記録を削除する
- **THEN** 10月10日の呼び出しの記録は残り、予算の期間の合計に数えられる

#### Scenario: 予算の期間より前の呼び出し

- **WHEN** 締め日が10日で、10月9日に記録した呼び出しがあり、11月9日の正午に古い記録を削除する
- **THEN** 10月9日の呼び出しの記録は削除される

#### Scenario: 実行履歴は30日で消える

- **WHEN** 締め日が10日で、10月10日に実行し、11月9日の正午に古い記録を削除する
- **THEN** その実行履歴は読み出せず、その実行の呼び出しの記録は実行に属さない呼び出しとして残る
