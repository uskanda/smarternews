# Spec Delta

## ADDED Requirements

### Requirement: 入力のある読む画面のダイアログの外の操作

読む画面のダイアログに入力があるか、ダイアログが応答を待っている間、ダイアログの外が押されたとき、画面はダイアログを閉じてはならない（MUST NOT）。
対象のダイアログは、購読フィードの追加、購読フィードの設定、トピックを追加、隠すフィルターを作る、ハイライト、メモを書いてハイライトするの6つである。
入力があるとは、ダイアログの欄の値が開いたときの値から変わっていることをいう。購読フィードの追加では、URLの欄が空でないことをいう。

#### Scenario: メモを書いている途中で外を押す

- **WHEN** ハイライトのダイアログでメモを書く欄を開き、文字を入力して、ダイアログの外の本文を押す
- **THEN** ダイアログは開いたままで、入力した文字が残っている

#### Scenario: 候補を待つ間に一覧を押す

- **WHEN** 購読フィードの追加のダイアログにWebページのURLを入れ、候補を待つ間にダイアログの外の一覧を押す
- **THEN** ダイアログは開いたままで、URLが残っている

#### Scenario: 開いたままの値で外を押す

- **WHEN** 選んだ文字列から隠すフィルターを作るダイアログを開き、何も変えずにダイアログの外を押す
- **THEN** ダイアログが閉じる

### Requirement: 入力のある読む画面のダイアログを閉じる前の確認

読む画面のダイアログに入力がある間、Escapeか「やめる」か「閉じる」が選ばれたとき、画面は、ダイアログを閉じる前に確認を求めなければならない（MUST）。
確認の題は「保存していない変更があります」、操作は「破棄して閉じる」と「編集を続ける」で、トピックの編集の確認と同じである。
「破棄して閉じる」を選ぶと、入力を捨ててダイアログを閉じる。「編集を続ける」を選ぶと、入力を残してダイアログに戻る。
入力がないときは、確認なしに閉じる。

#### Scenario: メモを書いている途中でEscapeを押す

- **WHEN** メモを書いてハイライトするダイアログで文字を入力し、Escapeを押す
- **THEN** 題が「保存していない変更があります」の確認が表示され、ダイアログは開いたままである

#### Scenario: 編集を続ける

- **WHEN** 確認で「編集を続ける」を選ぶ
- **THEN** 確認が閉じ、ダイアログには入力した文字が残っている

#### Scenario: 破棄して閉じる

- **WHEN** 確認で「破棄して閉じる」を選ぶ
- **THEN** ダイアログが閉じ、ハイライトは増えない

#### Scenario: 入力のないダイアログを閉じる

- **WHEN** トピックを追加するダイアログを開き、文章とカテゴリを変えずに「やめる」を選ぶ
- **THEN** 確認なしにダイアログが閉じる

### Requirement: 購読フィードの設定の登録解除とほかの設定

購読フィードの設定のダイアログで切り替えを変えたあと、「登録を解除」または「ほかの設定」が選ばれたとき、画面は、保存していない変更の確認を出してはならない（MUST NOT）。
切り替えた値は捨てる。

#### Scenario: 切り替えてから登録を解除を選ぶ

- **WHEN** 購読フィードXの設定のダイアログで翻訳の切り替えを入れ、「登録を解除」を選ぶ
- **THEN** 保存していない変更の確認は出ず、登録を解除するかを確かめるダイアログが開く

### Requirement: メモの入力欄のやめる

記事へのメモまたはハイライトのメモの入力欄に、保存済みのメモと違う書きかけがある間、「やめる」が選ばれたとき、画面は、保存していない変更があることを示して確認を求めなければならない（MUST）。
確認の題と操作は、読む画面のダイアログを閉じる前の確認と同じである。
「破棄して閉じる」を選ぶと、書きかけを捨てて入力欄を閉じる。書きかけがないときは、確認なしに入力欄を閉じる。

#### Scenario: 記事へのメモの書きかけをやめる

- **WHEN** 記事へのメモの入力欄に文字を入力し、「やめる」を選ぶ
- **THEN** 題が「保存していない変更があります」の確認が表示され、入力欄は開いたままである

#### Scenario: 確認で破棄する

- **WHEN** その確認で「破棄して閉じる」を選ぶ
- **THEN** 入力欄が閉じ、記事へのメモのボタンが表示される

## MODIFIED Requirements

### Requirement: ダイアログの取りやめ

利用者がダイアログを閉じる操作またはEscapeのキーを選んだとき、画面は、購読フィードを登録せずにダイアログを閉じなければならない（MUST）。
URLの欄に入力があるときは、閉じる前に、読む画面のダイアログを閉じる前の確認を求める。
次に開いたダイアログは、入力していない状態から始まる。

#### Scenario: 入力の途中で閉じる

- **WHEN** ダイアログにURLを入力し、追加を選ばずにEscapeを押し、確認で「破棄して閉じる」を選ぶ
- **THEN** ダイアログが閉じ、購読フィードは増えず、フォーカスは「購読フィードを追加」の操作にある

#### Scenario: 入力のないダイアログを閉じる

- **WHEN** URLを入力せずにEscapeを押す
- **THEN** 確認なしにダイアログが閉じ、フォーカスは「購読フィードを追加」の操作にある

#### Scenario: 閉じたあとに開き直す

- **WHEN** URLを入力し、確認で「破棄して閉じる」を選んでダイアログを閉じ、もう一度「購読フィードを追加」を選ぶ
- **THEN** URLの入力欄は空で、カテゴリには開いているカテゴリが選ばれている

### Requirement: 購読フィードの設定の取りやめ

利用者が保存を選ばずにダイアログを閉じたとき、画面は、購読フィードの設定を変えてはならない（MUST NOT）。
切り替えを変えたあとにEscapeまたは「やめる」を選んだときは、閉じる前に、読む画面のダイアログを閉じる前の確認を求める。

#### Scenario: 切り替えてから閉じる

- **WHEN** 購読フィードXのダイアログで翻訳の切り替えを入れ、保存を選ばずにEscapeを押し、確認で「破棄して閉じる」を選ぶ
- **THEN** ダイアログが閉じ、購読フィードXの翻訳は切れたままである
