# Spec Delta

## ADDED Requirements

### Requirement: 記事へのメモの書きかけの保持

記事へのメモの入力欄に保存済みのメモと違う書きかけがある間、Webの画面は、その書きかけを記事ごとにブラウザーのタブの中に覚えなければならない（MUST）。
覚えた書きかけは、同じタブで別の記事を開いても、画面を再読み込みしても残る。タブを閉じると消える。
書きかけを保存したとき、確認で破棄したとき、書きかけが保存済みのメモと同じになったとき、画面は覚えた書きかけを消す。

#### Scenario: 別の記事へ移って戻る

- **WHEN** 記事Aの記事へのメモの入力欄に「あとで比べる」と書き、保存せずに一覧の記事Bを開いてから、記事Aを開き直す
- **THEN** 記事Aの記事へのメモの入力欄が開いていて、「あとで比べる」が入っている

#### Scenario: 保存したあと

- **WHEN** 書きかけを保存し、別の記事へ移ってから戻る
- **THEN** 記事へのメモの入力欄は閉じていて、保存したメモが表示されている

### Requirement: 書きかけのある記事を開いたときのフォーカス

書きかけを覚えている記事を開いたとき、Webの画面は、記事へのメモの入力欄にフォーカスを移してはならない（MUST NOT）。
記事を開いたあとも、1文字のキーで一覧の別の記事へ移れる。

#### Scenario: 書きかけのある記事を開く

- **WHEN** 記事へのメモの書きかけを覚えている記事を一覧で開く
- **THEN** 入力欄は開いているが、フォーカスは入力欄になく、`j` と `k` で一覧の別の記事へ移れる
