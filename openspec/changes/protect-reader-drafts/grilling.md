# grilling 記録: protect-reader-drafts

GitHubのissueの195番のコメントで、1ラウンドの質問に答えた記録である。
issueは、読む画面のダイアログが外を押すと確認なしに閉じて入力が消えること、記事へのメモの書きかけが一覧の別の行を押すと消えることの指摘である（監査ID U-01）。
質問の前に、読む画面のダイアログが6つあり、どれもRadixの既定で外を押すと閉じること、記事の画面が `key={articleId}` で作り直されることを確かめた。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 記事へのメモの書きかけを覚える場所 | タブごとの保存領域（sessionStorage）に覚える。再読み込みしても残り、タブを閉じると消える（A） | 第1ラウンド Q1 |
| 隠すフィルターを作るダイアログの扱い | 同じ保護を入れる。開いたときの値から変えたときだけ、入力があるとみなす（A） | 第1ラウンド Q2 |
| 書きかけのある記事へ戻ったときの見せ方 | 入力欄を開いた状態で書きかけを見せる。フォーカスは移さない（A） | 第1ラウンド Q3 |
| 記事へのメモの「やめる」 | ダイアログと同じ確認を出す。破棄を選ぶと、覚えた書きかけも消す（A） | 第1ラウンド Q4 |
| 実装の計画 | 共通のダイアログの外枠に保護を置き、ハイライトの2つのダイアログと隠すフィルターのダイアログもその外枠を使う。「登録を解除」と「ほかの設定」は確認なしに捨てるまま | 計画の承認（会話中に確認） |
