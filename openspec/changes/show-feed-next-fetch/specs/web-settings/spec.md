# Spec Delta

## MODIFIED Requirements

### Requirement: 購読フィードの一覧

購読フィードの設定の画面が開かれたとき、画面は、すべての購読フィードを、名前、カテゴリ、取得周期、有効と無効の別、取得の状況とともに表示しなければならない（MUST）。

#### Scenario: 失敗している購読フィード

- **WHEN** 直近の取得に失敗した購読フィードがある
- **THEN** その行に、最後に成功した日時と失敗の理由が、色だけに頼らず言葉で表示される

#### Scenario: 続けて失敗している購読フィード

- **WHEN** 3回続けて取得に失敗した購読フィードと、1回だけ失敗した購読フィードがある
- **THEN** 3回の行には「3回続けて失敗」と表示され、1回の行には失敗の回数は表示されない

#### Scenario: 次の取得

- **WHEN** 次の取得の日時が未来の購読フィード、その日時が過ぎた購読フィード、一時停止中の購読フィードがある
- **THEN** 未来の行には次の取得の日時が、過ぎた行には「次の取得」に続けて「まもなく」が表示され、一時停止中の行には次の取得は表示されない
