# Spec Delta

## ADDED Requirements

### Requirement: 保存した検索の一覧

左のペインの保存した検索が選ばれたとき、画面は、保存した検索語と絞り込みで、未読の記事だけを検索した結果を一覧に表示しなければならない（MUST）。
一覧は、既読も表示する切り替えを持つ。

#### Scenario: 保存した検索を開く

- **WHEN** 検索語「量子」に一致する記事が未読1件と既読1件ある状態で、検索語「量子」の保存した検索を開く
- **THEN** 一覧には未読の1件だけが並び、見出しは保存した検索の名前である

#### Scenario: 既読も表示する

- **WHEN** 保存した検索の一覧で、既読も表示する切り替えをオンにする
- **THEN** 一覧には既読の1件も並ぶ

### Requirement: 保存した検索の一覧での一括の既読

保存した検索の一覧で、画面は、一括の既読の操作、重要度4以上の切り替え、並び順のメニューを表示してはならない（MUST NOT）。

#### Scenario: 一括の既読は出ない

- **WHEN** 未読の記事がある保存した検索を開く
- **THEN** 一覧に「すべて既読にする」のボタンは表示されない

### Requirement: 検索の結果からの保存

検索の結果の画面で「検索を保存」を選んだとき、画面は、名前の入力欄を、検索語を既定の値として表示しなければならない（MUST）。
保存すると、画面は、そのときの検索語と、カテゴリまたは購読フィードの絞り込みを持つ保存した検索を作る。未読だけかどうかは保存しない。

#### Scenario: 絞り込んだ検索を保存する

- **WHEN** 検索語「量子」、購読フィードXの絞り込み、未読だけの検索の結果で「検索を保存」を選び、名前を変えずに保存する
- **THEN** 名前「量子」、検索語「量子」、購読フィードXの絞り込みの保存した検索ができ、左のペインに並ぶ

### Requirement: 検索語がないときの保存

検索語が空の間、画面は、「検索を保存」を選べないようにしなければならない（MUST）。

#### Scenario: 検索語がない

- **WHEN** 検索語なしで検索の画面を開く
- **THEN** 画面の「検索を保存」は選べない
