# Spec Delta

## ADDED Requirements

### Requirement: 保存した検索の操作

APIは、保存した検索について、並び順での一覧、作成、名前の変更、削除、別の保存した検索の前か末尾への移動の操作を提供しなければならない（MUST）。
作成した保存した検索は、並び順の末尾に置く。

#### Scenario: 作成して一覧を読む

- **WHEN** 名前「A」と「B」の保存した検索を順に作成し、一覧を読む
- **THEN** 「A」「B」の順に返る

#### Scenario: 先頭へ移動する

- **WHEN** 「A」「B」の順に並ぶ状態で、「B」を「A」の前へ移動する
- **THEN** 一覧は「B」「A」の順になる

#### Scenario: 名前を変える

- **WHEN** 保存した検索「A」の名前を「C」に変える
- **THEN** 一覧では名前が「C」になり、検索語と絞り込みは変わらない

### Requirement: 保存した検索の入力の誤り

保存した検索の作成で、検索語が空のとき、検索語が200文字を超えるとき、カテゴリと購読フィードの両方を指定したとき、存在しないカテゴリか購読フィードを指定したとき、APIは、作成を拒み、入力の誤りを返さなければならない（MUST）。

#### Scenario: 両方を指定する

- **WHEN** カテゴリAと購読フィードXの両方を指定して保存した検索を作成する
- **THEN** 入力の誤りが返り、保存した検索は増えない

#### Scenario: 空の検索語

- **WHEN** 空白だけの検索語で保存した検索を作成する
- **THEN** 入力の誤りが返る

### Requirement: 件数の応答の保存した検索ごとの未読数

件数の応答は、保存した検索ごとに、その識別子と未読数を含まなければならない（MUST）。

#### Scenario: 件数を読む

- **WHEN** 保存した検索が2つある状態で件数を読む
- **THEN** 応答には、2つの保存した検索それぞれの未読数が含まれる
