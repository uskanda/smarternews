# Spec Delta

## ADDED Requirements

### Requirement: 保存した検索の条件

サーバーは、保存した検索ごとに、名前、検索語、カテゴリまたは購読フィードの絞り込みを保存しなければならない（MUST）。
絞り込みは、なしか、カテゴリ1つか、購読フィード1つのどれかである。
未読だけかどうかは、保存した検索の条件に含めない。

#### Scenario: 購読フィードで絞り込んだ検索を保存する

- **WHEN** 検索語「量子」、購読フィードXの絞り込み、名前「X の量子」で検索を保存し、保存した検索を読み出す
- **THEN** 名前「X の量子」、検索語「量子」、購読フィードXの絞り込みを持つ保存した検索が返る

#### Scenario: 同じ条件をもう一度保存する

- **WHEN** 検索語「量子」で絞り込みのない検索を保存したあと、同じ条件でもう一度保存する
- **THEN** 2つの保存した検索が並ぶ

### Requirement: 保存した検索の未読数

サーバーは、保存した検索ごとに、その条件に未読だけを加えた検索の結果の件数を、未読数として数えなければならない（MUST）。
数には、終了したイベントの記事を含め、フィルターで隠した配信記事と、購読フィードで絞り込んでいない検索での隠した重複を含めない。

#### Scenario: 終了したイベントを数える

- **WHEN** 検索語「量子」に一致する未読の記事が、ニュースの記事1件と終了したイベントの記事1件ある状態で、検索語「量子」の保存した検索の未読数を読む
- **THEN** 未読数は2である

#### Scenario: 既読とフィルターで隠した記事は数えない

- **WHEN** 検索語「量子」に一致する記事が、未読1件、既読1件、フィルターで隠した未読の配信記事1件ある状態で、未読数を読む
- **THEN** 未読数は1である

### Requirement: LLMを使わない数え方

サーバーは、保存した検索の未読数を数えるのに、言語モデルを呼んではならない（MUST NOT）。

#### Scenario: 件数を読む

- **WHEN** 保存した検索が3つある状態で、件数を読む
- **THEN** 言語モデルは呼ばれない

### Requirement: 絞り込みの対象の削除

保存した検索の絞り込みに使っているカテゴリまたは購読フィードが削除されたとき、サーバーは、その保存した検索を削除しなければならない（MUST）。

#### Scenario: 購読フィードを削除する

- **WHEN** 購読フィードXで絞り込んだ保存した検索と、絞り込みのない保存した検索がある状態で、購読フィードXを削除する
- **THEN** 絞り込みのない保存した検索だけが残る
