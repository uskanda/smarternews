# Spec Delta

## ADDED Requirements

### Requirement: 保存した検索の往復

書き出した設定ファイルを空のサーバーに読み込んだとき、サーバーは、書き出し元と同じ保存した検索を、同じ並び順で持たなければならない（MUST）。
絞り込みのカテゴリは識別名で、購読フィードはURLで指す。

#### Scenario: 別のサーバーへ移す

- **WHEN** 絞り込みのない保存した検索と、カテゴリ `tools` で絞り込んだ保存した検索と、購読フィードXで絞り込んだ保存した検索を持つサーバーから書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーでも、3つの保存した検索が同じ名前、検索語、絞り込み、並び順で並ぶ

### Requirement: 保存した検索の読み込みの重複

名前、検索語、絞り込みのすべてが一致する保存した検索を含む設定ファイルを読み込むとき、サーバーは、その保存した検索を新しく作ってはならない（MUST NOT）。

#### Scenario: 同じファイルを2回読み込む

- **WHEN** 保存した検索を2つ含む設定ファイルを、同じサーバーに2回読み込む
- **THEN** 保存した検索は2つのままである

### Requirement: 保存した検索の読み込みの誤り

設定ファイルの保存した検索が、ファイルとサーバーのどちらにもないカテゴリか購読フィードを指すとき、サーバーは、ファイル全体の読み込みを拒まなければならない（MUST）。

#### Scenario: 存在しないカテゴリを指す

- **WHEN** 存在しないカテゴリ `nowhere` で絞り込んだ保存した検索を含む設定ファイルを読み込む
- **THEN** 読み込みは拒まれ、何も保存されない
