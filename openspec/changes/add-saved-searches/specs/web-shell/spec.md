# Spec Delta

## ADDED Requirements

### Requirement: 「保存した検索」の区切り

保存した検索が1つ以上ある間、画面は、左のペインの上の段と「カテゴリ」の間に、見出し「保存した検索」の区切りを置かなければならない（MUST）。
区切りの下には、保存した検索を並び順で、未読数つきで表示する。

#### Scenario: 保存した検索がある

- **WHEN** 未読が3件の保存した検索の量子と、未読がない保存した検索の電池がある状態で、画面を開く
- **THEN** 左のペインの「ダイジェスト」の下、「カテゴリ」の上に、見出し「保存した検索」と量子、電池が並び、量子の横に3が表示される

### Requirement: 保存した検索がないときの区切り

保存した検索が1つもない間、画面は、見出し「保存した検索」を表示してはならない（MUST NOT）。

#### Scenario: 保存した検索がない

- **WHEN** 保存した検索がない状態で、画面を開く
- **THEN** 左のペインに見出し「保存した検索」はない

### Requirement: 保存した検索の間のキー移動

Shift+JとShift+Kで左のペインの項目を移るとき、画面は、上の段の項目と最初のカテゴリの間で、保存した検索を並び順に通らなければならない（MUST）。

#### Scenario: 上の段から下へ移る

- **WHEN** 保存した検索の量子がある状態で、「注釈」を開いてShift+Jを押す
- **THEN** 保存した検索の量子が開く

### Requirement: 保存した検索の既読の項目を隠す

既読の項目を隠す設定が有効な間、画面は、未読が0件の保存した検索を左のペインに表示してはならない（MUST NOT）。開いている保存した検索は表示する。

#### Scenario: 未読のない保存した検索

- **WHEN** 既読の項目を隠す設定が有効で、未読のない保存した検索の電池を開いていない状態で、画面を開く
- **THEN** 電池は左のペインに表示されない

#### Scenario: 開いている保存した検索

- **WHEN** 既読の項目を隠す設定が有効で、未読のない保存した検索の電池を開く
- **THEN** 電池は左のペインに表示される

### Requirement: 保存した検索の項目のメニュー

画面は、保存した検索の項目のメニューで、名前の変更、削除、1つ上と1つ下への移動を提供しなければならない（MUST）。
削除は、確認ののちに行う。

#### Scenario: 名前を変える

- **WHEN** 保存した検索の量子のメニューで名前の変更を選び、量子計算と入力して保存する
- **THEN** 左のペインの項目の名前が量子計算になる

#### Scenario: 削除する

- **WHEN** 保存した検索の量子のメニューで削除を選び、確認で削除を選ぶ
- **THEN** 量子は左のペインからなくなる

#### Scenario: 下へ移動する

- **WHEN** 量子、電池の順に並ぶ状態で、量子のメニューで下へ移動を選ぶ
- **THEN** 電池、量子の順に並ぶ
