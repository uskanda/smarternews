# Spec Delta

## MODIFIED Requirements

### Requirement: イベントの一覧

種別がイベントのカテゴリが選ばれたとき、画面は、終了していないイベントを開催日ごとにまとめ、開催日の近い順に表示しなければならない（MUST）。
画面は、記事の一覧と同じ次の表示を出さなければならない（MUST）。

- 取得中は、読み込み中の表示
- 取得に失敗したときは、理由と「もう一度試す」のボタン
- 続きがあるときは、「さらに読み込む」

空の文「これから開催されるイベントはありません」は、取得に成功し、イベントが1件もないときだけ表示する。
一覧の上部には「読み直す」と「すべて既読にする」を置く。「すべて既読にする」はそのカテゴリを範囲とする。未読のイベントが1件もなく、続きもないときは表示しない。取り消しの手段と次の項目へ移る設定の扱いは、記事の一覧と同じにする。
「既読も表示」と重要度4以上の切り替えと並び順のメニューは、表示しない。

#### Scenario: 同じ日に2つのイベントがある

- **WHEN** 明日のイベントが2件、3日後のイベントが1件、昨日終了したイベントが1件ある
- **THEN** 明日の日付の下に2件、3日後の日付の下に1件が表示され、昨日のイベントは表示されない

#### Scenario: 取得している間

- **WHEN** イベントのカテゴリを開き、一覧の応答がまだ届いていない
- **THEN** 読み込み中の表示が出て、空の文は表示されない

#### Scenario: 取得に失敗する

- **WHEN** イベントのカテゴリの一覧の取得が失敗する
- **THEN** 失敗の理由と「もう一度試す」のボタンが表示され、ボタンを押すと一覧が取得し直される

#### Scenario: 51件以上ある

- **WHEN** 終了していないイベントが51件あるカテゴリを開く
- **THEN** 開催の近い50件と「さらに読み込む」が表示され、押すと残りの1件が表示される

#### Scenario: すべて既読にする

- **WHEN** 未読のイベントが3件あるカテゴリで「すべて既読にする」を選ぶ
- **THEN** そのカテゴリの3件が既読になり、その操作を取り消す手段が表示される

#### Scenario: 未読のイベントがない

- **WHEN** すべてのイベントが既読で、続きもないカテゴリを開く
- **THEN** 一括の既読のボタンは表示されず、「読み直す」は表示される
