# Proposal

## Why

画面を開いたときにカテゴリの取得だけが失敗すると、左のペインにカテゴリが出ず、理由も出ない。カテゴリの一覧のURLを開いていると、本文は `読み込み中…` のまま止まる。
「読み直す」と `r` は記事と件数だけを取り直すので、ページを読み込み直すまで直らない（Issue #211）。

## What Changes

- 左のペインのカテゴリ・購読フィード・件数のどれかの取得が失敗し、そのデータもないときは、検索欄のすぐ下に1行を出す。読み込めなかったものの名前を並べ、再試行のボタンを1つ置く。
- カテゴリや購読フィードの一覧のURLを開いていて、その一覧の取得が失敗したとき、本文側に `読み込み中…` の代わりに失敗と再試行のボタンを出す。
- 「読み直す」と `r` は、記事と件数に加えて、失敗しているカテゴリと購読フィードの問い合わせも取り直す。成功しているものは取り直さない。
- Androidアプリとサーバーには手を入れない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-shell`：「失敗の表示」に左のペインと本文側のシナリオを足す。「手動の更新」と「キーボードでの一覧の再取得」に、失敗しているカテゴリと購読フィードを取り直すことを書き足す。

## Impact

- `apps/web/src/shell/Shell.tsx`：`useNavModels` が失敗の状態を返し、左のペインに失敗の1行を置く
- `apps/web/src/reader/ReaderPage.tsx`：本文側の失敗の表示と、`refresh` で取り直す範囲
- APIとサーバー：変えない
