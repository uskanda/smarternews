# Spec Delta

## ADDED Requirements

### Requirement: 「購読フィード」と「未分類」の一覧の追加の操作

「購読フィード」または「未分類」の記事の一覧を表示している間、画面は、一覧の上部に「購読フィードを追加」の操作を表示しなければならない（MUST）。
個々の購読フィードの一覧、「未読」「すべて」「スター」の一覧、検索の一覧には表示しない。

#### Scenario: 「購読フィード」の一覧

- **WHEN** 上段の項目の「購読フィード」の記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードを追加」が表示される

#### Scenario: 「未分類」の一覧

- **WHEN** 左のペインの「未分類」の記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードを追加」が表示される

#### Scenario: 個々の購読フィードの一覧

- **WHEN** 購読フィードXの記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードを追加」は表示されず、「購読フィードの設定」が表示される

### Requirement: カテゴリなしで始まる追加のダイアログ

利用者が「購読フィード」または「未分類」の一覧の上部の「購読フィードを追加」を選んだとき、画面は、記事の一覧を表示したまま、追加のダイアログを開かなければならない（MUST）。
ダイアログは、カテゴリの一覧から開くものと同じである。
ダイアログのカテゴリは「なし（未分類）」を選んだ状態にし、開いた直後のフォーカスはURLの入力欄に置く。
登録できたときは、ダイアログを閉じ、追加したことを知らせ、フォーカスを「購読フィードを追加」の操作に戻す。記事の一覧は、開いていた一覧のまま変えない。

#### Scenario: カテゴリなしで開く

- **WHEN** 左のペインの「未分類」の記事の一覧で「購読フィードを追加」を選ぶ
- **THEN** 記事の一覧の上にダイアログが開き、カテゴリに「なし（未分類）」が選ばれ、URLの入力欄にフォーカスがある

#### Scenario: カテゴリなしで追加する

- **WHEN** 上段の項目の「購読フィード」の一覧から開いたダイアログに、フィードのURLを入力して追加する
- **THEN** 購読フィードはカテゴリなしで登録され、ダイアログが閉じ、「購読フィード」の記事の一覧が表示されたままで、フォーカスは「購読フィードを追加」にある

#### Scenario: カテゴリを選んで追加する

- **WHEN** 左のペインの「未分類」の一覧から開いたダイアログで、カテゴリにAを選んで追加する
- **THEN** 購読フィードはカテゴリAで登録され、「未分類」の記事の一覧が表示されたままである
