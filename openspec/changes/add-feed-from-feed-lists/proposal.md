# Proposal

## Why

読んでいる一覧から購読フィードを追加するボタンは、ニュースのカテゴリの一覧にしかない（issue #205、監査ID U-12）。
「購読フィード」と「未分類」の一覧から追加するには、「設定」「購読フィードを設定する」の順に押して、設定の画面へ移る必要がある。
カテゴリに属さないフィードを足したいときにこそ使う2つの一覧で、その場で追加できるようにする。

## What Changes

- Webの画面で、「購読フィード」と「未分類」の記事の一覧の上部にも「購読フィードを追加」のボタンを置く。位置、名前、ダイアログ、追加のあとの動きは、カテゴリの一覧と同じにする。
- この2つの一覧から開いたダイアログのカテゴリは、「なし（未分類）」から始める。利用者はダイアログでカテゴリを選び直せる。
- 個々の購読フィードの一覧、「未読」「すべて」「スター」、検索、カテゴリの「AI生成」、イベントのカテゴリには、これまでどおり置かない。
- 進行中の変更 `add-feed-from-category` のweb-readerの差分の「カテゴリ以外の一覧には表示しない」の文とシナリオを、この変更に合わせて直す。
- 設定の画面、Androidアプリ、サーバー、APIは変えない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-reader`: 2つの一覧の要件を足す。「購読フィード」と「未分類」の一覧から、カテゴリなしで始まるダイアログで購読フィードを追加する

## Impact

- `apps/web`: `AddFeedDialog` が、開いているカテゴリを省けるようになる。`ReaderPage` が2つの一覧でもボタンを出す。
- 進行中の変更 `add-feed-from-category` の `specs/web-reader/spec.md`。
- サーバー、API、`packages/client`、Androidアプリに変更はない。LLMの呼び出しも変わらない。
