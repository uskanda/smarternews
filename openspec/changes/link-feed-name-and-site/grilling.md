# grilling 記録: link-feed-name-and-site

GitHubのissueの219番のコメントで、1ラウンドの質問に答えた記録である。
issueは、配信記事の本文の購読フィードの名前がリンクでなく、保存しているサイトのURLもOPMLの書き出しにしか使っていないという指摘である（Web UIの監査のR-09）。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 購読フィードの名前を押したあとの画面 | 本文を残し、中央の一覧をその購読フィードの未読の一覧（左のペインから開いた一覧と同じ内容）に切り替える。狭い画面では一覧へ移る（A） | 第1ラウンド Q1 |
| 対象 | Webだけを変える。Androidアプリは変えない（A） | 第1ラウンド Q2 |
| サイトのURLがない購読フィード | 「サイトを開く」を表示しない。フィードのURLからの推測はしない（A） | 第1ラウンド Q3 |
| 「サイトを開く」の形と場所 | 新しいタブで開くリンク。一覧の上部では2段目の「購読フィードの設定」の隣、設定の行では「記事の一覧」の隣に置く | 会話中に確認（計画の承認） |
| その購読フィードの一覧を開いているとき | 本文の名前をリンクにしない | 会話中に確認（計画の承認） |
| 実装の計画 | 2026-11-15に承認された計画のとおり（APIは変えない） | 会話中に確認 |
