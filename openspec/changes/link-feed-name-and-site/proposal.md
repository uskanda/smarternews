# Proposal

## Why

配信記事の本文の画面で、購読フィードの名前はリンクのない文字である。「未読」で読んだ記事の配信元のほかの記事を見るには、左のペインからその購読フィードを探すしかない。また、購読フィードのサイトのURLは取得のたびに保存しているが、使うのはOPMLの書き出しだけで、画面からサイトを開く道がない。

## What Changes

- 配信記事の本文の購読フィードの名前を、その購読フィードの未読の一覧へのリンクにする。広い画面では本文を残したまま中央の一覧を切り替え、狭い画面では一覧へ移る。その購読フィードの一覧で開いた記事では、リンクにしない。
- 購読フィードの一覧の上部の2段目に、サイトを新しいタブで開く「サイトを開く」のリンクを置く。
- 設定の購読フィードの行の「記事の一覧」の隣に、同じ「サイトを開く」のリンクを置く。
- サイトのURLがない購読フィードでは「サイトを開く」を出さない。
- APIとデータベースは変えない。Androidアプリは対象外とする。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-reader`: 本文の購読フィードの名前を一覧へのリンクにし、購読フィードの一覧の上部にサイトへのリンクを置く。
- `web-settings`: 購読フィードの行にサイトへのリンクを置く。
