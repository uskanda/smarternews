# Spec Delta

## ADDED Requirements

### Requirement: 本文の購読フィードの名前から一覧へ移る操作

配信記事の本文が開かれたとき、画面は、補足の行の購読フィードの名前を、その購読フィードの未読の一覧へのリンクとして表示しなければならない（MUST）。
広い画面では、リンクは本文を開いたまま中央の一覧をその購読フィードの一覧に切り替えなければならない（MUST）。一覧は、左のペインから開いたときと同じ未読の一覧でなければならない（MUST）。
狭い画面では、リンクはその購読フィードの一覧を開かなければならない（MUST）。
その購読フィードの一覧で開いた記事では、名前をリンクにしてはならない（MUST NOT）。

#### Scenario: 未読の一覧で読んだ記事の配信元へ移る

- **WHEN** 広い画面で、未読の一覧から配信記事を開き、本文の購読フィードの名前を選ぶ
- **THEN** 本文はその記事のまま残り、中央の一覧はその購読フィードの未読の一覧に切り替わる

#### Scenario: 狭い画面

- **WHEN** 狭い画面で配信記事を開き、本文の購読フィードの名前を選ぶ
- **THEN** その購読フィードの一覧が開く

#### Scenario: その購読フィードの一覧で開いた記事

- **WHEN** 購読フィードの一覧から、その購読フィードの記事を開く
- **THEN** 本文の購読フィードの名前はリンクでない文字で表示される

### Requirement: 購読フィードの一覧からサイトを開く操作

購読フィードの一覧の上部は、その購読フィードのサイトのURLが分かっているとき、2段目に、サイトを新しいタブで開く「サイトを開く」のリンクを表示しなければならない（MUST）。
サイトのURLが分からない購読フィードでは、このリンクを表示してはならない（MUST NOT）。フィードのURLからサイトのURLを推測してはならない（MUST NOT）。

#### Scenario: サイトのURLが分かっている購読フィード

- **WHEN** 取得でサイトのURLを保存した購読フィードの一覧を開く
- **THEN** 上部に「サイトを開く」のリンクがあり、そのURLを新しいタブで開く

#### Scenario: サイトのURLが分からない購読フィード

- **WHEN** サイトのURLを保存していない購読フィードの一覧を開く
- **THEN** 一覧の上部に「サイトを開く」のリンクは表示されない
