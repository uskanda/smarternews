# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードの行からサイトを開く操作

設定の購読フィードの行は、その購読フィードのサイトのURLが分かっているとき、「記事の一覧」の隣に、サイトを新しいタブで開く「サイトを開く」のリンクを表示しなければならない（MUST）。
リンクの読み上げ名は「<購読フィード名>のサイトを開く」でなければならない（MUST）。
サイトのURLが分からない購読フィードの行では、このリンクを表示してはならない（MUST NOT）。

#### Scenario: サイトのURLが分かっている購読フィード

- **WHEN** サイトのURLを保存した購読フィードの行を見る
- **THEN** 行の「記事の一覧」の隣に「サイトを開く」のリンクがあり、そのURLを新しいタブで開く

#### Scenario: サイトのURLが分からない購読フィード

- **WHEN** サイトのURLを保存していない購読フィードの行を見る
- **THEN** 行に「サイトを開く」のリンクは表示されない
