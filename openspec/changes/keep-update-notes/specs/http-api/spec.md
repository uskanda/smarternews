## ADDED Requirements

### Requirement: 前回読んでから加わったことの提供

APIは、記事の詳細に、前回読んでから加わったことを、文と時刻の組として古い順に返さなければならない（MUST）。
書き直す前に読んだ時刻を持つ記事では、その時刻より後の更新の記録をすべて返す。
書き直す前に読んだ時刻を持たない記事では、最新の書き直しの時刻の記録だけを返す。
書き直されていない記事と配信記事では、その項目は空である。
記事の一覧と検索の結果の今回加わったことは、最新の1文のまま変えない。

#### Scenario: 読んだあとの2回の書き直し

- **WHEN** 12時半に読んだ記事が、13時と14時の続報で文を持って書き直され、記事の詳細を要求する
- **THEN** 前回読んでから加わったことは、13時の文、14時の文の順である

#### Scenario: 最新の書き直しに文がない

- **WHEN** 12時半に読んだ記事が、13時の続報で文を持って、14時の続報で文を持たずに書き直され、記事の詳細を要求する
- **THEN** 前回読んでから加わったことは13時の文1件で、一覧の今回加わったことは空である

#### Scenario: もう一度読んだあとの書き直し

- **WHEN** 13時の書き直しのあと13時半に読み、14時に文を持って書き直された記事の詳細を要求する
- **THEN** 前回読んでから加わったことは14時の文だけである

#### Scenario: 一度も読まれていない記事

- **WHEN** 一度も既読にされないまま13時と14時の続報で文を持って書き直された記事の詳細を要求する
- **THEN** 前回読んでから加わったことは14時の文だけである

#### Scenario: 一度も読まれず最新の書き直しに文がない

- **WHEN** 一度も既読にされないまま、13時に文を持って、14時に文を持たずに書き直された記事の詳細を要求する
- **THEN** 前回読んでから加わったことは空である
