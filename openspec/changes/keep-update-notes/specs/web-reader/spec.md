## ADDED Requirements

### Requirement: 前回読んでから加わったことの表示

前回読んでから加わったことが2件以上あるとき、画面は本文の画面に、「前回読んでから加わったこと」の見出しで、それぞれの文を古い順に、書き直した日時を添えて表示しなければならない（MUST）。
前回読んでから加わったことが1件で、それが最新の書き直しのものでないときも、画面は同じ形で表示する。
前回読んでから加わったことが最新の書き直しの1件だけのとき、画面は今と同じく「今回の更新で加わったこと」の見出しでその文を表示する。
その区画は、見出しと未確認の表示のあと、読み手への影響の前に置く。

#### Scenario: 読んだあとに2回書き直された記事

- **WHEN** 前回読んでから加わったことが2件ある記事を選ぶ
- **THEN** 本文の前に「前回読んでから加わったこと」の見出しと、2つの文が古い順に日時付きで表示される

#### Scenario: 1回だけ書き直された記事

- **WHEN** 前回読んでから加わったことが最新の書き直しの1件だけの記事を選ぶ
- **THEN** 本文の前に「今回の更新で加わったこと」の見出しとその文が表示される

#### Scenario: 最新の書き直しに文がない記事

- **WHEN** 前回読んでから加わったことが1件で、それが最新の書き直しより前のものである記事を選ぶ
- **THEN** 本文の前に「前回読んでから加わったこと」の見出しと、その文が日時付きで表示される
