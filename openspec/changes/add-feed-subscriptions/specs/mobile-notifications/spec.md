# Spec Delta

## ADDED Requirements

### Requirement: 配信記事を通知しないこと

アプリは、配信記事の通知を出してはならない（MUST NOT）。

#### Scenario: すべての新着を通知する設定

- **WHEN** 通知の設定が、生成記事のすべての新着を通知する値で、前回の確認より後に生成記事が1件と配信記事が20件できる
- **THEN** 通知は生成記事の1件だけについて出る

### Requirement: 通知の設定の名前

アプリは、すべての新着を通知する設定の名前を、生成記事だけが対象であると分かる言葉で表示しなければならない（MUST）。

#### Scenario: 設定の画面を開く

- **WHEN** 設定の画面で通知の設定を開く
- **THEN** 選択肢に「AI生成のすべての新着」が表示される
