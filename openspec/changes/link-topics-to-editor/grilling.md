# grilling 記録: link-topics-to-editor

GitHubのissueの110番のコメントで、1ラウンドの質問に答えた記録である。
issueは、外れた記事から、その記事を選んだトピックの編集へ移る道がないという指摘である（Web UIの監査のU-03）。
モバイルアプリにはトピックの編集がないため、Webだけを対象にした。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 本文の画面でのトピックの出し方 | 補足の行のすぐ下に別の行を設ける。「トピック」の見出しを付けて各トピックをリンクで並べ、長い文は2行で切る。トピックのない記事では出さない（B） | 第1ラウンド Q1 |
| トピックの編集を開いた状態のURL | ハッシュで表す（`/settings/categories/<id>#topic-<topicId>`）。開くとそのトピックまでスクロールし、編集を開き、文章の欄にフォーカスを移す。見つからなければカテゴリの画面をそのまま開く（A） | 第1ラウンド Q2 |
| 実行の詳細で、まとめない表示のトピック名 | 同じ遷移先へのリンクにする（B） | 第1ラウンド Q3 |
| 実装の計画 | 2026-11-06に承認された計画のとおり（API は変えず、`topicEditPath` を共通にする） | 会話中に確認 |
