# Spec Delta

## MODIFIED Requirements

### Requirement: トピックごとのまとめ

画面は、除外した候補を、当たったトピックごとにまとめて表示できなければならない（MUST）。
画面は、まとめるかどうかによらず、候補に当たった各トピックから、そのトピックの編集を開いた状態のカテゴリの画面へ進めなければならない（MUST）。

#### Scenario: 外れの多いトピックを見つける

- **WHEN** 除外した候補の一覧でトピックごとの表示を選び、あるトピックを直すリンクを選ぶ
- **THEN** トピックごとに除外の件数と候補が表示され、リンクの先ではそのトピックの編集が開いた状態になる

#### Scenario: まとめない表示からトピックを直しに行く

- **WHEN** トピックごとの表示を切り、候補の下に並んだトピック名を選ぶ
- **THEN** そのトピックの編集が開いた状態のカテゴリの画面へ移る
