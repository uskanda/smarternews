# Spec Delta

## ADDED Requirements

### Requirement: 当てはまったトピックの表示

生成記事の本文が開かれたとき、画面は、その記事に当てはまったトピックを、補足の行のすぐ下に、そのトピックの編集へのリンクとして表示しなければならない（MUST）。
長いトピックの文章は表示を2行で切ってよいが、読み上げ名には全文を使わなければならない（MUST）。
当てはまったトピックのない記事と、配信記事では、この行を表示してはならない（MUST NOT）。

#### Scenario: 外れた記事からトピックを直しに行く

- **WHEN** トピックが2つ当てはまった生成記事を開き、1つ目のトピックのリンクを選ぶ
- **THEN** その記事のカテゴリの画面が開き、そのトピックの編集が開いた状態になる

#### Scenario: トピックのない記事

- **WHEN** 配信記事か、当てはまったトピックの記録がない生成記事を開く
- **THEN** トピックの行は表示されない
