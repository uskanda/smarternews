# Spec Delta

## ADDED Requirements

### Requirement: トピックの編集を開いた状態で開く

カテゴリの画面が `#topic-<トピックのid>` 付きのURLで開かれたとき、画面は、そのトピックまでスクロールし、そのトピックの編集を開き、トピックの文章の欄にフォーカスを移さなければならない（MUST）。
ほかのトピックの編集は閉じたままにしなければならない（MUST）。
該当するトピックがないとき、画面はカテゴリの画面をふつうに表示しなければならない（MUST）。

#### Scenario: リンクからトピックの編集を開く

- **WHEN** トピックが2つあるカテゴリの画面を、2つ目のトピックを指すハッシュ付きで開く
- **THEN** 2つ目のトピックの編集が開き、トピックの文章の欄にフォーカスがあり、1つ目のトピックの編集は閉じている

#### Scenario: 削除済みのトピックを指す

- **WHEN** 存在しないトピックを指すハッシュ付きでカテゴリの画面を開く
- **THEN** どのトピックの編集も開かず、カテゴリの画面がふつうに表示される
