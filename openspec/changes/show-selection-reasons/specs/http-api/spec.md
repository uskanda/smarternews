# Spec Delta

## MODIFIED Requirements

### Requirement: 記事の詳細

記事の詳細の要求を受けたとき、APIは、タイトル、要約、本文、重要度、出典、当たったトピック、読み手への影響、未確認の印、更新回数、前の記事への参照を返さなければならない（MUST）。
APIは、出典ごとに、その出典を選んだ判定の理由と重要度を返さなければならない（MUST）。理由と重要度が保存されていない出典では、それぞれnullを返さなければならない（MUST）。

#### Scenario: 更新された記事を開く

- **WHEN** 続報で1回更新された記事の詳細を要求する
- **THEN** 応答には、更新回数1と、更新後の本文と、すべての出典が含まれる

#### Scenario: 出典の理由を受け取る

- **WHEN** 判定の理由と重要度を保存した出典を持つ記事の詳細を要求する
- **THEN** 応答のその出典には、`reason` と `importance` が含まれる

#### Scenario: 理由のない出典

- **WHEN** 配信記事か、理由を保存する前に書かれた記事の詳細を要求する
- **THEN** 応答の出典の `reason` と `importance` はnullになる
