# Spec Delta

## ADDED Requirements

### Requirement: 出典ごとの選ばれた理由の表示

生成記事の本文が開かれたとき、画面は、「出典」の区画の各出典の下に、その出典の判定の重要度と理由を1行で表示しなければならない（MUST）。
重要度と理由のどちらか一方だけが保存されている出典では、ある方だけを表示しなければならない（MUST）。どちらもない出典では、この行を表示してはならない（MUST NOT）。
理由はモデルが書いた文であるため、HTMLとして解釈せず、ただの文字として表示しなければならない（MUST）。

#### Scenario: 理由のある出典

- **WHEN** 重要度4と理由「新しい脆弱性の報告」が保存された出典を持つ生成記事を開く
- **THEN** その出典のリンクの下に、重要度4と「新しい脆弱性の報告」が1行で表示される

#### Scenario: 理由のない出典

- **WHEN** 理由と重要度のどちらも保存されていない出典を持つ生成記事を開く
- **THEN** その出典には、リンクとサイト名だけが表示される

#### Scenario: HTMLのタグを含む理由

- **WHEN** 理由に`<b>`を含む出典を持つ生成記事を開く
- **THEN** 理由は`<b>`の文字を含んだまま表示され、太字の要素は作られない
