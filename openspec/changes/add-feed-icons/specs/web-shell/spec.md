# Spec Delta

## ADDED Requirements

### Requirement: 左のペインの購読フィードのアイコン

左のペインの購読フィードの項目は、名前の前に、文字の高さの四方の枠を置かなければならない（MUST）。
購読フィードがアイコンを持つとき、画面はその枠に、中継のパスのアイコンを描かなければならない（MUST）。
アイコンを持たないとき、またはアイコンを読み込めなかったとき、画面は枠を空けたまま何も描いてはならない（MUST NOT）。
アイコンは名前と別に読み上げてはならない（MUST NOT）。
購読フィード以外の項目と、記事の一覧の行には、アイコンを出してはならない（MUST NOT）。

#### Scenario: アイコンのある購読フィード

- **WHEN** アイコンを持つ購読フィードが左のペインに並ぶ
- **THEN** その名前の前に、中継のパスのアイコンが文字の高さで表示される

#### Scenario: アイコンのない購読フィード

- **WHEN** アイコンを持つ購読フィードと持たない購読フィードが、同じカテゴリの下に並ぶ
- **THEN** 2つの名前の書き出しの位置は揃い、アイコンを持たない購読フィードの枠には何も描かれない

#### Scenario: 記事の一覧の行

- **WHEN** アイコンを持つ購読フィードの記事が、記事の一覧に並ぶ
- **THEN** その行の配信元は文字だけで示され、アイコンは表示されない
