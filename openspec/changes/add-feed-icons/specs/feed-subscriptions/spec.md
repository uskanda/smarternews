# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードのアイコンを探す順番

サーバーは、購読フィードのアイコンを次の順に探し、画像の形式を判別できた最初のものを、その購読フィードのアイコンとして記録しなければならない（MUST）。

1. フィードの記述：Atomの `<icon>`、またはJSON Feedの `favicon`
2. サイトのページのHTMLの、`rel` に `icon` を含む `<link>`
3. サイトのオリジンの直下の `/favicon.ico`

サーバーは、RSSの `<image>` をアイコンとして使ってはならない（MUST NOT）。
アイコンを探す取得には、購読フィードの取得と同じ取得の作法を適用し、robots.txtが禁じるURLを取得してはならない（MUST NOT）。
どの候補からも画像を得られないとき、その購読フィードはアイコンを持たない。

#### Scenario: Atomのiconがあるフィード

- **WHEN** `<icon>` にPNGの画像を書いたAtomのフィードを登録する
- **THEN** その画像の元のURLが、購読フィードのアイコンとして記録される

#### Scenario: HTMLにだけアイコンを書くサイト

- **WHEN** RSSのフィードを登録し、サイトのページの `<link rel="icon">` がPNGの画像を指し、`/favicon.ico` もある
- **THEN** `<link rel="icon">` の画像の元のURLが、アイコンとして記録される

#### Scenario: favicon.icoしかないサイト

- **WHEN** フィードとサイトのページのどちらもアイコンを示さず、`/favicon.ico` がICOの画像を返す
- **THEN** `/favicon.ico` の元のURLが、アイコンとして記録される

#### Scenario: RSSのimageだけがあるフィード

- **WHEN** `<image>` にロゴの画像を書いたRSSのフィードを登録し、サイトのページも `/favicon.ico` も画像を返さない
- **THEN** その購読フィードはアイコンを持たない

#### Scenario: 画像でない応答

- **WHEN** `<link rel="icon">` が指すURLがHTMLのページを返し、`/favicon.ico` がPNGの画像を返す
- **THEN** `/favicon.ico` の元のURLが、アイコンとして記録される

### Requirement: 購読フィードのアイコンを探す時機

サーバーは、購読フィードの取得に成功したとき、まだアイコンを探していないか、前に探してから30日を過ぎていれば、記事を保存したあとにアイコンを探さなければならない（MUST）。
内容が変わらなかったという応答のときも、同じ条件で探さなければならない（MUST）。
それ以外の取得のときは、アイコンを探してはならない（MUST NOT）。
探しても見つからなかったとき、サーバーは以前のアイコンを消さなければならない（MUST）。

#### Scenario: 登録のとき

- **WHEN** 購読フィードを登録する
- **THEN** 登録の取得のあとに、その購読フィードのアイコンが探される

#### Scenario: 30日以内の取得

- **WHEN** アイコンを探してから10日後に、その購読フィードを取得する
- **THEN** アイコンを探すための要求は送られない

#### Scenario: 30日を過ぎたあとの取得

- **WHEN** アイコンを探してから31日後に、その購読フィードを取得する
- **THEN** アイコンが探し直され、探した時刻が更新される

### Requirement: アイコンを探すときの失敗の扱い

アイコンを探すのに失敗しても、サーバーは、その購読フィードの取得を失敗として記録してはならない（MUST NOT）。

#### Scenario: アイコンの取得がすべて失敗する

- **WHEN** フィードの取得は成功し、アイコンの候補のURLがどれもHTTPステータス500を返す
- **THEN** 配信記事は保存され、その取得は成功として記録され、購読フィードはアイコンを持たない

### Requirement: APIでのアイコンの返し方

APIは、購読フィードのアイコンを、署名した画像の中継のパスとして返さなければならない（MUST）。
アイコンの元のURLを、APIの応答に含めてはならない（MUST NOT）。
アイコンのない購読フィードでは、アイコンをnullとして返さなければならない（MUST）。

#### Scenario: 購読フィードの一覧

- **WHEN** アイコンを持つ購読フィードがあり、`GET /api/v1/feeds` を要求する
- **THEN** その購読フィードの `iconUrl` は `/api/v1/image-proxy/` で始まり、応答にアイコンの元のURLは含まれない
