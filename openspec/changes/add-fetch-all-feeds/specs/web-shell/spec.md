# Spec Delta

## ADDED Requirements

### Requirement: 左のペインの一括の即時の取得

購読フィードが1つ以上あるとき、左のペインは、「カテゴリ」の見出しの行に、すべての購読フィードをいま取得する操作「いま取得」を表示しなければならない（MUST）。
読み上げ用の名前は「すべての購読フィードをいま取得」とする。
利用者がこの操作を選んだとき、画面は、すべての有効な購読フィードの即時の取得を求める。

#### Scenario: 左のペインからいま取得する

- **WHEN** 新しい項目のある有効な購読フィードがある状態で、左のペインの「すべての購読フィードをいま取得」を選ぶ
- **THEN** 購読フィードが取得され、取得が終わると、左のペインの未読数と表示中の一覧が、60秒を待たずに新しくなる

#### Scenario: 購読フィードがない

- **WHEN** 購読フィードを1つも登録していない状態で、左のペインを見る
- **THEN** 操作「すべての購読フィードをいま取得」は表示されない

### Requirement: 左のペインの一括の即時の取得の間の表示

一括の即時の取得を待っている購読フィードがある間、左のペインは、「いま取得」の操作を`取得中…`と表示し、選べない状態にしなければならない（MUST）。
この表示は、設定の購読フィードの画面から求めた取得でも、画面を読み込み直したあとでも同じである。

#### Scenario: 取得の途中

- **WHEN** 左のペインの「すべての購読フィードをいま取得」を選び、取得がまだ終わっていない
- **THEN** 操作は`取得中…`と表示され、選べない

#### Scenario: 読み込み直したあと

- **WHEN** 一括の即時の取得を待っている購読フィードがある状態で、画面を開く
- **THEN** 左のペインの操作は`取得中…`と表示され、選べない

### Requirement: 一括の即時の取得の間の再取得

一括の即時の取得を待っている購読フィードがある間、画面は、60秒ごとではなく3秒ごとに購読フィードの状態を取得し直さなければならない（MUST）。

#### Scenario: 取得が終わるのを待つ

- **WHEN** 一括の即時の取得を求めたあと、サーバーですべての取得が終わり、3秒が過ぎる
- **THEN** 操作の表示が`取得中…`から戻る

### Requirement: 左のペインからの一括の即時の取得の終わりの知らせ

左のペインから一括の即時の取得を求めた画面で、待っている購読フィードがなくなったとき、画面は、取得が終わったことを知らせなければならない（MUST）。
失敗した取得があるときは、その件数を知らせる。取得する購読フィードがなかったときは、取得を始めずにそのことを知らせる。

#### Scenario: すべて成功する

- **WHEN** 左のペインの「すべての購読フィードをいま取得」を選び、すべての取得が成功する
- **THEN** すべての購読フィードを取得したことが知らされる

#### Scenario: 一部が失敗する

- **WHEN** 左のペインの「すべての購読フィードをいま取得」を選び、1つの取得が失敗する
- **THEN** 1件の取得に失敗したことが知らされる

#### Scenario: 取得する購読フィードがない

- **WHEN** 購読フィードがすべて一時停止中の状態で、左のペインの「すべての購読フィードをいま取得」を選ぶ
- **THEN** 取得は始まらず、取得する購読フィードのないことが知らされる
