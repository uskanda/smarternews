# Spec Delta

## ADDED Requirements

### Requirement: 一括の即時の取得の操作

購読フィードが1つ以上あるとき、購読フィードの一覧の画面は、すべての購読フィードをいま取得する操作「すべていま取得」を、一覧の上に表示しなければならない（MUST）。
利用者がこの操作を選んだとき、画面は、すべての有効な購読フィードの即時の取得を求める。

#### Scenario: すべていま取得する

- **WHEN** 有効な購読フィードが2つある状態で、「すべていま取得」を選ぶ
- **THEN** 2つの購読フィードが取得され、それぞれの行の最後に成功した日時が、再読み込みなしで新しくなる

#### Scenario: 取得する購読フィードがない

- **WHEN** 購読フィードがすべて一時停止中の状態で、「すべていま取得」を選ぶ
- **THEN** 取得は始まらず、取得する購読フィードのないことが知らされる

### Requirement: 一括の即時の取得の間の表示

一括の即時の取得を待っている購読フィードがある間、購読フィードの一覧の画面は、「すべていま取得」の操作を`取得中…`と表示し、選べない状態にしなければならない（MUST）。

#### Scenario: 取得の途中

- **WHEN** 操作「すべていま取得」を選び、取得がまだ終わっていない
- **THEN** 操作は`取得中…`と表示され、選べない

#### Scenario: 取得が終わる

- **WHEN** 操作「すべていま取得」を選び、すべての取得が終わる
- **THEN** 操作は「すべていま取得」の表示に戻り、選べる

### Requirement: 一括の即時の取得の終わりの知らせ

一括の即時の取得を求めた画面で、待っている購読フィードがなくなったとき、画面は、取得が終わったことを知らせなければならない（MUST）。
失敗した取得があるときは、その件数を知らせる。Retry-Afterの待ちで飛ばした購読フィードがあるときは、その件数も知らせる。

#### Scenario: すべて成功する

- **WHEN** 操作「すべていま取得」を選び、すべての取得が成功する
- **THEN** すべての購読フィードを取得したことが知らされる

#### Scenario: 一部が失敗する

- **WHEN** 操作「すべていま取得」を選び、2つの購読フィードのうち1つの取得が失敗する
- **THEN** 1件の取得に失敗したことが知らされ、その行に失敗の理由が表示される

#### Scenario: 待っているものを飛ばす

- **WHEN** Retry-Afterの示す時刻を待っている購読フィードが1つある状態で「すべていま取得」を選び、ほかの取得が成功する
- **THEN** 取得が終わったことと、待つように求められている1件を飛ばしたことが知らされる
