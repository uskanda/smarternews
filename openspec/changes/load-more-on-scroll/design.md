# Design

## Context

記事の一覧（`ReaderPage.tsx`）と注釈の一覧（`AnnotationList.tsx`）は、どちらも `useInfiniteQuery` で1回50件ずつ読み込む。
続きは、末尾の「さらに読み込む」のボタンで読み込んでいた。
スクロールで既読にする設定が有効なときは、ボタンの下に一覧の高さの余白（`data-scroll-read-room`）がある。
続きの読み込みに失敗すると、`isError` が真になり、一覧の先頭に `ErrorNotice` が出ていた。
テストの道具（`testing/setup.ts`）の `IntersectionObserver` は何もしない代用品で、既存のテストは最初の50件だけを読み込んだ状態を保てる。

この変更を作ったあと、mainに変更 `show-list-end`（Issue #108）が入った。
記事の一覧の末尾が見えたら続きを読み込む点は同じだが、ボタンをいつも出し、200px手前で読み込み始め、注釈の一覧は扱わない。
mainを取り込むときに、記事の一覧の続きの読み込みはこの変更の `LoadMore` に置き換えた。
理由は、ボタンを出す場面、失敗の知らせ方、読み込みを始める位置を、Issue #188で利用者が個別に選んだからである。
`show-list-end` の「一覧の最後です」の表示、`j` での末尾への移動、`j` の失敗の知らせはそのまま残す。
`show-list-end` の代用品（`intersect`）は既定の代用品として残し、見張りの `rootMargin` を読む `intersectionOptions` を足した。

## Goals / Non-Goals

**Goals:**

- 末尾の近くまで送ったら、続きを自動で読み込む。
- 読み込みの間と失敗のときの表示を末尾に出し、失敗のときだけボタンでやり直せるようにする。

**Non-Goals:**

- イベントの一覧と、設定の「隠している記事」の続きの読み込み
- Androidアプリの先読み

## Decisions

- 一覧の末尾に置く部品 `LoadMore`（`apps/web/src/ui/LoadMore.tsx`）を作り、2つの一覧で使う。
  受け取るのは、`useInfiniteQuery` の結果とスクロールする要素の参照である。
  結果からは、続きの有無、取得とエラーの状態、`fetchNextPage`、読み込んだページの数を読む。
- 高さのない目印の要素を `IntersectionObserver` で見張る。`root` はスクロールする要素で、`rootMargin` を `0px 0px 100% 0px` にして、一覧の高さ1つ分手前で交差させる。
- 見張るのは、続きがあり、取得の途中でもエラーの状態でもない間だけである。交差したら見張りをやめて `fetchNextPage` を呼ぶ。
  失敗のあとは `isError` が真なので、見張らない。ボタン、読み直し（`refetch` が通るとエラーは消える）、別の一覧への切り替えで、この状態は終わる。
  取得の途中に見張らないのは、60秒ごとの再取得と続きの読み込みが重ならないようにするためである。
- 見張りは、読み込んだページの数と見張る条件が変わるたびに付け直す。`IntersectionObserver` は見張りを始めたときに1度知らせる。
  そのため、50件を読み込んでも目印がまだ範囲の中にあるときや、読み直しでエラーが消えたときにも続けて読み込める。
- 表示は、読み込み中は `Loading`、失敗のときは「続きを読み込めませんでした」とボタン「さらに読み込む」、それ以外は目印だけである。目印は、記事の一覧ではスクロールで既読にするときの余白より上に置く。
- 一覧の先頭の `ErrorNotice` は、`isFetchNextPageError` のときは出さない。最初の読み込みや読み直しの失敗では、今までどおり出す。
- `j` での続きの読み込み（`moveOn`）は変えない。失敗したときは `isFetchNextPageError` が真になるので、同じく末尾の知らせとボタンが出る。
- テストでは、交差を起こせる代用品（`intersect`）を使い、見張りの `rootMargin` を `intersectionOptions` で読む。読み込みの間の表示は、テストの応答を止めておく `hold` で確かめる。

## Risks / Trade-offs

- 一覧の高さが目印までの高さより大きい短い一覧では、開いた直後に続きを読み込む。→ 末尾が見えているので、読み込むのが正しい。
- 失敗のあとに末尾で上下しても読み込まないので、つながりが戻ったことに気づかないことがある。→ 記事の一覧は60秒ごとの再取得が通るとエラーが消え、自動の読み込みに戻る。注釈の一覧はボタンか「読み直す」で戻る。
