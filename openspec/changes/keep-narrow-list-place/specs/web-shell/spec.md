# Spec Delta

## MODIFIED Requirements

### Requirement: 狭い画面での切り替え

画面の幅が狭いとき、画面は1つのペインだけを表示し、利用者の操作で他のペインへ切り替えなければならない（MUST）。
本文から一覧へ戻ったとき、一覧は離れたときのスクロール位置から表示し、直前に開いた記事の行を選んだ状態で表示範囲の中に示さなければならない（MUST）。戻り方が「一覧へ戻る」でもブラウザーの戻る操作でも同じである。
狭い画面の本文の末尾には、一覧の並びで隣の記事へ移る「前の記事」と「次の記事」を置かなければならない（MUST）。隣の記事がない側は置かない。

#### Scenario: 狭い画面で記事を開く

- **WHEN** 幅390pxの画面で、一覧から記事を選ぶ
- **THEN** 本文だけが表示され、一覧へ戻るボタンがある

#### Scenario: 横方向にはみ出さない

- **WHEN** 幅390pxの画面で、長い見出しとURLを含む記事を表示する
- **THEN** 画面は横方向にスクロールしない

#### Scenario: 一覧へ戻る

- **WHEN** 幅390pxの画面で、一覧を下へ送ってから記事を開き、「一覧へ戻る」を選ぶ
- **THEN** 一覧は離れたときの位置から表示され、開いていた記事の行が選ばれ、その行のリンクにフォーカスがある

#### Scenario: 次の記事へ進んでから戻る

- **WHEN** 幅390pxの画面で、本文の末尾の「次の記事」を何度か選んで、一覧の表示範囲の外の記事まで進んでから戻る
- **THEN** 最後に開いた記事の行が選ばれ、表示範囲の中に入るまで一覧が送られている

#### Scenario: 戻すときのスクロールで既読にしない

- **WHEN** 設定の「スクロールで既読にする」を有効にし、幅390pxの画面で一覧を送ってから記事を開いて戻る
- **THEN** 一覧の位置を戻すスクロールでは、どの行も既読にならない

#### Scenario: 本文の末尾の「次の記事」

- **WHEN** 幅390pxの画面で、一覧の1件目の本文の末尾にある「次の記事」を選ぶ
- **THEN** 2件目の本文が表示される。「次の記事」には2件目の見出しが示されていた

#### Scenario: 一覧の端の記事

- **WHEN** 幅390pxの画面で、一覧の1件目の本文を表示する
- **THEN** 本文の末尾には「次の記事」だけがあり、「前の記事」はない

#### Scenario: 広い画面

- **WHEN** 幅1280pxの画面で本文を表示する
- **THEN** 本文の末尾に「前の記事」と「次の記事」はない

### Requirement: キーボードでの記事の移動

記事の一覧が表示されている間、`j` と `k` のキーが押されたとき、画面は次または前の記事を選んで本文を表示しなければならない（MUST）。
読み込んだ最後の記事を選んでいて、一覧に続きのページがあるとき、`j` は次のページを読み込んでから、その最初の記事を選ばなければならない（MUST）。

#### Scenario: 次の記事へ進む

- **WHEN** 一覧の1件目を選んだ状態で `j` を押す
- **THEN** 2件目が選ばれ、その本文が表示される

#### Scenario: 続きのページへ進む

- **WHEN** 一覧に続きのページがあり、読み込んだ最後の記事を選んだ状態で `j` を押す
- **THEN** 次のページが読み込まれ、その最初の記事が選ばれて本文が表示される

#### Scenario: 続きのない最後の記事

- **WHEN** 一覧に続きのページがなく、最後の記事を選んだ状態で `j` を押す
- **THEN** 選んでいる記事は変わらない

### Requirement: 本文の端での記事の移動

本文の末尾が表示されている状態で `Space` が押されたとき、画面は `j` を押したときと同じく次の記事へ移らなければならない（MUST）。続きのページを読み込む場合も `j` と同じである。
本文の先頭が表示されている状態で `Shift+Space` が押されたとき、画面は `k` を押したときと同じく前の記事へ移らなければならない（MUST）。
本文が表示されていないとき、`Space` は `j` を押したときと同じ記事を選ぶ。`Shift+Space` は `k` を押したときと同じ記事を選ぶ。

#### Scenario: 末尾で次の記事へ移る

- **WHEN** 一覧の1件目の本文を末尾までスクロールした状態で `Space` を押す
- **THEN** 2件目が選ばれ、その本文が先頭から表示される

#### Scenario: 短い本文

- **WHEN** 本文のペインに全体が収まる記事を表示した状態で `Space` を押す
- **THEN** 次の記事が選ばれる

#### Scenario: 先頭で前の記事へ戻る

- **WHEN** 一覧の2件目の本文を先頭から表示した状態で `Shift+Space` を押す
- **THEN** 1件目が選ばれる

#### Scenario: 末尾で続きのページへ移る

- **WHEN** 一覧に続きのページがあり、読み込んだ最後の記事の本文を末尾まで表示した状態で `Space` を押す
- **THEN** 次のページが読み込まれ、その最初の記事が選ばれる
