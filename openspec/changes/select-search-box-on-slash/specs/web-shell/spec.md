## MODIFIED Requirements

### Requirement: 左のペインの検索欄

画面は、左のペインの上端に、記事を検索する入力欄を表示しなければならない（MUST）。
入力欄のプレースホルダーは、補足の文字の色（`on-surface-muted`）で表示する。

#### Scenario: 広い画面で開く

- **WHEN** 幅1280pxの画面で記事の一覧を開く
- **THEN** 左のペインの「未読」の項目より上に、検索欄が表示される

#### Scenario: 狭い画面で開く

- **WHEN** 幅390pxの画面で、左のペインに切り替える
- **THEN** 項目の一覧より上に、検索欄が表示される

#### Scenario: プレースホルダーの色

- **WHEN** 検索欄が空のまま表示される
- **THEN** プレースホルダーの「記事を検索」は、補足の文字の色（`on-surface-muted`）で表示される

### Requirement: 検索欄へ移るキー

入力欄にフォーカスがない間、`/` のキーが押されたとき、画面は検索欄にフォーカスを移し、欄の文字をすべて選ばなければならない（MUST）。
狭い画面では、`/` で左のペインを開いて検索欄へ移る。ペインがすでに開いているときも、検索欄へ移して文字をすべて選ぶ。
入力欄にフォーカスがある間は、`/` を文字として入力欄に入れる。

#### Scenario: 記事を読んでいる途中で探す

- **WHEN** 記事の一覧で記事を選んだ状態で `/` を押す
- **THEN** 検索欄にフォーカスが移り、検索欄に `/` は入らない

#### Scenario: 前の検索語を打ち替える

- **WHEN** 幅1280pxの画面で「Blog」を検索したあとに別の一覧へ移り、`/` を押して `x` を打つ
- **THEN** 検索欄は「x」になる

#### Scenario: 狭い画面で検索語を選ぶ

- **WHEN** 幅390pxの画面で「Blog」の検索の結果を表示したまま `/` を押す
- **THEN** 開いたペインの検索欄にフォーカスがあり、「Blog」がすべて選ばれている

#### Scenario: 開いているペインで押す

- **WHEN** 幅390pxの画面で「Blog」の検索の結果を表示し、ペインを開いて項目のリンクにフォーカスを置いたまま `/` を押す
- **THEN** 検索欄にフォーカスが移り、「Blog」がすべて選ばれている

#### Scenario: キー操作の一覧に出る

- **WHEN** `?` を押してキー操作の一覧を開く
- **THEN** 一覧に、`/` と検索欄へ移る操作の対応が含まれる
