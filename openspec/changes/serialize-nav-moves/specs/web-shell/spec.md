## MODIFIED Requirements

### Requirement: 並べ替えの失敗の扱い

並び順の保存に失敗したとき、画面は、左のペインを保存済みの順に戻し、失敗したことを知らせなければならない（MUST）。

#### Scenario: サーバーに届かない

- **WHEN** サーバーに届かない状態で、カテゴリをドラッグして離す
- **THEN** 左のペインは元の順に戻り、並べ替えられなかったことが表示される

#### Scenario: 続けた移動の応答が逆の順に届く

- **WHEN** カテゴリを続けて2回移動し、2回目の応答が1回目より先に届く
- **THEN** 左のペインとサーバーの並びは、2回の移動のあとの並びになる

#### Scenario: 移動の直前に購読フィードの再取得が始まっている

- **WHEN** 購読フィードの一覧の再取得が終わる前に購読フィードを移動し、そのあとで再取得の応答が届く
- **THEN** 左のペインは、移動のあとの並びのまま変わらない

#### Scenario: 続けた移動の1回目が失敗する

- **WHEN** カテゴリを続けて2回移動し、1回目の保存が失敗する
- **THEN** 左のペインは保存済みの順になり、並べ替えられなかったことの知らせは1つだけ表示される
