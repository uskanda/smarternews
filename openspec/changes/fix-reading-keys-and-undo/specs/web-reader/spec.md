# Spec Delta

## ADDED Requirements

### Requirement: 別の一覧を開いたときの表示位置

表示する項目か絞り込みが変わったとき、画面は一覧を先頭から表示しなければならない（MUST）。

#### Scenario: 以前に開いた一覧を選ぶ

- **WHEN** 未読の一覧を下までスクロールしたあと、左のペインで、少し前に開いたカテゴリAを選ぶ
- **THEN** カテゴリAの一覧は先頭の記事から表示される

### Requirement: 一括の既読を選べる条件

表示中の一覧に未読の記事が残る間、画面は一括の既読を選べるようにしなければならない（MUST）。
まだ読み込んでいない記事も、残る未読に数える。

#### Scenario: 読み込んだ行をすべて読む

- **WHEN** 未読が120件ある一覧で、読み込んだ50件をすべて既読にする
- **THEN** 一括の既読のボタンと `Shift+A` は使えるままで、選ぶと残りの70件が既読になる

### Requirement: 大量の記事の取り消し

一括の既読の取り消しが選ばれたとき、画面は、既読にした記事の数にかかわらず、その操作で既読になった記事をすべて未読に戻さなければならない（MUST）。

#### Scenario: 6000件を取り消す

- **WHEN** 未読が6000件ある一覧で一括の既読を選び、続けて取り消しを選ぶ
- **THEN** 6000件すべてが未読に戻る

### Requirement: 取り消しの失敗の表示

一括の既読の取り消しが失敗したとき、画面は、取り消せなかったことと、もう一度試す手段を表示しなければならない（MUST）。

#### Scenario: サーバーに届かない

- **WHEN** サーバーが止まった状態で、一括の既読の取り消しを選ぶ
- **THEN** 取り消せなかったことと「もう一度試す」が表示される

### Requirement: 取り消しのあとの一覧

一括の既読の取り消しが終わったとき、画面は、いま開いている一覧で既読にした記事の行を一覧から消してはならない（MUST NOT）。

#### Scenario: 移った先で読んでから取り消す

- **WHEN** 一括の既読で次の項目Bへ移り、Bの未読の一覧で記事を2件読んでから、取り消しを選ぶ
- **THEN** Bの一覧には、読んだ2件の行が残る
