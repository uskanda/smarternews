## ADDED Requirements

### Requirement: フィードのないページを購読する操作

入力されたURLのページにフィードが見つからなかったとき、購読フィードの追加の画面は、そのページをWebページの購読フィードとして購読する操作を表示しなければならない（MUST）。
画面は、利用者がこの操作を選ぶまで、セレクターの候補を求めない。

#### Scenario: フィードのないページのURLを入力する

- **WHEN** フィードの指定を持たないページのURLを入力して追加する
- **THEN** 画面は、フィードが見つからなかったことと、そのページを購読する操作を表示し、LLMの呼び出し回数は増えない

### Requirement: セレクターの候補と見本の表示

利用者がページを購読する操作を選んだとき、画面は、セレクターの候補を求め、候補ごとに見本を表示しなければならない（MUST）。
見本は、抜き出せる記事の件数と、10件までの記事のタイトル、リンク、日時である。日時のない記事には、日時がないことを表示する。
候補を待つ間は、候補を探していることを表示する。

#### Scenario: 候補を選んで登録する

- **WHEN** 2つの候補が返り、利用者が2つ目の見本を確かめて選び、カテゴリを選んで追加する
- **THEN** 2つ目の候補のセレクターの組でWebページの購読フィードが登録され、一覧に加わる

### Requirement: LLMを使わなかったことの表示

候補にLLMの提案を使わなかったとき、画面は、そのことを一文で表示しなければならない（MUST）。
この一文は、誤りとしては表示しない。

#### Scenario: 上限に達した日に候補を求める

- **WHEN** その日の提案の呼び出しが1日の上限に達した状態で、ページを購読する操作を選ぶ
- **THEN** 画面は推定した候補と見本を表示し、LLMを使わなかったことを一文で表示する

#### Scenario: LLMの提案を使った

- **WHEN** セレクターの提案のタスクが成功し、その候補が表示される
- **THEN** LLMを使わなかったことの一文は表示されない

### Requirement: セレクターを手で入れる欄

候補が1つも返らなかったとき、画面は、項目、タイトル、リンク、日時のセレクターを手で入れる欄と、見本を求める操作を表示しなければならない（MUST）。
見本を確かめたあとで、入れたセレクターの組でWebページの購読フィードを登録できる。

#### Scenario: 候補のないページ

- **WHEN** 候補が空で返ったあと、利用者が項目のセレクターを入れて見本を求める
- **THEN** 画面はその組で抜き出せる記事の件数と見本を表示し、追加を選ぶとWebページの購読フィードが登録される

#### Scenario: 記事を抜き出せないセレクター

- **WHEN** 利用者が、ページの要素に当たらない項目のセレクターを入れて見本を求める
- **THEN** 画面は、記事を抜き出せなかったことを表示し、追加の操作は選べない

### Requirement: Webページの購読フィードの全文の自動の取得の既定

Webページの購読フィードを追加する画面は、全文を自動で取得する切り替えを、入った状態で表示しなければならない（MUST）。
切り替えのそばに、ページから得るのはタイトル、リンク、日時だけで、本文は全文の取得で得ることを説明する。

#### Scenario: 候補を選ぶ画面を開く

- **WHEN** ページを購読する操作を選び、候補が表示される
- **THEN** 全文を自動で取得する切り替えは入った状態で、そのそばに説明が表示される

### Requirement: 「候補を出し直す」操作

Webページの購読フィードの編集の画面は、「候補を出し直す」操作を表示しなければならない（MUST）。
利用者がこの操作を選んだとき、画面はセレクターの候補と見本を表示し、選んだ候補のセレクターの組を保存する。
候補のないときとLLMを使わなかったときの表示は、追加の画面と同じである。

#### Scenario: 構造の変わったページ

- **WHEN** 更新が止まった印を持つWebページの購読フィードを編集する画面で、「候補を出し直す」を選び、候補を1つ選んで保存する
- **THEN** その購読フィードのセレクターの組は、選んだ候補のものになる

#### Scenario: フィードの購読フィード

- **WHEN** Atomのフィードの購読フィードの編集の画面を開く
- **THEN** 画面は「候補を出し直す」操作を表示しない

### Requirement: セレクターの組の編集

Webページの購読フィードの編集の画面は、保存済みのセレクターの組を手で書き換える欄と、見本を求める操作を表示しなければならない（MUST）。

#### Scenario: 日時のセレクターを足す

- **WHEN** 日時のセレクターを持たないWebページの購読フィードの編集で、日時のセレクターを入れて見本を確かめ、保存する
- **THEN** その購読フィードのセレクターの組は、入れた日時のセレクターを持つ
