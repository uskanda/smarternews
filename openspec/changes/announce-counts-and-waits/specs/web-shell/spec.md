# Spec Delta

## ADDED Requirements

### Requirement: 左のペインの数の読み上げ

左のペインで一覧を開く項目の数は、読み上げで何を数えるかが分からなければならない（MUST）。
未読数は名前に続けて「、未読N件」と読み、「スター」の項目の数は「、スターN件」と読む。見える数字は読み上げから外し、数字が2度読まれないようにする。見た目は変えない。

#### Scenario: 未読のある購読フィード

- **WHEN** 未読が3件ある購読フィード「Example Blog」の項目を支援技術で読む
- **THEN** 項目の名前は「Example Blog、未読3件」になる

#### Scenario: スターの項目

- **WHEN** スターの付いた記事が2件あり、「スター」の項目を支援技術で読む
- **THEN** 項目の名前は「スター、スター2件」になる

#### Scenario: 数のない項目

- **WHEN** 未読が0件の項目を支援技術で読む
- **THEN** 項目の名前は名前だけになる

### Requirement: 読み込み中の知らせ

画面が `読み込み中…` を表示するとき、その文は `role="status"` で支援技術に知らされなければならない（MUST）。

#### Scenario: 一覧の読み込み

- **WHEN** 画面がデータを読み込んでいる
- **THEN** `読み込み中…` の文が `role="status"` の中に表示される
