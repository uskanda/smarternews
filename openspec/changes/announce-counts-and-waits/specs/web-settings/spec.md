# Spec Delta

## ADDED Requirements

### Requirement: 設定ファイルの読み込みの結果の知らせ

設定ファイルの読み込みが終わったとき、結果の文は `role="status"` で支援技術に知らされなければならない（MUST）。購読フィードの画面のOPMLの読み込みの結果と同じ扱いである。

#### Scenario: 読み込みが終わる

- **WHEN** 設定ファイルを読み込み、結果の文が表示される
- **THEN** 結果の文は `role="status"` の中にある

### Requirement: トピックの試しと書き直しの案の待ちと終わりの知らせ

トピックの試しと書き直しの案は、それぞれ `role="status"` の枠を1つ持ち、待っていることと終わったことを支援技術に知らせなければならない（MUST）。
枠は、試しや案を求める前から空のまま画面にあり、中の文だけを入れ替える。
試しの枠には、待つ間は `試しています…` を入れる。終わったときは次のどれかを入れる：試した件数と入れ替わった件数の1文／断りの文／途中で止めた文／試せなかった文／結果がない文。
書き直しの案の枠には、待つ間は `案を出しています…` を入れる。終わったときは次のどれかを入れる：「この案を使う」の説明／断りの文／案を出せなかった文。
候補や案の一覧、検索語と判定基準の表は枠の外に置く。`role="alert"` で知らせるエラーの枠も、この枠には入れない。見た目は変えない。

#### Scenario: 試しが終わる

- **WHEN** 試しを選び、試しが終わる
- **THEN** 枠の文は `試しています…` から `N件を試し、M件の結論が入れ替わりました。` に入れ替わり、候補の一覧は枠の外にある

#### Scenario: 試しが断られる

- **WHEN** 試しの1日の上限に達した状態で、試しを選ぶ
- **THEN** 枠には上限に達したため試せないことの文が入る

#### Scenario: 書き直しの案が出る

- **WHEN** 書き直しの案を求め、案が返る
- **THEN** 枠の文は `案を出しています…` から「この案を使う」の説明に入れ替わり、案の一覧は枠の外にある

#### Scenario: 求める前

- **WHEN** トピックの編集の画面を開いたばかりで、試しと案をまだ求めていない
- **THEN** 2つの枠は空のまま画面にある
