# Spec Delta

## ADDED Requirements

### Requirement: スターを付けた時刻の保存

スターのない記事にスターを付ける変更を受けたとき、APIは、その時刻をスターを付けた時刻として保存し、以後の一覧と詳細で返さなければならない（MUST）。

#### Scenario: スターを付ける

- **WHEN** 10時に、スターのない記事にスターを付け、その記事を要求する
- **THEN** スターを付けた時刻として10時が返る

### Requirement: スターの付け直しでの時刻の維持

すでにスターのある記事にスターを付ける変更を受けたとき、APIは、スターを付けた時刻を変えてはならない（MUST NOT）。

#### Scenario: もう一度付ける

- **WHEN** 10時にスターを付けた記事に、11時にもう一度スターを付ける
- **THEN** スターを付けた時刻は10時のままである

### Requirement: スターを外したときの時刻の削除

スターを外す変更を受けたとき、APIは、その記事のスターを付けた時刻を消さなければならない（MUST）。

#### Scenario: 外してから付け直す

- **WHEN** 10時にスターを付けた記事のスターを11時に外し、12時に付け直す
- **THEN** スターを外している間はスターを付けた時刻がなく、付け直したあとは12時が返る

### Requirement: 移行の前のスターの時刻

スターを付けた時刻を保存できる版へ更新したとき、サーバーは、すでにスターのある記事に、その記事の最終更新の時刻をスターを付けた時刻として入れなければならない（MUST）。

#### Scenario: 更新の前からあるスター

- **WHEN** 最終更新が3週間前の記事にスターがある状態で、サーバーを更新する
- **THEN** その記事のスターを付けた時刻として、3週間前の最終更新の時刻が返る

### Requirement: スターを付けた順の一覧

スターを指定し、並び順にスターを付けた順を指定した記事の一覧の要求を受けたとき、APIは、スターのある記事を、スターを付けた時刻の新しい順に返さなければならない（MUST）。
スターを付けた時刻が同じ記事は、識別子の大きい順に並べる。

#### Scenario: 古い記事にいまスターを付ける

- **WHEN** 最終更新が1時間前の記事Aに昨日スターを付け、最終更新が3週間前の記事Bにいまスターを付けてから、スターを付けた順の「スター」の一覧を要求する
- **THEN** B、Aの順で返る

### Requirement: スターを付けた順の一覧の分割

スターを付けた順の一覧が1回の件数の上限を超えるとき、APIは、スターを付けた順のまま続きを取得するための値を返さなければならない（MUST）。

#### Scenario: スターを付けた順で続きを取得する

- **WHEN** スターのある記事が120件あり、スターを付けた順で1回の件数を50にした一覧を要求し、返された値で続きを2回要求する
- **THEN** 50件、50件、20件が重複なく、スターを付けた順で返り、最後の応答には続きの値がない

#### Scenario: 並び順の違う続きの値

- **WHEN** 新しい順の「スター」の一覧で返された続きの値を、スターを付けた順の一覧の要求に付ける
- **THEN** APIは、入力が不正であることを示す応答を返す

### Requirement: スターを付けた順を受け付けない一覧

スターを指定しない記事の一覧の要求で、並び順にスターを付けた順を指定されたとき、APIは、入力が不正であることを示す応答を返さなければならない（MUST）。

#### Scenario: カテゴリの一覧で指定する

- **WHEN** カテゴリAを指定し、並び順にスターを付けた順を指定して一覧を要求する
- **THEN** APIは、入力が不正であることを示す応答を返す

### Requirement: 表示の設定でのスターを付けた順

APIは、「スター」の項目の表示の設定で、並び順としてスターを付けた順を受け付けなければならない（MUST）。

#### Scenario: 「スター」をスターを付けた順にする

- **WHEN** 固定の項目の「スター」の並び順をスターを付けた順に変え、表示の設定を読み出す
- **THEN** 読み出した表示の設定では、「スター」の並び順はスターを付けた順として返る

### Requirement: スターを付けた順を持てない項目

「スター」以外の項目の表示の設定で、並び順にスターを付けた順を指定されたとき、APIは、入力が不正であることを示す応答を返さなければならない（MUST）。

#### Scenario: 購読フィードをスターを付けた順にする

- **WHEN** 購読フィードXの並び順をスターを付けた順に変える操作を呼ぶ
- **THEN** APIは、入力が不正であることを示す応答を返し、表示の設定は変わらない
