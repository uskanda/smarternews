# Spec Delta

## MODIFIED Requirements

### Requirement: 並び順のメニュー

記事の一覧を表示している間、画面は、一覧のペインの上部に並び順のメニューを表示しなければならない（MUST）。
メニューの選択肢は「新しい順」と「古い順」の2つで、「スター」の一覧でだけ「スターを付けた順」を加えた3つにする。メニューを開く前から、いまの並び順が分かるようにする。

#### Scenario: 購読フィードの一覧を開く

- **WHEN** 並び順を変えていない購読フィードXを左のペインで選ぶ
- **THEN** 一覧のペインの上部に並び順のメニューが表示され、いまの並び順は新しい順と読み取れる

#### Scenario: キーボードだけで選ぶ

- **WHEN** 並び順のメニューへキーボードでフォーカスを移し、キーの操作だけで「古い順」を選ぶ
- **THEN** 一覧は古い順に表示される

#### Scenario: 「スター」のメニューを開く

- **WHEN** 左のペインで「スター」を選び、並び順のメニューを開く
- **THEN** メニューには「新しい順」「古い順」「スターを付けた順」の3つが表示される

#### Scenario: カテゴリのメニューを開く

- **WHEN** 左のペインでカテゴリAを選び、並び順のメニューを開く
- **THEN** メニューには「新しい順」と「古い順」の2つだけが表示される

## ADDED Requirements

### Requirement: スターを付けた順の表示

「スター」の並び順がスターを付けた順の間、画面は、「スター」の一覧をスターを付けた時刻の新しい順に表示しなければならない（MUST）。

#### Scenario: 古い記事にいまスターを付けた

- **WHEN** 最終更新が3週間前の記事にいまスターを付けてから、スターを付けた順にした「スター」を開く
- **THEN** その記事は一覧の先頭に表示される

#### Scenario: アプリで選んだ並び順

- **WHEN** アプリで「スター」をスターを付けた順にしたあとで、Webの画面を読み込み直し、「スター」を選ぶ
- **THEN** 並び順のメニューはスターを付けた順と読み取れ、一覧はスターを付けた順に表示される

### Requirement: 検索の結果のスターだけの表示

利用者がスターだけの表示を選んだとき、画面は、検索の結果のうちスターのある記事だけを表示しなければならない（MUST）。
検索を始めたときは、スターのない記事を含む表示にする。

#### Scenario: スターだけに切り替える

- **WHEN** 検索の結果にスターのある記事が1件、スターのない記事が2件ある状態で、スターだけの表示に切り替える
- **THEN** スターのある1件だけが表示される

#### Scenario: 絞り込みを外す

- **WHEN** スターだけの表示にした検索の結果が空のときに、絞り込みを外す
- **THEN** スターだけの表示も外れ、記事全体から一致した記事が表示される
