# Spec Delta

## ADDED Requirements

### Requirement: 「スター」のスターを付けた順の保持

サーバーは、「スター」の項目の並び順として、スターを付けた順を保存しなければならない（MUST）。
スターを付けた順を保存できるようにする更新は、それまでに保存した並び順を変えてはならない。

#### Scenario: 再起動のあとも残る

- **WHEN** 固定の項目の「スター」の並び順をスターを付けた順にしてから、サーバーを再起動する
- **THEN** 再起動のあとも、「スター」の並び順はスターを付けた順のままである

#### Scenario: 更新の前に保存した並び順

- **WHEN** 固定の項目の「スター」とカテゴリAを古い順にしたサーバーを、スターを付けた順を保存できる版へ更新する
- **THEN** 更新のあとも、その2つの項目は古い順のままである

### Requirement: 設定ファイルでのスターを付けた順の拒否

「スター」以外の項目にスターを付けた順を指定した設定ファイルを読み込んだとき、サーバーは、その設定ファイルを拒否しなければならない（MUST）。

#### Scenario: カテゴリにスターを付けた順を指定する

- **WHEN** カテゴリ `tools` の並び順にスターを付けた順を指定した設定ファイルを読み込む
- **THEN** 読み込みは拒否され、何も保存されない

### Requirement: スターを付けた順の往復

「スター」をスターを付けた順にしたサーバーから書き出した設定ファイルを空のサーバーに読み込んだとき、サーバーは、「スター」の並び順をスターを付けた順にしなければならない（MUST）。

#### Scenario: 別のサーバーへ移す

- **WHEN** 固定の項目の「スター」をスターを付けた順にしたサーバーから書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーでも、「スター」はスターを付けた順である
