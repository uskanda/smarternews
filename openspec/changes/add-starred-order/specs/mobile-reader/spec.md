# Spec Delta

## MODIFIED Requirements

### Requirement: 並び順のメニュー

記事の一覧を表示している間、アプリは、一覧の画面の上部に並び順のメニューを表示しなければならない（MUST）。
メニューの選択肢は「新しい順」と「古い順」の2つで、「スター」の一覧でだけ「スターを付けた順」を加えた3つにする。メニューを開く前から、いまの並び順が分かるようにする。

#### Scenario: 購読フィードの一覧を開く

- **WHEN** 並び順を変えていない購読フィードXを引き出しで選ぶ
- **THEN** 一覧の画面の上部に並び順のメニューが表示され、いまの並び順は新しい順と読み取れる

#### Scenario: 「スター」のメニューを開く

- **WHEN** 引き出しで「スター」を選び、並び順のメニューを開く
- **THEN** メニューには「新しい順」「古い順」「スターを付けた順」の3つが表示される

#### Scenario: カテゴリのメニューを開く

- **WHEN** 引き出しでカテゴリAを選び、並び順のメニューを開く
- **THEN** メニューには「新しい順」と「古い順」の2つだけが表示される

## ADDED Requirements

### Requirement: スターを付けた順の表示

「スター」の並び順がスターを付けた順の間、アプリは、「スター」の一覧をスターを付けた時刻の新しい順に表示しなければならない（MUST）。

#### Scenario: Webで選んだ並び順

- **WHEN** Webの画面で「スター」をスターを付けた順にしたあとで、アプリで「スター」を開く
- **THEN** 並び順はスターを付けた順と読み取れ、一覧はスターを付けた順に表示される

### Requirement: 検索の結果のスターだけの表示

利用者がスターだけの表示を選んだとき、アプリは、検索の結果のうちスターのある記事だけを表示しなければならない（MUST）。
検索を始めたときは、スターのない記事を含む表示にする。

#### Scenario: スターだけに切り替える

- **WHEN** 検索の結果にスターのある記事が1件、スターのない記事が2件ある状態で、スターだけの表示に切り替える
- **THEN** スターのある1件だけが表示される
