# Spec Delta

## ADDED Requirements

### Requirement: スターだけの検索

スターだけを指定した検索を受けたとき、サーバーは、一致する記事のうちスターのあるものだけを返さなければならない（MUST）。
並びは、ほかの検索と同じく最終更新の新しい順である。

#### Scenario: スターだけを探す

- **WHEN** スターのある記事が1件、スターのない記事が2件あり、どれも「電池」を含む状態で、スターだけを指定して「電池」を検索する
- **THEN** スターのある1件だけが返る

### Requirement: スターだけの検索での重複

スターだけを指定した検索を受けたとき、サーバーは、重複として記録した配信記事を、スターがあれば結果に含めなければならない（MUST）。

#### Scenario: 重複にスターを付ける

- **WHEN** 重複として記録した配信記事が「電池」を含み、スターがある状態で、スターだけを指定して「電池」を検索する
- **THEN** その配信記事が返る

#### Scenario: スターを指定しない検索

- **WHEN** 同じ状態で、絞り込みを指定せずに「電池」を検索する
- **THEN** その配信記事は返らない
