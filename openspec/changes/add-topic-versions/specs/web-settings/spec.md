# Spec Delta

## ADDED Requirements

### Requirement: トピックの履歴

トピックの編集を開いている間、画面は「履歴」の区画に、そのトピックの版を新しい順に表示しなければならない（MUST）。各版には、作った日時、契機、前の版から変わった項目の名前を示す。最初の版には、変わった項目の代わりに最初の版であることを示す。

#### Scenario: 履歴を見る

- **WHEN** 作ってから文章を1回直したトピックの編集を開く
- **THEN** 履歴の区画に「編集」の版と「作成」の版がこの順に並び、「編集」の版に「文章」が変わった項目として示される

### Requirement: この版に戻す

画面は、今の版以外の各版に「この版に戻す」を置かなければならない（MUST）。押したとき、画面は確かめのダイアログを出し、利用者が戻すことを選んだときだけ戻す。戻した後は、トピック、トピックの成績、版の一覧を問い合わせ直し、戻したことを知らせる。編集中の欄に保存していない変更がある間、「この版に戻す」は押せず、その理由を示す。

#### Scenario: 前の版に戻す

- **WHEN** 文章を直したトピックの履歴で、「作成」の版の「この版に戻す」を押し、ダイアログで戻すことを選ぶ
- **THEN** トピックの文章が最初の文章に戻り、履歴の先頭に「版に戻す」の版が現れる

#### Scenario: 保存していない変更がある

- **WHEN** トピックの文章の欄を書き換えたまま、履歴を見る
- **THEN** 「この版に戻す」は押せず、先に保存するか変更を取り消すよう示される

### Requirement: 成績の変更前と変更後

トピックの成績に版の切れ目があるとき、画面はそのトピックの行で、同じ項目を「変更前（切れ目の日まで）」と「変更後（切れ目の日から）」の2列で並べ、切れ目の契機を示さなければならない（MUST）。切れ目がなければ、1列のまま表示する。狭い画面では、変更前と変更後を縦に並べる。

#### Scenario: 変更の前後を比べる

- **WHEN** 10日前に判定基準を変え、その前の外れが2/5件、その後が0/3件のトピックの成績を見る
- **THEN** そのトピックの行に、変更前の列で「外れ 2/5件（40%）」、変更後の列で「外れ 0/3件」が表示される

### Requirement: カテゴリの履歴

カテゴリの編集の画面は、最低重要度と件数上限の版を新しい順に一覧で表示しなければならない（MUST）。各版には、作った日時、契機、2つの値を示す。戻す操作は置かない。

#### Scenario: カテゴリの履歴を見る

- **WHEN** 最低重要度を3から4に変えたカテゴリの編集の画面を開く
- **THEN** カテゴリの履歴に、最低重要度4の版と最低重要度3の版がこの順に並ぶ
