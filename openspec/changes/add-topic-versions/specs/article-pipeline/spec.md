# Spec Delta

## ADDED Requirements

### Requirement: 解釈の結果の版

実行がトピックを解釈して結果を反映したとき、残す項目のどれかが変わっていれば、実行は契機「解釈」の版を1つ作らなければならない（MUST）。版の時刻は解釈した時刻とする。値が直前の版と同じなら版を作らず、直前の版を解釈済みとして扱う。

#### Scenario: 文章を直した後の実行

- **WHEN** 文章を直したトピックを持つカテゴリを実行し、解釈が新しい判定基準を返す
- **THEN** そのトピックに、新しい判定基準を持つ契機「解釈」の解釈済みの版が1つ増える
