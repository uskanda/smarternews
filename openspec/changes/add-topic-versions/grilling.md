# grilling 記録: add-topic-versions

GitHubのissueの145番のコメントで、2ラウンドの質問（Q1〜Q5、Q6〜Q10）に答えた記録である。
issueは、トピックとカテゴリの設定を変更ごとに版として残し、#138 の成績を版の前後で比べられるようにする提案である。

第1ラウンド（Q1〜Q5）は、#138（トピックの成績）がマージされる前に出した。利用者は「#138を実装した。改めて検討して」と答えたため、第1ラウンドの問いには回答がない。第2ラウンド（Q6〜Q10）は、#138 の成績の区画と集計を踏まえて同じ論点を問い直したもので、第1ラウンドの問いを置き換える。利用者は Q6〜Q10 のすべてを A と答え、その後に出した計画を変更なしで承認した（`/ok`）。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| #138 の成績を版で分ける扱い（第1ラウンド） | 回答なし。#138 のマージ後に第2ラウンド Q6 に置き換えた | 第1ラウンド Q1 |
| 版を作る契機（第1ラウンド） | 回答なし。第2ラウンド Q7 に置き換えた | 第1ラウンド Q2 |
| トピックで版に残す項目（第1ラウンド） | 回答なし。第2ラウンド Q8 に置き換えた | 第1ラウンド Q3 |
| 「この版に戻す」の動き（第1ラウンド） | 回答なし。第2ラウンド Q9 に置き換えた | 第1ラウンド Q4 |
| カテゴリの版の見せ方（第1ラウンド） | 回答なし。第2ラウンド Q10 に置き換えた | 第1ラウンド Q5 |
| 成績を版の切れ目で分ける見せ方 | 成績の区画の各行で、直近30日の中に版の切れ目があれば、最後の切れ目の前と後に分けて、同じ項目を「変更前（日付まで）」「変更後（日付から）」の2列で並べる。切れ目がなければ1列のまま。APIの応答に、切れ目の時刻と、前と後の成績を足す（A） | 第2ラウンド Q6 |
| 版を作る契機 | 残す項目のどれかが変わったら、契機を問わず版を作る。契機（作成、編集、解釈、設定ファイル、版に戻す）を記録する。設定ファイルの読み込みでは、1つのトピックにつき1つの版にまとめる（A） | 第2ラウンド Q7 |
| トピックで版に残す項目 | 文章、検索語、判定基準、取得元（フィードのURL、ニュース検索、LLM検索）、検索の言語と地域。有効と無効の別は残さない（A） | 第2ラウンド Q8 |
| 「この版に戻す」の動き | 選んだ版の値を今の値として保存し、契機「版に戻す」の新しい版を作る。古い版は消さない。解釈済みの版なら解釈済みのまま戻し、解釈の時刻は戻した時刻にする。取得元は利用者が決めたものとして扱う。未解釈の版なら未解釈として戻り、次の実行で解釈される（A） | 第2ラウンド Q9 |
| カテゴリの版の扱い | 最低重要度と件数上限の履歴を、カテゴリの画面に一覧で出す。戻す操作は置かない。トピックの成績はカテゴリの変更では分けない（A） | 第2ラウンド Q10 |

## 計画で決めたこと

承認を求めた計画（issueのコメント）で、次を決めた。利用者は変更なしで承認した。

| 決定 | 選択 |
|---|---|
| LLM | 呼ばない |
| 表 | `topic_versions` と `category_versions`（移行 `030_versions.sql`）。トピックやカテゴリを消すと版も消える |
| 既存の行 | 移行で、既存のトピックとカテゴリに今の値で最初の版を1つずつ入れる。時刻は作成時刻、契機は `created` |
| 切れ目 | 直近30日の中で、最初の版を除いた最後の版の時刻。候補は集めた時刻、記事は作った時刻で前と後に分ける。外れは記事が作られた側に数える。全体の数は #138 のまま返す |
| API | `GET /api/v1/topics/:id/versions`、`POST /api/v1/topics/:id/versions/:versionId/restore`、`GET /api/v1/categories/:id/versions`。成績の各項目に `boundary`、`before`、`after` を足す。別のトピックの版と存在しない版は404 |
| Web | トピックの編集に「履歴」の区画（日時、契機、前の版との違い、今の版以外に「この版に戻す」）。保存していない変更があるときは押せず、確かめのダイアログを経て戻す。成績の区画に2列の表示。カテゴリの画面に最低重要度と件数上限の履歴 |
| 変えないこと | Androidアプリ（トピックの設定の画面がない）、設定ファイルの書き出し（履歴は入れない）、版の数の上限（設けない） |

- カテゴリの版を「この版に戻す」こと（Q10 の C）。
