# Spec Delta

## MODIFIED Requirements

### Requirement: キーボードでの記事の操作

記事が選ばれている間、`s`、`m`、`o` のキーが押されたとき、画面はそれぞれ、スターの切り替え、既読の切り替え、主な出典を開く操作をしなければならない（MUST）。
本文のペインに記事を開いていて、その記事に「リンクをコピー」が表示されている間、`c` のキーが押されたとき、画面は「リンクをコピー」と同じ操作をしなければならない（MUST）。
`c` のキーは、キー操作の一覧に表示する。

#### Scenario: スターを付ける

- **WHEN** 記事を選んだ状態で `s` を押す
- **THEN** その記事にスターが付き、もう一度押すと外れる

#### Scenario: キーでリンクをコピーする

- **WHEN** 配信記事を本文のペインに開いた状態で `c` を押す
- **THEN** その記事の見出しとURLのリンクがクリップボードに入り、知らせ「リンクをコピーしました」が表示される

#### Scenario: コピーできる記事を開いていない

- **WHEN** 出典の無い生成記事を本文のペインに開いた状態で `c` を押す
- **THEN** 何もコピーされず、知らせも表示されない
