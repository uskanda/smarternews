# Spec Delta

## ADDED Requirements

### Requirement: 記事のリンクのコピー

本文の画面は、主な出典のURLがある記事に、操作「リンクをコピー」を表示しなければならない（MUST）。
利用者が選んだとき、画面は、記事の見出しとURLを `[見出し](URL)` の形の文字列にしてクリップボードへ書き、結果を知らせとして表示する。
見出しは本文の画面の見出しと同じで、翻訳したタイトルがあればそれを使う。URLは、`o` のキーで開く主な出典のURLを使う。
見出しの中の `\`、`[`、`]` は、前に `\` を付けて書く。URLの中の `(`、`)`、空白は、パーセント符号に置き換える。
主な出典のURLが無い記事には、操作を表示しない。
ブラウザーのクリップボードのAPIが使えないとき（素のHTTPで開いたときなど）も、画面はほかの方法でコピーする。

#### Scenario: 配信記事のリンクをコピーする

- **WHEN** タイトルが「新しい版の公開」で、元のページが `https://example.com/a` の配信記事を開き、「リンクをコピー」を選ぶ
- **THEN** クリップボードに `[新しい版の公開](https://example.com/a)` が入り、知らせ「リンクをコピーしました」が表示される

#### Scenario: タイトルを翻訳した配信記事

- **WHEN** 元のタイトルが「New release」で、翻訳したタイトルが「新しい版の公開」の配信記事で、「リンクをコピー」を選ぶ
- **THEN** クリップボードに入るリンクの文字は「新しい版の公開」である

#### Scenario: 生成記事のリンクをコピーする

- **WHEN** 出典が2つある生成記事を開き、「リンクをコピー」を選ぶ
- **THEN** クリップボードに、生成記事のタイトルと、出典の一覧の先頭の出典のURLからなるリンクが入る

#### Scenario: 出典の無い生成記事

- **WHEN** 出典の無い生成記事を開く
- **THEN** 操作「リンクをコピー」は表示されない

#### Scenario: コピーに失敗する

- **WHEN** ブラウザーがクリップボードへの書き込みを拒み、ほかの方法でもコピーできない状態で、「リンクをコピー」を選ぶ
- **THEN** 知らせ「リンクをコピーできませんでした」が表示される
