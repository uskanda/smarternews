# Spec Delta

## ADDED Requirements

### Requirement: 翻訳の切り替え

購読フィードの追加と編集の画面は、翻訳するかどうかの切り替えを表示し、保存できるようにしなければならない（MUST）。
切り替えのそばに、記事のタイトルと本文が翻訳のために外部へ送られることを説明する。

#### Scenario: 編集で有効にする

- **WHEN** 購読フィードの編集で、翻訳する切り替えを入れて保存する
- **THEN** 購読フィードの一覧で、その購読フィードに翻訳する印が表示される

#### Scenario: 説明

- **WHEN** 購読フィードの編集の画面を開く
- **THEN** 切り替えのそばに、タイトルと本文が外部へ送られることが表示される

### Requirement: 翻訳の利用の状況の表示

購読フィードの設定の画面は、その月に翻訳のAPIへ送った文字数と月の上限を表示しなければならない（MUST）。
APIキーが設定されていないとき、画面は、LLMだけで翻訳することを表示する。

#### Scenario: 今月の文字数

- **WHEN** その月に12,000文字を送り、月の上限が450,000文字の状態で、購読フィードの設定の画面を開く
- **THEN** 12,000文字と450,000文字が表示される

#### Scenario: APIキーがない

- **WHEN** APIキーを設定していないサーバーで、購読フィードの設定の画面を開く
- **THEN** 翻訳にLLMだけを使うことが表示される
