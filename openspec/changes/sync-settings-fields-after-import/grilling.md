# grilling 記録: sync-settings-fields-after-import

GitHubのissueの92番のコメントで、1ラウンドの質問に答えた記録である。
issueは、設定ファイルを読み込んだ直後に同じ画面で全体設定を保存すると、読み込んだ値が元の値に戻るという指摘である（監査ID B-06）。
質問の前に、読み手情報と全体設定の欄が設定の値を `useState` の初期値にだけ使い、全体設定の保存が7項目をすべて送ることを確かめた。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 入力欄を新しい値に合わせる方法 | 欄を作り直さず、設定の値が変わったときだけ入力値を新しい値に置き換える。保存のあともフォーカスは残る（A） | 第1ラウンド Q1 |
| 読み込みの時点で保存していない入力 | 入力を捨て、読み込んだ値を表示する。読み込みの確認のダイアログの文は変えない（A） | 第1ラウンド Q2 |
| 基本の取得周期の欄を含めるか | 含めない。設定の画面の読み手情報と全体設定の2つの欄だけを直す（A） | 第1ラウンド Q3 |
