# Spec Delta

## ADDED Requirements

### Requirement: 届いた設定の値の入力欄への反映

読み手情報または全体設定の欄が表示する設定の値が変わったとき、画面はその欄の入力値を新しい値に置き換えなければならない（MUST）。

#### Scenario: 設定ファイルを読み込んだあとに全体設定を保存する

- **WHEN** タイムゾーンと読み手情報が今と違う設定ファイルを読み込み、更新が止まったとみなす日数だけを変えて全体設定を保存する
- **THEN** タイムゾーンと読み手情報の入力欄は読み込んだ値を表示し、保存のあとも、保存済みのタイムゾーンと読み手情報は読み込んだ値のまま変わらない

#### Scenario: 保存していない入力がある状態で読み込む

- **WHEN** 全体設定に保存していない入力がある状態で、タイムゾーンが今と違う設定ファイルを読み込む
- **THEN** 全体設定の入力欄は読み込んだ値を表示し、全体設定は保存していない変更として扱われない

#### Scenario: ほかの欄の値だけが変わる

- **WHEN** 全体設定に保存していない入力がある状態で、読み手情報だけを保存する
- **THEN** 全体設定の入力は残る

### Requirement: 保存のあとのフォーカス

利用者が読み手情報または全体設定の「保存する」を選んで保存に成功したとき、画面はフォーカスをそのボタンに残さなければならない（MUST）。

#### Scenario: 全体設定を保存する

- **WHEN** 全体設定の「保存する」を押して保存に成功する
- **THEN** フォーカスはその「保存する」のボタンにある
