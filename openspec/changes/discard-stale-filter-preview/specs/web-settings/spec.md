## ADDED Requirements

### Requirement: 古い条件の確認の結果を出さない

件数の確認の結果を待つ間に利用者が入力を変えたとき、画面は、変える前の入力に対する件数と誤りを表示してはならない（MUST NOT）。

#### Scenario: 待つ間に条件を変えた件数

- **WHEN** 条件「特売」で確認を選び、結果が届く前に条件の値を「特売の予告」に変える
- **THEN** 結果が届いても件数は表示されず、もう一度確認を選ぶと「特売の予告」で隠れる件数が表示される

#### Scenario: 待つ間に条件を変えた誤り

- **WHEN** 正規表現 `(特売` で確認を選び、結果が届く前に値を `(特売)` に変える
- **THEN** 結果が届いても、正規表現が誤っていることは表示されない
