# Spec Delta

## MODIFIED Requirements

### Requirement: フィルターの一覧

フィルターの設定の画面が開かれたとき、画面は、すべてのフィルターを、種類、適用する範囲、条件、有効と無効の別、隠している配信記事の件数とともに表示しなければならない（MUST）。
画面は、どのフィルターの隠した配信記事の一覧を開いているかをURLに持たなければならない（MUST）。開閉では履歴の項目を増やさない。URLが示すフィルターのうち、ないものと無効のものは開かない。
別の画面からフィルターの設定の画面へ戻ったとき、画面は、離れたときに開いていた隠した配信記事の一覧を開き、離れたときのスクロール位置から表示しなければならない（MUST）。

#### Scenario: 隠している件数

- **WHEN** ある隠すフィルターが配信記事を4件隠している
- **THEN** その行に、隠すフィルターであること、範囲、条件、4件が表示される

#### Scenario: 設定の画面から開く

- **WHEN** 設定の画面で「フィルター」を選ぶ
- **THEN** フィルターの設定の画面が開く

#### Scenario: 隠している記事を開いて戻る

- **WHEN** あるフィルターの「隠している記事」を開き、画面を下へ送ってから記事を開き、ブラウザーの戻る操作で戻る
- **THEN** そのフィルターの隠した配信記事の一覧は開いたままで、画面は離れたときの位置から表示される

#### Scenario: URLで開く

- **WHEN** あるフィルターの一覧を開いていることと、存在しないフィルターの番号を示すURLで、フィルターの設定の画面を開く
- **THEN** そのフィルターの隠した配信記事の一覧が開いていて、存在しない番号は何も起こさない
