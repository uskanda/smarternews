# Spec Delta

## MODIFIED Requirements

### Requirement: トピックごとのまとめ

画面は、除外した候補を、当たったトピックごとにまとめて表示できなければならない（MUST）。
画面は、まとめるかどうかによらず、候補に当たった各トピックから、そのトピックの編集を開いた状態のカテゴリの画面へ進めなければならない（MUST）。
画面は、まとめるかどうかをURLに持たなければならない（MUST）。切り替えでは履歴の項目を増やさない。
別の画面から実行の詳細の画面へ戻ったとき、画面は、離れたときのまとめる表示とスクロール位置から表示しなければならない（MUST）。

#### Scenario: 外れの多いトピックを見つける

- **WHEN** 除外した候補の一覧でトピックごとの表示を選び、あるトピックを直すリンクを選ぶ
- **THEN** トピックごとに除外の件数と候補が表示され、リンクの先ではそのトピックの編集が開いた状態になる

#### Scenario: まとめない表示からトピックを直しに行く

- **WHEN** トピックごとの表示を切り、候補の下に並んだトピック名を選ぶ
- **THEN** そのトピックの編集が開いた状態のカテゴリの画面へ移る

#### Scenario: トピックを直して戻る

- **WHEN** トピックごとの表示を選び、画面を下へ送ってから「このトピックを直す」を選び、ブラウザーの戻る操作で戻る
- **THEN** 除外した候補はトピックごとにまとめて表示され、画面は離れたときの位置から表示される

#### Scenario: 切り替えで履歴を増やさない

- **WHEN** 実行履歴から実行の詳細を開き、トピックごとの表示を入れて切ってから、ブラウザーの戻る操作をする
- **THEN** 実行履歴の画面へ戻る

#### Scenario: URLで開く

- **WHEN** まとめる表示を示すURLで実行の詳細を開く
- **THEN** 除外した候補はトピックごとにまとめて表示される
