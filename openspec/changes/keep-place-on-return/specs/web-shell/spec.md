# Spec Delta

## ADDED Requirements

### Requirement: ダイジェストの画面へ戻ったときの位置

別の画面からダイジェストの画面へ戻ったとき、画面は、ダイジェストの本文と過去のダイジェストの一覧を、それぞれ離れたときのスクロール位置から表示しなければならない（MUST）。
再読み込みしたときは、先頭から表示してよい。

#### Scenario: 根拠の記事から戻る

- **WHEN** 幅390pxの画面で、ダイジェストを下へ送ってから根拠の記事を開き、ブラウザーの戻る操作で戻る
- **THEN** ダイジェストは離れたときの位置から表示される

#### Scenario: 広い画面で戻る

- **WHEN** 幅1280pxの画面で、過去のダイジェストの一覧と本文をそれぞれ下へ送ってから根拠の記事を開き、ブラウザーの戻る操作で戻る
- **THEN** 一覧と本文は、それぞれ離れたときの位置から表示される

#### Scenario: 新しく開く

- **WHEN** ダイジェストを下へ送ってから根拠の記事を開き、そこから左のペインの「ダイジェスト」を選ぶ
- **THEN** ダイジェストは先頭から表示される
