# Spec Delta

## MODIFIED Requirements

### Requirement: 当てはまったトピックの表示

生成記事の本文が開かれたとき、画面は、その記事に当てはまったトピックを、出典の下、末尾の操作の前に、そのトピックの編集へのリンクとして表示しなければならない（MUST）。
長いトピックの文章は表示を2行で切ってよいが、読み上げ名には全文を使わなければならない（MUST）。
当てはまったトピックのない記事と、配信記事では、この行を表示してはならない（MUST NOT）。

#### Scenario: 外れた記事からトピックを直しに行く

- **WHEN** トピックが2つ当てはまった生成記事を開き、1つ目のトピックのリンクを選ぶ
- **THEN** その記事のカテゴリの画面が開き、そのトピックの編集が開いた状態になる

#### Scenario: 外れの印の近くのトピック

- **WHEN** トピックが当てはまった生成記事を開く
- **THEN** トピックの区画は、見出しと出典より後ろで、末尾の操作の並びより前にある

#### Scenario: トピックのない記事

- **WHEN** 配信記事か、当てはまったトピックの記録がない生成記事を開く
- **THEN** トピックの行は表示されない

## ADDED Requirements

### Requirement: 本文の上部のスターと既読の操作

記事の本文が開かれている間、画面は、見出しの前の補足の行に、スターと既読を切り替える操作を表示しなければならない（MUST）。

#### Scenario: スクロールせずにスターを付ける

- **WHEN** 記事を開き、補足の行のスターを付ける操作を選ぶ
- **THEN** 記事にスターが付き、補足の行と末尾の操作が、どちらもスターを外す操作に変わる

#### Scenario: スクロールせずに未読に戻す

- **WHEN** 既読の記事を開き、補足の行の未読に戻す操作を選ぶ
- **THEN** 記事が未読に戻る。補足の行の操作は「既読にする」へ変わる

### Requirement: 末尾のスターと既読の操作の維持

記事の本文が開かれている間、画面は、補足の行の操作に加えて、本文の末尾にもスターと既読を切り替える操作を表示しなければならない（MUST）。

#### Scenario: 読み終えてからスターを付ける

- **WHEN** 記事を末尾まで読み、末尾のスターを付ける操作を選ぶ
- **THEN** 記事にスターが付く
