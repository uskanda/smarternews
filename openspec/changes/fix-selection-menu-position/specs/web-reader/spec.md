# Spec Delta

## MODIFIED Requirements

### Requirement: 文字を選んだときのメニュー

本文の原文の文字が選ばれたとき、画面は、選んだ範囲の近くに、ハイライトを付ける操作と、メモを書いてハイライトを付ける操作のメニューを表示しなければならない（MUST）。
原文は、注釈の仕様が定めるハイライトの対象の本文を指す。
メニューは画面の中に収め、選んだ範囲が本文のペインの見える部分にある間は、スクロールしても範囲の近くに表示する。

#### Scenario: ハイライトを付ける

- **WHEN** 本文の1文をマウスで選び、メニューのハイライトを付ける操作を押す
- **THEN** その1文がハイライトされ、注釈の一覧にその1文の行が加わる

#### Scenario: メモを書いてハイライトを付ける

- **WHEN** 本文の1文を選び、メニューのメモを書く操作を押し、メモを入力して保存する
- **THEN** その1文がハイライトされ、本文の中でメモの印が付く

#### Scenario: 行の右端の語を選ぶ

- **WHEN** 幅390pxの画面で、本文の行の右端の語を選ぶ
- **THEN** メニューは画面の幅の中に収まり、はみ出す分だけ左へずれて表示される

#### Scenario: 画面の下端にかかる文を選ぶ

- **WHEN** 画面の下端にかかる1文を選び、範囲の下にはメニューが入らない
- **THEN** メニューは選んだ範囲の上に表示される

#### Scenario: 選んだあとで本文をスクロールする

- **WHEN** 本文の1文を選んだあと、本文のペインを少しスクロールする
- **THEN** メニューは選んだ範囲に付いて動き、範囲の近くに表示される

#### Scenario: 選んだ範囲が見えなくなる

- **WHEN** 本文の1文を選んだあと、その1文が本文のペインの見える部分と少しも重ならなくなるまでスクロールし、そのあと元の位置へ戻す
- **THEN** 範囲が外れている間はメニューが表示されず、範囲が見える部分に戻るとまた表示される
