# grilling 記録: add-feed-articles-list

Issue #128「配信記事だけの一覧」の計画の記録である。
計画の段階で、質問は出していない。どの判断もIssueの文面か既存の規約から決まるためで、計画に「前提にした判断」として7つを並べ、変えたいものがあれば承認に添えてもらう形にした。

## 決定

| 決定 | 選択 | 出典 |

| 項目の位置 | 「AI生成」のすぐ下。並びは「未読」「すべて」「スター」「AI生成」「購読フィード」「最近読んだ記事」「注釈」 | Issue #128の計画 前提2（`/ok` で承認） |
| 購読フィードが1つもないときの表示 | 常に表示する。Issueが「固定の項目」としており、「AI生成」と同じ扱いにする | Issue #128の計画 前提3（`/ok` で承認） |
| 未読数の出し方 | 画面の側で、件数のAPIの未読の総数から生成記事の未読数を引く。APIに項目は足さない | Issue #128の計画 前提4（`/ok` で承認） |

| 計画の承認 | 上の判断に沿った計画を、変更なしで承認 | Issue #128への返答（`/ok`） |
