# Spec Delta

## MODIFIED Requirements

### Requirement: 動かせない項目

画面は、次の項目をドラッグで動かせるようにしてはならない（MUST NOT）。
対象は、「未読」「すべて」「スター」「AI生成」、上段の「購読フィード」、「未分類」と、各カテゴリの「AI生成」である。
各カテゴリの「AI生成」は配下の先頭に、「未分類」はカテゴリの末尾に表示する。

#### Scenario: 「AI生成」より上には置けない

- **WHEN** カテゴリAの購読フィードXを、カテゴリAの「AI生成」の上までドラッグして離す
- **THEN** 購読フィードXは「AI生成」のすぐ下に表示される

#### Scenario: 上段の「購読フィード」をドラッグしようとする

- **WHEN** 左のペインの上段の「購読フィード」の上でマウスのボタンを押したまま動かす
- **THEN** ドラッグは始まらず、「購読フィード」は「AI生成」の下にとどまる

### Requirement: 「最近読んだ記事」を動かせないこと

画面は、左のペインの「最近読んだ記事」をドラッグで動かせるようにしてはならない（MUST NOT）。
ほかの項目のドラッグで、「最近読んだ記事」の位置を変えてはならない。

#### Scenario: 「最近読んだ記事」をドラッグしようとする

- **WHEN** 左のペインの「最近読んだ記事」の上でマウスのボタンを押したまま動かす
- **THEN** ドラッグは始まらず、「最近読んだ記事」は上段の「購読フィード」の下にとどまる
