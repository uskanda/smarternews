# Spec Delta

## ADDED Requirements

### Requirement: 上段の「購読フィード」の項目

画面は、左のペインの「AI生成」の下に、「購読フィード」の項目を、未読の配信記事の数つきで常に表示しなければならない（MUST）。
購読フィードが1つもないときも、項目は表示する。
既読の項目を隠す設定が有効な間も、未読の配信記事の有無にかかわらず、項目は表示する。

#### Scenario: 未読の配信記事がある

- **WHEN** 未読の生成記事が2件と、2つの購読フィードに未読の配信記事が合わせて10件ある状態で、画面を開く
- **THEN** 左のペインの「AI生成」の下に「購読フィード」が並び、その横に10が表示される

#### Scenario: 購読フィードがない

- **WHEN** 購読フィードが1つもない状態で、画面を開く
- **THEN** 左のペインの「AI生成」の下に「購読フィード」が並ぶ

### Requirement: 上段の「購読フィード」の一覧

左のペインの上段の「購読フィード」が選ばれたとき、画面は、全カテゴリと「未分類」の配信記事だけを一覧に表示しなければならない（MUST）。
一覧は未読の記事だけを表示し、既読も表示する切り替え、並び順のメニュー、一括の既読を持つ。
配信記事には重要度がないため、画面は、この一覧に重要度4以上の切り替えを表示してはならない（MUST NOT）。

#### Scenario: 上段の「購読フィード」を選ぶ

- **WHEN** カテゴリAの購読フィードと「未分類」の購読フィードに未読の配信記事が1件ずつあり、未読の生成記事が3件ある状態で、上段の「購読フィード」を選ぶ
- **THEN** 一覧には配信記事の2件だけが並ぶ

#### Scenario: 重要度の切り替えは出ない

- **WHEN** 上段の「購読フィード」を選ぶ
- **THEN** 既読も表示する切り替えと並び順のメニューは表示され、重要度4以上の切り替えは表示されない

#### Scenario: 一括の既読を選ぶ

- **WHEN** 未読の配信記事が2件と未読の生成記事が3件ある状態で、上段の「購読フィード」の一覧で一括の既読を選ぶ
- **THEN** 配信記事の2件は既読になり、生成記事の3件は未読のままである

## MODIFIED Requirements

### Requirement: 上部の項目での一括の既読

「未読」「すべて」「スター」「AI生成」「購読フィード」の一覧で一括の既読を選んだとき、画面は、設定にかかわらず、別の項目へ移ってはならない（MUST NOT）。

#### Scenario: 「未読」で一括の既読を選ぶ

- **WHEN** この設定が有効な状態で、「未読」の一覧で一括の既読を選ぶ
- **THEN** 画面は「未読」の一覧のままである

#### Scenario: 上段の「購読フィード」で一括の既読を選ぶ

- **WHEN** この設定が有効で、カテゴリAに未読がある状態で、上段の「購読フィード」の一覧で一括の既読を選ぶ
- **THEN** 画面は「購読フィード」の一覧のままである

### Requirement: 「最近読んだ記事」の項目

画面は、左のペインの上段の「購読フィード」の下に、「最近読んだ記事」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 左のペインを見る

- **WHEN** 画面を開く
- **THEN** 左のペインの上部に「未読」「すべて」「スター」「AI生成」「購読フィード」「最近読んだ記事」の順で項目が並び、「最近読んだ記事」の横に数字はない

### Requirement: 「注釈」の項目

画面は、左のペインの「最近読んだ記事」の下に、「注釈」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 左のペインを見る

- **WHEN** 画面を開く
- **THEN** 左のペインの上部に「未読」「すべて」「スター」「AI生成」「購読フィード」「最近読んだ記事」「注釈」の順で項目が並び、「注釈」の横に数字はない
