# Spec Delta

## ADDED Requirements

### Requirement: 引き出しの上段の「購読フィード」の項目

アプリは、引き出しの「AI生成」の下に、「購読フィード」の項目を、未読の配信記事の数つきで常に表示しなければならない（MUST）。
購読フィードが1つもないときも、項目は表示する。

#### Scenario: 未読の配信記事がある

- **WHEN** 未読の生成記事が2件と、2つの購読フィードに未読の配信記事が合わせて10件ある状態で、引き出しを開く
- **THEN** 「AI生成」の下に「購読フィード」が並び、その横に10が表示される

## MODIFIED Requirements

### Requirement: 動かせない項目

アプリは、次の項目をドラッグで動かせるようにしてはならない（MUST NOT）。
対象は、「未読」「すべて」「スター」「AI生成」、上段の「購読フィード」、「未分類」「設定」と、各カテゴリの「AI生成」である。

#### Scenario: 「未分類」を長押しする

- **WHEN** 引き出しの「未分類」を長押しする
- **THEN** ドラッグは始まらない

#### Scenario: 上段の「購読フィード」を長押しする

- **WHEN** 引き出しの上段の「購読フィード」を長押しする
- **THEN** ドラッグは始まらない

### Requirement: 引き出しの「最近読んだ記事」の項目

アプリは、引き出しの上段の「購読フィード」の下に、「最近読んだ記事」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 引き出しを開く

- **WHEN** 引き出しを開く
- **THEN** 上部に「未読」「すべて」「スター」「AI生成」「購読フィード」「最近読んだ記事」の順で項目が並び、「最近読んだ記事」の横に数字はない
