# Spec Delta

## ADDED Requirements

### Requirement: 上段の「購読フィード」の一覧

引き出しの上段の「購読フィード」が選ばれたとき、アプリは、全カテゴリと「未分類」の配信記事だけを一覧に表示しなければならない（MUST）。
一覧は未読の記事だけを表示し、既読を含める切り替え、並び順のメニュー、一括の既読を持つ。
配信記事には重要度がないため、アプリは、この一覧に重要度4以上の切り替えを表示してはならない（MUST NOT）。

#### Scenario: 上段の「購読フィード」を選ぶ

- **WHEN** カテゴリAの購読フィードと「未分類」の購読フィードに未読の配信記事が1件ずつあり、未読の生成記事が3件ある状態で、上段の「購読フィード」を選ぶ
- **THEN** 一覧には配信記事の2件だけが並ぶ

#### Scenario: 重要度の切り替えは出ない

- **WHEN** 上段の「購読フィード」の一覧で、絞り込みのメニューを開く
- **THEN** 既読を含める切り替えは表示され、重要度4以上の切り替えは表示されない

#### Scenario: 一括の既読を選ぶ

- **WHEN** 未読の配信記事が2件と未読の生成記事が3件ある状態で、上段の「購読フィード」の一覧で一括の既読を選ぶ
- **THEN** 配信記事の2件は既読になり、生成記事の3件は未読のままである

## MODIFIED Requirements

### Requirement: 一括の既読のあとの次の項目への移動

一括の既読のあとに次の項目へ移る設定が有効なとき、アプリは、一括の既読のあとに、引き出しの表示順でいまの項目より下にある、未読が1件以上の最初の項目を開かなければならない（MUST）。
カテゴリの一覧からは、次のカテゴリか「未分類」へ移る。
購読フィードの一覧と各カテゴリの「AI生成」の一覧からは、カテゴリをまたいで、次の購読フィードまたは「AI生成」へ移る。
当たる項目がないとき、および「未読」「すべて」「スター」「AI生成」と上段の「購読フィード」の一覧では、アプリは移らない。

#### Scenario: 次のカテゴリへ移る

- **WHEN** カテゴリA、B、Cが並び、Bに未読がなくCに未読がある状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** カテゴリCの一覧が開く

#### Scenario: 設定が無効

- **WHEN** この設定が無効な状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** アプリはカテゴリAの一覧のままである

#### Scenario: 移ったあとに取り消す

- **WHEN** 一括の既読で次の項目へ移ったあと、取り消しを選ぶ
- **THEN** 既読にした記事は未読に戻る

#### Scenario: 上段の「購読フィード」で一括の既読を選ぶ

- **WHEN** この設定が有効で、カテゴリAに未読がある状態で、上段の「購読フィード」の一覧で一括の既読を選ぶ
- **THEN** アプリは「購読フィード」の一覧のままである
