# Proposal

## Why

2026-11-13のWeb UIの監査（U-08）で、記事がないときの文が一覧の切り替えを反映しないと分かった。
未読が5件あるカテゴリで「重要度4以上だけ」を入れて0件になると、記事がないことだけが出て、左のペインの未読数の5と食い違って見える。
「既読も表示」を入れても0件のときは、既読も表示するよう勧める文が出て、すでに行った操作を勧めている。

## What Changes

- 「重要度4以上だけ」が入っていて記事がないとき、どの項目でも、重要度4以上の記事がないことを伝える文と「絞り込みを外す」のボタンを出す。ボタンを選ぶと絞り込みが外れる。
- 「既読も表示」が入っていて記事がないとき、既読も表示するよう勧める文を出さない。
- Androidアプリの空の一覧の文は変えない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-reader`: 要件の「記事がないときの表示」に、重要度で絞っているときと、既読も表示しているときのシナリオを足す。

## Impact

- `apps/web/src/reader/ReaderPage.tsx` の `EmptyList` とその呼び出し
- Webの画面のテスト（`reader.test.tsx`）
- Androidアプリは変えない
