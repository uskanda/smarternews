# Spec Delta

## ADDED Requirements

### Requirement: トピックの成績の区画

カテゴリの編集の画面は、トピックの区画のすぐ後に「トピックの成績」の区画を置き、トピックごとの直近30日の成績を表示しなければならない（MUST）。区画は、期間の始まりの日を示す。開いた記事、スター、外れは、作った記事の数に対する件数と割合で示す。

#### Scenario: 成績を確かめる

- **WHEN** 直近30日に生成記事を2件作り、そのうち1件に外れの印があるトピックを持つカテゴリの編集の画面を開く
- **THEN** トピックの区画の次に「トピックの成績」の区画があり、そのトピックの行に「外れ 1/2件（50%）」が表示される

#### Scenario: 候補のないトピック

- **WHEN** 直近30日に候補を集めていないトピックの行を見る
- **THEN** 候補がないことと、取得元と検索語を確かめるよう促す文が表示される

### Requirement: 問題のあるトピックを先頭へ

「問題のあるトピックを先頭へ」を選んでいる間、画面は、トピックの成績の行を次の順に並べなければならない（MUST）。

1. 集めた候補が0件のトピック
2. 外れの割合が大きい順。作った記事が0件なら、割合は0とする
3. 記事にならなかった候補の割合が大きい順
4. トピックのIDの順

選んでいないときは、トピックのIDの順に並べる。

#### Scenario: 並べ替える

- **WHEN** 候補のあるトピックA、候補のないトピックB、外れの印のある記事を持つトピックCが、この順に作られたカテゴリで、「問題のあるトピックを先頭へ」を選ぶ
- **THEN** 行はB、C、Aの順になり、選ぶのをやめるとA、B、Cの順に戻る

### Requirement: 成績からトピックの編集へ

トピックの成績の行のトピックの名前を選んだとき、画面は、そのトピックの編集を開かなければならない（MUST）。

#### Scenario: 成績から直す

- **WHEN** トピックの成績の行で、トピックの名前を選ぶ
- **THEN** トピックの区画で、そのトピックの編集が開き、文章の入力欄にそのトピックの文章が入っている

### Requirement: 成績の更新

トピックを追加、保存、削除、解釈し直したとき、画面はトピックの成績を問い合わせ直さなければならない（MUST）。

#### Scenario: トピックを追加する

- **WHEN** カテゴリの編集の画面でトピックを追加する
- **THEN** トピックの成績の区画に、そのトピックの行が現れる
