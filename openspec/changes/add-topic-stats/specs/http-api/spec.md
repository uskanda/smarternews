# Spec Delta

## ADDED Requirements

### Requirement: トピックの成績の提供

`GET /api/v1/categories/:id/topic-stats` を受けたとき、APIは、期間の始まり（`since`）と、トピックごとの直近30日の成績を返さなければならない（MUST）。成績は、カテゴリのすべてのトピックについて返す。トピックはIDの順に並べる。各トピックの成績は次の数を持つ。

- 集めた候補：全体と取得元ごと
- 除外：判定での除外、基準未満、件数上限、日付で外れた数
- 記事：作った記事、更新した記事、開いた記事、スター、外れ
- よく除外されるサイト

#### Scenario: 成績を求める

- **WHEN** カテゴリCのトピックTが直近30日にニュース検索で候補を3件集め、そのうち1件を判定が除外した状態で、Cの成績を要求する
- **THEN** Tの項目では、集めた候補が全体3件とニュース検索3件、判定での除外が1件になる

#### Scenario: 何も集めていないトピック

- **WHEN** 直近30日の候補と記事のどちらもないトピックを持つカテゴリの成績を要求する
- **THEN** そのトピックの項目は、すべての数が0で、よく除外されるサイトが空になる

#### Scenario: 存在しないカテゴリ

- **WHEN** 存在しないカテゴリの成績を要求する
- **THEN** 404が返る

### Requirement: 成績でのLLMの扱い

トピックの成績を求められたとき、APIはLLMを呼んではならない（MUST NOT）。

#### Scenario: 成績を求めても呼ばない

- **WHEN** 候補と記事のあるカテゴリの成績を要求する
- **THEN** LLMのタスクは1回も呼ばれない

### Requirement: 成績の候補の期間

APIは、成績の候補の数に、集めた時刻が期間の始まり以降の候補だけを数えなければならない（MUST）。

#### Scenario: 31日前の候補

- **WHEN** 31日前に集めた候補と、昨日集めた候補を持つトピックの成績を要求する
- **THEN** 集めた候補は1件になる

### Requirement: 成績の除外の数え方

APIは、除外された候補を理由の種類で分けて数えなければならない（MUST）。分け方は次のとおりとする。

- 理由の種類なし：判定での除外
- `below-minimum`：基準未満
- `over-limit`：件数上限
- `no-date`、`event-outside-window`、`event-no-date`：日付で外れた数

#### Scenario: 理由の種類ごとの数

- **WHEN** トピックの候補のうち、判定が2件、基準未満が1件、件数上限が2件、日付の3種類が1件ずつ除外された状態で成績を要求する
- **THEN** 判定での除外は2件、基準未満は1件、件数上限は2件、日付で外れた数は3件になる

### Requirement: 成績の記事の数え方

APIは、成績の記事の数に生成記事だけを数えなければならない（MUST）。それぞれの数は次のとおりとする。

- 作った記事：作った時刻が期間内の記事
- 更新した記事：続報で書き直され、最後の書き直しが期間内の記事
- 開いた記事：作った記事のうち、開いた時刻がある記事
- スター：作った記事のうち、今スターがある記事
- 外れ：作った記事のうち、このトピックの外れの印がある記事。印をいつ付けたかは問わない

#### Scenario: 配信記事を数えない

- **WHEN** トピックにつながった配信記事がある状態で成績を要求する
- **THEN** その配信記事は、作った記事とスターのどちらにも入らない

#### Scenario: 外れの割合の元になる数

- **WHEN** トピックが直近30日に生成記事を2件作り、そのうち1件に外れの印がある状態で成績を要求する
- **THEN** 作った記事は2件、外れは1件になる

#### Scenario: 印を外した記事

- **WHEN** 外れの印を付けてから外した生成記事がある状態で成績を要求する
- **THEN** その記事は外れに数えられない

### Requirement: よく除外されるサイト

APIは、トピックごとに、除外された候補が多いサイトを3つまで、サイト名と件数で返さなければならない（MUST）。件数の多い順に並べ、件数が同じサイトはサイト名の順にする。サイト名のない候補は数えない。

#### Scenario: 上位3サイト

- **WHEN** 除外された候補が、サイトAに1件、サイトBに3件、サイトCに2件、サイトDに2件、サイト名なしに5件ある状態で成績を要求する
- **THEN** よく除外されるサイトは、サイトB（3件）、サイトC（2件）、サイトD（2件）の順になる
