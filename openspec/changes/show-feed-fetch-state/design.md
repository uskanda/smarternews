# Design

## Context

APIの購読フィード（`Feed`）は、`lastError`（最後の取得の失敗の理由）、`stale`（有効で、`staleFeedDays` より長く新着がない）、`enabled` をすでに返している。設定の画面は、これを言葉の印で表示している。
読む画面と左のペインは、同じ `useFeeds` のキャッシュを読んでいる。左のペインの項目は、`packages/client` の `buildNav` が作る。動機は `proposal.md` の「Why」を参照する。

## Goals / Non-Goals

**Goals:**

- 状態の判定を1か所に置き、読む画面、左のペイン、のちのAndroidアプリが同じ判定を使えるようにする。
- 「いま取得」の処理を設定の画面と共有し、結果の表示を揃える。

**Non-Goals:**

- APIとサーバーの変更。必要な値はすでに返っている。
- Androidアプリの表示（`grilling.md` のQ6）。

## Decisions

### 状態の判定を packages/client の feedState に置く

`feedState(feed)` は `"failed" | "stale" | "paused" | null` を返す。強さの順は、失敗、更新の停止、一時停止である。`strongestFeedState` は、状態の並びからいちばん強いものを返す。言葉（`FEED_STATE_LABEL`）も同じ場所に置き、設定の画面の印と揃える。
画面ごとに判定を書くと、強さの順はずれうる。置き場所は、UIに依存しない `packages/client` とする。Androidアプリからも使えるようにするためである。

### buildNav が状態を持つ

フィードの項目には `state`、グループ（カテゴリと「未分類」）には下の購読フィードのいちばん強い状態を `childState` として持たせる。問題がないときは、その名前の値そのものを持たせない。既存の比較のテストと、項目の形を変えないためである。
折りたたんでいるかどうかは画面の状態なので、`childState` を出すかどうかは画面（`Shell`）が決める。

### 一覧の上部の行は見出しの下、スクロールの外に置く

`FeedStatusBanner` を、一覧の見出しの部分と、スクロールする行の間に置く。一覧をスクロールしても状態が見えたままになる。見た目は、既存の `ErrorNotice`（`error` の枠と文字）と月の予算の警告（`warning` の枠と文字）に合わせる。
読み上げでは `role="status"` とし、開いただけで割り込んで読み上げないようにする。

### 「いま取得」を useFetchFeedNow にまとめる

設定の画面の `FeedRow` の処理を、`apps/web/src/lib/fetch-now.ts` の `useFetchFeedNow` に移す。取得の結果の購読フィードで `["feeds"]` のキャッシュを置き換えるので、上部の行と左のペインの印は再読み込みなしで変わる。失敗のときに画面の下に出す短い知らせの文だけは、理由を表示している場所が画面ごとに違うため、呼ぶ側が渡す。

### 左のペインのアイコンは画面のコードの中のSVG

アイコンの部品を新しく入れず、16の座標のSVGを3つ、画面のコードの中に描く。失敗は感嘆符を入れた三角、更新の停止は時計、一時停止は2本の縦線である。外側の `span` に `role="img"`、`aria-label`、`title` を付け、SVG自体は読み上げから外す。
名前とアイコンの読み上げ名がつながって1語に聞こえないよう、間に読み上げ専用の「、」を置く。
折りたたんだカテゴリの行のアイコンは、カテゴリ自身の状態を表さない。そのため読み上げ名を「取得に失敗した購読フィードがあります」のようにする。

### 設定の画面の行の id とフォーカス

`FeedRow` の `li` に `id="feed-<識別子>"` を付け、名前の要素に `tabIndex={-1}` を付ける。URLのハッシュが `#feed-<数字>` で、一覧が読み込まれたら、その行を `scrollIntoView` し、名前にフォーカスを移す。
ハッシュは `window.location` ではなく、`React Router` の `useLocation` から読む。テストでも、ブラウザーでも同じに動く。

## Risks / Trade-offs

- 左のペインの幅が狭いと、アイコンのぶん名前が早く省略される。→ アイコンは文字の高さの正方形1つに限り、言葉の印にはしない（`grilling.md` のQ4）。
- 一時停止していて `lastError` も残っている購読フィードは、失敗として表示され「いま取得」が出る。→ 強さの順は決定どおりとする。いま取得は一時停止していても働くので、操作として誤りではない。
- 取得の失敗が続く購読フィードを多く持つと、左のペインに赤い印が並ぶ。→ 直すか一時停止するかを促す表示として受け入れる。一時停止すれば、印は目立たない色に変わる。
