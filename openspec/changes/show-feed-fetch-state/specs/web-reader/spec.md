# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードの一覧の取得の状態

購読フィードの一覧を表示するとき、画面は、その購読フィードの取得の状態を一覧の上部に1行で表示しなければならない（MUST）。
対象の状態は3つある。最後の取得の失敗、更新の停止、一時停止である。
状態が重なったときは、取得の失敗、更新の停止、一時停止の順に、強い1つだけを表示する。
取得の失敗の行は、失敗の理由と「いま取得」の操作を並べる。更新の停止の行は「いま取得」の操作を並べる。一時停止の行には「いま取得」を置かない。
どの行にも、設定の購読フィードの画面のその購読フィードの行へのリンクを、文の中に置く。
状態に問題のない購読フィードの一覧には、この行を表示しない。記事がないときの説明は、この行と並べて表示する。

#### Scenario: 取得に失敗した購読フィードを開く

- **WHEN** 最後の取得がHTTPの503で失敗した購読フィードFの一覧を開く
- **THEN** 一覧の上部に、取得に失敗したことと「サイトがエラーを返しました（HTTP 503）」という理由、「いま取得」、設定へのリンクが1行で並ぶ

#### Scenario: いま取得が成功する

- **WHEN** 取得に失敗した購読フィードの一覧の上部で「いま取得」を選び、取得が成功する
- **THEN** 上部の行は再読み込みなしで消え、取得した記事が一覧に並ぶ

#### Scenario: 一時停止した購読フィードを開く

- **WHEN** 一時停止した購読フィードの一覧を開く
- **THEN** 一覧の上部に、取得を一時停止していることと設定へのリンクが並び、「いま取得」は表示されない

#### Scenario: 設定へのリンクを選ぶ

- **WHEN** 一覧の上部の行の設定へのリンクを選ぶ
- **THEN** 設定の購読フィードの画面が開き、その購読フィードの行の名前にフォーカスがある

### Requirement: 左のペインの購読フィードの取得の状態の印

左のペインの購読フィードの行は、その購読フィードの取得の状態の印を、名前と未読数の間に表示しなければならない（MUST）。
対象の状態は、一覧の上部の行と同じ3つである。
印は状態ごとに形を変え、色だけで区別してはならない（MUST NOT）。印は、設定の購読フィードの画面の印と同じ言葉を、読み上げ名として持つ。
状態が重なったときは、取得の失敗、更新の停止、一時停止の順に、強い1つだけを表示する。

#### Scenario: 取得に失敗した購読フィード

- **WHEN** 左のペインに、最後の取得の失敗した購読フィードの行がある
- **THEN** その行の名前の右に、「取得に失敗」と読み上げられる印が表示される

#### Scenario: 問題のない購読フィード

- **WHEN** 最後の取得が成功し、更新も止まっていない購読フィードが左のペインにある
- **THEN** その行には状態の印が表示されない

## MODIFIED Requirements

### Requirement: カテゴリの下の項目の折りたたみ

利用者がカテゴリの折りたたみを選んだとき、画面は、そのカテゴリの下の項目を隠し、その状態をブラウザーに保存しなければならない（MUST）。
折りたたんだカテゴリと「未分類」の行には、下の購読フィードの中でいちばん強い取得の状態の印を表示しなければならない（MUST）。印の読み上げ名は、その状態の購読フィードが下にあることを示す。開いているときは、カテゴリの行に印を表示しない。

#### Scenario: 折りたたんで読み込み直す

- **WHEN** カテゴリAを折りたたみ、ブラウザーを再読み込みする
- **THEN** カテゴリAの下の項目は隠れたままで、カテゴリAの未読数は表示される

#### Scenario: 取得に失敗した購読フィードのあるカテゴリを折りたたむ

- **WHEN** 一時停止した購読フィードと、取得に失敗した購読フィードを下に持つカテゴリAを折りたたむ
- **THEN** カテゴリAの行に、取得に失敗した購読フィードがあることを示す印が表示される。開いているときは、カテゴリAの行に印はない
