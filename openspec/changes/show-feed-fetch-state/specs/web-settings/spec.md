# Spec Delta

## MODIFIED Requirements

### Requirement: 即時の取得の操作

利用者が購読フィードの「いま取得」を選んだとき、画面はその購読フィードの即時の取得を始め、終わったあとの取得の状況を表示しなければならない（MUST）。
購読フィードの画面が `/settings/feeds#feed-<識別子>` で開かれたとき、画面は一覧を読み込んだあと、その購読フィードの行までスクロールしなければならない（MUST）。行の名前には、フォーカスを移す。
読む画面の取得の状態の行から来た利用者が、すぐに原因を直せるようにするためである。

#### Scenario: いま取得する

- **WHEN** 購読フィードの「いま取得」を選び、取得が成功する
- **THEN** その行の最後に成功した日時が、再読み込みなしで新しくなる

#### Scenario: 行を指定して開く

- **WHEN** 3つの購読フィードがあり、2つ目の購読フィードの識別子を指定して購読フィードの画面を開く
- **THEN** 2つ目の購読フィードの行が表示され、その名前にフォーカスがある
