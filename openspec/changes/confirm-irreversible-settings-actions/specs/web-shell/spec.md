# Spec Delta

## MODIFIED Requirements

### Requirement: トークンの消去

利用者がトークンの消去を選んだとき、画面は確認を求めなければならない（MUST）。
確認には、次に開くとき、サーバーで表示したトークンをもう一度入力する必要があることを表示する。
利用者が確定したとき、画面は保存したトークンを消さなければならない（MUST）。

#### Scenario: 共用の端末で使い終える

- **WHEN** 設定の画面でトークンの消去を選び、確認で確定する
- **THEN** トークンの入力の画面に戻り、ブラウザーにトークンは残らない

#### Scenario: 消去をやめる

- **WHEN** 設定の画面でトークンの消去を選び、確認でやめる
- **THEN** 設定の画面のままで、ブラウザーにトークンが残る
