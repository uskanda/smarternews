# Spec Delta

## MODIFIED Requirements

### Requirement: フィルターの削除

利用者がフィルターの削除を選んだとき、画面は確認を求めなければならない（MUST）。
確認には、そのフィルターの要約と条件、一覧に戻る配信記事の件数（いま隠している件数）、削除せずに無効にもできることを表示する。一覧に戻る件数は、有効で1件以上を隠しているときだけ表示する。
画面は、利用者が確定するまでフィルターを削除してはならない（MUST NOT）。
利用者が確定したとき、画面はそのフィルターを削除し、一覧に戻った配信記事の件数を表示しなければならない（MUST）。

#### Scenario: フィルターを外す

- **WHEN** 配信記事を4件隠しているフィルターの削除を選び、確認で確定する
- **THEN** 確認には、そのフィルターの要約と、4件が一覧に戻ることが表示される。確定のあと、そのフィルターは一覧から消え、4件が一覧に戻ったことが表示される

#### Scenario: 削除をやめる

- **WHEN** フィルターの削除を選び、確認でやめる
- **THEN** そのフィルターは削除されず、一覧に残る

## ADDED Requirements

### Requirement: 設定ファイルの読み込みの確認

利用者が設定ファイルを選んで読み込みを選んだとき、画面は確認を求めなければならない（MUST）。
確認には、選んだファイルの名前と、次の3点を表示する。

- 一致するカテゴリ、トピック、購読フィードを更新すること
- ファイルにある読み手情報と全体設定を上書きすること
- 読み込みは元に戻せないので、先に書き出して控えを取れること

画面は、利用者が確定するまで設定ファイルを読み込んではならない（MUST NOT）。

#### Scenario: 確認を見てから読み込む

- **WHEN** 設定ファイルを選んで読み込みを選ぶ
- **THEN** 確認には、そのファイルの名前と、更新と上書きが起きること、元に戻せないことが表示され、確定するまで設定は何も変わらない

#### Scenario: 読み込みをやめる

- **WHEN** 設定ファイルを選んで読み込みを選び、確認でやめる
- **THEN** 設定は何も変わらず、作成と更新の件数は表示されない
