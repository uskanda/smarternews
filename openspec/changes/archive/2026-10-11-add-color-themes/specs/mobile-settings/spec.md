# Spec Delta

## ADDED Requirements

### Requirement: 配色の設定

設定の画面は、配色を「端末に従う」「ライト」「ダーク」「ダークブルー」から1つ選ぶ操作を表示しなければならない（MUST）。
選んだ配色は、その場でアプリの全体に適用する。

#### Scenario: 配色を選ぶ

- **WHEN** 設定の画面で配色に「ダーク」を選ぶ
- **THEN** 設定の画面と、戻った先の記事の一覧が「ダーク」で表示される

#### Scenario: 読み上げ

- **WHEN** 読み上げを使って配色の操作に移る
- **THEN** 4つの選択肢の名前と、どれが選ばれているかが読み上げられる
