# Spec Delta

## MODIFIED Requirements

### Requirement: 配色の切り替え

画面は、利用者が選んだ配色で表示しなければならない（MUST）。
選べる配色は、「ライト」「ダーク」「ダークブルー」と、「端末に従う」の4つである。
「端末に従う」のとき、画面は、端末が明るい配色を指定していれば「ライト」で、暗い配色を指定していれば「ダークブルー」で表示する。
利用者が1度も選んでいないとき、画面は「端末に従う」として扱う。
どの配色でも、本文と背景のコントラストはWCAG AAを満たす。

#### Scenario: 暗い配色の端末

- **WHEN** 配色を選んでいないブラウザーで、端末が暗い配色を指定している状態の画面を開く
- **THEN** 画面は「ダークブルー」で表示され、本文と背景のコントラストはWCAG AAを満たす

#### Scenario: 端末と違う配色を選ぶ

- **WHEN** 端末が明るい配色を指定している状態で、配色に「ダーク」を選ぶ
- **THEN** 画面は「ダーク」で表示され、本文と背景のコントラストはWCAG AAを満たす

#### Scenario: 端末に従うに戻す

- **WHEN** 配色に「ダーク」を選んだあとで「端末に従う」を選び、端末が明るい配色を指定している
- **THEN** 画面は「ライト」で表示される

## ADDED Requirements

### Requirement: 配色の選択の保存

画面は、利用者が選んだ配色をブラウザーに保存し、次に開いたときも同じ配色で表示しなければならない（MUST）。
保存できないブラウザーでは、画面は「端末に従う」で表示する。

#### Scenario: 再読み込み

- **WHEN** 配色に「ダーク」を選んでから、画面を再読み込みする
- **THEN** 画面は「ダーク」で表示される

### Requirement: 読み込みの途中の配色

画面は、選んだ配色を、最初の描画より前に適用しなければならない（MUST）。

#### Scenario: 暗い配色を選んだブラウザーで開く

- **WHEN** 端末が明るい配色を指定している状態で、配色に「ダーク」を保存済みのブラウザーが画面を開く
- **THEN** 画面は、明るい配色を1度も描かずに「ダーク」で表示される

### Requirement: 配色によらない表示

接続用のQRコードは、どの配色でも白地に黒で表示しなければならない（MUST）。

#### Scenario: 暗い配色でQRコードを出す

- **WHEN** 配色に「ダーク」を選んだ状態で、接続用のQRコードを表示する
- **THEN** QRコードは白地に黒で表示される
