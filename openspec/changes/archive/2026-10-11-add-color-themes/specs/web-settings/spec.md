# Spec Delta

## ADDED Requirements

### Requirement: 配色の選択の操作

設定の画面は、配色を「端末に従う」「ライト」「ダーク」「ダークブルー」から1つ選ぶ操作を表示しなければならない（MUST）。
選んだ配色は、保存の操作を待たずに、その場で画面に適用する。
この操作は、選んだ配色がこのブラウザーだけに保存されることを伝える。

#### Scenario: 配色を選ぶ

- **WHEN** 設定の画面で配色に「ダークブルー」を選ぶ
- **THEN** 画面はすぐに「ダークブルー」で表示され、操作は「ダークブルー」が選ばれた状態になる

#### Scenario: 選んでいないとき

- **WHEN** 配色を1度も選んでいないブラウザーで設定の画面を開く
- **THEN** 操作は「端末に従う」が選ばれた状態で表示される

#### Scenario: キーボードで選ぶ

- **WHEN** 配色の操作にフォーカスして、矢印キーで「ライト」へ移る
- **THEN** 画面は「ライト」で表示される
