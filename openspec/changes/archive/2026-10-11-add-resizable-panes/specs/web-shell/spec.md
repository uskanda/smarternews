# Spec Delta

## ADDED Requirements

### Requirement: ペインの幅の変更

利用者がペインの境目をドラッグしたとき、画面は、その境目の左にあるペインの幅を、ドラッグした距離だけ変えなければならない（MUST）。
対象は、項目の一覧のペインと、記事の一覧のペインである。

#### Scenario: 項目の一覧を広げる

- **WHEN** 幅1280pxの画面で、項目の一覧と記事の一覧の境目を右へ60pxドラッグする
- **THEN** 項目の一覧の幅は260pxになり、記事の一覧の幅は変わらない

#### Scenario: 記事の一覧を狭める

- **WHEN** 幅1280pxの画面で、記事の一覧と本文の境目を左へ50pxドラッグする
- **THEN** 記事の一覧の幅は330pxになる

### Requirement: キーボードでの幅の変更

境目にフォーカスがある間、左右の矢印キーが押されたとき、画面は、その境目の左にあるペインの幅を16pxずつ変えなければならない（MUST）。

#### Scenario: 矢印キーで広げる

- **WHEN** 項目の一覧の境目にフォーカスして、右の矢印キーを2回押す
- **THEN** 項目の一覧の幅は232pxになる

### Requirement: 幅の範囲

画面は、項目の一覧のペインの幅を160pxから400pxの範囲に、記事の一覧のペインの幅を280pxから640pxの範囲に保たなければならない（MUST）。

#### Scenario: 範囲を超えてドラッグする

- **WHEN** 項目の一覧の境目を、右へ500pxドラッグする
- **THEN** 項目の一覧の幅は400pxで止まる

### Requirement: 本文の幅の確保

ペインの幅が変えられたとき、または画面の幅が変わったとき、画面は、本文のペインの幅を360px未満にしてはならない（MUST NOT）。

#### Scenario: 広げたあとで画面を狭める

- **WHEN** 記事の一覧を640pxに広げたあと、画面の幅を1100pxにする
- **THEN** 本文のペインの幅は360px以上で、横方向のスクロールは発生しない

### Requirement: 既定の幅への復帰

利用者が境目をダブルクリックしたとき、画面は、その境目の左にあるペインを既定の幅に戻さなければならない（MUST）。

#### Scenario: 既定の幅に戻す

- **WHEN** 項目の一覧を300pxに広げたあと、その境目をダブルクリックする
- **THEN** 項目の一覧の幅は200pxになる

### Requirement: 幅の保存

ペインの幅が変えられたとき、画面は、その幅をブラウザーに保存し、次に開いたときも同じ幅で表示しなければならない（MUST）。

#### Scenario: 再読み込みする

- **WHEN** 項目の一覧を260pxに広げ、ブラウザーを再読み込みする
- **THEN** 項目の一覧は260pxで表示される

### Requirement: 境目の伝達

画面は、境目を、名前と現在の幅を持つ区切りとして、読み上げの機能に伝えなければならない（MUST）。

#### Scenario: 境目を読み上げる

- **WHEN** 項目の一覧の境目にフォーカスする
- **THEN** 名前「項目の一覧の幅」と、現在の幅、最小と最大の幅が伝わる

### Requirement: 1つのペインだけの画面での非表示

画面の幅が狭く、1つのペインだけを表示している間、画面は境目を表示してはならない（MUST NOT）。

#### Scenario: 狭い画面

- **WHEN** 幅390pxの画面で記事の一覧を表示する
- **THEN** 境目は表示されず、一覧は画面の幅いっぱいに表示される
