# Spec Delta

## ADDED Requirements

### Requirement: 接続用のQRコードの表示

利用者が接続用のQRコードを表示する操作をしたとき、画面は、開いているサーバーのURLとAPIのトークンを含むQRコードを表示しなければならない（MUST）。

#### Scenario: アプリをつなぐ

- **WHEN** 設定の画面で接続用のQRコードを表示し、Androidアプリで読み取る
- **THEN** アプリは、同じサーバーの未読の一覧を表示する

### Requirement: 操作の前のQRコードの非表示

利用者が表示する操作をするまで、画面は、接続用のQRコードを表示してはならない（MUST NOT）。

#### Scenario: 設定の画面を開いただけ

- **WHEN** 設定の画面を開く
- **THEN** 接続用のQRコードは表示されず、表示するためのボタンと、QRコードがトークンを含むことの説明が表示される
