# Spec Delta

## ADDED Requirements

### Requirement: 本文の下の抜き出した名前の表示

抜き出した名前のある記事が選ばれたとき、画面は、本文の下に抜き出した名前の区画を表示しなければならない（MUST）。
区画では、名前を種類ごとに分け、人、組織、製品、地名の順に、種類の見出しを付けて並べる。同じ種類の中は、保存した順に並べる。
生成記事と配信記事のどちらにも表示する。配信記事では、全文、配信された内容、訳のどれを表示している間も、内容の下に表示する。

#### Scenario: 2つの種類の名前を持つ記事

- **WHEN** 組織の名前を2件と人の名前を1件抜き出した生成記事を選ぶ
- **THEN** 本文の下に、「人」の見出しと1件の名前、「組織」の見出しと2件の名前が、この順で表示される

#### Scenario: 名前のない種類

- **WHEN** 製品の名前を1件も抜き出していない記事を選ぶ
- **THEN** 区画に「製品」の見出しは表示されない

#### Scenario: 訳を表示している配信記事

- **WHEN** 抜き出した名前のある配信記事で、本文の訳を表示する
- **THEN** 抜き出した名前の区画は、訳と原文の下に表示される

### Requirement: 抜き出した名前のない記事の表示

抜き出した名前のない記事が選ばれたとき、画面は、抜き出した名前の区画とその見出しを表示してはならない（MUST NOT）。

#### Scenario: 機能を入れる前の記事

- **WHEN** 機能を入れる前に保存した生成記事を選ぶ
- **THEN** 本文の下に、抜き出した名前の区画は表示されない

### Requirement: 抜き出した名前の安全な表示

画面は、抜き出した名前を、HTMLのタグとMarkdownの記法として解釈せずに、文字として表示しなければならない（MUST）。

#### Scenario: タグの文字列を含む名前

- **WHEN** `<script>` のタグの文字列を含む名前を抜き出した記事を選ぶ
- **THEN** その文字列は文字として表示され、スクリプトは実行されない

### Requirement: 名前を押したときの一覧

本文の下の名前が押されたとき、画面は、中央のペインにその名前の記事の一覧を表示しなければならない（MUST）。
本文のペインには、名前を押した記事を表示したまま残す。一覧の上部には、名前を表示する。
左のペインでは、どの項目も選ばれていない状態にする。

#### Scenario: 名前を押す

- **WHEN** カテゴリAの記事を読み、本文の下の名前の日本銀行を押す
- **THEN** 中央のペインに日本銀行という名前の記事の一覧が表示され、一覧の上部にその名前が表示され、本文のペインには元の記事が残る

#### Scenario: 一覧から別の記事を開く

- **WHEN** 名前の記事の一覧で、別の記事を選ぶ
- **THEN** 本文のペインにその記事が表示され、中央のペインには同じ名前の記事の一覧が残る

### Requirement: 名前の記事の一覧の1行

名前の記事の一覧で、画面は、各記事を記事の一覧と同じ1行で表示しなければならない（MUST）。
生成記事と配信記事は1つの一覧に混ぜ、最終更新の新しい順に並べる。

#### Scenario: 由来の違う記事

- **WHEN** 名前として日本銀行を抜き出した生成記事と配信記事が1件ずつある状態で、その名前を押す
- **THEN** 生成記事の行と配信記事の行が、記事の一覧と同じ形で、最終更新の新しい順に表示される

### Requirement: 名前の記事の一覧で出さない操作

名前の記事の一覧を表示している間、画面は、一括の既読、既読を含める切り替え、重要度4以上の切り替え、並び順のメニューを表示してはならない（MUST NOT）。
一覧は、既読の記事も含めて表示する。

#### Scenario: 一覧の上部を見る

- **WHEN** 本文の下の名前を押して、名前の記事の一覧を開く
- **THEN** 一覧の上部に、一括の既読、既読を含める切り替え、重要度4以上の切り替え、並び順のメニューは表示されない

#### Scenario: キーで一括の既読を試す

- **WHEN** 未読を含む名前の記事の一覧で `Shift+A` を押す
- **THEN** 何も既読にならない

### Requirement: 名前の記事の一覧をスクロールしても既読にしないこと

名前の記事の一覧を表示している間、画面は、一覧を送ったことで記事を既読にしてはならない（MUST NOT）。

#### Scenario: 一覧を送る

- **WHEN** スクロールで既読にする設定を有効にした状態で、未読を含む名前の記事の一覧を末尾まで送る
- **THEN** 一覧の記事はどれも未読のまま残る

### Requirement: 名前の記事の一覧に記事がないときの表示

名前の記事の一覧に入る記事が1件もないとき、画面は、その名前を含む記事のないことを表示しなければならない（MUST）。

#### Scenario: 記事が削除されたあとでURLを開く

- **WHEN** 名前として日本銀行を抜き出した唯一の記事が保存期間で削除されたあと、その名前の記事の一覧のURLを開く
- **THEN** 中央のペインに、日本銀行を含む記事のないことが表示される
