# Spec Delta

## ADDED Requirements

### Requirement: 抜き出した名前を照合しないこと

サーバーは、記事の抜き出した名前を、検索語と照合してはならない（MUST NOT）。
抜き出した名前は、照合する欄に含めない。

#### Scenario: 抜き出した名前にだけある語

- **WHEN** 本文に日銀とだけ書き、抜き出した名前が日本銀行で、ほかの欄に日本銀行を含まない配信記事がある状態で、日本銀行を検索する
- **THEN** その配信記事は結果に含まれない

#### Scenario: 本文にもある語

- **WHEN** 本文に日本銀行と書き、抜き出した名前も日本銀行の生成記事がある状態で、日本銀行を検索する
- **THEN** その生成記事は、本文に一致して結果に含まれる
