# Spec Delta

## MODIFIED Requirements

### Requirement: 別のカテゴリへの購読フィードの移動

ドラッグ中の購読フィードが別のカテゴリの上で0.5秒とどまったとき、画面は、そのカテゴリの中へ置けるようにしなければならない（MUST）。
そのカテゴリが折りたたまれているときは、開く。
0.5秒より前に離したとき、画面は購読フィードを動かしてはならない（MUST NOT）。
イベントのカテゴリは、置ける先にしない。

#### Scenario: とどまってから離す

- **WHEN** カテゴリAの購読フィードXをカテゴリBの上へドラッグし、0.5秒とどまってから、カテゴリBの中で離す
- **THEN** 購読フィードXはカテゴリBの下に表示され、カテゴリAの下からは消える

#### Scenario: とどまらずに離す

- **WHEN** カテゴリAの購読フィードXをカテゴリBの上へドラッグし、すぐに離す
- **THEN** 購読フィードXはカテゴリAの下の元の位置に表示される

#### Scenario: 「未分類」へ動かす

- **WHEN** カテゴリAの購読フィードXを「未分類」の上へドラッグし、0.5秒とどまってから離す
- **THEN** 購読フィードXは「未分類」の下に表示される

## ADDED Requirements

### Requirement: ドラッグ中の項目の表示

カテゴリまたは購読フィードをドラッグしている間、画面は、その項目の名前を四角で囲んで、ポインターのそばに表示しなければならない（MUST）。
この表示は、ポインターに付いて動く。ドラッグを終えたときと取りやめたとき、画面はこの表示を消す。
この表示は、読み上げの対象にしない。

#### Scenario: 購読フィードを掴む

- **WHEN** 購読フィードXを押して、4px以上動かす
- **THEN** 四角で囲んだ「X」の名前が、ポインターのそばに表示される

#### Scenario: 離す

- **WHEN** ドラッグ中の項目を離す
- **THEN** 四角の表示は消える

### Requirement: 置く先のカテゴリの強調

ドラッグ中の購読フィードが、購読フィードを置けるカテゴリの上にある間、画面は、そのカテゴリを配下の項目ごと太い枠で囲まなければならない（MUST）。
枠は、とどまる時間を待たずに表示する。「未分類」も同じように囲む。
購読フィードを置けないカテゴリには、枠を表示しない。カテゴリをドラッグしている間も、枠を表示しない。

#### Scenario: 別のカテゴリの上へ動かした直後

- **WHEN** カテゴリAの購読フィードXを、カテゴリBの上へドラッグする
- **THEN** カテゴリBが、すぐに太い枠で囲まれる

#### Scenario: 自分のカテゴリの上

- **WHEN** カテゴリAの購読フィードXを、カテゴリAの中でドラッグする
- **THEN** カテゴリAが、置ける状態の色の太い枠で囲まれる

#### Scenario: イベントのカテゴリの上

- **WHEN** 購読フィードXを、イベントのカテゴリの上へドラッグする
- **THEN** どのカテゴリにも枠は表示されない

### Requirement: 置けるようになったことの知らせ

別のカテゴリの上で0.5秒とどまり、置けるようになったとき、画面は、そのカテゴリの枠の色を変え、枠を2回点滅させなければならない（MUST）。
動きを減らす設定の端末では、画面は枠を点滅させず、色の変化だけで示す。

#### Scenario: 0.5秒とどまる

- **WHEN** カテゴリAの購読フィードXをカテゴリBの上へドラッグし、0.5秒とどまる
- **THEN** カテゴリBの枠の色が変わり、枠が2回点滅する

#### Scenario: 動きを減らす設定

- **WHEN** 動きを減らす設定の端末で、購読フィードXをカテゴリBの上へドラッグし、0.5秒とどまる
- **THEN** カテゴリBの枠は点滅せず、色だけが変わる
