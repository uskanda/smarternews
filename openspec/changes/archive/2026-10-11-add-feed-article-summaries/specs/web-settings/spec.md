# Spec Delta

## ADDED Requirements

### Requirement: 自動の要約の切り替え

購読フィードの追加と編集の画面は、自動で要約するかどうかの切り替えを表示し、保存できるようにしなければならない（MUST）。
切り替えのそばに、要約にLLMを使うことと、これから届く記事だけが対象になることを説明する。

#### Scenario: 編集で有効にする

- **WHEN** 購読フィードの編集で、自動で要約する切り替えを入れて保存する
- **THEN** 購読フィードの一覧で、その購読フィードに自動で要約する印が表示される

#### Scenario: 説明

- **WHEN** 購読フィードの編集の画面を開く
- **THEN** 切り替えのそばに、LLMを使うことと、これから届く記事だけを要約することが表示される
