# Spec Delta

## MODIFIED Requirements

### Requirement: 入力中のキー操作の無効化

文字を入力する欄にフォーカスがある間、画面は1文字のキーによる操作を受け付けてはならない（MUST NOT）。
文字を入力する欄は、1行の入力欄、複数行の入力欄、編集できる領域である。

#### Scenario: トピックの文章を入力する

- **WHEN** トピックの文章の入力欄で `s` を含む文字を入力する
- **THEN** 文字は入力欄に入り、スターの切り替えは起きない

## ADDED Requirements

### Requirement: 文字を入力しない部品でのキー操作

チェックボックス、選択欄、ボタンのように文字を入力しない部品にフォーカスがある間、画面は1文字のキーによる操作を受け付けなければならない（MUST）。

#### Scenario: チェックボックスを押したあとで次の記事へ移る

- **WHEN** 一覧の上の「既読も表示」をマウスで押し、続けて `j` を押す
- **THEN** 次の記事が開く

#### Scenario: 選択欄を選んだあとで次の記事へ移る

- **WHEN** 検索の結果の画面で、絞り込みの選択欄から購読フィードを選び、続けて `j` を押す
- **THEN** 次の記事が開き、絞り込みは変わらない

### Requirement: フォーカスのある部品でのSpace

チェックボックス、選択欄、ボタンにフォーカスがある間、`Space` が押されたとき、画面は本文の送りと記事の移動をしてはならない（MUST NOT）。

#### Scenario: チェックボックスでSpaceを押す

- **WHEN** 一覧の上の「重要度4以上だけ」にフォーカスがある状態で `Space` を押す
- **THEN** 切り替えが入り、本文は送られない

### Requirement: メニューを開いている間のキー操作の無効化

左のペインの項目のメニューを開いている間、画面は1文字のキーによる記事と項目の操作を受け付けてはならない（MUST NOT）。
メニューの中の矢印キー、Enter、Escapeは、メニューの操作に使う。

#### Scenario: メニューを開いて次の記事のキーを押す

- **WHEN** 購読フィードの項目のメニューを開いた状態で `j` を押す
- **THEN** 選んでいる記事は変わらず、メニューは開いたままである

### Requirement: 狭い画面の左のペインでのキー操作

狭い画面で左のペインを開いている間、画面は、項目と画面を移るキーのほかの1文字のキーによる操作を受け付けてはならない（MUST NOT）。
受け付けるキーは、`Shift+J`、`Shift+K`、`g` に続くキー、`/`、`?` である。

#### Scenario: 左のペインでSpaceを押す

- **WHEN** 狭い画面で記事を開いたまま左のペインを開き、項目にフォーカスを置いて `Space` を押す
- **THEN** 背後の記事は変わらない

#### Scenario: 左のペインでスターを切り替えようとする

- **WHEN** 狭い画面で記事を開いたまま左のペインを開き、`s` を押す
- **THEN** 背後の記事のスターは切り替わらない

#### Scenario: 左のペインで次の項目へ移る

- **WHEN** 狭い画面で左のペインを開き、`Shift+J` を押す
- **THEN** 左のペインの次の項目の一覧が開く

### Requirement: 操作のある知らせの表示時間

操作のある知らせにマウスが載っているか、知らせの中にフォーカスがある間、画面はその知らせを消してはならない（MUST NOT）。

#### Scenario: 知らせにマウスを載せたまま待つ

- **WHEN** 一括の既読の直後、知らせにマウスを載せたまま、知らせの表示時間より長く待つ
- **THEN** 知らせは表示されたままである

#### Scenario: 知らせのボタンにフォーカスを置いたまま待つ

- **WHEN** 一括の既読の直後、知らせの「取り消す」にフォーカスを置いたまま、知らせの表示時間より長く待つ
- **THEN** 知らせは表示されたままである

### Requirement: 知らせの操作のキー

操作のある知らせを表示している間、`z` が押されたとき、画面はその知らせの操作を選んだときと同じ操作をしなければならない（MUST）。

#### Scenario: キーで一括の既読を取り消す

- **WHEN** 一括の既読の直後に `z` を押す
- **THEN** 既読になった記事が未読に戻り、知らせは消える

#### Scenario: 知らせがないときに押す

- **WHEN** 知らせが出ていない状態で `z` を押す
- **THEN** 何も起きない
