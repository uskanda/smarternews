## ADDED Requirements

### Requirement: 全文の自動の取得の設定の提供

APIは、購読フィードの一覧、登録、変更で、全文の自動の取得の設定を扱わなければならない（MUST）。

#### Scenario: 変更して確かめる

- **WHEN** 購読フィードの変更で全文の自動の取得を有効にしてから、購読フィードの一覧を要求する
- **THEN** その購読フィードは、全文の自動の取得が有効として返る

### Requirement: 配信記事の全文の提供

APIは、記事の詳細で、配信記事の全文を、配信された内容とは別の項目として返さなければならない（MUST）。
全文があるときは、全文のMarkdown、表示のためのHTML、取得した時刻を返す。
全文がないときは、全文がないことを返す。

#### Scenario: 全文のある配信記事

- **WHEN** 全文を保存した配信記事の詳細を要求する
- **THEN** 応答に、配信された内容と、全文のMarkdown、HTML、取得した時刻が含まれる

#### Scenario: 全文のない記事

- **WHEN** 全文のない配信記事、または生成記事の詳細を要求する
- **THEN** 応答の全文は、ないことを示す値である

### Requirement: 全文の取得の状態の提供

APIは、記事の詳細で、配信記事の全文の取得の状態を返さなければならない（MUST）。
状態は、未取得、全文を待っている、取得済み、失敗のいずれかである。
失敗のときは、失敗の理由を返す。

#### Scenario: 全文を待つ配信記事

- **WHEN** 全文の自動の取得が有効な購読フィードで保存されたばかりの配信記事の詳細を要求する
- **THEN** 応答は、その記事が全文を待っていることを示す

#### Scenario: 失敗した配信記事

- **WHEN** 記事のURLが404を返したために全文の取得に失敗した配信記事の詳細を要求する
- **THEN** 応答は、失敗の状態と、HTTPステータス404を返したという理由を示す

### Requirement: 全文を取得する操作

APIは、配信記事の全文を取得する操作を提供しなければならない（MUST）。
操作は、取得が終わってから応答する。
応答は、取得した全文と取得した時刻、または失敗とその理由を示す。

#### Scenario: 取得して受け取る

- **WHEN** 全文のない配信記事について、全文を取得する操作を呼び、ページから本文を取り出せる
- **THEN** 応答に全文が含まれ、そのあとの記事の詳細は取得済みの状態と全文を返す

#### Scenario: 取得に失敗する

- **WHEN** 記事のURLの取得を `robots.txt` が禁じている配信記事について、全文を取得する操作を呼ぶ
- **THEN** 応答は失敗と、`robots.txt` が禁じているという理由を示し、記事の内容は変わらない

#### Scenario: 対象でない記事

- **WHEN** 生成記事について、全文を取得する操作を呼ぶ
- **THEN** APIは、入力が不正であることを示す応答を返す

#### Scenario: 存在しない記事

- **WHEN** 存在しない記事について、全文を取得する操作を呼ぶ
- **THEN** APIは、対象が存在しないことを示す応答を返す
