# Spec Delta

## MODIFIED Requirements

### Requirement: フィルターの適用先の説明

画面は、フィルターの追加の操作の近くに、次の3つを表示しなければならない（MUST）。

- 配信記事だけを隠すこと
- スターまたは注釈のある記事は隠さないこと
- 隠すフィルターと残すフィルターの両方に当たる記事は隠すこと

#### Scenario: 追加の前に確かめる説明

- **WHEN** フィルターの設定の画面を開く
- **THEN** 追加の操作の近くに、その3つの説明が表示されている

## ADDED Requirements

### Requirement: 削除で消える注釈のある配信記事の件数の表示

利用者が購読フィードの削除を選んだとき、画面は確認の中に、その購読フィードの配信記事のうち、注釈のある配信記事の件数を表示しなければならない（MUST）。
その配信記事と注釈も、購読フィードとともに消えることを示す。注釈のある配信記事がないときは、注釈について何も表示しない。

#### Scenario: 注釈のある配信記事を持つ購読フィード

- **WHEN** 40件の配信記事を持ち、うち3件に注釈のある購読フィードの削除を選ぶ
- **THEN** 確認には、注釈のある3件も注釈とともに消えることが表示され、確定するまで削除されない

#### Scenario: 注釈のない購読フィード

- **WHEN** 注釈のある配信記事を持たない購読フィードの削除を選ぶ
- **THEN** 確認には、注釈についての表示が加わらない
