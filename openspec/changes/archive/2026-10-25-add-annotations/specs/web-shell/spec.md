# Spec Delta

## ADDED Requirements

### Requirement: キーボードでのハイライト

本文の原文の文字を選んでいる間、`h` のキーが押されたとき、画面は、選んだ範囲にメモのないハイライトを付けなければならない（MUST）。
文字を選ぶ方法は、マウスでも、キーボードでもよい。

#### Scenario: 選んでから押す

- **WHEN** 本文の1文を選んだ状態で `h` を押す
- **THEN** その1文がハイライトされ、注釈の一覧にその1文の行が加わる

#### Scenario: 何も選ばずに押す

- **WHEN** 本文の文字を何も選んでいない状態で `h` を押す
- **THEN** ハイライトは増えず、画面の表示は変わらない

### Requirement: ハイライトを付けられない範囲でのキーの無効

ハイライトを付けられない範囲を選んでいる間、`h` のキーが押されたとき、画面は、ハイライトを付けてはならない（MUST NOT）。
付けられない範囲は、文字を選んだときのメニューを出さない範囲と、既存のハイライトと重なる範囲である。

#### Scenario: 訳を選んで押す

- **WHEN** 本文の訳のある配信記事で、訳のまとまりの1文を選んで `h` を押す
- **THEN** ハイライトは増えない

### Requirement: キーボードだけでの注釈の操作

画面は、本文のハイライトにTabキーでフォーカスを当てられるようにし、フォーカスのあるハイライトで `Enter` が押されたとき、そのハイライトの操作を表示しなければならない（MUST）。
操作を閉じたとき、フォーカスはそのハイライトに戻す。

#### Scenario: キーボードでメモを書く

- **WHEN** Tabキーで本文のハイライトにフォーカスを当てて `Enter` を押し、メモを書く操作を選んでメモを保存する
- **THEN** そのハイライトにメモが付き、フォーカスはそのハイライトに戻る

### Requirement: 「注釈」を動かせないこと

画面は、左のペインの「注釈」をドラッグで動かせるようにしてはならない（MUST NOT）。
ほかの項目のドラッグで、「注釈」の位置を変えてはならない。

#### Scenario: 「注釈」をドラッグしようとする

- **WHEN** 左のペインの「注釈」の上でマウスのボタンを押したまま動かす
- **THEN** ドラッグは始まらず、「注釈」は「最近読んだ記事」の下にとどまる
