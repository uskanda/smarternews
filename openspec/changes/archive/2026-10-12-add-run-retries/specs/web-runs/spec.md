# Spec Delta

## ADDED Requirements

### Requirement: やり直しの表示

実行履歴の一覧と詳細で、画面は、やり直しの実行に、何回目のやり直しかを表示しなければならない（MUST）。
詳細では、元の実行へ移る操作を表示する。

#### Scenario: やり直しの行

- **WHEN** 1回目のやり直しを含む実行履歴の一覧を開く
- **THEN** その行に、1回目のやり直しであることが表示される

#### Scenario: 元の実行へ移る

- **WHEN** やり直しの実行の詳細で、元の実行へ移る操作を選ぶ
- **THEN** 元の定時の実行の詳細が表示される

### Requirement: やり直しの予定の表示

失敗した実行の詳細で、画面は、やり直しの予定があるときはその時刻を表示しなければならない（MUST）。
予定がないときは、その理由を表示する。理由は次の4つのいずれかである。
上限に達した。次の定時の実行が先に始まった。カテゴリが無効になった。手動の実行である。

#### Scenario: やり直しを待つ実行

- **WHEN** 失敗して、やり直しを待っている実行の詳細を開く
- **THEN** やり直しの予定の時刻が表示される

#### Scenario: 上限に達した実行

- **WHEN** 最後のやり直しが失敗した実行の詳細を開く
- **THEN** やり直しの上限に達したことと、次の実行が次の定時であることが表示される

#### Scenario: 手動の実行の失敗

- **WHEN** 失敗した手動の実行の詳細を開く
- **THEN** 自動ではやり直さないことが表示される
