# Spec Delta

## ADDED Requirements

### Requirement: 一括の既読のあとに移る設定の編集

全体設定の画面は、一括の既読のあとに次の項目へ移る設定を、切り替えとして表示し、保存できるようにしなければならない（MUST）。

#### Scenario: 有効にして保存する

- **WHEN** 全体設定の画面でこの切り替えを入れて保存する
- **THEN** 記事を読む画面の一括の既読は、次の項目へ移るようになる

### Requirement: 設定の画面での並び順

カテゴリの一覧の画面と購読フィードの一覧の画面は、左のペインと同じ並び順で項目を表示しなければならない（MUST）。

#### Scenario: 並べ替えたあとに設定を開く

- **WHEN** 左のペインでカテゴリBをカテゴリAの上へ動かしてから、カテゴリの一覧の画面を開く
- **THEN** カテゴリB、カテゴリAの順に表示される
