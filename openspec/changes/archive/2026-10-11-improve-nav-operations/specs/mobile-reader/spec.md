# Spec Delta

## ADDED Requirements

### Requirement: 一括の既読のあとの次の項目への移動

一括の既読のあとに次の項目へ移る設定が有効なとき、アプリは、一括の既読のあとに、引き出しの表示順でいまの項目より下にある、未読が1件以上の最初の項目を開かなければならない（MUST）。
カテゴリの一覧からは、次のカテゴリか「未分類」へ移る。
購読フィードの一覧と各カテゴリの「AI生成」の一覧からは、カテゴリをまたいで、次の購読フィードまたは「AI生成」へ移る。
当たる項目がないとき、および「未読」「すべて」「スター」「AI生成」の一覧では、アプリは移らない。

#### Scenario: 次のカテゴリへ移る

- **WHEN** カテゴリA、B、Cが並び、Bに未読がなくCに未読がある状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** カテゴリCの一覧が開く

#### Scenario: 設定が無効

- **WHEN** この設定が無効な状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** アプリはカテゴリAの一覧のままである

#### Scenario: 移ったあとに取り消す

- **WHEN** 一括の既読で次の項目へ移ったあと、取り消しを選ぶ
- **THEN** 既読にした記事は未読に戻る
