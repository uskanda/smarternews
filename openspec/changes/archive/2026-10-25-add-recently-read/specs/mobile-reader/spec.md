# Spec Delta

## ADDED Requirements

### Requirement: 最近読んだ記事の一覧

引き出しの「最近読んだ記事」が選ばれたとき、アプリは、既読の時刻が直近7日以内の記事を、既読の時刻の新しい順に表示しなければならない（MUST）。
開いた記事、行を払って既読にした記事、一括の既読で既読にした記事のどれも表示する。生成記事と配信記事は1つの一覧に混ぜる。
この機能を入れる前から既読の記事は表示しない。

#### Scenario: 一括の既読の押し間違いを探す

- **WHEN** 記事Aを開いて読み、そのあとカテゴリBで一括の既読を選んで3件を既読にしてから、「最近読んだ記事」を選ぶ
- **THEN** 一括の既読で既読になった3件が先に、記事Aがそのあとに表示される

#### Scenario: 8日前に読んだ記事

- **WHEN** 既読の時刻が8日前の記事がある状態で、「最近読んだ記事」を選ぶ
- **THEN** その記事は表示されない

### Requirement: 最近読んだ記事の一覧の1行

アプリは、最近読んだ記事の一覧の各行に、更新の時刻の代わりに既読の時刻を表示しなければならない（MUST）。
生成記事の行と配信記事の行のどちらにも適用する。ほかの一覧の行の時刻は変えない。

#### Scenario: 昨日更新された記事を今日読んだ

- **WHEN** 昨日の18時に更新された記事を今日の9時に開いて読み、「最近読んだ記事」を選ぶ
- **THEN** その行の時刻には、今日の9時が表示される

### Requirement: 最近読んだ記事の一覧での未読への切り替え

最近読んだ記事の一覧で記事を未読に戻したとき、アプリは、利用者が一覧を更新するまで、その行を未読の表示で一覧に残さなければならない（MUST）。
一覧を更新したあとは、その行を表示しない。
未読に戻す操作は、行を払う操作、行の長押しの操作、本文の画面の未読に戻す操作のどれでもよい。

#### Scenario: 行を払って戻す

- **WHEN** 最近読んだ記事の一覧で、記事の行を左へ払う
- **THEN** その記事は未読になり、行は未読の表示で同じ位置に残る

#### Scenario: 戻したあとで引いて更新する

- **WHEN** 最近読んだ記事の一覧で記事を未読に戻し、一覧を引いて更新する
- **THEN** その記事は一覧に表示されない

### Requirement: 最近読んだ記事の一覧で出さない操作

最近読んだ記事の一覧を表示している間、アプリは、一括の既読、既読を含める切り替え、重要度4以上の切り替えを表示してはならない（MUST NOT）。

#### Scenario: 一覧の上部を見る

- **WHEN** 引き出しで「最近読んだ記事」を選ぶ
- **THEN** 一括の既読、既読を含める切り替え、重要度4以上の切り替えは表示されない

### Requirement: 最近読んだ記事がないときの表示

最近読んだ記事の一覧に当たる記事がないとき、アプリは、直近7日に読んだ記事がないことと、「未読」を開く操作を表示しなければならない（MUST）。

#### Scenario: 7日間読んでいない

- **WHEN** 直近7日の間に1件も既読にしていない状態で、「最近読んだ記事」を選ぶ
- **THEN** 直近7日に読んだ記事がないことと、「未読」を開く操作が表示される
