# Spec Delta

## ADDED Requirements

### Requirement: 「最近読んだ記事」の項目

画面は、左のペインの「AI生成」の下に、「最近読んだ記事」の項目を、数字を付けずに常に表示しなければならない（MUST）。

#### Scenario: 左のペインを見る

- **WHEN** 画面を開く
- **THEN** 左のペインの上部に「未読」「すべて」「スター」「AI生成」「最近読んだ記事」の順で項目が並び、「最近読んだ記事」の横に数字はない

### Requirement: 最近読んだ記事の一覧

左のペインの「最近読んだ記事」が選ばれたとき、画面は、既読の時刻が直近7日以内の記事を、既読の時刻の新しい順に表示しなければならない（MUST）。
開いた記事、手で既読にした記事、一括の既読で既読にした記事のどれも表示する。生成記事と配信記事は1つの一覧に混ぜる。
この機能を入れる前から既読の記事は表示しない。

#### Scenario: 一括の既読の押し間違いを探す

- **WHEN** 記事Aを開いて読み、そのあとカテゴリBで一括の既読を選んで3件を既読にしてから、「最近読んだ記事」を選ぶ
- **THEN** 一括の既読で既読になった3件が先に、記事Aがそのあとに表示される

#### Scenario: 8日前に読んだ記事

- **WHEN** 既読の時刻が8日前の記事がある状態で、「最近読んだ記事」を選ぶ
- **THEN** その記事は表示されない

### Requirement: 最近読んだ記事の一覧の1行

画面は、最近読んだ記事の一覧の各行に、更新の時刻の代わりに既読の時刻を表示しなければならない（MUST）。
生成記事の行と配信記事の行のどちらにも適用する。ほかの一覧の行の時刻は変えない。

#### Scenario: 昨日更新された記事を今日読んだ

- **WHEN** 昨日の18時に更新された記事を今日の9時に開いて読み、「最近読んだ記事」を選ぶ
- **THEN** その行の時刻には、今日の9時が表示される

### Requirement: 最近読んだ記事の一覧での未読への切り替え

最近読んだ記事の一覧で記事を未読に戻したとき、画面は、利用者が別の項目へ移るか更新を選ぶまで、その行を未読の見た目で一覧に残さなければならない（MUST）。
別の項目へ移ったあと、または更新のあとは、その行を表示しない。

#### Scenario: 誤って既読にした記事を戻す

- **WHEN** 最近読んだ記事の一覧で記事を選び、未読に戻す操作を選ぶ
- **THEN** その記事は未読になり、左のペインの未読数が1つ増え、行は未読の見た目で一覧に残る

#### Scenario: 戻したあとで更新する

- **WHEN** 最近読んだ記事の一覧で記事を未読に戻し、更新を選ぶ
- **THEN** その記事は一覧に表示されない

### Requirement: 最近読んだ記事の一覧で出さない操作

最近読んだ記事の一覧を表示している間、画面は、一括の既読、既読を含める切り替え、重要度4以上の切り替えを表示してはならない（MUST NOT）。

#### Scenario: 一覧の上部を見る

- **WHEN** 左のペインで「最近読んだ記事」を選ぶ
- **THEN** 一覧の上部に、一括の既読、既読を含める切り替え、重要度4以上の切り替えは表示されない

### Requirement: 最近読んだ記事がないときの表示

最近読んだ記事の一覧に当たる記事がないとき、画面は、直近7日に読んだ記事がないことと、「未読」を開く操作を表示しなければならない（MUST）。

#### Scenario: 7日間読んでいない

- **WHEN** 直近7日の間に1件も既読にしていない状態で、「最近読んだ記事」を選ぶ
- **THEN** 直近7日に読んだ記事がないことと、「未読」を開く操作が表示される
