## ADDED Requirements

### Requirement: 画面の上部の予算の警告

予算の期間の合計が、月の予算に警告の割合を掛けた金額以上の間、画面は、どの画面を開いていても上部に予算の警告を表示しなければならない（MUST）。
警告は、使った金額の割合を言葉と数で伝え、設定の画面のプロバイダーの区画へ移る手段を持つ。

#### Scenario: 記事の一覧を開いている

- **WHEN** 月の予算が100米ドル、警告の割合が0.8で、期間の合計が85米ドルの状態で記事の一覧を開く
- **THEN** 画面の上部に、月の予算の85%を使ったことが表示され、そこからプロバイダーの区画へ移れる

#### Scenario: 警告の割合より少ない

- **WHEN** 月の予算が100米ドル、警告の割合が0.8で、期間の合計が50米ドルの状態で記事の一覧を開く
- **THEN** 画面の上部に予算の警告は表示されない

#### Scenario: 次の予算の期間になる

- **WHEN** 警告の表示が出ている状態で次の予算の期間が始まり、画面がプロバイダーの状況を取得し直す
- **THEN** 画面の上部の予算の警告は消える
