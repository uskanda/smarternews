## ADDED Requirements

### Requirement: 上限で停止した直近の実行の説明

直近の実行の状態が上限で停止のとき、アプリは、止まった上限の種類に応じた説明を表示しなければならない（MUST）。
アプリは、金額と予算の警告を表示しない。

#### Scenario: 回数の上限で止まった

- **WHEN** カテゴリAの直近の実行が、1日あたりの呼び出しの上限で止まっている
- **THEN** カテゴリAの行に、LLMの呼び出し回数が上限に達したため途中で止まったことが表示される

#### Scenario: 月の予算で止まった

- **WHEN** カテゴリAの直近の実行が、月の予算で止まっている
- **THEN** カテゴリAの行に、月の予算に達したため途中で止まったことが表示される
