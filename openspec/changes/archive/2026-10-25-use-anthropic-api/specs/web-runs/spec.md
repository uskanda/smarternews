## MODIFIED Requirements

### Requirement: 上限で停止した実行の説明

状態が上限で停止の実行について、画面は、止まった上限の種類と、残りは次の実行で続くことを表示しなければならない（MUST）。
月の予算で止まった実行では、次の予算の期間が始まるまでAPIのプロバイダーを呼ばないことも表示する。

#### Scenario: 上限で止まった実行

- **WHEN** 実行あたりの呼び出しの上限で止まった実行の詳細を開く
- **THEN** 呼び出し回数の上限に達したことと、完成した記事は保存済みであることが表示される

#### Scenario: 月の予算で止まった実行

- **WHEN** 月の予算で止まった実行の詳細を開く
- **THEN** 月の予算に達したことと、次の予算の期間の初日と、完成した記事は保存済みであることが表示される

## ADDED Requirements

### Requirement: 予算の期間の金額の表示

設定の画面は、プロバイダーの区画に、予算の期間の初日と最終日、期間の合計の金額、月の予算を表示しなければならない（MUST）。
金額は米ドルで、小数点以下2桁まで表示する。

#### Scenario: 期間の途中で開く

- **WHEN** 予算の期間が10月10日から11月9日、期間の合計が12.34米ドルで、月の予算を100米ドルとした状態で設定の画面を開く
- **THEN** プロバイダーの区画に、10月10日から11月9日までの期間と、12.34米ドルと100米ドルが表示される

### Requirement: タスクごととプロバイダーごとの金額の表示

設定の画面は、プロバイダーの区画に、予算の期間に使った金額をタスクごととプロバイダーごとに表示しなければならない（MUST）。

#### Scenario: 内訳を確かめる

- **WHEN** 予算の期間に、判定で1.20米ドル、本文の生成で3.40米ドルを使った状態で設定の画面を開く
- **THEN** タスクごとの内訳に判定の1.20米ドルと本文の生成の3.40米ドルが表示され、プロバイダーごとの内訳にも同じ合計が表示される

### Requirement: 金額のわからない呼び出しの表示

予算の期間に金額のわからない呼び出しがあるとき、設定の画面は、プロバイダーの区画にその件数を表示しなければならない（MUST）。
画面は、その件数の分だけ、表示した合計が実際の金額より少ない場合のあることも伝える。

#### Scenario: 時間切れがあった期間

- **WHEN** 予算の期間に金額のわからない呼び出しが2件ある状態で設定の画面を開く
- **THEN** プロバイダーの区画に、金額のわからない呼び出しの件数として2件と表示される

#### Scenario: 金額のわからない呼び出しがない期間

- **WHEN** 予算の期間に金額のわからない呼び出しがない状態で設定の画面を開く
- **THEN** 金額のわからない呼び出しについての表示は出ない

### Requirement: プロバイダーの区画の予算の警告

予算の期間の合計が、月の予算に警告の割合を掛けた金額以上の間、設定の画面は、プロバイダーの区画に警告を表示しなければならない（MUST）。
警告は、使った金額の割合を言葉と数で伝え、色だけで伝えない。月の予算に達しているときは、APIのプロバイダーを呼ばずにいることも伝える。

#### Scenario: 警告の割合を超える

- **WHEN** 月の予算が100米ドル、警告の割合が0.8で、期間の合計が85米ドルの状態で設定の画面を開く
- **THEN** プロバイダーの区画に、月の予算の85%を使ったことが警告として表示される

#### Scenario: 月の予算に達する

- **WHEN** 月の予算が100米ドルで、期間の合計が100.04米ドルの状態で設定の画面を開く
- **THEN** プロバイダーの区画に、月の予算に達したことと、次の予算の期間の初日まで、APIのプロバイダーを呼ばないことが表示される
