# Proposal

## Why

Claude Maxの契約で、月100米ドル分までAnthropicのAPIを呼べるようになった（#73）。
今のLLMの呼び出しはすべて `claude` コマンドを経由しており、呼び出しごとにプロセスを起動している。
APIを直接呼ぶアダプターを足し、`fast` と `smart` の区分けはそのままに、使った金額を記録して月の予算を超えないようにする。

## What Changes

- Anthropic SDKでMessages APIを呼ぶアダプター `anthropic` を足す。`claude-cli` と `openai-compatible` は残す。`providers` を書かないときの既定は `claude-cli` のままにする。
- `anthropic` のプロバイダーは、APIキーを `apiKeyEnv` が示す環境変数から読む。プロバイダーごとに `effort`（思考の量）を設定できる。
- 検索のタスクは、APIのサーバー側の道具でWebの検索とページの取得をする。1回の呼び出しで検索する回数に上限を置き、設定で変えられる。ほかのタスクには道具を渡さない。
- サーバーは、モデルごとの単価の表を持ち、設定のプロバイダーごとに単価を上書きできる。単価のわからないモデルを `anthropic` で指定すると、起動を中止する。
- 呼び出しの記録に、入力、出力、キャッシュの読み、キャッシュの書きのトークン数、Web検索の回数、金額（米ドル）を足す。`anthropic` 以外の呼び出しと、応答が届かなかった呼び出しの金額は空にする。
- 設定に月の予算（既定100米ドル）、警告の割合（既定0.8）、締め日（既定1日）を足す。予算の期間は、締め日のUTCの0時から翌月の締め日の前日までとする。その日がない月は末日を締め日にする。
- 予算の期間に使った金額が月の予算に達している間、サーバーは金額のかかるプロバイダーを呼ばない。実行は「上限で停止」で終わり、要約は次の期間へ持ち越し、LLMでの翻訳は翻訳できなかったことを返す。ほかのアダプターに割り当てたタスクは動き続ける。サーバーは今の呼び出し回数の上限も、これまでどおり守る。
- 実行履歴に、止まった上限の種類（実行あたり、1日、月の予算）を残す。Webとアプリの画面は、種類に応じた説明を出す。
- APIのプロバイダーの状況に、予算の期間、期間の合計、月の予算、警告の割合、タスク別とプロバイダー別の金額、金額のわからない呼び出しの件数を足す。
- Webの設定の「プロバイダー」の区画に、上の金額を表示する。使った金額が警告の割合を超えたら、区画と画面の上部に警告を出す。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `llm-tasks`: `anthropic` のアダプター、思考の量、APIでの検索の道具、単価、トークン数と金額の記録、月の予算、予算の期間、上限に達したときの止め方を足す
- `runs`: 上限で停止した実行の履歴が、止まった上限の種類を持つことを足す
- `http-api`: プロバイダーの状況に予算と金額を足し、実行に止まった上限の種類を足す
- `web-runs`: 上限で停止した実行の説明を上限の種類に合わせる。プロバイダーの区画に予算と金額と警告を足す
- `web-shell`: 使った金額が警告の割合を超えたときの、画面の上部の警告を足す
- `mobile-settings`: 上限で停止した直近の実行の説明を、上限の種類に合わせる

## Impact

- `packages/core`: `llm/` に `anthropic` のアダプターと単価の表を足す。`config.ts` にアダプターの設定と予算の設定を足す。`llm/runner.ts` が記録と予算の判定をする。移行で `llm_calls` に列を、`runs` に止まった上限の種類の列を足す
- `packages/core` の依存に `@anthropic-ai/sdk` を足す
- `apps/server`: `GET /api/v1/providers` の応答が増える。起動のときに単価のないモデルを検出する
- `packages/client`: 止まった上限の種類の説明の文言と、金額の整形を足す
- `apps/web`: 設定の「プロバイダー」の区画、実行履歴の説明、画面の上部の警告
- `apps/mobile`: 上限で停止した実行の説明の文言だけを変える
- `examples/config.example.yaml` と `docs/` のプロバイダーの説明に、`anthropic` と予算の設定を足す
- テストは実際のAPIを呼ばない。SDKの呼び出しを差し替え、記録済みの応答で動かす
