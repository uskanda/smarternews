# grilling 記録: use-anthropic-api

GitHubのissue #73（LLMの呼び出しをAPI経由にする）について、会話の中で2つのラウンドに分けて行った。
成果物を書く前に、面談で扱わなかったアプリの説明文の扱いを第3ラウンドで確かめた。
最初に前提を1つ訂正した。Messages APIの応答には金額が入っておらず、返るのはトークン数とWeb検索の回数である。
そこで、金額をサーバーが「トークン数 × モデルごとの単価」から計算する前提を置いて質問した。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| アダプターの追加 | Anthropic SDKを使うアダプター `anthropic` を足す。`claude-cli` と `openai-compatible` は残す。`providers` を書かないときの既定は `claude-cli` のままにする | round 1 Q1 |
| モデルの区分け | `fast` と `smart` のプロバイダー名と、タスクの割り当ての仕組みをそのまま使う。利用者は個人の設定でアダプターを書き換える | round 1 Q1 |
| APIキーの渡し方 | `apiKeyEnv` に環境変数の名前を書き、キーはサービスの環境で渡す。キーはAPIの応答、実行履歴、ログに出さない | round 1 Q2 |
| 思考の量 | プロバイダーごとに `effort` を設定できるようにする。書かなければモデルの既定にする | round 1 Q3 |
| 検索のタスク | `anthropic` のアダプターは検索できると申告し、サーバー側の道具でWebの検索とページの取得をする。1回の呼び出しで検索する回数に上限を置き、設定で変えられる | round 1 Q4 |
| 単価の持ち方 | コードに単価の表を持ち、プロバイダーごとに設定で上書きできる。単価のわからないモデルを `anthropic` で指定したら起動しない | round 1 Q5 |
| 呼び出しごとの記録 | 入力、出力、キャッシュの読み、キャッシュの書きのトークン数、Web検索の回数、金額（米ドル）を残す。`anthropic` 以外の呼び出しの金額は空にし、CLIが返す金額も記録しない | round 1 Q6 |
| 期間の区切り | 締め日を設定で指定する（利用者の環境では今のところ10日） | round 1 Q7 |
| 月の上限の動き | 月の予算の上限（既定100米ドル）と警告の割合を設定に置く。警告の割合で警告し、上限に達したら「上限で停止」としてそれ以上呼ばない | round 1 Q8 |
| 上限を超えたときの切り替え | `claude-cli` のプロバイダーへ切り替えて続ける動きは、この変更に入れない | round 1 Q8 |
| 表示と警告の場所 | Webの設定の「プロバイダー」の区画に、期間の合計、上限、タスク別とプロバイダー別の金額を出す。警告の割合を超えたら、その区画と画面の上部に警告を出す | round 1 Q9 |
| アプリ | Androidアプリの画面と通知には出さない | round 1 Q9 |
| 範囲の外 | プロンプトのキャッシュ、Batch API、前の期間の金額の表示は、この変更に入れない | round 1 Q10 |
| 締め日の時刻 | 締め日のUTCの0時を期間の境目にする | round 2 Q1 |
| 締め日がない月 | 指定した日がない月は、その月の末日を締め日にする | round 2 Q1 |
| 期間の表示 | 画面には「今月」ではなく、期間の初日と最終日を出す | round 2 Q1 |
| 止める範囲 | 上限に達したとき止めるのは、金額のかかるプロバイダーへの呼び出しだけにする。ほかのアダプターに割り当てたタスクは動き続ける。要約は次の期間へ持ち越し、LLMでの翻訳は翻訳できなかったことを返す | round 2 Q2 |
| 止まった上限の記録 | 実行履歴は止まった上限の種類（実行あたり、1日、月の予算）を持ち、Webの実行履歴がそれを表示する | round 2 Q3 |
| 警告の段階 | 警告は1段階にし、割合を設定で変えられる（既定0.8） | round 2 Q4 |
| 金額のわからない呼び出し | 時間切れなどで応答が届かなかった呼び出しは、金額を空にして合計に数えない。画面にその件数を出す | round 2 Q5 |
| アプリの説明文 | アプリの「上限で停止」の説明文を、止まった上限の種類に応じて変える。文言はWebとアプリが共有する `packages/client` に置く。金額と警告はアプリに出さない | round 3 Q1 |

## 後回しにしたもの

- 月の上限に達したあと、`claude-cli` のプロバイダーへ切り替えて動き続ける仕組み
- プロンプトのキャッシュとBatch APIによる費用の削減
- 前の期間の金額の表示
- Androidアプリへの表示と通知
