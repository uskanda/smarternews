# grilling 記録: add-more-shortcuts

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 足すキー | `Shift+A`（一括の既読、取り消しを出す）、`Shift+J` と `Shift+K`（左のペインの次と前の項目）、`Space`（本文を1画面分送り、末尾なら次の記事へ）、`r`（一覧の再取得）、`u`（未読だけの表示と既読を含む表示の切り替え）、`g` に続くキー。`n` と `p` は足さない。今の `j` と `k` で足りる | round 1 Q1 |
| 割り当ての方針 | 衝突しない限り、Inoreaderと同じキーにする。乗り換えた手が迷わないため | round 1 Q2 |
| 割り当ての変更 | 利用者がキーの割り当てを変える機能は、今回入れない | round 1 Q3 |
| アプリ | アプリで物理キーボードを使ったときの操作は対象にしない | round 1 Q4 |
| `Shift+J` と `Shift+K` の移動先 | 左のペインに表示している項目を上から順にたどる。折りたたんだカテゴリの下の購読フィードは飛ばす | round 2 Q1 |
| `Space` の逆 | `Shift+Space` も足す。本文を1画面分戻し、本文の先頭で押したときは前の記事へ移る | round 2 Q2 |
| `r` の範囲 | 一覧をサーバーから読み直すだけにする。購読フィードの即時の取得は始めない。即時の取得は今と同じく設定の画面から行う | round 2 Q3 |
| `g` に続くキー | `a` で全体、`s` でスター、`e` でイベント、`r` で最近読んだ記事（#51）。`g` を押してから1秒のうちに次のキーが来なければ、何もしない | round 2 Q4 |
| `u` の切り替えの保存 | 今の画面の切り替えの操作と同じ扱いにする。キーを足すだけで、保存のしかたは変えない | round 2 Q5 |
| `g a` の行き先 | 「未読」（全カテゴリの未読で、最初に開く一覧）へ移る。「すべて」ではない | round 3 Q1 |
| `g e` の行き先 | 押すたびに、左のペインの並びで次の種別がイベントのカテゴリへ移る。最後のカテゴリの次は最初へ戻る。いまの項目がイベントのカテゴリでなければ、最初のイベントのカテゴリへ移る。イベントのカテゴリが1つなら、そのカテゴリへ移るのと同じになる | round 3 Q2 |

## 後回しにしたもの

- 利用者によるキーの割り当ての変更
- アプリで物理キーボードを使ったときのキー操作
- `n` と `p`（本文を開かずに選ぶ記事だけを動かす操作）
- `/`（検索欄へ移る）は#47、`w`（全文の取得）は#52で足す。この変更では扱わない
