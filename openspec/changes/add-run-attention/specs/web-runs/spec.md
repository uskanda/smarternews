# Spec Delta

## ADDED Requirements

### Requirement: 実行履歴の画面の注意の区画

確認していない注意の項目がある間、実行履歴の画面は、見出しの下、実行の一覧の上に「注意」の区画を表示しなければならない（MUST）。
各項目には、何が起きたかの説明、対象へのリンク、「確認した」の操作を並べる。対象へのリンクは、実行を指す項目では実行の詳細へ、トピックを指す項目ではそのカテゴリの設定の画面へ移る。
確認していない項目がないとき、画面は区画を表示してはならない（MUST NOT）。

#### Scenario: 失敗したカテゴリを確かめる

- **WHEN** やり直しを使い切って失敗したカテゴリAがある状態で、実行履歴を開く
- **THEN** 実行履歴の「注意」の区画に、カテゴリAの実行が失敗したことと、その実行の詳細へのリンクが並ぶ

#### Scenario: 注意がない

- **WHEN** 注意の項目がない状態で、実行履歴を開く
- **THEN** 実行履歴の「注意」の区画は表示されない

### Requirement: 注意の項目の確認

利用者が注意の項目の「確認した」を選んだとき、画面は、再読み込みなしでその項目を区画から除かなければならない（MUST）。
確認が失敗したとき、画面は失敗を知らせ、項目を区画に残す。

#### Scenario: 確認する

- **WHEN** 実行履歴の「注意」の区画の項目の「確認した」を選ぶ
- **THEN** その項目は区画から消え、左のペインの「実行履歴」の件数が1減る

#### Scenario: サーバーに届かない

- **WHEN** サーバーが止まっている状態で「確認した」を選ぶ
- **THEN** 確認できなかったことが表示され、項目は区画に残る
