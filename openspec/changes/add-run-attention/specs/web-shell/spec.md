# Spec Delta

## ADDED Requirements

### Requirement: 左のペインの注意の件数の印

確認していない注意の項目がある間、左のペインの「実行履歴」の行は、その件数を表示しなければならない（MUST）。
件数は`注意N件`という読み上げ名を持つ。件数が0のとき、行に件数を表示してはならない（MUST NOT）。
画面の上部には、注意のための表示を置いてはならない（MUST NOT）。

#### Scenario: 注意が2件ある

- **WHEN** 確認していない注意の項目が2件ある状態で画面を開く
- **THEN** 左のペインの「実行履歴」の行に2が表示され、`注意2件`と読み上げられる

#### Scenario: 注意がない

- **WHEN** 注意の項目がない状態で画面を開く
- **THEN** 左のペインの「実行履歴」の行に件数は表示されない
