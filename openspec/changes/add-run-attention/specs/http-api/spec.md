# Spec Delta

## ADDED Requirements

### Requirement: 注意の一覧

APIは、確認していない注意の項目の一覧と、その件数を返す操作を提供しなければならない（MUST）。
各項目は、種類、確認するときの鍵、対象のカテゴリとトピック、検索先と検索語、指す実行、続き始めた日時のうち、その種類に当てはまるものを持つ。

#### Scenario: 失敗したカテゴリがある

- **WHEN** やり直しを使い切って失敗したカテゴリがある状態で、注意の一覧を要求する
- **THEN** 種類が実行の失敗で、そのカテゴリと実行を指す項目が返り、件数は1である

### Requirement: 注意の項目を確認する操作

APIは、鍵を受け取り、その注意の項目を確認したことを保存する操作を提供しなければならない（MUST）。
同じ鍵を2回受け取っても、エラーにしてはならない（MUST NOT）。空の鍵は入力の誤りとして拒否する。

#### Scenario: 確認すると件数が減る

- **WHEN** 2件の注意の項目のうち1件の鍵で確認の操作を送り、注意の一覧を要求する
- **THEN** 残りの1件だけが返り、件数は1である
