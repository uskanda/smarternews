# Spec Delta

## ADDED Requirements

### Requirement: カテゴリの画面の直近の実行

カテゴリの画面は、実行の区画に、そのカテゴリの直近の実行を1行で表示しなければならない（MUST）。
行には、開始の日時、契機、状態、作った記事の数、更新した記事の数を並べ、開始の日時を実行の詳細へのリンクにする。
実行中や待機中の間は、行にその状態を出し、実行が終わると、画面を読み込み直さなくても結果に変わる。
実行が1件もないときは「まだ実行していません」と表示する。

#### Scenario: 終わった実行

- **WHEN** 記事を3件作り1件更新して成功した実行があるカテゴリの画面を開く
- **THEN** 実行の区画に「成功」と、作成の数の3件と、更新の数の1件が表示され、開始の日時がその実行の詳細へのリンクになっている

#### Scenario: 失敗した実行

- **WHEN** 直近の実行が失敗したカテゴリの画面を開く
- **THEN** 実行の区画の行に「失敗」が表示される

#### Scenario: いますぐ実行

- **WHEN** カテゴリの画面で「いますぐ実行」を選ぶ
- **THEN** 実行の区画の行が、待機中か実行中の状態になる

#### Scenario: 実行がない

- **WHEN** 一度も実行していないカテゴリの画面を開く
- **THEN** 実行の区画に「まだ実行していません」が表示される

### Requirement: カテゴリの画面の区画へのリンク

カテゴリの画面は、見出しの下に、5つの区画へのリンクを並べなければならない（MUST）。
区画は、画面の順に、カテゴリの設定、トピック、トピックの成績、実行、削除とする。
リンクは幅が足りなければ折り返し、画面をスクロールすると一緒に流れる。

#### Scenario: リンクの並び

- **WHEN** カテゴリの画面を開く
- **THEN** 見出しの下に、5つの区画へのリンクが上の順に並び、それぞれのリンクの先にその区画がある

#### Scenario: リンクで区画へ移る

- **WHEN** 区画のリンクの「実行」を選ぶ
- **THEN** 画面は実行の区画までスクロールする

### Requirement: アドレスで指定したカテゴリの画面の区画への移動

アドレスで区画を指定してカテゴリの画面を開いたとき、画面は、トピックとトピックの成績を読み込んだあとに、その区画までスクロールしなければならない（MUST）。

#### Scenario: 実行の区画を指定して開く

- **WHEN** 実行の区画を指定してカテゴリの画面を開く
- **THEN** トピックとトピックの成績を読み込んだあと、画面は実行の区画までスクロールする
