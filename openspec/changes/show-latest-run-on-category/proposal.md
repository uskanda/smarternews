# Proposal

## Why

カテゴリの画面で「いますぐ実行」を押すと、実行中の文が出て、終わると消えるだけである（issue #197）。
作った記事の数も、失敗したかどうかも、この画面では分からない。確かめるには、実行履歴を開いて先頭の行を選ぶ必要がある。
また、実行の区画は「トピックの成績」の区画の下にあり、トピックが多いと長くスクロールしないと届かない。

## What Changes

- 実行の区画に、このカテゴリの直近の実行を1行で出す。開始の日時、契機、状態、作った記事と更新した記事の数を並べ、開始の日時を実行の詳細へのリンクにする。
- 実行中や待機中のときは、行にその状態が出る。終わると、画面を読み込み直さなくても結果に変わる。
- 実行がないときは「まだ実行していません」と出す。
- カテゴリの画面の見出しの下に、5つの区画（カテゴリの設定、トピック、トピックの成績、実行、削除）へのリンクを並べる。アドレスで区画を指定して開いたときも、その区画へ移る。
- 区画の並びは変えない。サーバー、API、Androidアプリは変えない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-settings`: 3つの要件を足す。カテゴリの画面の直近の実行、カテゴリの画面の区画へのリンク、アドレスで指定したカテゴリの画面の区画への移動

## Impact

- `apps/web`: カテゴリの画面の実行の区画に直近の実行の行を足す。見出しの下に区画のリンクを置き、各区画にidを付け、アドレスの区画までスクロールする部品を使う。
- サーバー、API、`packages/client`、Androidアプリに変更はない。LLMの呼び出しは増えない。
