# Spec Delta

## ADDED Requirements

### Requirement: 左のペインの検索欄

画面は、左のペインの上端に、記事を検索する入力欄を表示しなければならない（MUST）。

#### Scenario: 広い画面で開く

- **WHEN** 幅1280pxの画面で記事の一覧を開く
- **THEN** 左のペインの「未読」の項目より上に、検索欄が表示される

#### Scenario: 狭い画面で開く

- **WHEN** 幅390pxの画面で、左のペインに切り替える
- **THEN** 項目の一覧より上に、検索欄が表示される

### Requirement: 検索の開始

検索欄に語を入れてEnterキーが押されたとき、画面は検索の結果の画面へ移らなければならない（MUST）。
空白だけのときは移らない。

#### Scenario: 語を入れて検索する

- **WHEN** 検索欄に「電池」と入れてEnterキーを押す
- **THEN** 検索の結果の画面に、「電池」の結果が表示される

#### Scenario: 空のまま押す

- **WHEN** 検索欄が空のままEnterキーを押す
- **THEN** 表示中の画面は変わらない

### Requirement: 検索欄へ移るキー

入力欄にフォーカスがない間、`/` のキーが押されたとき、画面は検索欄にフォーカスを移さなければならない（MUST）。
入力欄にフォーカスがある間は、`/` を文字として入力欄に入れる。

#### Scenario: 記事を読んでいる途中で探す

- **WHEN** 記事の一覧で記事を選んだ状態で `/` を押す
- **THEN** 検索欄にフォーカスが移り、検索欄に `/` は入らない

#### Scenario: キー操作の一覧に出る

- **WHEN** `?` を押してキー操作の一覧を開く
- **THEN** 一覧に、`/` と検索欄へ移る操作の対応が含まれる

### Requirement: 検索の結果の画面のURL

検索の結果の画面は、検索語と結果の絞り込みを含むURLを持たなければならない（MUST）。
そのURLを開いたとき、画面は同じ検索語と絞り込みの結果を表示する。

#### Scenario: 再読み込みする

- **WHEN** 検索語が「電池」の結果の画面で、ブラウザーの再読み込みをする
- **THEN** 画面は、「電池」の検索の結果を、同じ絞り込みのまま表示する

#### Scenario: 記事を開いてから戻る

- **WHEN** 検索語が「電池」の結果から記事を開き、別の項目の一覧へ移ったあと、ブラウザーの戻る操作をする
- **THEN** 画面は、「電池」の検索の結果と、開いていた記事の本文を表示する

### Requirement: 検索欄の表示の保持

検索の結果の画面を表示している間、画面は検索欄に、その結果の検索語を表示しなければならない（MUST）。

#### Scenario: URLから開く

- **WHEN** 検索語が「電池」の結果の画面のURLを、新しいタブで開く
- **THEN** 検索欄に「電池」が入っている
