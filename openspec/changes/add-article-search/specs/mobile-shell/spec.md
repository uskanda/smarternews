# Spec Delta

## ADDED Requirements

### Requirement: 引き出しの検索欄

アプリは、引き出しの上端に、記事を検索する入力欄を表示しなければならない（MUST）。

#### Scenario: 引き出しを開く

- **WHEN** 引き出しを開く
- **THEN** 検索欄が、「未読」の項目より上に表示される

### Requirement: 引き出しからの検索の開始

検索欄に語を入れて確定したとき、アプリは引き出しを閉じ、検索の結果の画面を表示しなければならない（MUST）。
空白だけのときは画面を変えない。

#### Scenario: 語を入れて確定する

- **WHEN** 引き出しの検索欄に「電池」と入れ、キーボードの検索のキーを押す
- **THEN** 引き出しが閉じ、検索語が「電池」の結果の画面が表示される

#### Scenario: 空のまま確定する

- **WHEN** 検索欄が空のまま、キーボードの検索のキーを押す
- **THEN** 引き出しは開いたままで、表示中の画面は変わらない

### Requirement: 検索欄の読み上げ用の名前

アプリは、引き出しの検索欄に、記事を検索する欄であることを示す読み上げ用の名前を付けなければならない（MUST）。

#### Scenario: 読み上げで確かめる

- **WHEN** 読み上げの支援技術で、引き出しの検索欄に触れる
- **THEN** 記事を検索する欄であることが読み上げられる
