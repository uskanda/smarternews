# Spec Delta

## ADDED Requirements

### Requirement: 翻訳の途中で元の文が変わったときの翻訳し直し

配信記事の本文を翻訳する操作で、訳を保存する前に題か本文の元の文が翻訳を始めたときから変わっていたとき、サーバーは、変わった後の文で一度だけ翻訳し直さなければならない（MUST）。
本文の元の文は、全文を保存した記事では全文、それ以外では配信された内容である。
翻訳し直しの結果は、同じ記事について進行中の翻訳を待っていた操作にも返す。
読み直した記事に、本文の訳と題の訳がすでに保存されていれば、サーバーはその訳を返す。

#### Scenario: 配信された内容の翻訳の途中で全文が保存される

- **WHEN** 配信された内容を翻訳している途中で、その記事に全文が保存される
- **THEN** サーバーは全文を翻訳し直して保存し、全文の訳を返す

#### Scenario: 途中で届いた2つ目の操作

- **WHEN** 配信された内容を翻訳している途中で全文が保存され、そのあとで同じ記事を翻訳する操作がもう1つ届く
- **THEN** 2つの操作は、どちらも全文の訳を受け取る

### Requirement: 翻訳し直しの回数の上限

翻訳し直した後でも、訳を保存する前に元の文がまた変わっていたとき、サーバーは、訳を保存せずに、いま翻訳できないことを返さなければならない（MUST）。

#### Scenario: 元の文が2回変わる

- **WHEN** 最初の翻訳の途中と、翻訳し直しの途中で、どちらも元の文が変わる
- **THEN** 操作はいま翻訳できないことを返し、記事に本文の訳は保存されない
