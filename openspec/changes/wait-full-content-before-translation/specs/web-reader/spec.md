# Spec Delta

## ADDED Requirements

### Requirement: 全文を待つ間の翻訳の保留

翻訳の対象の配信記事で、全文の取得の途中の間、または記事が全文を待っていて取得の依頼が応答のないまま終わっていない間、画面は本文を翻訳する操作を呼んではならない（MUST NOT）。
待つ間、画面は翻訳の途中であることを表示せず、全文の取得の途中であることだけを表示する。

#### Scenario: 全文を待つ記事を開く

- **WHEN** 翻訳と全文の自動の取得が有効な購読フィードの、全文を待っている配信記事を選ぶ
- **THEN** 全文が届くまで本文を翻訳する操作は呼ばれず、全文が届くと一度だけ呼ばれ、全文の訳が表示される

#### Scenario: 本文の訳のない記事で全文を取得する

- **WHEN** 翻訳の対象で本文の訳のない配信記事で、全文を取得する
- **THEN** 取得の途中は本文を翻訳する操作は呼ばれず、全文が届くと全文の訳が表示される

### Requirement: 全文が届かなかったときの翻訳

翻訳の対象で全文を待つ配信記事で、全文の取得が失敗したとき、または取得の依頼に応答がなかったとき、画面は配信された内容を翻訳する操作を呼ばなければならない（MUST）。

#### Scenario: 全文の取得が失敗する

- **WHEN** 翻訳の対象で全文を待つ配信記事を選び、全文の取得が失敗する
- **THEN** 画面は本文を翻訳する操作を呼び、配信された内容の訳を表示する

#### Scenario: 取得の依頼に応答がない

- **WHEN** 翻訳の対象で全文を待つ配信記事を選び、全文を取得する依頼に応答がない
- **THEN** 画面は本文を翻訳する操作を呼び、配信された内容の訳を表示する
