# Spec Delta

## ADDED Requirements

### Requirement: その場の編集の欄を開いたときのフォーカス
トピック・フィルター・語のまとまり・購読フィードの「編集」で欄を開いたとき、Webの設定画面は、欄の中で操作できる最初の入力欄へフォーカスを移さなければならない（MUST）。最初の入力欄がラジオボタンのまとまりのとき、移す先は選ばれているラジオボタンでなければならない（MUST）。

#### Scenario: トピックの編集を開く
- **WHEN** トピックの「編集」を押す
- **THEN** フォーカスは「トピックの文章」の欄にある

#### Scenario: フィルターの編集を開く
- **WHEN** 残すフィルターの「編集」を押す
- **THEN** フォーカスは、「種類」のラジオボタンのうち、選ばれている「残すフィルター」にある

#### Scenario: 語のまとまりの編集を開く
- **WHEN** 語のまとまりの「編集」を押す
- **THEN** フォーカスは「まとまりの名前」の欄にある

#### Scenario: 購読フィードの編集を開く
- **WHEN** 購読フィードの「編集」を押す
- **THEN** フォーカスは「名前」の欄にある

### Requirement: その場の編集の欄を閉じたときのフォーカス
その場の編集の欄を保存・やめる・閉じるで閉じたとき、Webの設定画面は、その欄を開いた「編集」のボタンへフォーカスを戻さなければならない（MUST）。

#### Scenario: トピックの編集を閉じる
- **WHEN** トピックの編集の欄で「閉じる」を押す
- **THEN** フォーカスはそのトピックの「編集」のボタンにある

#### Scenario: トピックを保存して閉じる
- **WHEN** トピックの編集の欄で「トピックを保存」を押し、保存が済む
- **THEN** フォーカスはそのトピックの「編集」のボタンにある

#### Scenario: フィルターの編集をやめる
- **WHEN** フィルターの編集の欄で「やめる」を押す
- **THEN** フォーカスはそのフィルターの「編集」のボタンにある

#### Scenario: 語のまとまりを保存して閉じる
- **WHEN** 語のまとまりの編集の欄で「保存」を押し、保存が済む
- **THEN** フォーカスはそのまとまりの「編集」のボタンにある

#### Scenario: 購読フィードの編集をやめる
- **WHEN** 購読フィードの編集の欄で「やめる」を押す
- **THEN** フォーカスはそのフィードの「編集」のボタンにある

### Requirement: 開いていない欄はフォーカスを動かさない
画面を開いたとき、Webの設定画面は、フィルターの追加の欄のように初めから出ている欄へフォーカスを移してはならない（MUST NOT）。

#### Scenario: フィルターの画面を開く
- **WHEN** フィルターの画面を開く
- **THEN** フォーカスは追加の欄の入力欄にない
