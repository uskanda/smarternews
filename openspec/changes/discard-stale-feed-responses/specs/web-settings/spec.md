# Spec Delta

## ADDED Requirements

### Requirement: 応答を待つ間に入力が変わったときの扱い

購読フィードの追加で、画面は、応答を待つ間に入力が変わったとき、変わる前の入力に対する応答を反映してはならない（MUST NOT）。
対象は、フィードを探す応答、記事の見つけ方の候補、セレクターの見本である。
フィードを探している間、画面は、URLの欄を読み取り専用にし、フォーカスを欄に残さなければならない（MUST）。
登録は、登録する時点で画面が表示しているカテゴリと切り替えの値で行わなければならない（MUST）。
フォームを閉じたあと、または画面を離れたあとに届いた応答で、購読フィードを登録してはならない（MUST NOT）。

#### Scenario: フィードを探す間のURLの欄

- **WHEN** URLの欄でEnterを押して、フィードを探し始める
- **THEN** 探している間、URLの欄は読み取り専用になり、フォーカスは欄に残る。応答が届くと、欄はまた編集できる

#### Scenario: 探す間に変えたカテゴリと切り替え

- **WHEN** フィードを探している間に、カテゴリと翻訳の切り替えを変え、フィードが1件見つかる
- **THEN** 登録された購読フィードは、変えたあとのカテゴリと翻訳の切り替えを持つ

#### Scenario: 候補を待つ間にURLを直す

- **WHEN** フィードのないページAの候補を待つ間に、URLの欄をフィードのない別のページBに直し、Bの候補が表示されたあとに、Aの候補が届く
- **THEN** Aの候補は表示されず、Bの候補が表示されたままで、「このページを追加」はBを登録する

#### Scenario: 見本を待つ間にセレクターを直す

- **WHEN** セレクターを手で入力して見本を待つ間に、項目のセレクターを直し、そのあとに直す前の組の見本が届く
- **THEN** 直す前の組の見本は表示されず、「このページを追加」は押せないままである

#### Scenario: 探す間にダイアログを閉じる

- **WHEN** カテゴリの一覧の上のダイアログでフィードを探し始め、応答の前にダイアログを閉じ、そのあとにフィードが1件見つかる
- **THEN** 購読フィードは登録されない
