# Spec Delta

## ADDED Requirements

### Requirement: キーボードでの一括の既読

一括の既読を選べる一覧が表示されている間、`Shift` を押しながら `A` が押されたとき、画面は一括の既読のボタンを選んだときと同じ操作をしなければならない（MUST）。
既読にする範囲、取り消しの手段、次の項目へ移る設定の扱いは、ボタンで選んだときと同じにする。

#### Scenario: キーで一括の既読にする

- **WHEN** カテゴリAの一覧に未読が3件ある状態で `Shift+A` を押す
- **THEN** 3件が既読になり、その操作を取り消す手段が表示される

#### Scenario: Shiftを押さずに押す

- **WHEN** Caps Lockを入れた状態で、`Shift` を押さずに `a` のキーを押す
- **THEN** 一括の既読は起きない

#### Scenario: 一括の既読を選べない一覧

- **WHEN** 種別がイベントのカテゴリの一覧で `Shift+A` を押す
- **THEN** 何も既読にならない

### Requirement: キーボードでの項目の移動

`Shift+J` または `Shift+K` が押されたとき、画面は、左のペインに表示している記事の一覧の項目を上から順に見て、いまの項目の次または前の項目を開かなければならない（MUST）。
折りたたんだカテゴリの下の項目は表示していないため、たどる対象に入らない。
「設定」と「実行履歴」は記事の一覧ではないため、たどる対象に入らない。

#### Scenario: 次のカテゴリへ移る

- **WHEN** カテゴリAとカテゴリBが並び、どちらにも購読フィードがない状態で、カテゴリAの一覧で `Shift+J` を押す
- **THEN** カテゴリBの一覧が開く

#### Scenario: カテゴリの下の項目へ移る

- **WHEN** 購読フィードを持つカテゴリAを開いて、`Shift+J` を押す
- **THEN** カテゴリAの下の「AI生成」の一覧が開く

#### Scenario: 折りたたんだカテゴリを飛ばす

- **WHEN** 購読フィードを持つカテゴリAを折りたたみ、その下にカテゴリBが並ぶ状態で、カテゴリAの一覧で `Shift+J` を押す
- **THEN** カテゴリBの一覧が開く

#### Scenario: 前の項目へ戻る

- **WHEN** 左のペインの「スター」の一覧で `Shift+K` を押す
- **THEN** その上の「すべて」の一覧が開く

### Requirement: 端とその外での項目の移動

いまの項目が最後の項目のとき、`Shift+J` が押されても、画面は別の項目を開いてはならない（MUST NOT）。
いまの項目が最初の項目のときの `Shift+K` も、同じく別の項目を開かない。
いまの画面に当たる項目が左のペインにないとき、画面は `Shift+J` で最初の項目を開き、`Shift+K` で最後の項目を開かなければならない（MUST）。

#### Scenario: 最後の項目で進む

- **WHEN** 左のペインの最後の項目の一覧で `Shift+J` を押す
- **THEN** 同じ一覧のままである

#### Scenario: 設定の画面から移る

- **WHEN** 設定の画面で `Shift+J` を押す
- **THEN** 左のペインの最初の項目である「未読」の一覧が開く

### Requirement: キーボードでの本文の送り

本文が表示されている間、`Space` が押されたとき、画面は本文のペインを下へ1画面分スクロールしなければならない（MUST）。
`Shift+Space` が押されたとき、画面は本文のペインを上へ1画面分スクロールしなければならない（MUST）。

#### Scenario: 長い本文を送る

- **WHEN** 本文のペインより長い記事を先頭から表示した状態で `Space` を押す
- **THEN** 本文が1画面分下へスクロールし、選んでいる記事は変わらない

#### Scenario: 長い本文を戻す

- **WHEN** 長い記事を途中まで送った状態で `Shift+Space` を押す
- **THEN** 本文が1画面分上へスクロールし、選んでいる記事は変わらない

### Requirement: 本文の端での記事の移動

本文の末尾が表示されている状態で `Space` が押されたとき、画面は `j` を押したときと同じく次の記事へ移らなければならない（MUST）。
本文の先頭が表示されている状態で `Shift+Space` が押されたとき、画面は `k` を押したときと同じく前の記事へ移らなければならない（MUST）。
本文が表示されていないとき、`Space` は `j` を押したときと同じ記事を選ぶ。`Shift+Space` は `k` を押したときと同じ記事を選ぶ。

#### Scenario: 末尾で次の記事へ移る

- **WHEN** 一覧の1件目の本文を末尾までスクロールした状態で `Space` を押す
- **THEN** 2件目が選ばれ、その本文が先頭から表示される

#### Scenario: 短い本文

- **WHEN** 本文のペインに全体が収まる記事を表示した状態で `Space` を押す
- **THEN** 次の記事が選ばれる

#### Scenario: 先頭で前の記事へ戻る

- **WHEN** 一覧の2件目の本文を先頭から表示した状態で `Shift+Space` を押す
- **THEN** 1件目が選ばれる

### Requirement: ボタンでのSpaceの扱い

ボタンにフォーカスがある間、`Space` または `Shift+Space` が押されたとき、画面は本文を送らず、記事も移ってはならない（MUST NOT）。
そのキーは、フォーカスのあるボタンを押す操作として働く。

#### Scenario: スターのボタンをSpaceで押す

- **WHEN** Tabキーで本文のスターのボタンにフォーカスを当て、`Space` を押す
- **THEN** スターが切り替わり、本文の位置と選んでいる記事は変わらない

### Requirement: キーボードでの一覧の再取得

記事の一覧が表示されている間、`r` が押されたとき、画面は一覧の更新のボタンを押したときと同じく、件数と表示中の一覧をすぐに取得し直さなければならない（MUST）。
画面は、このキーで購読フィードの取得を始めてはならない（MUST NOT）。

#### Scenario: キーで一覧を読み直す

- **WHEN** 未読の一覧を開いたまま、サーバーで新しい記事が作られ、60秒を待たずに `r` を押す
- **THEN** 一覧に新しい記事が現れ、左のペインの未読数が増える

#### Scenario: 購読フィードを取得しない

- **WHEN** 購読フィードの一覧で `r` を押す
- **THEN** その購読フィードの取得は始まらない

### Requirement: キーボードでの既読を含む表示の切り替え

既読を含める切り替えを選べる一覧が表示されている間、`u` が押されたとき、画面はその切り替えを反対の状態にしなければならない（MUST）。
切り替えた状態の保ち方は、画面の切り替えを操作したときと同じにする。

#### Scenario: 既読も表示する

- **WHEN** カテゴリAの未読だけの一覧で `u` を押す
- **THEN** カテゴリAの既読の記事も一覧に表示され、既読を含める切り替えが入った状態で表示される

#### Scenario: 未読だけに戻す

- **WHEN** 既読を含める切り替えが入った一覧で `u` を押す
- **THEN** 一覧は未読の記事だけになる

#### Scenario: 切り替えのない一覧

- **WHEN** 左のペインの「未読」の一覧で `u` を押す
- **THEN** 一覧は変わらない

### Requirement: gに続くキーでの項目の移動

`g` が押されてから1秒のうちに次のキーが押されたとき、画面はその次のキーに当たる一覧を開かなければならない（MUST）。
次のキーと開く一覧の対応は次のとおり。

- `a`：「未読」（全カテゴリの未読の一覧）
- `s`：「スター」
- `e`：種別がイベントのカテゴリ。どのカテゴリを開くかは、要件「gとeでのイベントのカテゴリの移動」に従う
- `r`：「最近読んだ記事」

当たる項目が左のペインにないとき、画面は何も開かない。

#### Scenario: 未読へ移る

- **WHEN** カテゴリAの一覧で `g` を押し、続けて `a` を押す
- **THEN** 画面に「未読」の一覧が開き、「すべて」の一覧は開かない

#### Scenario: スターへ移る

- **WHEN** カテゴリAの一覧で `g` を押し、続けて `s` を押す
- **THEN** 画面に「スター」の一覧が開く

#### Scenario: 最近読んだ記事へ移る

- **WHEN** 左のペインに「最近読んだ記事」の項目がある状態で `g` を押し、続けて `r` を押す
- **THEN** 画面に「最近読んだ記事」の一覧が開き、表示中の一覧の再取得は起きない

#### Scenario: 入力欄での文字の入力

- **WHEN** トピックの文章の入力欄で `g` と `s` を続けて入力する
- **THEN** 2つの文字は入力欄に入り、「スター」の一覧は開かない

### Requirement: gとeでのイベントのカテゴリの移動

`g` に続けて `e` が押されたとき、いまの項目の種別がイベントのカテゴリなら、画面は左のペインの並びでその次の、種別がイベントのカテゴリの一覧を開かなければならない（MUST）。
いまの項目が最後のイベントのカテゴリのときは、左のペインで最初に並ぶイベントのカテゴリの一覧を開く。
いまの項目がイベントのカテゴリでないとき、または当たる項目が左のペインにないとき、画面は左のペインで最初に並ぶイベントのカテゴリの一覧を開かなければならない（MUST）。
いまの項目の決め方は、`Shift+J` と `Shift+K` での項目の移動と同じにする。
種別がイベントのカテゴリがないとき、画面は何も開かない。

#### Scenario: イベントのカテゴリへ移る

- **WHEN** 種別がイベントのカテゴリEとカテゴリFがこの順に並ぶ状態で、「未読」の一覧で `g` を押し、続けて `e` を押す
- **THEN** カテゴリEのイベントの一覧が開く

#### Scenario: 次のイベントのカテゴリへ移る

- **WHEN** 種別がイベントのカテゴリEとカテゴリFがこの順に並ぶ状態で、カテゴリEの一覧で `g` を押し、続けて `e` を押す
- **THEN** カテゴリFのイベントの一覧が開く

#### Scenario: 最後から最初へ戻る

- **WHEN** 種別がイベントのカテゴリEとカテゴリFがこの順に並ぶ状態で、カテゴリFの一覧で `g` を押し、続けて `e` を押す
- **THEN** カテゴリEのイベントの一覧が開く

#### Scenario: イベントのカテゴリが1つだけ

- **WHEN** 種別がイベントのカテゴリがカテゴリEだけの状態で、カテゴリEの一覧で `g` を押し、続けて `e` を押す
- **THEN** カテゴリEのイベントの一覧が表示されたままである

#### Scenario: 設定の画面から移る

- **WHEN** 種別がイベントのカテゴリEとカテゴリFがこの順に並ぶ状態で、設定の画面で `g` を押し、続けて `e` を押す
- **THEN** カテゴリEのイベントの一覧が開く

#### Scenario: イベントのカテゴリがない

- **WHEN** 種別がイベントのカテゴリがない状態で `g` を押し、続けて `e` を押す
- **THEN** 開いている画面は変わらない

### Requirement: gのあとの待ち時間

`g` が押されてから1秒のうちに次のキーが押されなかったとき、画面は何もしてはならない（MUST NOT）。
1秒を過ぎてから押されたキーは、そのキー1つの操作として扱う。
`g` のあとに、`a`、`s`、`e`、`r` のどれでもないキーが1秒のうちに押されたとき、画面はそのキーの操作をしてはならない（MUST NOT）。

#### Scenario: 1秒を過ぎてから次のキーを押す

- **WHEN** 記事を選んだ状態で `g` を押し、1秒を過ぎてから `s` を押す
- **THEN** 画面に「スター」の一覧は開かず、選んでいる記事のスターが切り替わる

#### Scenario: gだけを押す

- **WHEN** カテゴリAの一覧で `g` だけを押して、2秒待つ
- **THEN** 開いている画面は変わらない

#### Scenario: 対応のないキーが続く

- **WHEN** 記事を選んだ状態で `g` を押し、続けて `m` を押す
- **THEN** 選んでいる記事の既読と未読は変わらない
