# grilling 記録: unify-ui-wording

Issue #121（監査ID U-14）のコメントで、5つの質問と推奨の答えを出した。Issueのオーナーは5つともAを選び、そのあと計画を `/ok` で承認した。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 購読フィードの画面の説明文 | A：「登録したフィードを定期的に取得し、配信された記事をそのまま一覧に並べます。要約と翻訳は、選んだ購読フィードの記事だけに行います。」にする | 第1ラウンド Q1 |
| 「登録を解除」にそろえる範囲 | A：左のペインと設定の画面の両方をそろえる。確認のタイトルは「購読フィードの登録を解除しますか」、ボタンは「登録を解除する」、知らせは「購読フィードの登録を解除しました」「登録を解除できませんでした。もう一度試してください。」。設定の画面の行のボタンは「登録を解除」（aria-labelは「〇〇の登録を解除」）。フィルターも消えることを伝える文の「削除されます」は残す | 第1ラウンド Q2 |
| 保存のボタンの名前 | A：すべて「保存する」にする。テストは区画の中でボタンを探す。知らせの「〜を保存しました」は変えない | 第1ラウンド Q3 |
| 「更新」の語の使い分け | A：一覧を取り直す2つのボタンを「読み直す」にする。続報の印「更新」、「更新 n回」、実行履歴の「更新」は残す | 第1ラウンド Q4 |
| 「フィードを追加」「フィードの設定」の名前 | A：「購読フィードを追加」「購読フィードの設定」にする。「選んだフィードを追加」と「このページを追加」は残す | 第1ラウンド Q5 |
| 計画 | 承認。追加の変更の指示はなし | 会話中に確認（Issueのコメントの `/ok`） |
