# Spec Delta

## ADDED Requirements

### Requirement: トピックの試しの操作

APIは、トピックと試す文章を受けて試しを始める操作と、試しの結果を問い合わせる操作を提供しなければならない（MUST）。
始める操作は、試しを受け付けるとすぐに、試しの識別子を返す。上限、1日の上限、予算のどれかで試せないときは、試しを始めずに、その理由を返す。
問い合わせる操作は、試しの状態（動いている、成功した、失敗した、上限で停止した）と、成功したときの結果を返す。
試しの結果はサーバーのメモリーにだけ置き、記事、候補、判定済みのURL、トピックは変えてはならない（MUST NOT）。同時に動く試しは1つまでとする。

#### Scenario: 試して結果を得る

- **WHEN** 試しを始める操作を呼び、返った識別子で、試しが終わったあとに問い合わせる
- **THEN** APIは、成功した状態と、試した件数、入れ替わった候補の一覧を返し、トピックと候補は試しの前と同じである

#### Scenario: 別の試しが動いている

- **WHEN** 試しが動いている間に、もう1つの試しを始める操作を呼ぶ
- **THEN** APIは、衝突を示す応答を返す

#### Scenario: 試しが使えない

- **WHEN** 試しの1日の上限を0にした状態で、試しを始める操作を呼ぶ
- **THEN** APIは試しを始めず、上限を理由に返す

#### Scenario: 存在しない試し

- **WHEN** 存在しない識別子で、試しの結果を問い合わせる
- **THEN** APIは、存在しないことを示す応答を返す
