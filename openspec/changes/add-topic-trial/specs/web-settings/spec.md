# Spec Delta

## ADDED Requirements

### Requirement: トピックの試し

トピックの編集で利用者が試しを選んだとき、画面は、編集中の文章と検索の言語と地域で試しを求め、その結果を表示しなければならない（MUST）。
結果は、新しい検索語と判定基準、試した候補の件数、判定の結論が採用と除外の間で入れ替わった候補の件数と一覧である。一覧では、候補ごとに、前の結論と理由、新しい結論と理由を並べる。新しい重要度がカテゴリの最低の重要度を下回る候補には、その旨を添える。
試しは何も保存しない。編集中の文章は保存されず、保存していない変更の表示もそのまま残る。

#### Scenario: 文章を直して試す

- **WHEN** トピックの文章を書き換え、保存せずに試しを選ぶ
- **THEN** 書き換えた文章で試しが求められ、トピックの保存は求められない。結果に、入れ替わった候補が前と新しい理由とともに表示される

#### Scenario: 入れ替わりがない

- **WHEN** 試しの結果に、入れ替わった候補がない
- **THEN** 画面は、入れ替わる候補がないことを表示する

#### Scenario: 上限で断られる

- **WHEN** 試しの1日の上限に達した状態で、試しを選ぶ
- **THEN** 画面は、上限に達したため試せないことを表示する

#### Scenario: 試している間

- **WHEN** 試しが動いている
- **THEN** 画面は試している最中であることを表示し、終わると結果に置き換える
