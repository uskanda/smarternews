# Proposal

## Why

実行の記録は30日残るが、実行履歴の一覧に出るのは新しい100件だけである。
続きを読み込む操作はなく、切れていることも表示しないため、利用者は古い実行がないと思い込む（Issue #204）。
カテゴリで絞り込めば、そのカテゴリの100件までは出る。

## What Changes

- 実行履歴の一覧が上限の100件に達したとき、表の下に注記を1行出す。
  - 絞り込みなし：「新しい100件だけを表示しています。カテゴリで絞り込むと、それより古い実行が出ます。」
  - カテゴリで絞り込み中：「このカテゴリの新しい100件だけを表示しています。」
- 上限の100件を定数にし、一覧の取得と注記の判定で同じ値を使う。
- 続きの読み込みは足さない。APIとサーバーは変えない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-runs`：「実行履歴の一覧」の要求に、表示する件数の上限と、上限に達したときの注記を足す。

## Impact

- `apps/web/src/api/queries.ts`：上限の定数と `useRuns`
- `apps/web/src/runs/RunsPage.tsx`：注記
- `apps/web/src/runs/runs.test.tsx`：注記のテスト
- 実行の一覧のAPI、カテゴリの画面、モバイル：変えない
