# Spec Delta

## MODIFIED Requirements

### Requirement: 実行履歴の一覧

実行履歴の画面が開かれたとき、画面は実行を新しい順に表示しなければならない（MUST）。各行には、カテゴリ、契機、開始の日時、状態、集めた候補の数、除外した数、作った記事と更新した記事の数、LLMの呼び出し回数を出す。
画面が表示する実行は、新しい100件までである。表示した実行が100件に達したとき、画面は、表の下に、新しい100件だけを表示していることを書かなければならない（MUST）。
カテゴリで絞り込んでいないときは、カテゴリで絞り込むとそれより古い実行が出ることも書く。絞り込み中は、絞り込みを勧める文を出さない。

#### Scenario: 今朝の実行を確かめる

- **WHEN** 今朝のスケジュールで3つのカテゴリが実行されたあとに実行履歴を開く
- **THEN** 3つの実行が新しい順に表示され、それぞれの契機は「スケジュール」である

#### Scenario: 実行が100件を超える

- **WHEN** 30日のうちに実行が120件ある状態で、カテゴリで絞り込まずに実行履歴を開く
- **THEN** 新しい100件が表示され、表の下の注記は、新しい100件だけを表示していることと、カテゴリで絞り込むとそれより古い実行が出ることを伝える

#### Scenario: 実行が100件に満たない

- **WHEN** 実行が99件ある状態で実行履歴を開く
- **THEN** 99件が表示され、100件だけを表示している旨の注記は表示されない

#### Scenario: 絞り込み中に100件に達する

- **WHEN** カテゴリAの実行が100件ある状態で、実行履歴をカテゴリAで絞り込む
- **THEN** 表の下に、このカテゴリの新しい100件だけを表示していることが表示され、絞り込みを勧める文は表示されない
