# Spec Delta

## MODIFIED Requirements

### Requirement: キーボードでの一覧の再取得

記事の一覧が表示されている間、`r` が押されたとき、画面は一覧の更新のボタンを押したときと同じく、件数と表示中の一覧をすぐに取得し直さなければならない（MUST）。
注釈の一覧が表示されている間、`r` が押されたとき、画面は件数と注釈の一覧をすぐに取得し直さなければならない（MUST）。
画面は、このキーで購読フィードの取得を始めてはならない（MUST NOT）。

#### Scenario: キーで一覧を読み直す

- **WHEN** 未読の一覧を開いたまま、サーバーで新しい記事が作られ、60秒を待たずに `r` を押す
- **THEN** 一覧に新しい記事が現れ、左のペインの未読数が増える

#### Scenario: キーで注釈の一覧を読み直す

- **WHEN** 注釈の一覧を開いたまま、サーバーで注釈が作られ、`r` を押す
- **THEN** 注釈の一覧に、その注釈の行が現れる

#### Scenario: 購読フィードを取得しない

- **WHEN** 購読フィードの一覧で `r` を押す
- **THEN** その購読フィードの取得は始まらない
