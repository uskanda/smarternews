# Spec Delta

## ADDED Requirements

### Requirement: 記事全体へのメモの書き直しでの注釈の一覧の行

注釈の一覧のまだ読み込んでいないページにある記事全体へのメモが書き直されたとき、画面は、そのメモの行を一覧の先頭に入れてはならない（MUST NOT）。
その行は、続きを読み込んだときに、メモを作った時刻の位置に、書き直した内容で1つだけ現れる。

#### Scenario: 2ページ目にある記事全体へのメモを書き直す

- **WHEN** 注釈が1ページに収まらないほどあり、2ページ目にある記事全体へのメモを書き直す
- **THEN** 一覧の先頭に行は入らず、「さらに読み込む」のあとも、そのメモの行は1つで、内容は書き直したものになる

### Requirement: 新しい記事全体へのメモの注釈の一覧での位置

記事全体へのメモのなかった記事にメモが書かれたとき、画面は、そのメモの行を注釈の一覧の先頭に入れなければならない（MUST）。

#### Scenario: 新しい記事全体へのメモを書く

- **WHEN** 注釈の一覧を表示したまま、メモのない記事にメモを書く
- **THEN** 一覧の先頭に、そのメモの行が現れる

### Requirement: 記事の削除のあとの注釈の一覧

購読フィードの登録の解除やカテゴリの削除で記事が消えたとき、画面は、消えた記事の注釈の行を注釈の一覧から除かなければならない（MUST）。

#### Scenario: 注釈の一覧を表示したまま購読フィードの登録を解除する

- **WHEN** 注釈の一覧を表示したまま、左のペインのメニューから、注釈のある配信記事の購読フィードの登録を解除する
- **THEN** その記事の注釈の行が一覧からなくなり、ほかの記事の行は残る

#### Scenario: カテゴリを削除してから注釈の一覧へ戻る

- **WHEN** 注釈の一覧を読み込んだあと、注釈のある生成記事のカテゴリを削除し、注釈の一覧へ戻る
- **THEN** その生成記事の注釈の行はなく、ほかの記事の行は残る
