# Spec Delta

## MODIFIED Requirements

### Requirement: 項目のメニュー

利用者が左のペインのカテゴリまたは購読フィードを右クリックしたとき、画面は、その項目のメニューを開かなければならない（MUST）。
購読フィードのメニューには「登録を解除」「上へ移動」「下へ移動」を、カテゴリのメニューには「上へ移動」「下へ移動」「カテゴリの設定」を出す。
動かせない項目には、メニューを出さない。「AI生成」の行と「未分類」は、これに当たる。

#### Scenario: 購読フィードのメニュー

- **WHEN** 左のペインの購読フィードを右クリックする
- **THEN** メニューが開き、「登録を解除」「上へ移動」「下へ移動」が並ぶ

#### Scenario: カテゴリのメニュー

- **WHEN** 左のペインのカテゴリを右クリックする
- **THEN** メニューが開き、「上へ移動」「下へ移動」「カテゴリの設定」が並ぶ

#### Scenario: 端にある項目

- **WHEN** カテゴリの中で先頭にある購読フィードのメニューを開く
- **THEN** メニューの「上へ移動」は、選べない状態で表示される

## ADDED Requirements

### Requirement: メニューからのカテゴリの設定

利用者がカテゴリのメニューで「カテゴリの設定」を選んだとき、画面は、そのカテゴリの設定の画面を開かなければならない（MUST）。

#### Scenario: カテゴリの設定を開く

- **WHEN** 左のペインのカテゴリBのメニューで「カテゴリの設定」を選ぶ
- **THEN** カテゴリBの設定の画面が開く
