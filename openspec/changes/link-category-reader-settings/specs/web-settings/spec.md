# Spec Delta

## ADDED Requirements

### Requirement: カテゴリの設定から一覧へのリンク

カテゴリの設定の画面は、見出しの下に、そのカテゴリの一覧へ進むリンクを表示しなければならない（MUST）。
リンクの文言は、ニュースのカテゴリでは「記事の一覧」、イベントのカテゴリでは「イベントの一覧」とする。
リンクは、有効と無効のどちらのカテゴリにも表示する。
保存していない変更があるとき、このリンクで画面を離れる前に、ほかの移動と同じ確認を出す。

#### Scenario: ニュースのカテゴリ

- **WHEN** ニュースのカテゴリAの設定の画面で「記事の一覧」を選ぶ
- **THEN** カテゴリAの記事の一覧が開く

#### Scenario: イベントのカテゴリ

- **WHEN** イベントのカテゴリEの設定の画面を開く
- **THEN** 見出しの下に、カテゴリEの一覧を指す「イベントの一覧」のリンクがあり、「記事の一覧」のリンクはない

#### Scenario: 無効のカテゴリ

- **WHEN** 無効にしたカテゴリAの設定の画面を開く
- **THEN** カテゴリAの記事の一覧を指す「記事の一覧」のリンクがある

#### Scenario: 保存していない変更がある

- **WHEN** カテゴリAの設定の画面で名前を書き換え、保存せずに「記事の一覧」を選ぶ
- **THEN** 保存していない変更があることを確かめるダイアログが出て、まだ設定の画面にいる
