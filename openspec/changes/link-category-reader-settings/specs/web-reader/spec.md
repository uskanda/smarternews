# Spec Delta

## ADDED Requirements

### Requirement: 一覧からカテゴリの設定へのリンク

1つのカテゴリの一覧を表示している間、画面は、一覧の上部に、そのカテゴリの設定の画面へ進む「カテゴリの設定」のリンクを表示しなければならない（MUST）。
1つのカテゴリの一覧は、カテゴリの記事の一覧、カテゴリの「AI生成」の一覧、イベントのカテゴリのイベントの一覧である。
記事の一覧では、リンクは見出しの下の、切り替えが並ぶ行に置く。イベントの一覧では、見出しの下に置く。
1つのカテゴリでない一覧（「未読」「すべて」、購読フィードの一覧など）には、このリンクを表示しない。

#### Scenario: カテゴリの記事の一覧

- **WHEN** カテゴリAの記事の一覧を開く
- **THEN** 一覧の上部に「カテゴリの設定」のリンクがあり、カテゴリAの設定の画面を指す

#### Scenario: AI生成の一覧から設定へ進む

- **WHEN** カテゴリAの「AI生成」の一覧で「カテゴリの設定」を選ぶ
- **THEN** カテゴリAの設定の画面が開く

#### Scenario: イベントの一覧

- **WHEN** イベントのカテゴリEの一覧を開く
- **THEN** 見出しの下に「カテゴリの設定」のリンクがあり、カテゴリEの設定の画面を指す

#### Scenario: カテゴリでない一覧

- **WHEN** 利用者が「すべて」の一覧、または購読フィードの一覧を開く
- **THEN** 一覧の上部に「カテゴリの設定」のリンクは表示されない
