# Spec Delta

## ADDED Requirements

### Requirement: 名前の記事の一覧からトピックを足す

名前の記事の一覧を名前つきで表示している間、画面は、一覧の上部に「トピックを足す…」の操作を表示しなければならない（MUST）。
操作を選んだとき、画面は、トピックを足すダイアログを、文章の下書きをその名前にして開かなければならない（MUST）。
カテゴリの初期値は、本文のペインに開いている元の記事で決める。
種類がニュースかイベントのカテゴリが1つもないとき、画面は、この操作を表示してはならない（MUST NOT）。

#### Scenario: 名前からトピックを足す

- **WHEN** 記事の下の名前を押して名前の記事の一覧を開き、「トピックを足す…」を選ぶ
- **THEN** ダイアログの文章の欄にその名前が入り、カテゴリには元の記事のカテゴリが選ばれている

#### Scenario: トピックを持てるカテゴリがない

- **WHEN** 種類がニュースかイベントのカテゴリが1つもない状態で、名前の記事の一覧を開く
- **THEN** 「トピックを足す…」の操作は表示されない

### Requirement: 選んだ文字列からトピックを足す

記事のペインの記事の中で文字が選ばれたとき、画面は、文字を選んだときのメニューと右クリックのメニューに「トピックを足す…」の操作を表示しなければならない（MUST）。
生成記事と配信記事のどちらでも、タイトル、本文、訳、要約のどれの選択でも表示する。
前後の空白を除いた文字列が1〜200文字でない選択、入力欄の中の選択、表示しない要素の中の選択では、表示してはならない（MUST NOT）。
種類がニュースかイベントのカテゴリが1つもないときも、表示してはならない（MUST NOT）。
操作を選んだとき、画面は、選んだ文字列の改行を空白に置き換えた値を下書きにして、トピックを足すダイアログを開かなければならない（MUST）。

#### Scenario: 生成記事の本文の語を選ぶ

- **WHEN** 生成記事の本文の1語を選ぶ
- **THEN** 文字を選んだときのメニューに、ハイライトの操作と並んで「トピックを足す…」が表示される

#### Scenario: 訳を選ぶ

- **WHEN** 配信記事の訳の1語を選ぶ
- **THEN** 「トピックを足す…」は表示され、隠すフィルターを作る操作は表示されない

#### Scenario: 改行を含む選択

- **WHEN** 2つの段落にまたがる文字を選び、「トピックを足す…」を選ぶ
- **THEN** ダイアログの文章の欄には、改行が空白に置き換わった文字列が入る

#### Scenario: 長すぎる選択

- **WHEN** 201文字の文字列を選ぶ
- **THEN** 「トピックを足す…」は表示されない

### Requirement: トピックを足すダイアログ

トピックを足すダイアログは、カテゴリと文章の2つの欄を持たなければならない（MUST）。
カテゴリの選択肢は、種類がニュースかイベントのカテゴリを、左のペインと同じ並びで並べる。
カテゴリの初期値は、開いている記事のカテゴリとする。配信記事では、購読フィードのカテゴリとする。
それが選択肢にないときは、左のペインに並ぶカテゴリのうち先頭のものとする。
文章の上限は2000文字とし、設定の画面のトピックにそろえる。
追加したとき、画面は、選んだカテゴリにトピックを作り、ダイアログを閉じ、`追加しました。次の実行で解釈されます。`と知らせなければならない（MUST）。
知らせには、作ったトピックの編集を開く操作を置く。
追加のとき、画面は、実行を始めてはならず、開いている記事と一覧を閉じてはならない（MUST NOT）。
有効かどうかや取得元などのほかの項目は、設定の画面でトピックを足したときと同じ既定値にする。
追加に失敗したとき、画面は、ダイアログを開いたまま、失敗したことを表示しなければならない（MUST）。

#### Scenario: 追加して編集へ移る

- **WHEN** ダイアログで「追加する」を押し、知らせの「編集する」を選ぶ
- **THEN** 選んだカテゴリにトピックが作られ、そのトピックの編集を開いた設定の画面へ移る

#### Scenario: 追加しても記事は残る

- **WHEN** ダイアログで「追加する」を押す
- **THEN** ダイアログは閉じ、開いている記事と一覧はそのまま表示され、実行は始まらない

#### Scenario: カテゴリのない記事

- **WHEN** カテゴリのない配信記事で、トピックを足すダイアログを開く
- **THEN** 左のペインに並ぶ先頭のニュースかイベントのカテゴリが選ばれている

#### Scenario: 追加に失敗する

- **WHEN** サーバーが追加を拒む
- **THEN** ダイアログは開いたままで、失敗したことが表示される

### Requirement: 同じ文章のトピックの知らせ

ダイアログで選んだカテゴリに、文章の欄と同じ文章のトピックがあるとき、画面は、`同じ文章のトピックがあります`と表示し、そのトピックの編集へのリンクを出さなければならない（MUST）。
同じかどうかは、両方をNFKCで正規化し、小文字にし、前後の空白を除いてから比べる。
このとき、画面は、追加を止めてはならない（MUST NOT）。

#### Scenario: 全角と大文字の違いだけのトピックがある

- **WHEN** カテゴリに全角の英字で書いた `Ｂａｎｋ ｏｆ Ｊａｐａｎ` のトピックがあり、文章の欄が前後に空白のある小文字の `bank of japan` である
- **THEN** `同じ文章のトピックがあります`とリンクが表示され、「追加する」は押せる
