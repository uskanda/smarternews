## ADDED Requirements

### Requirement: 外れの印のキー

生成記事の本文が表示されている間、`x` のキーが押されたとき、画面は本文のペインの外れの印の操作と同じ操作をしなければならない（MUST）。配信記事の本文が表示されている間と、本文が表示されていない間は、`x` のキーで何もしてはならない（MUST NOT）。キー操作の一覧は `x` を含まなければならない（MUST）。

#### Scenario: キーで印を付ける

- **WHEN** 生成記事を開いた状態で `x` を押す
- **THEN** その記事に外れの印が付いて既読になり、「取り消す」を持つ知らせが出る

#### Scenario: 配信記事でキーを押す

- **WHEN** 配信記事を開いた状態で `x` を押す
- **THEN** 何も変わらず、`x` による変更の要求はサーバーへ送られない

#### Scenario: キー操作の一覧を出す

- **WHEN** `?` を押す
- **THEN** 一覧に `x` と、生成記事の外れの印の切り替えであることが表示される
