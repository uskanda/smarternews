## ADDED Requirements

### Requirement: トピックの外れの件数の表示

カテゴリの編集の画面のトピックの一覧で、前の解釈のあとの外れが1件以上あるトピックについて、画面はその件数と、解釈で判定基準に反映されることを表示しなければならない（MUST）。解釈が済んだトピックには、解釈し直す操作も表示しなければならない（MUST）。操作が選ばれたとき、画面はそのトピックを次の実行で解釈し直す状態にしなければならない（MUST）。外れが0件のトピックには、何も表示しない。

#### Scenario: 解釈のあとに外れがある

- **WHEN** 解釈が済み、前の解釈のあとに外れが2件あるトピックを表示する
- **THEN** 外れが2件あることと、解釈し直すと判定基準に反映されることが表示され、「解釈し直す」のボタンが出る

#### Scenario: 解釈し直す

- **WHEN** 解釈し直すボタンを選ぶ
- **THEN** トピックは次の実行で解釈される状態になり、外れの件数が次の解釈で反映されることが表示される
