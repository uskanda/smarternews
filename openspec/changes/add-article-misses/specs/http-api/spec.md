## ADDED Requirements

### Requirement: 外れの印の変更

`PATCH /api/v1/articles/:id` が `missed` を含むとき、サーバーは生成記事の外れの印を変えなければならない（MUST）。`true` なら、記事の見出し、カテゴリ、その時点の記事のトピック、印を付けた時刻を外れの記録として保存し、記事を既読にする。すでに印のある記事では、最初の記録をそのまま残す。`false` なら外れの記録を消し、既読の状態は変えない。同じ要求に `isRead` があるときは、`isRead` の値を既読の状態にする。記事の詳細の応答は、外れの印があるかを `missed` で示さなければならない（MUST）。

#### Scenario: 外れの印を付ける

- **WHEN** 未読の生成記事に `{"missed":true}` を送る
- **THEN** 応答の `missed` は `true`、`isRead` は `true` になり、外れの記録がその記事の見出しとトピックとともに保存される

#### Scenario: 印を付けたことを取り消す

- **WHEN** 未読のときに印を付けた記事に `{"missed":false,"isRead":false}` を送る
- **THEN** 外れの記録が消え、記事は未読に戻る

#### Scenario: 印だけを外す

- **WHEN** 外れの印のある既読の記事に `{"missed":false}` を送る
- **THEN** 外れの記録が消え、記事は既読のまま残る

### Requirement: 配信記事での外れの拒否

`missed` を含む要求が配信記事に送られたとき、サーバーは400を返し、何も変えてはならない（MUST）。誤りの項目は `missed`、理由のコードは `not_allowed` とする。

#### Scenario: 配信記事に印を付けようとする

- **WHEN** 未読の配信記事に `{"missed":true}` を送る
- **THEN** 400が返り、記事は未読のままで、外れの記録は作られない

### Requirement: 記事が消えたあとの外れの記録

生成記事が削除されたとき、サーバーはその記事の外れの記録を、見出しとトピックとともに残さなければならない（MUST）。外れの印は記事の保持を変えてはならない（MUST NOT）。トピックが削除されたときは記録からそのトピックとのつながりだけを外し、カテゴリが削除されたときはそのカテゴリの記録を消さなければならない（MUST）。

#### Scenario: 180日を過ぎた記事を消す

- **WHEN** 外れの印を付けた生成記事が、スターと注釈のどちらもないまま180日を過ぎる
- **THEN** 記事は消え、外れの記録は見出しとトピックとともに残る

#### Scenario: カテゴリを消す

- **WHEN** 外れの記録があるカテゴリを削除する
- **THEN** そのカテゴリの外れの記録も消える

### Requirement: トピックの外れの件数

トピックの応答は、そのトピックの外れのうち、前の解釈より後に印を付けたものの件数を `missesSinceInterpretation` で示さなければならない（MUST）。解釈の時刻が記録されていないトピックでは、すべての外れを数える。

#### Scenario: 解釈のあとに印を付ける

- **WHEN** 解釈より前に1件、解釈より後に1件の外れの印を付けたトピックを取得する
- **THEN** `missesSinceInterpretation` は1である
