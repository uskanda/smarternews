## ADDED Requirements

### Requirement: キーで移ったときのフォーカスの移動

一覧の中にフォーカスがある間、`j` か `k` のキー、または本文の末尾での `Space` で記事か注釈を移ったとき、画面は、選んだ行のリンクへフォーカスを移さなければならない（MUST）。
このとき一覧のスクロールは、キーで移ったときのいつもの動きのままにする。

#### Scenario: 行をクリックしてから次の記事へ進む

- **WHEN** 記事の一覧の1件目の行をクリックしてから `j` を押す
- **THEN** 2件目が選ばれ、フォーカスの枠は2件目の行のリンクに表示される

#### Scenario: 注釈の一覧で次の注釈へ進む

- **WHEN** 注釈の一覧の1件目の行をクリックしてから `j` を押す
- **THEN** 2件目の注釈が選ばれ、フォーカスは2件目の行のリンクにある

### Requirement: 一覧の外にフォーカスがあるときのキーでの移動

一覧の外にフォーカスがある間、`j` か `k` のキー、または本文の末尾での `Space` で記事か注釈を移ったとき、画面は、フォーカスを一覧へ移してはならない（MUST NOT）。

#### Scenario: 本文にフォーカスがあるときに次の記事へ進む

- **WHEN** 本文のペインにフォーカスがある状態で `j` を押す
- **THEN** 次の記事が選ばれ、フォーカスは一覧の行へ移らない
