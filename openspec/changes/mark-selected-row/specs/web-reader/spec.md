## ADDED Requirements

### Requirement: 選択中の行の形の目印

画面は、記事の一覧、イベントの一覧、注釈の一覧の選択中の行に、地の色に加えて、行の右端に上から下までの縦線を表示しなければならない（MUST）。
縦線は選択中の行だけに表示し、ほかの行には表示しない。

#### Scenario: 記事を選ぶ

- **WHEN** 記事の一覧で2件目の記事を選ぶ
- **THEN** 2件目の行の右端に縦線が表示され、ほかの行には表示されない

#### Scenario: 注釈を選ぶ

- **WHEN** 注釈の一覧で1件目の注釈を開く
- **THEN** 1件目の行の右端に縦線が表示される

### Requirement: 未読の行の読み上げ

画面は、記事の一覧とイベントの一覧の未読の行で、見出しの前に、読み上げ用の「未読。」を置かなければならない（MUST）。
「未読。」は、重要度の読み上げより前に置く。既読の行には置かない。

#### Scenario: 未読と既読が混ざった一覧を読み上げる

- **WHEN** 既読を含める切り替えを入れた一覧に、重要度4の未読の記事と既読の記事がある
- **THEN** 未読の行のリンクは「未読。重要度4。」で始まる名前で読み上げられ、既読の行のリンクの名前に「未読」は含まれない
