# grilling 記録: show-embedded-media-links

GitHubのissueの213番のコメントで、1ラウンドの質問（Q1、Q2）に答えた記録である。
issueは、内容の変換が `iframe`、`video`、`audio`、`object`、`embed` の要素を中身ごと捨てるため、動画や音声を埋め込んだ記事で読み手が動画のあったことに気付けない、というWeb UIの監査の項目（R-03）である。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 表の変換をこのissueに含めるか | このissueは埋め込みだけを扱い、表は別のissueに分ける。表は今の ` \| ` 区切りの段落のままにする（A） | 第1ラウンド Q1 |
| `source` の子で指す動画と音声 | 要素に `src` がないときは、http(s)の最初の `source` の `src` をリンク先にする（A） | 第1ラウンド Q2 |

## 計画で決めたこと

承認を求めた計画（issueのコメント）で、次を決めた。利用者は変更なしで承認した。

| 決定 | 選択 |
|---|---|
| 文言 | 出力言語に従う。日本語は「埋め込み（ホスト名）」、英語は「Embedded content (host)」 |
| 照合用の `text` | リンクの文字を入れない。画像とアドレスを入れないのと同じ扱い |
| 翻訳の答えの読み取り | `google.ts` では今までどおり埋め込みを捨てる。変換にオプションを足し、配信の内容と全文の取得だけで有効にする |
| 翻訳の区切り | 埋め込みのリンクだけの段落は、画像だけの段落と同じく翻訳しない |
| 捨てるもの | 幅か高さが0か1の枠、`object` と `embed`、`src` がhttp(s)でない要素は、今までどおり捨てる |
| 段落の扱い | 段落の途中にあっても、前後の文章とは別の段落にする |
| 枠の表示 | 枠は表示しない。「動画と埋め込みの枠は表示しない」という決定（add-feed-subscriptionsの第2ラウンドQ12）は変えず、画面も変えない |
| 保存済みの記事 | 次の取得で書き換えとして扱われ、本文の翻訳が消える。LLMは使わない |
