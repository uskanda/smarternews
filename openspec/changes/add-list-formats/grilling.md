## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 足す形式 | タイトルだけを1行に詰めたリストと、展開（本文を一覧に続けて並べる）の2つ。画像が中心の2つの形式（画像と抜粋を格子に並べる形式と、画像を左に置いた大きめの行の形式）は足さない | 第1ラウンド Q1 |
| 対象の画面 | まずWebに入れる。アプリは別のissueで決める | 第1ラウンド Q2 |
| 形式を選ぶ単位 | 左のペインの項目ごとに決め、サーバーに保存する。並び順（#48）と同じ単位 | 第1ラウンド Q3 |
| 展開の形式と本文のペイン | 本文のペインを閉じ、一覧のペインを広げる | 第1ラウンド Q4 |
| 画像の出し方 | 画像が中心の形式を足さないので決めない | 第1ラウンド Q5 |
| 展開の形式で自動で走る処理 | 要約の依頼、翻訳、全文の取得、開いた記録は、表示範囲に入った記事にだけ走らせる。読み込んだだけの記事には走らせない | 第3ラウンド Q1（A） |
| 展開の形式での既読 | #50の設定に従うのに加えて、`j`・`k` で移った先の記事と、見出しを押して選んだ記事を既読にする | 第3ラウンド Q2（B） |
| 展開の形式での操作の対象 | 表示範囲の上端にある記事。スクロールすると対象も移る。対象には選択中の行と同じ右端の線を出す | 第3ラウンド Q3（A） |
| 形式を選べる項目 | 並び順のメニューと同じ項目。イベントのカテゴリ、最近読んだ記事、注釈、検索の結果、名前の記事の一覧は今の形式のまま | 第3ラウンド Q4（A） |
| タイトルのみの1行 | タイトルの右に購読フィードかカテゴリの名前と時刻を小さく出す。重要度の印は今の左の線と見出しの線。スター、「更新」、「未確認」は残す。要約、出典の件数、語のまとまりの印は出さない | 第3ラウンド Q5（A） |
| 展開の形式で並べる内容 | 本文のペインと同じもの（`ArticleView`）を記事ごとに並べる | 第3ラウンド Q6（A） |
| 展開の形式の読み込みの単位 | 10件ずつ。末尾に近づいたら続きを自動で読み込む | 第3ラウンド Q7（A） |
| 展開の形式でのキー | `j`・`k` は次と前の記事の見出しを上端へ送る。`Space` と `Shift+Space` は一覧を1画面分送る | 第3ラウンド Q8（A） |
| 切り替えの操作と形式の名前 | 並び順のメニューの隣に「表示」のボタンを置き、ボタンの文字にいまの形式の名前を含める。メニューには「標準」「タイトルのみ」「展開」を並べる | 第3ラウンド Q9（A） |
| 既定の形式 | 今の形式（標準）。移行のあとも画面は変わらない | 第3ラウンド Q10（A） |
| 計画 | 計画（issueのコメント 6923439382）を、そのまま承認 | 会話中に確認（コメント 6950787354 の /ok） |

- 画像が中心の2つの形式と、その画像の出し方（#66の画像のプロキシと合わせて決める）
