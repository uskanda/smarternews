# Spec Delta

## MODIFIED Requirements

### Requirement: ペインの構成

画面の幅が広いとき、画面は、項目の一覧、記事の一覧、本文の3つのペインを同時に表示しなければならない（MUST）。
ただし、記事の一覧が「展開」の形式の間は、本文のペインを閉じ、記事の一覧のペインを広げる。

#### Scenario: 広い画面

- **WHEN** 幅1280pxの画面で記事を選ぶ
- **THEN** 左に項目の一覧、中央に記事の一覧、右に本文が同時に表示される

#### Scenario: 展開の形式の項目

- **WHEN** 幅1280pxの画面で、形式を「展開」にした項目を選ぶ
- **THEN** 左に項目の一覧、右に記事の一覧が表示され、本文のペインは表示されない

## ADDED Requirements

### Requirement: 展開の形式でのキーボードでの記事の移動

「展開」の形式の間、`j` または `k` のキーが押されたとき、画面は、対象の記事の次または前の記事の見出しを表示範囲の上端へ送り、その記事を既読にしなければならない（MUST）。
読み込んだ最後の記事で `j` が押されたとき、続きがあれば読み込んでから進む。

#### Scenario: 次の記事へ進む

- **WHEN** 形式が「展開」の一覧の1件目が上端にある状態で `j` を押す
- **THEN** 2件目の見出しが上端に来て、2件目は既読になり、1件目は未読のままである

### Requirement: 展開の形式でのページ送り

「展開」の形式の間、`Space` のキーが押されたとき、画面は、記事の一覧を1画面より1行少ない分だけ下へ送らなければならない（MUST）。
`Shift+Space` のときは、同じ分だけ上へ戻す。

#### Scenario: 1画面分を送る

- **WHEN** 形式が「展開」の一覧の先頭で `Space` を押し、続けて `Shift+Space` を押す
- **THEN** 一覧は1画面より少し少ない分だけ下へ進み、そのあと先頭に戻る

### Requirement: 展開の形式でのキーボードでの記事の操作

「展開」の形式の間、`s`、`m`、`o`、`w`、`x` のキーが押されたとき、画面は、表示範囲の上端にある記事に対して、本文のペインの記事と同じ操作をしなければならない（MUST）。

#### Scenario: 上端の記事にスターを付ける

- **WHEN** 形式が「展開」の一覧を2件目が上端に来るまでスクロールし、`s` を押す
- **THEN** 2件目にスターが付き、1件目は変わらない
