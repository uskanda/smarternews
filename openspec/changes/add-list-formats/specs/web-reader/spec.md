# Spec Delta

## ADDED Requirements

### Requirement: 形式のメニュー

並び順のメニューを表示している間、画面は、その隣に一覧の形式のメニューを表示しなければならない（MUST）。
メニューの選択肢は「標準」「タイトルのみ」「展開」の3つである。メニューを開くボタンは、「表示」の語と、いまの形式の名前を示す。

#### Scenario: 形式を変えていない項目

- **WHEN** 形式を変えていないカテゴリAを左のペインで選ぶ
- **THEN** 並び順のメニューの隣に形式のメニューが表示され、いまの形式は「標準」と読み取れる

### Requirement: 形式のメニューを出さない一覧

イベントの一覧、最近読んだ記事の一覧、注釈の一覧、検索の結果、名前の記事の一覧を表示している間、画面は形式のメニューを表示してはならない（MUST NOT）。
これらの一覧は「標準」の形式で表示する。

#### Scenario: 最近読んだ記事を開く

- **WHEN** 左のペインで「最近読んだ記事」を選ぶ
- **THEN** 形式のメニューは表示されず、一覧は「標準」の形式で表示される

### Requirement: 形式の切り替え

利用者が形式のメニューで形式を選んだとき、画面は、表示中の項目の一覧を選んだ形式で表示し直さなければならない（MUST）。
選んだ形式は、その項目の形式としてサーバーに保存する。並び順は変えない。

#### Scenario: タイトルのみに変える

- **WHEN** 古い順にしたカテゴリBで、形式のメニューから「タイトルのみ」を選ぶ
- **THEN** カテゴリBの一覧は1行ずつの形式で表示され、並び順は古い順のままである

### Requirement: 形式の保存の失敗

形式の保存に失敗したとき、画面は、一覧とメニューを元の形式に戻し、保存できなかったことを伝えなければならない（MUST）。

#### Scenario: サーバーに届かない

- **WHEN** サーバーに届かない状態で、形式のメニューから「展開」を選ぶ
- **THEN** 一覧とメニューは「標準」に戻り、表示を保存できなかったことが表示される

### Requirement: タイトルのみの行

「タイトルのみ」の形式の間、画面は記事の一覧の1行で見出しと名前と時刻を1段に並べなければならない（MUST）。
名前は、配信記事では購読フィードの名前、生成記事ではカテゴリの名前である。
重要度の印は「標準」と同じく行の左の線と見出しの線で示し、スター、「更新」、「未確認」の印も出す。

#### Scenario: 重要度5の未確認の記事

- **WHEN** 形式が「タイトルのみ」の一覧に、重要度5で未確認の生成記事がある
- **THEN** その行は1段で、見出しに重要度の線が重なり、「未確認」の印が出る

### Requirement: タイトルのみの行で出さないもの

「タイトルのみ」の形式の間、画面は、記事の一覧の行に、要約、出典の件数、語のまとまりの印を表示してはならない（MUST NOT）。

#### Scenario: 要約のある記事

- **WHEN** 形式が「タイトルのみ」の一覧に、要約と出典を持つ生成記事がある
- **THEN** その行に要約と出典の件数は表示されない

### Requirement: タイトルのみの一覧での記事の選択

「タイトルのみ」の形式の間、行が選ばれたとき、画面は「標準」と同じく、その記事を本文のペインに表示しなければならない（MUST）。

#### Scenario: 行を押す

- **WHEN** 形式が「タイトルのみ」の一覧で記事Aの行を押す
- **THEN** 本文のペインに記事Aが表示され、記事Aは既読になる

### Requirement: 展開の形式の記事の並び

「展開」の形式の間、画面は、一覧の記事ごとに、本文のペインに出すものと同じ内容を一覧に続けて並べなければならない（MUST）。
全文、要約の区画、メモ、ハイライト、出典、操作のボタンも出す。

#### Scenario: 表示範囲に入った配信記事

- **WHEN** 形式が「展開」の一覧で、全文と自動の要約を持つ配信記事が表示範囲に入る
- **THEN** その記事の全文と要約の区画が、一覧の中に表示される

### Requirement: 展開の形式の読み込み

「展開」の形式の間、画面は、記事を10件ずつ読み込まなければならない（MUST）。
読み込んだ記事の末尾が表示範囲に近づいたとき、続きの10件を読み込む。

#### Scenario: 15件ある一覧

- **WHEN** 15件の記事がある項目を「展開」で開き、末尾までスクロールする
- **THEN** 最初は10件が並び、末尾に近づくと残りの5件が加わる

### Requirement: 表示範囲に入る前の記事

「展開」の形式の間、表示範囲にまだ入っていない記事について、画面は、記事の取得、要約の依頼、翻訳、全文の取得、開いた記録の送信をしてはならない（MUST NOT）。
その記事は、補足、見出し、一覧の要約だけを表示する。

#### Scenario: 読み込んだだけの記事

- **WHEN** 形式が「展開」の一覧で10件を読み込み、1件目だけが表示範囲にある
- **THEN** 2件目から10件目の開いた記録は送られず、要約も依頼されない

### Requirement: 表示範囲に入った記事

「展開」の形式の間、記事が初めて表示範囲に入ったとき、画面はその記事を取得しなければならない（MUST）。
取得したあとは、本文のペインで開いたときと同じ処理（要約の依頼、翻訳、全文の取得、開いた記録の送信）を走らせる。
表示範囲に入っただけでは、記事を既読にしない。

#### Scenario: スクロールで2件目が入る

- **WHEN** 形式が「展開」の一覧をスクロールし、2件目の記事が表示範囲に入る
- **THEN** 2件目の本文が表示され、開いた記録が送られ、2件目は未読のままである

### Requirement: 展開の形式の対象の記事

「展開」の形式の間、画面は、表示範囲の上端にある記事を、キー操作の対象として示さなければならない（MUST）。
対象の記事には、一覧の選択中の行と同じ右端の線を出す。スクロールすると、対象も移る。

#### Scenario: 1件目を通り過ぎる

- **WHEN** 形式が「展開」の一覧で、1件目の記事の下端が表示範囲の上端を越えるまでスクロールする
- **THEN** 右端の線は2件目の記事に移る

### Requirement: 見出しを押して選ぶ

「展開」の形式の間、記事の見出しが押されたとき、画面は、その記事の見出しを表示範囲の上端へ送り、その記事を既読にしなければならない（MUST）。

#### Scenario: 3件目の見出しを押す

- **WHEN** 形式が「展開」の一覧で、3件目の記事の見出しを押す
- **THEN** 3件目の見出しが上端に来て、3件目は既読になる

### Requirement: 展開の形式でのスクロールによる既読

「展開」の形式の間、スクロールした記事を既読にする設定が有効なとき、画面は、表示範囲の上端を越えた記事を既読にしなければならない（MUST）。

#### Scenario: 設定が有効

- **WHEN** スクロールした記事を既読にする設定が有効な状態で、「展開」の1件目を上端の先までスクロールする
- **THEN** 1件目は既読になり、2件目は未読のままである

### Requirement: 展開の形式からリンクで開いた記事

「展開」の形式の項目で、パスで記事が指定されたとき、画面は、その記事だけを一覧へ戻るリンクとともに表示しなければならない（MUST）。

#### Scenario: その後の記事のリンク

- **WHEN** 形式が「展開」の一覧で、記事の「この話題のその後の記事」のリンクを押す
- **THEN** リンク先の記事だけが表示され、一覧へ戻るリンクがある
