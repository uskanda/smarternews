# Spec Delta

## ADDED Requirements

### Requirement: 表示の設定の一覧の形式

APIは、項目ごとの表示の設定の読み出しと変更で、並び順に加えて一覧の形式を扱わなければならない（MUST）。
形式は `standard`、`compact`、`expanded` のどれかである。形式を変えていない項目は `standard` として返す。

#### Scenario: 形式を変える

- **WHEN** 購読フィードXの形式を `expanded` に変える操作を呼ぶ
- **THEN** APIは、購読フィードXの表示の設定を、並び順と形式 `expanded` を含めて返す

#### Scenario: 並び順だけを変える

- **WHEN** 形式を `compact` にした「未読」の並び順を古い順に変える操作を呼ぶ
- **THEN** APIは、並び順を古い順、形式を `compact` として返す

### Requirement: 知らない形式の変更

知らない形式への変更を受けたとき、APIは、入力が不正であることを示す応答を返さなければならない（MUST）。

#### Scenario: 知らない名前の形式

- **WHEN** 固定の項目の「未読」の形式を `cards` に変える操作を呼ぶ
- **THEN** APIは、入力が不正であることを示す応答を返し、表示の設定は変わらない

### Requirement: 表示の設定を持たない項目の形式

イベントのカテゴリと最近読んだ記事の形式の変更を受けたとき、APIは、入力が不正であることを示す応答を返さなければならない（MUST）。

#### Scenario: 最近読んだ記事

- **WHEN** 最近読んだ記事の形式を `expanded` に変える操作を呼ぶ
- **THEN** APIは、入力が不正であることを示す応答を返し、表示の設定は変わらない
