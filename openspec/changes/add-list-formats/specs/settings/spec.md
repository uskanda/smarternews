# Spec Delta

## ADDED Requirements

### Requirement: 項目ごとの一覧の形式の保持

サーバーは、左のペインの項目ごとに、Webの記事の一覧の形式を保存しなければならない（MUST）。
形式は「標準」「タイトルのみ」「展開」のどれかで、既定は「標準」である。形式を保存する項目は、並び順を保存する項目と同じである。

#### Scenario: 再起動のあとも残る

- **WHEN** 購読フィードXの形式を「展開」にしてから、サーバーを再起動する
- **THEN** 購読フィードXの形式は「展開」のままである

#### Scenario: 移行の前からある設定

- **WHEN** 並び順を古い順にした項目を持つサーバーを、形式のある版へ入れ替える
- **THEN** その項目の並び順は古い順のままで、形式は「標準」である

### Requirement: 並び順と形式の別々の変更

並び順だけの変更を受けたとき、サーバーは、その項目の形式を変えてはならない（MUST NOT）。
形式だけの変更を受けたときも、並び順を変えない。

#### Scenario: 並び順を戻しても形式は残る

- **WHEN** 固定の項目の「すべて」を古い順と「展開」にしてから、並び順だけを新しい順に戻す
- **THEN** 固定の項目の「すべて」の形式は「展開」のままである

### Requirement: 既定に戻った項目の表示の設定

並び順と形式の両方が既定に戻ったとき、サーバーは、その項目を表示の設定を変えた項目として扱ってはならない（MUST NOT）。

#### Scenario: 両方を既定に戻す

- **WHEN** 固定の項目の「スター」を古い順と「タイトルのみ」にしてから、新しい順と「標準」に戻し、表示の設定を読み出す
- **THEN** 固定の項目の「スター」は、表示の設定を変えた項目として返らない

### Requirement: 設定ファイルへの形式の書き出し

設定ファイルの書き出しは、形式を「標準」以外にした項目とその形式を含めなければならない（MUST）。
「標準」の形式は書かない。

#### Scenario: タイトルのみにした項目

- **WHEN** 固定の項目の「未読」を「タイトルのみ」にした状態で書き出す
- **THEN** 返されたYAMLには、「未読」が `format: compact` として含まれ、並び順は書かれない

### Requirement: 設定ファイルからの形式の読み込み

設定ファイルの読み込みを受けたとき、サーバーは、設定ファイルに書かれた項目の形式を保存しなければならない（MUST）。
形式を書いていない項目は、保存済みの形式を変えない。

#### Scenario: 形式を書いていない古い設定ファイル

- **WHEN** 固定の項目の「未読」を「展開」にしたサーバーへ、「未読」の並び順だけを書いた設定ファイルを読み込む
- **THEN** 固定の項目の「未読」の形式は「展開」のままである

### Requirement: 知らない形式の拒否

知らない形式が書かれた設定ファイルの読み込みを受けたとき、サーバーは、不正な設定ファイルとして拒否しなければならない（MUST）。

#### Scenario: 知らない名前の形式

- **WHEN** `format: cards` を書いた設定ファイルを読み込む
- **THEN** サーバーは不正な箇所を返し、設定ファイルのほかの内容も保存されない

### Requirement: 形式の往復

書き出した設定ファイルを空のサーバーに読み込んだとき、サーバーは、書き出し元と同じ項目ごとの形式を持たなければならない（MUST）。

#### Scenario: 別のサーバーへ移す

- **WHEN** 固定の項目の「未読」を「タイトルのみ」に、カテゴリ `tools` を古い順と「展開」にしたサーバーから書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーでも、「未読」は「タイトルのみ」で、`tools` は古い順と「展開」である
