# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードの設定からの登録解除

購読フィードの一覧から開いた「購読フィードの設定」のダイアログは、その購読フィードの「登録を解除」の操作を表示しなければならない（MUST）。
利用者が「登録を解除」を選んだとき、画面は、保存していない切り替えを捨てて設定のダイアログを閉じ、登録を解除するかを確かめるダイアログを開かなければならない（MUST）。
確かめるダイアログは、設定の画面の登録解除と同じ内容を伝える。消える配信記事の件数、そのうちスターの付いた件数と注釈のある件数、元に戻せないこと、その購読フィードに範囲を絞ったフィルター、取得だけを止める一時停止である。

#### Scenario: 登録を解除を選ぶ

- **WHEN** 購読フィードXの一覧で「購読フィードの設定」を開き、「登録を解除」を選ぶ
- **THEN** 設定のダイアログが閉じ、Xの配信記事の件数と元に戻せないことを述べる確認のダイアログが開く

#### Scenario: 確かめて解除する

- **WHEN** 確認のダイアログで登録の解除を選ぶ
- **THEN** 購読フィードXは削除され、左のペインから消え、解除したことが知らされ、画面は「未読」の一覧を開く

#### Scenario: 確認で取りやめる

- **WHEN** 確認のダイアログでやめるを選ぶ
- **THEN** 購読フィードXは残り、Xの一覧が表示されたままで、フォーカスは「購読フィードの設定」の操作にある

#### Scenario: 解除に失敗する

- **WHEN** 確認のダイアログで登録の解除を選び、削除に失敗する
- **THEN** 解除できなかったことが知らされ、Xの一覧が表示されたままである
