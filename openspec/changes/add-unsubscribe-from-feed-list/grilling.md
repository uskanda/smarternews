Issue #178「フィードを表示中のペインからフィードを削除できるようにする」で、計画についての質問に答えてもらった。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 登録解除の操作を置く場所 | A：「購読フィードの設定」のダイアログの下端に「登録を解除」を置く。押すと設定のダイアログを閉じ、確認のダイアログを開く | Issue #178 第1ラウンド Q1 |
| 操作と確認の文言 | A：左のペインと設定の画面と同じ「登録を解除」の文言と確認の文面にし、確認のダイアログは3か所で共有する部品にまとめる | Issue #178 第1ラウンド Q2 |
| 解除したあとに開く画面 | A：左のペインのメニューからの解除と同じく「未読」の一覧を開く | Issue #178 第1ラウンド Q3 |
| 対象とする画面 | A：Webの画面だけにする。Androidアプリには手を入れない | Issue #178 第1ラウンド Q4 |
| 計画の承認 | 上の4つの答えに沿った計画を承認 | Issue #178への返答（`/ok`） |
