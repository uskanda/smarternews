## ADDED Requirements

### Requirement: 今回の更新で加わったことの表示

続報で更新された記事が今回加わったことを持つとき、画面はそれを本文より前に、「今回の更新で加わったこと」の見出しつきで表示しなければならない（MUST）。
その区画は、見出しと未確認の表示のあと、読み手への影響の前に置く。

#### Scenario: 今回加わったことのある記事

- **WHEN** 更新回数が1で今回加わったことを持つ記事を選ぶ
- **THEN** 本文の前に「今回の更新で加わったこと」の見出しとその文が表示される

#### Scenario: 今回加わったことのない記事

- **WHEN** 更新回数が1で今回加わったことのない記事を選ぶ
- **THEN** 本文の画面に「今回の更新で加わったこと」は表示されない

### Requirement: 新しい出典の印

生成記事の出典が新しい出典のとき、画面は出典の一覧のその出典に「新しい出典」の印を表示しなければならない（MUST）。

#### Scenario: 読んだあとに加わった出典

- **WHEN** 出典A、Bのうち、前回読んだあとに出典Bが加わった記事を選ぶ
- **THEN** 出典Bにだけ「新しい出典」の印が付く

### Requirement: 一覧の行の更新の1行

記事が今回加わったことを持つとき、画面は一覧のその行に、要約の1行の代わりに、「更新：」に続けて今回加わったことを1行に収めて表示しなければならない（MUST）。
既読の記事でも未読の記事でも同じように表示する。
検索の結果で抜粋があるときは、抜粋を表示する。

#### Scenario: 続報で書き直された記事の行

- **WHEN** 今回加わったことを持つ記事が一覧にある
- **THEN** その行の要約の場所に「更新：」とその文が表示され、要約は表示されない

#### Scenario: 既読にした記事の行

- **WHEN** 今回加わったことを持つ記事を既読にして、既読を含む一覧で見る
- **THEN** その行の要約の場所に「更新：」とその文が表示されたままである

#### Scenario: 検索の結果

- **WHEN** 今回加わったことを持つ記事が、本文の語で検索の結果に出る
- **THEN** その行には抜粋が表示される

## MODIFIED Requirements

### Requirement: 前の記事への参照

記事が前の記事への参照を持つとき、画面は前の記事の連なりを、新しい順に、それぞれの記事を開く操作として表示しなければならない（MUST）。
連なりの各記事には、見出しと最初の公開日を表示する。

#### Scenario: 1週間後の続報

- **WHEN** 前の記事への参照を持つ記事を選ぶ
- **THEN** 前の記事の見出しが表示され、選ぶとその記事が開く

#### Scenario: 3つ目の続報

- **WHEN** 記事Cが記事Bを、記事Bが記事Aを前の記事として参照し、記事Cを選ぶ
- **THEN** 本文の画面の「この話題の前の記事」に、記事B、記事Aの順で見出しと最初の公開日が表示される
