# Spec Delta

## ADDED Requirements

### Requirement: 期間を選んだ一括の既読

一括の既読を選べる一覧で、画面は、「1日より古い記事」「3日より古い記事」「1週間より古い記事」を選ぶメニューを表示しなければならない（MUST）。
利用者が期間を選んだとき、画面は、表示中の項目と絞り込みに当たる未読の記事のうち、基準の時刻より前に更新されたものだけを既読にしなければならない（MUST）。
基準の時刻は、いまの時刻からその期間を引いた時刻と、一覧を読み込んだ時刻の早いほうである。
期間を選んだ一括の既読にも、一括の既読の取り消しの要件が当てはまる。大量の記事の取り消し、取り消しの失敗の表示、取り消しのあとの一覧の要件も同じである。
当たる記事が1件もないとき、画面は、その期間より古い未読がないことを知らせ、取り消しの手段を表示しない。

#### Scenario: 1日より古い記事を既読にする

- **WHEN** 2日前の未読と6時間前の未読がある一覧で、「1日より古い記事」を選ぶ
- **THEN** 2日前の記事だけが既読になり、6時間前の記事は未読のまま残り、既読にした件数と取り消しの手段が表示される

#### Scenario: 重要度で絞り込んだまま期間を選ぶ

- **WHEN** 重要度4以上の切り替えを入れた状態で、「1日より古い記事」を選ぶ
- **THEN** 1日より古い記事のうち重要度4以上のものだけが既読になり、重要度3以下の未読は残る

#### Scenario: 当たる記事がない

- **WHEN** 1日より古い未読がない一覧で、「1日より古い記事」を選ぶ
- **THEN** 既読になる記事はなく、1日より古い未読はないと知らされ、取り消しの手段は表示されない

## MODIFIED Requirements

### Requirement: 一括の既読のあとの次の項目への移動

一括の既読のあとに次の項目へ移る設定が有効なとき、画面は、一括の既読のあとに、左のペインの表示順でいまの項目より下にある、未読が1件以上の最初の項目を開かなければならない（MUST）。
カテゴリの一覧からは、次のカテゴリか「未分類」へ移る。
購読フィードの一覧と各カテゴリの「AI生成」の一覧からは、カテゴリをまたいで、次の購読フィードまたは「AI生成」へ移る。
当たる項目がないとき、画面は移らない。
期間を選んだ一括の既読のあとは、画面は、設定にかかわらず、いまの一覧にとどまらなければならない（MUST）。

#### Scenario: 次のカテゴリへ移る

- **WHEN** カテゴリA、B、Cが並び、Bに未読がなくCに未読がある状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** カテゴリCの一覧が開く

#### Scenario: 次の購読フィードへ移る

- **WHEN** カテゴリAの最後の購読フィードXの一覧で、一括の既読を選ぶ。カテゴリBの「AI生成」には未読がある
- **THEN** カテゴリBの「AI生成」の一覧が開く

#### Scenario: 下に未読がない

- **WHEN** いまの項目より下に未読のある項目がない状態で、一括の既読を選ぶ
- **THEN** 画面はいまの項目のままである

#### Scenario: 設定が無効

- **WHEN** この設定が無効な状態で、カテゴリAの一覧で一括の既読を選ぶ
- **THEN** 画面はカテゴリAの一覧のままである

#### Scenario: 期間を選んで既読にする

- **WHEN** この設定が有効で、カテゴリCに未読がある状態で、カテゴリAの一覧で「1日より古い記事」を選ぶ
- **THEN** 画面はカテゴリAの一覧のままで、1日以内の記事を読み続けられる
