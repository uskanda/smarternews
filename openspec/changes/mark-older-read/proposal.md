# Proposal

## Why

一括の既読は、一覧を読み込んだ時刻より前の未読をすべて既読にする。
数日ぶりに開いたとき、古い記事だけを片付けて直近の分を残す、という読み方ができない（Issue #125）。
APIは任意の `before` を受け付けるので、画面から期間に応じた時刻を送れば足りる。

## What Changes

- 「すべて既読にする」のすぐ右に、「▾」だけの細いボタン（読み上げは「期間を選んで既読にする」）を足す。
- 押すとメニューが開き、「1日より古い記事」「3日より古い記事」「1週間より古い記事」を選べる。
- 選ぶと、表示中の項目と絞り込みに当たる未読のうち、その期間より古いものだけを既読にする。取り消しの知らせは「すべて既読にする」と同じに出す。
- 期間を選んだときは、「次の項目へ移る」設定が有効でも、いまの一覧にとどまる。
- 「すべて既読にする」の1回押す動きと `Shift+A` は変えない。Androidアプリには手を入れない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-reader`：期間を選んだ一括の既読の要件を足し、一括の既読のあとの次の項目への移動に例外を足す。

## Impact

- `apps/web/src/reader/MarkOlderMenu.tsx`（新規）：期間のメニュー
- `apps/web/src/reader/ReaderPage.tsx`：一括の既読の処理を分け、メニューを見出しの行に置く
- `DESIGN.md`：期間のメニューの項を足す
- APIとサーバー：変えない。既存の一括の既読のAPIを使う
