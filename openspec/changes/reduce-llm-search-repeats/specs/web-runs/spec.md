# Spec Delta

## ADDED Requirements

### Requirement: LLM検索の注意の項目の「元に戻す」

LLM検索を1日1回に減らしていることを示す注意の項目に、画面は「元に戻す」の操作を並べなければならない（MUST）。
利用者が「元に戻す」を選び、操作が成功したとき、画面は、再読み込みなしでその項目を区画から除く。失敗したときは失敗を知らせ、項目を区画に残す。

#### Scenario: 元に戻す

- **WHEN** 実行履歴の「注意」の区画で、LLM検索の項目の「元に戻す」を選ぶ
- **THEN** その項目は区画から消え、そのトピックのLLM検索は次の実行から毎回使われる

#### Scenario: サーバーに届かない

- **WHEN** サーバーが止まっている状態で「元に戻す」を選ぶ
- **THEN** 元に戻せなかったことが表示され、項目は区画に残る
