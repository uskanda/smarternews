# Spec Delta

## ADDED Requirements

### Requirement: 検索のタスクに渡す直近の見出し

クローラーは、検索のタスクに、そのトピックに結び付いた生成記事の見出しを、最後に書いたか更新した新しい順に10件まで渡さなければならない（MUST）。
配信記事の見出しは渡さない。期間では絞らない。

#### Scenario: 記事が12件あるトピック

- **WHEN** 生成記事が12件結び付いたトピックで、LLM検索を使う
- **THEN** 検索のタスクには、最後に書いたか更新した新しい順に10件の見出しが渡る

#### Scenario: 配信記事

- **WHEN** トピックに結び付いた記事が、生成記事1件と配信記事1件である
- **THEN** 検索のタスクには、生成記事の見出しだけが渡る

### Requirement: 直近の見出しの指示

見出しが1件以上あるとき、検索のタスクは、見出しを取得したデータとして示し、その記事にした同じページは挙げず、同じ話題の新しい展開や続報のページは含めるよう指示しなければならない（MUST）。
見出しがないとき、検索のタスクは見出しの区画を含めてはならない（MUST NOT）。

#### Scenario: 見出しがある

- **WHEN** 見出しを2件渡して検索のタスクを組み立てる
- **THEN** 指示に2件の見出しと、同じページを避けて新しい展開を含める旨が入る

#### Scenario: 見出しがない

- **WHEN** 見出しを渡さずに検索のタスクを組み立てる
- **THEN** 指示に見出しの区画はない
