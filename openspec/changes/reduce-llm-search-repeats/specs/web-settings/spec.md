# Spec Delta

## ADDED Requirements

### Requirement: 減らしているLLM検索の表示

トピックのLLM検索を1日1回に減らしている間、トピックの編集は、LLM検索の選択の近くに、減らしていることと「元に戻す」の操作を表示しなければならない（MUST）。
利用者が「元に戻す」を選んで操作が成功したとき、画面はその表示を消す。失敗したときは失敗を知らせ、表示を残す。

#### Scenario: 減らしているトピックを開く

- **WHEN** LLM検索を減らしているトピックの編集を開く
- **THEN** LLM検索の選択の近くに、新しい候補が続けて見つからないため1日1回に減らしていることと、「元に戻す」が表示される

#### Scenario: 元に戻す

- **WHEN** その表示の「元に戻す」を選ぶ
- **THEN** 表示が消え、画面を開き直しても表示されない

#### Scenario: 減らしていないトピック

- **WHEN** LLM検索を減らしていないトピックの編集を開く
- **THEN** 減らしていることの表示はない
