# Spec Delta

## ADDED Requirements

### Requirement: 一覧の末尾の表示

記事が1件以上あり、続きのページがない間、記事の一覧は最後の行の下に「一覧の最後です」と表示しなければならない（MUST）。
未読のある次の項目がある間、この表示はその項目を開く操作を並べなければならない（MUST）。
続きのページのない最後の記事を選んだ状態で `j` が押されたとき、画面は選んでいる記事を変えずに、この表示が見える位置まで一覧を送らなければならない（MUST）。本文の末尾で `Space` が押されたときも同じである。
このとき、画面は一覧の最後であることを読み上げにも伝えなければならない（MUST）。
狭い画面で最後の記事の本文を表示している間、本文の末尾の「次の記事」の位置にも、同じ文と操作を置かなければならない（MUST）。

#### Scenario: 続きのない一覧の末尾

- **WHEN** 記事が3件の項目を開く
- **THEN** 最後の行の下に「一覧の最後です」と表示される

#### Scenario: 続きのある一覧

- **WHEN** 記事が51件ある項目を開き、最初の50件だけを読み込んでいる
- **THEN** 末尾に「一覧の最後です」は表示されない

#### Scenario: 未読のある次の項目を開く

- **WHEN** 下に未読のあるカテゴリが並ぶカテゴリの一覧で、末尾の「未読のある次の項目を開く」を選ぶ
- **THEN** 未読のある次のカテゴリの一覧が開く

#### Scenario: 次の項目のない一覧

- **WHEN** 上部の「未読」の一覧を末尾まで表示する
- **THEN** 表示されるのは「一覧の最後です」だけで、次の項目を開く操作はない

#### Scenario: 最後の記事で次へ進む

- **WHEN** 続きのページのない一覧の最後の記事を選んだ状態で `j` を押す
- **THEN** 選んでいる記事は変わらず、一覧は末尾の表示が見える位置まで送られ、一覧の最後であることが読み上げに伝わる

#### Scenario: 最後の記事の本文の末尾

- **WHEN** 続きのページのない一覧の最後の記事の本文を末尾まで表示した状態で `Space` を押す
- **THEN** 選んでいる記事は変わらず、一覧の最後であることが読み上げに伝わる

#### Scenario: 狭い画面の本文の末尾

- **WHEN** 幅390pxの画面で、続きのページのない一覧の最後の記事の本文を表示する
- **THEN** 本文の末尾に「一覧の最後です」があり、未読のある次の項目があればそれを開く操作が並ぶ

## MODIFIED Requirements

### Requirement: 続きの読み込み

一覧の末尾までスクロールされ、まだ表示していない記事があるとき、画面は続きの記事を読み込んで一覧に足さなければならない（MUST）。

#### Scenario: 120件の一覧

- **WHEN** 記事が120件ある項目を開き、末尾までのスクロールを繰り返す
- **THEN** 120件すべてが重複なく表示される

#### Scenario: 続きの読み込みに失敗する

- **WHEN** 末尾までスクロールしたあとの続きの読み込みが失敗する
- **THEN** 画面は読み込めなかったことを示し、読み込みを自動では繰り返さない。「さらに読み込む」を選ぶと読み込み直す
