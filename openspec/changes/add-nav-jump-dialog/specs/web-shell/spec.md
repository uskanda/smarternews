# Spec Delta

## ADDED Requirements

### Requirement: 名前を打っての項目の移動

`g` に続けて `u` が押されたとき、画面は入力欄と候補の一覧を持つダイアログ「項目へ移る」を開き、入力欄にフォーカスを置かなければならない（MUST）。
候補は、左のペインのカテゴリ（「未分類」を含む）と購読フィードで、左のペインと同じ順に並ぶ。
折りたたんだカテゴリの下の購読フィードと、未読のない項目を隠す設定で隠している項目も、候補に入る。
各候補は名前と未読数を示す。購読フィードの候補は、属するカテゴリの名前を薄い色で並べて示す。
入力があるとき、画面は、空白で区切った語をすべて名前に含む候補だけを残さなければならない（MUST）。比べるときは、全角と半角、大文字と小文字を区別しない。
開いた直後と入力を変えた直後は、先頭の候補を選んでいる。`↑` と `↓` で選ぶ候補を移し、端では止まる。
Enterか候補のクリックで、画面はその一覧を開き、ダイアログを閉じて、フォーカスを内容へ移さなければならない（MUST）。狭い画面で左のペインを開いていたときは、そのペインも閉じる。
当たる候補がないとき、画面は「当てはまる項目はありません」と示し、Enterで何も開いてはならない（MUST NOT）。
日本語入力の変換を確定するEnterで、画面は一覧を開いてはならない（MUST NOT）。
ダイアログの中で打ったキーは、背後の一覧に働いてはならない（MUST NOT）。

#### Scenario: 名前の一部で購読フィードへ移る

- **WHEN** 購読フィード「Example Blog」がある状態で、`g` を押し、続けて `u` を押して「blog」と打ち、Enterを押す
- **THEN** 購読フィード「Example Blog」の一覧が開き、ダイアログは閉じて、`j` で一覧の記事を選べる

#### Scenario: 全角の入力で当てる

- **WHEN** 購読フィード「Example Blog」がある状態で、ダイアログに全角の大文字で「blog」を打つ
- **THEN** 候補に「Example Blog」が残る

#### Scenario: 複数の語で絞る

- **WHEN** 購読フィード「Tech News」と「World News」がある状態で、ダイアログに「news tech」と打つ
- **THEN** 候補は「Tech News」だけになる

#### Scenario: 矢印のキーで選ぶ

- **WHEN** ダイアログに2つ以上の候補が出ている状態で、`↓` を押してからEnterを押す
- **THEN** 2番目の候補の一覧が開く

#### Scenario: 折りたたんだカテゴリの下の購読フィード

- **WHEN** カテゴリAを折りたたんだ状態で、ダイアログにカテゴリAの購読フィードXの名前を打ってEnterを押す
- **THEN** 購読フィードXの一覧が開く

#### Scenario: 隠している項目

- **WHEN** 未読のない項目を隠す設定で、未読のない購読フィードXが左のペインに出ていない状態で、ダイアログにXの名前を打ってEnterを押す
- **THEN** 購読フィードXの一覧が開く

#### Scenario: 当たる候補がない

- **WHEN** ダイアログに、どの名前にも含まれない文字列を打ってEnterを押す
- **THEN** 画面に「当てはまる項目はありません」と示され、開いている画面は変わらない

#### Scenario: 変換中のEnter

- **WHEN** 日本語入力の変換中にEnterを押す
- **THEN** 一覧は開かず、ダイアログは開いたままである

#### Scenario: Escで閉じる

- **WHEN** ダイアログを開いた状態でEscを押す
- **THEN** ダイアログが閉じ、開いている画面は変わらない

#### Scenario: ダイアログの中の文字は一覧に働かない

- **WHEN** 記事を選んだ状態でダイアログを開き、`s` と `j` を打つ
- **THEN** 文字は入力欄に入り、選んでいる記事とそのスターは変わらない

#### Scenario: 狭い画面の左のペイン

- **WHEN** 狭い画面で左のペインを開いた状態で、`g` と `u` を押し、候補を選んでEnterを押す
- **THEN** 選んだ一覧が開き、ダイアログと左のペインの両方が閉じる

## MODIFIED Requirements

### Requirement: gに続くキーでの項目の移動

`g` が押されてから1秒のうちに次のキーが押されたとき、画面はその次のキーに当たる一覧を開かなければならない（MUST）。
次のキーと開く一覧の対応は次のとおり。

- `a`：「未読」（全カテゴリの未読の一覧）
- `s`：「スター」
- `e`：種別がイベントのカテゴリ。どのカテゴリを開くかは、要件「gとeでのイベントのカテゴリの移動」に従う
- `r`：「最近読んだ記事」
- `u`：名前を打って選んだカテゴリか購読フィード。要件「名前を打っての項目の移動」に従う

当たる項目が左のペインにないとき、画面は何も開かない。

#### Scenario: 未読へ移る

- **WHEN** カテゴリAの一覧で `g` を押し、続けて `a` を押す
- **THEN** 画面に「未読」の一覧が開き、「すべて」の一覧は開かない

#### Scenario: スターへ移る

- **WHEN** カテゴリAの一覧で `g` を押し、続けて `s` を押す
- **THEN** 画面に「スター」の一覧が開く

#### Scenario: 最近読んだ記事へ移る

- **WHEN** 左のペインに「最近読んだ記事」の項目がある状態で `g` を押し、続けて `r` を押す
- **THEN** 画面に「最近読んだ記事」の一覧が開き、表示中の一覧の再取得は起きない

#### Scenario: 項目へ移るダイアログを開く

- **WHEN** カテゴリAの一覧で `g` を押し、続けて `u` を押す
- **THEN** ダイアログ「項目へ移る」が開き、既読も表示するかの切り替えは起きない

#### Scenario: 入力欄での文字の入力

- **WHEN** トピックの文章の入力欄で `g` と `s` を続けて入力する
- **THEN** 2つの文字は入力欄に入り、「スター」の一覧は開かない

### Requirement: gのあとの待ち時間

`g` が押されてから1秒のうちに次のキーが押されなかったとき、画面は何もしてはならない（MUST NOT）。
1秒を過ぎてから押されたキーは、そのキー1つの操作として扱う。
`g` のあとに、`a`、`s`、`e`、`r`、`u` のどれでもないキーが1秒のうちに押されたとき、画面はそのキーの操作をしてはならない（MUST NOT）。

#### Scenario: 1秒を過ぎてから次のキーを押す

- **WHEN** 記事を選んだ状態で `g` を押し、1秒を過ぎてから `s` を押す
- **THEN** 画面に「スター」の一覧は開かず、選んでいる記事のスターが切り替わる

#### Scenario: gだけを押す

- **WHEN** カテゴリAの一覧で `g` だけを押して、2秒待つ
- **THEN** 開いている画面は変わらない

#### Scenario: 対応のないキーが続く

- **WHEN** 記事を選んだ状態で `g` を押し、続けて `m` を押す
- **THEN** 選んでいる記事の既読と未読は変わらない
