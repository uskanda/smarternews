# Spec Delta

## ADDED Requirements

### Requirement: 選んだ文字列から隠すフィルターを作る操作

配信記事のタイトルの原文または本文の原文の文字が選ばれたとき、画面は、選んだ文字列から隠すフィルターを作る操作を表示しなければならない（MUST）。
本文の原文は、全文と配信された内容のどちらを表示している間も対象にする。
訳、要約の区画、生成記事の文字では表示してはならない（MUST NOT）。
前後の空白を除いた文字列が200文字を超える選択と、段落をまたぐ選択でも表示しない。

#### Scenario: 配信記事の本文の語を選ぶ

- **WHEN** 配信記事の本文の原文の1語を選ぶ
- **THEN** 文字を選んだときのメニューに、隠すフィルターを作る操作が表示される

#### Scenario: 訳を選ぶ

- **WHEN** 本文の訳のある配信記事で、訳のまとまりの1語を選ぶ
- **THEN** 隠すフィルターを作る操作は表示されない

#### Scenario: 生成記事の本文を選ぶ

- **WHEN** 生成記事の本文の1語を選ぶ
- **THEN** 隠すフィルターを作る操作は表示されない

#### Scenario: 段落をまたいで選ぶ

- **WHEN** 配信記事の本文で、1つ目の段落の末尾から2つ目の段落の先頭までを選ぶ
- **THEN** 隠すフィルターを作る操作は表示されない

### Requirement: 本文での右クリックのメニュー

記事のペインで操作できる文字が選ばれている間に、その記事のペインが右クリックされたとき、画面は、選択への操作のメニューを開かなければならない（MUST）。
メニューには、文字を選んだときのメニューと同じ操作と、選んだ文字列のコピーを出す。
操作できる文字が選ばれていないとき、画面は、ブラウザーの標準のメニューを妨げてはならない（MUST NOT）。
記事のペインにフォーカスがある間は、メニューを開くキーまたは `Shift+F10` でも開ける。

#### Scenario: 選んだ語の上で右クリックする

- **WHEN** 配信記事の本文の1語を選び、その上で右クリックする
- **THEN** 隠すフィルターを作る操作とコピーの操作のあるメニューが開く

#### Scenario: 何も選ばずに右クリックする

- **WHEN** 文字を選ばずに、本文の上で右クリックする
- **THEN** ブラウザーの標準のメニューが開く

### Requirement: フィルターを作るダイアログの既定値

隠すフィルターを作る操作が選ばれたとき、画面は、フィルターの設定の画面と同じ入力欄のダイアログを開かなければならない（MUST）。
既定値は、種類は隠すフィルター、範囲は全体、欄はタイトルと内容、方法は部分一致とする。値には、選んだ文字列の前後の空白を除いたものを入れる。
範囲の選択肢では、全体の次に、開いている記事の購読フィードと、その購読フィードのカテゴリを並べる。
保存の前に、隠れる件数を確かめられる。

#### Scenario: ダイアログを開く

- **WHEN** 配信記事の本文の1語を選び、隠すフィルターを作る操作を押す
- **THEN** ダイアログが開き、値にその語が入る。隠すフィルター、全体、タイトルと内容、部分一致を選んだ状態になっている

#### Scenario: 件数を確かめる

- **WHEN** ダイアログで隠れる件数を確かめる操作を押す
- **THEN** 保存すると隠れる件数が表示され、フィルターはまだ登録されない

### Requirement: 選んだ文字列から作ったフィルターの保存のあと

選んだ文字列から作ったフィルターが保存されたとき、画面は、開いている記事の表示を残したまま、一覧と件数を読み直さなければならない（MUST）。
隠したことと隠した件数を知らせ、取り消す操作を表示する。
取り消す操作が選ばれたときは、作ったフィルターを削除する。

#### Scenario: 開いている記事が隠れる

- **WHEN** 開いている配信記事のタイトルの語から隠すフィルターを作って保存する
- **THEN** 記事の表示は残ったまま、その記事は一覧からなくなり、隠した件数が知らされる

#### Scenario: 取り消す

- **WHEN** 保存のあとの知らせで、取り消す操作を押す
- **THEN** 作ったフィルターが削除され、隠れた記事が一覧に戻る

## MODIFIED Requirements

### Requirement: 文字を選んだときのメニュー

本文の原文の文字が選ばれたとき、画面は、選んだ範囲の近くに、ハイライトを付ける操作と、メモを書いてハイライトを付ける操作のメニューを表示しなければならない（MUST）。
原文は、注釈の仕様が定めるハイライトの対象の本文を指す。
配信記事では、このメニューに、選んだ文字列から隠すフィルターを作る操作も加える。

#### Scenario: ハイライトを付ける

- **WHEN** 本文の1文をマウスで選び、メニューのハイライトを付ける操作を押す
- **THEN** その1文がハイライトされ、注釈の一覧にその1文の行が加わる

#### Scenario: メモを書いてハイライトを付ける

- **WHEN** 本文の1文を選び、メニューのメモを書く操作を押し、メモを入力して保存する
- **THEN** その1文がハイライトされ、本文の中でメモの印が付く

#### Scenario: 配信記事の本文を選ぶ

- **WHEN** 配信記事の本文の1文を選ぶ
- **THEN** メニューに、ハイライトを付ける操作、メモを書く操作、隠すフィルターを作る操作が並ぶ

### Requirement: 注釈を付けない箇所でのメニューの非表示

訳、要約の区画、タイトル、読み手への影響、出典、イベントの詳細の文字が選ばれたとき、画面は、文字を選んだときのメニューを表示してはならない（MUST NOT）。
選んだ範囲が、原文とそれ以外の両方にまたがるときも表示しない。
ただし、配信記事のタイトルの原文では、隠すフィルターを作る操作だけのメニューを表示する。

#### Scenario: 訳を選ぶ

- **WHEN** 本文の訳のある配信記事で、訳のまとまりの1文を選ぶ
- **THEN** 文字を選んだときのメニューは表示されない

#### Scenario: 要約の区画を選ぶ

- **WHEN** 要約のある配信記事で、要約の区画の1文を選ぶ
- **THEN** 文字を選んだときのメニューは表示されない

#### Scenario: 配信記事のタイトルを選ぶ

- **WHEN** 配信記事のタイトルの原文の1語を選ぶ
- **THEN** 隠すフィルターを作る操作だけのメニューが表示される

### Requirement: ハイライトと重なる範囲

選んだ範囲が既存のハイライトと重なるとき、画面は、文字を選んだときのメニューに、ハイライトを付ける操作を表示してはならない（MUST NOT）。
1つの文字に2つのハイライトが重ならないようにするためである。
配信記事では、隠すフィルターを作る操作は表示する。

#### Scenario: ハイライトの一部を選び直す

- **WHEN** ハイライトした1文の後半から次の文の前半までを選ぶ
- **THEN** メニューにハイライトを付ける操作は表示されない

#### Scenario: 配信記事でハイライトと重なる範囲を選ぶ

- **WHEN** 配信記事で、ハイライトした1文の一部を選ぶ
- **THEN** 隠すフィルターを作る操作だけのメニューが表示される

### Requirement: 配信された内容を表示している間のハイライト

全文のある配信記事で配信された内容を表示している間、画面は、ハイライトを表示してはならない（MUST NOT）。
文字を選んだときのメニューに、ハイライトの操作も表示しない。隠すフィルターを作る操作は表示する。フィルターが照合するのは、配信された内容だからである。
全文の表示へ戻すと、ハイライトを表示する。

#### Scenario: 配信された内容へ切り替える

- **WHEN** 全文にハイライトのある配信記事で、配信された内容へ切り替える
- **THEN** ハイライトは表示されず、内容の文字を選ぶと、隠すフィルターを作る操作だけのメニューが表示される
