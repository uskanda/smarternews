# grilling 記録: add-filter-from-selection

GitHubのissueの80番のコメントで、1ラウンドの質問に答えた記録である。
issueは、本文の文字を選んで右クリックし、フィルターやストップワードを指定したいという要望である。
ストップワードは全体の隠すフィルターに統合済みなので、この変更は、選んだ文字列から隠すフィルターを作る操作として扱う。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 操作の入口 | 右クリックのメニューと、文字を選んだときのメニューの両方に置く。独自の右クリックのメニューを出すのは、本文に操作できる選択があるときだけにする（C） | Q1 |
| 選んだあとの流れ | ダイアログを開き、選んだ文字列を値に入れる。種類、範囲、欄、方法を変えられ、保存の前に隠れる件数を確かめられる。フィルターの設定の画面と同じ入力欄を使う（A） | Q2 |
| ダイアログの既定値 | 種類は隠すフィルター、方法は部分一致、範囲は全体、欄はタイトルと内容。範囲の選択肢では、開いている記事の購読フィードとカテゴリを先頭のほうに並べる | Q3 |
| 操作を出す記事と箇所 | 配信記事のタイトル（原文）と本文の原文で出す。全文の表示中も出す。訳、要約、生成記事では出さない。200文字を超える選択と、段落をまたぐ選択でも出さない（A） | Q4 |
| Androidアプリ | 今回はWebだけを変える（A） | Q5 |
| 開いている記事が隠れるとき | 記事の表示はそのまま残し、一覧からだけ消す。隠した件数と取り消しの操作を知らせる。取り消すと、作ったフィルターを削除する（A） | Q6 |
