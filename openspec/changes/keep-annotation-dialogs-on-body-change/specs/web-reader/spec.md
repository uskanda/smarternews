# Spec Delta

## ADDED Requirements

### Requirement: 本文が差し替わったときの注釈のダイアログの保持

注釈のダイアログを開いている間、訳や全文が届いて本文が差し替わったとき、Web UIはそのダイアログを閉じてはならない（MUST NOT）。対象のダイアログは、選択から開く「メモを書く」「隠すフィルターを作る…」「トピックを足す…」と、ハイライトのメモの書き直しである。ダイアログに入力した文字は残し、そのまま保存できなければならない（MUST）。

#### Scenario: 訳が届いても書きかけのメモが残る

- **WHEN** 翻訳を待っている記事で、本文の選択から「メモを書く」を開いて文字を入れ、そのあと訳が届く
- **THEN** ダイアログは開いたままで、入れた文字が残っている

#### Scenario: 訳が届いたあとに書きかけのメモを保存する

- **WHEN** 訳が届いたあとに、残っていた書きかけのメモを保存する
- **THEN** 選んだ文字列がメモ付きのハイライトとして保存される

#### Scenario: 訳が届いてもハイライトのメモの書き直しが残る

- **WHEN** 翻訳を待っている記事で、ハイライトのメモを書き直している途中に訳が届く
- **THEN** ダイアログは開いたままで、入れた文字が残っている

#### Scenario: 訳が届いても隠すフィルターとトピックのダイアログが残る

- **WHEN** 翻訳を待っている記事で、「隠すフィルターを作る…」か「トピックを足す…」のダイアログで値を変えている途中に訳が届く
- **THEN** ダイアログは開いたままで、変えた値が残っている

#### Scenario: 全文が届いても書きかけのメモが残る

- **WHEN** 全文を取得している記事で、本文の選択から「メモを書く」を開いて文字を入れ、そのあと全文が届く
- **THEN** ダイアログは開いたままで、入れた文字が残っている
