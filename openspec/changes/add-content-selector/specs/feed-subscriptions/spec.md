# Spec Delta

## ADDED Requirements

### Requirement: 本文のセレクターの保持

サーバーは、購読フィードごとに、本文のセレクターを1つ保持しなければならない（MUST）。
既定は指定なしとする。指定なしの購読フィードの全文と要約は、これまでどおりReadabilityの結果から取り出す。

#### Scenario: 登録したときの既定

- **WHEN** 本文のセレクターを指定せずに購読フィードを登録する
- **THEN** その購読フィードの本文のセレクターは指定なしである

#### Scenario: 指定して解除する

- **WHEN** 購読フィードの本文のセレクターを `article .body` にしてから、指定なしに戻す
- **THEN** 購読フィードの一覧で、その購読フィードの本文のセレクターは指定なしとして返る

### Requirement: 使えない本文のセレクターの拒否

ページを読む仕組みで使えない本文のセレクターを受けたとき、サーバーは、それを保存してはならない（MUST NOT）。

#### Scenario: ページを読む仕組みが知らない書き方

- **WHEN** 購読フィードの変更で、本文のセレクターに、CSSとしては読めるがページを読む仕組みが知らない書き方の値を送る
- **THEN** 変更は不正な入力として断られ、本文のセレクターは前の値のままである

### Requirement: 本文のセレクターでの全文の取り出し

本文のセレクターを指定した購読フィードの記事の全文を取得するとき、サーバーは、そのセレクターに当たる最初の要素を、Readabilityの結果の代わりに全文へ変換しなければならない（MUST）。
変換の規則と、配信された内容より短いときの失敗（`shorter`）は、指定のないときと同じである。

#### Scenario: 関連記事の一覧を含むページ

- **WHEN** 本文のセレクターが `article .body` の購読フィードで、その要素と関連記事の一覧を含むページの全文を取得する
- **THEN** 保存された全文は `article .body` の要素の文章だけを含み、関連記事の一覧は含まない

#### Scenario: 複数の要素に当たる

- **WHEN** 本文のセレクターがページの2つの要素に当たる
- **THEN** 保存された全文は、ページの順で最初の要素の文章だけを含む

#### Scenario: 当たった要素が配信された内容より短い

- **WHEN** 本文のセレクターに当たる要素の文章が、配信された内容より短い
- **THEN** 全文は保存されず、失敗の理由として `shorter` が記録される

### Requirement: 本文のセレクターが当たらないページ

本文のセレクターを指定した購読フィードで、ページに当たる要素がないとき、または当たった要素の文章が空のとき、サーバーは、Readabilityの結果から本文を取り出さなければならない（MUST）。

#### Scenario: 構造が変わったページ

- **WHEN** 本文のセレクターに当たる要素がないページの全文を取得する
- **THEN** 全文は、本文のセレクターを指定していないときと同じ内容で保存される

### Requirement: 本文のセレクターでの要約の入力

全文を保存していない記事の要約のためにサーバーがページを読むとき、サーバーは、その購読フィードの本文のセレクターで本文を取り出さなければならない（MUST）。
当たる要素がないときは、Readabilityの結果を使う。

#### Scenario: 全文の自動の取得が無効な購読フィード

- **WHEN** 全文の自動の取得が無効で、本文のセレクターを指定した購読フィードの記事を要約する
- **THEN** 要約の入力は、ページで本文のセレクターに当たる要素の文章である

### Requirement: 本文のセレクターを変えたときの未読の記事の全文

購読フィードの本文のセレクターが変わったとき、サーバーは、その購読フィードの未読の記事の全文と失敗の記録と本文の訳を消さなければならない（MUST）。
既読の記事とほかの購読フィードの記事の全文は、消してはならない（MUST NOT）。
同じ値を送った変更では、何も消してはならない（MUST NOT）。
自動の要約がすでに作った要約は、消さない。

#### Scenario: セレクターを直す

- **WHEN** 全文を保存した未読の記事Aと既読の記事Bを持つ購読フィードの本文のセレクターを変える
- **THEN** 記事Aの全文と本文の訳は消え、記事Bの全文は残る

#### Scenario: 取得し直す

- **WHEN** 全文の自動の取得が有効な購読フィードの本文のセレクターを変える
- **THEN** 全文を消した未読の記事は、全文を待つ記事に戻り、新しいセレクターで全文が取得される

#### Scenario: 同じ値

- **WHEN** 購読フィードの変更で、いまと同じ本文のセレクターを送る
- **THEN** その購読フィードの記事の全文は、どれも消えない

### Requirement: 本文のセレクターでのLLMの不使用

サーバーは、本文のセレクターでの取り出しと、その見本のために、LLMを呼び出してはならない（MUST NOT）。

#### Scenario: 見本を求める

- **WHEN** 本文のセレクターの見本を求める
- **THEN** LLMの呼び出しの記録は増えない
