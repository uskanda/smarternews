# Spec Delta

## ADDED Requirements

### Requirement: 設定ファイルでの本文のセレクターの扱い

設定ファイルの書き出しは、本文のセレクターを指定した購読フィードに、その値を書かなければならない（MUST）。
設定ファイルの読み込みは、購読フィードに書かれた本文のセレクターを保存しなければならない（MUST）。
本文のセレクターが書かれていない購読フィードは、新しく登録するときは指定なしとし、すでにあるときは保存済みの値を保つ。

#### Scenario: 往復

- **WHEN** 本文のセレクターを指定した購読フィードを持つサーバーから設定ファイルを書き出し、空のサーバーへ読み込む
- **THEN** 読み込んだサーバーの購読フィードは、同じ本文のセレクターを持つ

#### Scenario: 指定のない購読フィードを書き出す

- **WHEN** 本文のセレクターを指定していない購読フィードを持つサーバーから設定ファイルを書き出す
- **THEN** その購読フィードの項目に、本文のセレクターは現れない

#### Scenario: 値のない購読フィードを読み込む

- **WHEN** 本文のセレクターを指定した購読フィードFを持つサーバーへ、Fに本文のセレクターを書いていない設定ファイルを読み込む
- **THEN** Fの本文のセレクターは、前の値のままである

#### Scenario: 使えない値

- **WHEN** 本文のセレクターにCSSセレクターとして読めない値を書いた設定ファイルを読み込む
- **THEN** 読み込みは不正な設定ファイルとして断られ、何も変わらない
