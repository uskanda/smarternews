# Spec Delta

## ADDED Requirements

### Requirement: 本文のセレクターの欄

購読フィードの編集の画面は、本文のセレクターの欄を表示し、保存できるようにしなければならない（MUST）。
欄のそばに、全文と要約の本文をページのどの要素から取り出すかの指定であることと、値を変えるとその購読フィードの未読の記事の全文を取得し直すことを説明する。
欄を空にして保存すると、指定なしに戻る。

#### Scenario: 指定して保存する

- **WHEN** 購読フィードの編集で、本文のセレクターに `article .body` を入れて保存する
- **THEN** 編集をもう一度開くと、本文のセレクターの欄に `article .body` が入っている

#### Scenario: 説明

- **WHEN** 購読フィードの編集の画面を開く
- **THEN** 本文のセレクターの欄のそばに、値を変えると未読の記事の全文を取得し直すことが表示される

#### Scenario: CSSセレクターでない値

- **WHEN** 本文のセレクターにCSSセレクターとして読めない値を入れて保存する
- **THEN** 欄のそばに誤りが表示され、購読フィードは保存されない

### Requirement: 本文のセレクターの見本

利用者が本文のセレクターの見本を求めたとき、画面は、見本に使った記事のタイトルと、セレクターが要素に当たったかどうかと、取り出した本文の先頭を表示しなければならない（MUST）。
要素に当たらなかったときは、Readabilityの結果に戻ることを表示する。
見本を求めても、購読フィードは保存しない。

#### Scenario: 当たるセレクター

- **WHEN** 本文のセレクターを入れて見本を見るボタンを選び、要素に当たる
- **THEN** 画面は、記事のタイトルと、要素に当たったことと、本文の先頭を表示する

#### Scenario: 当たらないセレクター

- **WHEN** 本文のセレクターを入れて見本を見るボタンを選び、要素に当たらない
- **THEN** 画面は、要素に当たらずReadabilityの結果に戻ることと、その本文の先頭を表示する

#### Scenario: 見本に使える記事がない

- **WHEN** URLを持つ記事が1件もない購読フィードで、見本を見るボタンを選ぶ
- **THEN** 画面は、見本に使える記事がないことを表示する
