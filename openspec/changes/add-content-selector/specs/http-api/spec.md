# Spec Delta

## ADDED Requirements

### Requirement: 本文のセレクターの提供

APIは、購読フィードの一覧、登録、変更で、本文のセレクターを扱わなければならない（MUST）。
変更で値を空にすると、指定なしに戻る。

#### Scenario: 変更して確かめる

- **WHEN** 購読フィードの変更で本文のセレクターを `main article` にしてから、購読フィードの一覧を要求する
- **THEN** その購読フィードは、本文のセレクター `main article` とともに返る

#### Scenario: CSSセレクターでない値

- **WHEN** 購読フィードの変更で、本文のセレクターにCSSセレクターとして読めない値を送る
- **THEN** APIは、入力が不正であることを示す応答と、本文のセレクターの項目の誤りを返す

### Requirement: 本文の見本を求める操作

APIは、購読フィードと本文のセレクターを受けて、本文の見本を返す操作を提供しなければならない（MUST）。
見本は、その購読フィードのURLのある最新の記事1件のページから取り出す。
応答は、使った記事のタイトルとURL、要素に当たったかどうか、変換した本文の先頭と文字数を含む。
本文が配信された内容より短いときは、そのことも含む。
この操作は、何も保存してはならない（MUST NOT）。

#### Scenario: 見本を確かめる

- **WHEN** URLのある記事を持つ購読フィードで、ページの要素に当たる本文のセレクターを付けて見本を求める
- **THEN** APIは、最新の記事のタイトルとURL、要素に当たったこと、その要素から変換した本文の先頭と文字数を返す

#### Scenario: 当たらないセレクター

- **WHEN** ページのどの要素にも当たらない本文のセレクターで見本を求める
- **THEN** APIは、要素に当たらなかったことと、Readabilityの結果から変換した本文の先頭を返す

#### Scenario: 記事がない

- **WHEN** URLのある記事を1件も持たない購読フィードで見本を求める
- **THEN** APIは、見本に使える記事がないことを返す

#### Scenario: ページを読めない

- **WHEN** 最新の記事のページが404を返す購読フィードで見本を求める
- **THEN** APIは、使った記事と、全文の取得の失敗と同じ形の理由を返す

#### Scenario: 何も保存しない

- **WHEN** 見本を求めたあとで、使った記事を要求する
- **THEN** その記事の全文と全文の取得の状態は、見本を求める前と同じである
