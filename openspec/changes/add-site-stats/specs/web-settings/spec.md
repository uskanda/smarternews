# Spec Delta

## ADDED Requirements

### Requirement: 「出典のサイト」の区画

カテゴリの編集の画面は、トピックの成績の区画のすぐ後に「出典のサイト」の区画を置き、直近30日のサイトごとの候補、採用、除外、記事、開いた記事、スター、外れを、候補の多い順にすべて表示しなければならない（MUST）。ホスト名が不明の候補は「不明」の行にまとめる。

#### Scenario: 成績を確かめる

- **WHEN** 直近30日に `example.org` の候補が3件あるカテゴリの編集の画面を開く
- **THEN** トピックの成績の区画の次に「出典のサイト」の区画があり、`example.org` の行に候補3件が表示される

#### Scenario: 候補のないカテゴリ

- **WHEN** 直近30日に候補のないカテゴリの編集の画面を開く
- **THEN** 「出典のサイト」の区画に、候補がまだないことが表示される

### Requirement: サイトを候補から除く操作

サイトの行の「このサイトを候補から除く」を選んだとき、画面は、確認のダイアログを出さずに、そのサイトをカテゴリの除外の一覧に入れなければならない（MUST）。ホスト名が不明の行には、この操作を置かない。

#### Scenario: サイトを除く

- **WHEN** `example.org` の行で「このサイトを候補から除く」を選ぶ
- **THEN** 区画の先頭の除外中のサイトの一覧に `example.org` が加わる

### Requirement: 除外中のサイトの一覧

カテゴリに除外中のサイトがある間、画面は、「出典のサイト」の区画の先頭に、除外中のサイトの一覧を、それぞれの「除外をやめる」とともに表示しなければならない（MUST）。

#### Scenario: 除外をやめる

- **WHEN** 除外中のサイトの一覧の `example.org` で「除外をやめる」を選ぶ
- **THEN** 確認のダイアログは出ず、`example.org` が除外中のサイトの一覧から外れる

### Requirement: サイトのフィードを探す操作

サイトの行の「このサイトのフィードを探す」を選んだとき、画面は、カテゴリの編集の画面のままダイアログで購読フィードの追加の欄を開き、URLに `https://ホスト名/` を入れてフィードを探し始めなければならない（MUST）。カテゴリは、ニュースのカテゴリならそのカテゴリを、イベントのカテゴリなら「なし」を選んだ状態にする。ホスト名が不明の行には、この操作を置かない。

#### Scenario: ニュースのカテゴリ

- **WHEN** ニュースのカテゴリCの画面で、フィードを1つ案内している `example.org` の行の「このサイトのフィードを探す」を選ぶ
- **THEN** ダイアログが開き、URLに `https://example.org/` が入り、見つかったフィードが選ぶ欄に表示され、カテゴリにCが選ばれている

#### Scenario: イベントのカテゴリ

- **WHEN** イベントのカテゴリの画面で、サイトの行の「このサイトのフィードを探す」を選ぶ
- **THEN** ダイアログのカテゴリは「なし」が選ばれている

### Requirement: 探したフィードの購読の確認

「このサイトのフィードを探す」でフィードが1つだけ見つかったとき、画面は、利用者が追加を選ぶまで購読してはならない（MUST NOT）。

#### Scenario: 1つだけ見つかる

- **WHEN** 「このサイトのフィードを探す」で、フィードが1つだけ見つかる
- **THEN** そのフィードは選ぶ欄に表示され、「選んだフィードを追加」を選ぶまで購読フィードの一覧に加わらない

### Requirement: トピックの成績のサイトの除外の表示

トピックの成績の区画は、各トピックの除外の内訳に「サイトの除外」の件数を表示しなければならない（MUST）。

#### Scenario: サイトの除外の件数

- **WHEN** 除外したサイトの候補が2件あるトピックの成績の行を見る
- **THEN** その行に「サイトの除外 2件」が表示される
