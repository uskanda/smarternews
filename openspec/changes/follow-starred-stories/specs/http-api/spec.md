## ADDED Requirements

### Requirement: その後の記事の連なりの提供

記事の詳細の要求を受けたとき、APIは、その記事を前の記事として参照する記事と、それらをさらに参照する記事を後ろにたどった連なりを、最初の公開の新しい順に最大20件、それぞれの見出しと最初の公開日時とともに返さなければならない（MUST）。
スターの有無にかかわらず、後の記事を持つすべての生成記事で返す。
連なりが自分に戻ったときは、そこで止める。

#### Scenario: 2つの続報がある記事

- **WHEN** 記事Bが記事Aを、記事Cが記事Bを前の記事として参照し、記事Aの詳細を要求する
- **THEN** その後の記事として、記事C、記事Bの順で返る

#### Scenario: 後の記事のない記事

- **WHEN** どの記事からも前の記事として参照されていない記事の詳細を要求する
- **THEN** その後の記事は空で返る

### Requirement: スター付きの記事に続く記事かどうかの提供

記事の一覧と詳細で、APIは、記事ごとに、前の記事の連なり（最大20件）のどれかにスターが付いているかどうかを返さなければならない（MUST）。

#### Scenario: スター付きの記事の続報

- **WHEN** スターを付けた記事Aを記事Bが前の記事として参照し、記事Bを含む一覧を要求する
- **THEN** 記事Bは、スター付きの記事に続く記事として返る

#### Scenario: スターのない連なり

- **WHEN** スターのない記事Aを記事Bが前の記事として参照し、記事Bを含む一覧を要求する
- **THEN** 記事Bは、スター付きの記事に続く記事として返らない

### Requirement: 未読の続報の件数の提供

記事の一覧と詳細で、APIは、スター付きの生成記事ごとに、その後の記事の連なりのうち未読の記事の件数を返さなければならない（MUST）。
スターのない記事と配信記事では0を返す。

#### Scenario: 未読の続報がある

- **WHEN** スターを付けた記事Aを、未読の記事Bが前の記事として参照し、記事Aを含む一覧を要求する
- **THEN** 記事Aの未読の続報の件数は1で返る

#### Scenario: 続報を読んだあと

- **WHEN** 同じ状態で記事Bを既読にしてから、記事Aを含む一覧を要求する
- **THEN** 記事Aの未読の続報の件数は0で返る

### Requirement: スター付きの話題での絞り込み

記事の一覧の要求でスター付きの話題が指定されたとき、APIは、スターの付いた記事と、スター付きの記事に続く記事だけを返さなければならない（MUST）。

#### Scenario: スター付きの話題を指定する

- **WHEN** スター付きの記事A、記事Aを前の記事として参照する記事B、無関係の記事Cがある状態で、スター付きの話題を指定して一覧を要求する
- **THEN** 記事Aと記事Bだけが返る
