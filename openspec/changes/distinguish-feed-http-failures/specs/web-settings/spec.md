# Spec Delta

## ADDED Requirements

### Requirement: 配信を終えた購読フィードの印

設定の購読フィードの画面は、配信の終了が記録された購読フィードの行に、「取得に失敗」の代わりに「配信終了」の印を表示しなければならない（MUST）。
失敗の理由は、ほかの失敗と同じく行に表示する。

#### Scenario: 410を返す購読フィードの行

- **WHEN** 最後の取得が410で失敗した購読フィードのある状態で、設定の購読フィードの画面を開く
- **THEN** その行には「配信終了」が表示され、「取得に失敗」は表示されず、理由「配信を終えたと返しています（HTTP 410）」が表示される
