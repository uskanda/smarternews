# Spec Delta

## ADDED Requirements

### Requirement: 配信を終えた購読フィードの一覧の表示

配信の終了が記録された購読フィードの一覧を表示するとき、画面は、一覧の上部の取得の状態の行に、配信を終えたと返していることと、その日付を表示しなければならない（MUST）。
行は、登録の解除を勧め、設定の購読フィードの画面のその購読フィードの行へのリンク「設定で登録を解除する」と、「いま取得」の操作を並べる。
行の色は、取得の失敗と同じエラーの色とする。
状態が重なったときは、配信の終了を、取得の失敗、更新の停止、一時停止のどれよりも強い状態として扱う。

#### Scenario: 410を返す購読フィードを開く

- **WHEN** 2月27日から410を返し続けている購読フィードFの一覧を開く
- **THEN** 一覧の上部の1行に、配信を終えたと返していることと日付「HTTP 410、2月27日から」、登録の解除を勧める文、「設定で登録を解除する」のリンク、「いま取得」が並ぶ

#### Scenario: 登録の解除のリンクを選ぶ

- **WHEN** 配信を終えた購読フィードの一覧の上部で「設定で登録を解除する」を選ぶ
- **THEN** 設定の購読フィードの画面が開き、その購読フィードの行が表示される

### Requirement: 左のペインの配信の終了の印

左のペインの購読フィードの行は、配信の終了が記録された購読フィードに、「配信終了」と読み上げられる印を表示しなければならない（MUST）。
印の形と色は、取得の失敗の印と同じにする。読み上げ名と、ポインターを重ねたときの表示で区別する。
折りたたんだカテゴリの行では、下の購読フィードに配信を終えたものがあれば、「配信を終えた購読フィードがあります」と読み上げられる印を、ほかの状態の印より優先して表示する。

#### Scenario: 配信を終えた購読フィードの行

- **WHEN** 左のペインに、配信の終了が記録された購読フィードの行がある
- **THEN** その行の名前の右に、「配信終了」と読み上げられる印が表示される

#### Scenario: 折りたたんだカテゴリ

- **WHEN** 配信を終えた購読フィードと取得に失敗した購読フィードを含むカテゴリを折りたたむ
- **THEN** カテゴリの行に「配信を終えた購読フィードがあります」と読み上げられる印が表示される

### Requirement: 429と410の理由の文言

購読フィードの取得の失敗の理由を表示するとき、画面は、429と410を、ほかのHTTPの失敗と異なる文言で表示しなければならない（MUST）。
429は「アクセスが多すぎると返されました（HTTP 429）」、410は「配信を終えたと返しています（HTTP 410）」とする。

#### Scenario: 429で失敗した購読フィード

- **WHEN** 最後の取得が429で失敗した購読フィードの一覧を開く
- **THEN** 一覧の上部の行の理由は「アクセスが多すぎると返されました（HTTP 429）」になる
