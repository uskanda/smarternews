# Spec Delta

## ADDED Requirements

### Requirement: Retry-Afterの尊重

取得がHTTPの429または503で失敗し、応答にRetry-Afterがあるとき、サーバーは、その値の示す時刻より前に、その購読フィードの自動の取得を始めてはならない（MUST NOT）。
値は、秒数とHTTPの日付の両方の形を読む。失敗の時刻から24時間より先を示す値は、24時間後として扱う。
読めない値と、失敗の時刻より後でない時刻は無視し、「失敗が続くときの間隔」だけに従う。
2倍に延ばした間隔のほうが遅いときは、その間隔に従う。
429と503以外の失敗のRetry-Afterは無視する。
この扱いは、RSSとAtomの購読フィードと、Webページの購読フィードの両方に適用する。

#### Scenario: 429にRetry-Afterが付く

- **WHEN** 取得周期を30分にした購読フィードの取得が、Retry-Afterの「18000」（5時間）を付けた429で失敗する
- **THEN** 次の自動の取得は、失敗から5時間より前には始まらない

#### Scenario: 503に日付のRetry-Afterが付く

- **WHEN** 購読フィードの取得が、失敗の6時間後の日付をRetry-Afterに付けた503で失敗する
- **THEN** 次の自動の取得は、その日付より前には始まらない

#### Scenario: 24時間より先の指定

- **WHEN** 購読フィードの取得が、1週間後を示すRetry-Afterを付けた429で失敗する
- **THEN** 次の自動の取得は、失敗の24時間後に予定される

#### Scenario: Retry-Afterのない429

- **WHEN** 取得周期を30分にした購読フィードの取得が、Retry-Afterのない429で初めて失敗する
- **THEN** 次の自動の取得は、ほかの失敗と同じく60分後に予定される

#### Scenario: 404に付いたRetry-After

- **WHEN** 購読フィードの取得が、Retry-Afterを付けた404で失敗する
- **THEN** Retry-Afterは無視され、次の自動の取得は2倍に延ばした間隔だけで予定される

#### Scenario: 成功で指定が消える

- **WHEN** Retry-Afterで待っていた購読フィードの次の取得が成功する
- **THEN** 次の取得は、取得周期のとおりに予定される

### Requirement: 待っている間の即時の取得

Retry-Afterの示す時刻を待っている間に、利用者が購読フィードの即時の取得を求めたとき、サーバーは、待たずにその購読フィードを取得しなければならない（MUST）。

#### Scenario: 待っている間にいま取得する

- **WHEN** Retry-Afterで5時間待つことになった購読フィードの即時の取得を、1時間後に求める
- **THEN** サーバーはすぐにその購読フィードを取得する

### Requirement: 配信の終了の記録

購読フィードの取得がHTTPの410で失敗したとき、サーバーは、その購読フィードに配信の終了の時刻を記録しなければならない（MUST）。
時刻は、続けて受けた410のうち最初のものの時刻とする。410以外の応答（成功とほかの失敗）を受けたときは、配信の終了の記録を消す。
410の失敗も、ほかの失敗と同じく、失敗の理由と続けて失敗した回数を記録し、「失敗が続くときの間隔」に従って取得を続ける。
この扱いは、RSSとAtomの購読フィードと、Webページの購読フィードの両方に適用する。

#### Scenario: 410が続く

- **WHEN** 購読フィードの取得が2回続けて410で失敗する
- **THEN** 配信の終了の時刻は1回目の失敗の時刻のままで、続けて失敗した回数は2になる

#### Scenario: 410のあとに成功する

- **WHEN** 配信の終了が記録された購読フィードの次の取得が成功する
- **THEN** 配信の終了の記録と失敗の理由は消える

#### Scenario: 410のあとにほかの失敗

- **WHEN** 配信の終了が記録された購読フィードの次の取得が500で失敗する
- **THEN** 配信の終了の記録は消え、失敗の理由は500のものになる

### Requirement: 配信の終了による無効化の禁止

購読フィードの取得が410で失敗したとき、サーバーは、その購読フィードを無効にしてはならない（MUST NOT）。

#### Scenario: 410を受けた購読フィード

- **WHEN** 有効な購読フィードの取得が410で失敗する
- **THEN** その購読フィードは有効なままである
