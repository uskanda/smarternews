# Spec Delta

## ADDED Requirements

### Requirement: 未読のない項目の非表示

未読のない項目を隠す設定が入っている間、左のペインは、未読が0のカテゴリ、「未分類」、カテゴリの下の「AI生成」、購読フィードを表示してはならない（MUST NOT）。
未読が0のカテゴリは、その下の項目ごと表示しない。
上の段の項目（未読、すべて、スター、AI生成、最近読んだ記事、注釈）とダイジェストは、未読が0でも表示する。

#### Scenario: 未読のない購読フィードとカテゴリを隠す

- **WHEN** 設定を入れた状態で、未読が1件の購読フィードAと未読が0の購読フィードBを持つカテゴリTと、未読が0のカテゴリCがある
- **THEN** 左のペインにはカテゴリTと購読フィードAが表示され、購読フィードB、カテゴリTの下の「AI生成」、カテゴリCは表示されない

#### Scenario: 上の段を残す

- **WHEN** 設定を入れた状態で、どの一覧にも未読がない
- **THEN** 左のペインの上の段の項目とダイジェストはすべて表示される

#### Scenario: 設定を入れていないとき

- **WHEN** 設定を入れていない状態で、未読が0の購読フィードがある
- **THEN** その購読フィードは左のペインに表示される

### Requirement: 取得に問題のある購読フィードの表示

未読のない項目を隠す設定が入っている間、左のペインは、最後の取得に失敗した購読フィードと、更新が止まった購読フィードを、未読が0でもその親のカテゴリとともに表示しなければならない（MUST）。
一時停止中の購読フィードは、未読が0なら表示しない。

#### Scenario: 取得に失敗した購読フィード

- **WHEN** 設定を入れた状態で、未読が0のカテゴリCの下に、未読が0で最後の取得に失敗した購読フィードFがある
- **THEN** 左のペインにカテゴリCと購読フィードFが表示され、購読フィードFには取得に失敗した印が付く

#### Scenario: 一時停止中の購読フィード

- **WHEN** 設定を入れた状態で、未読が0で一時停止中の購読フィードPがある
- **THEN** 購読フィードPは左のペインに表示されない

### Requirement: 開いている項目の表示

未読のない項目を隠す設定が入っている間、左のペインは、開いている一覧の項目を未読が0でも表示しなければならない（MUST）。
開いている項目が購読フィードか、カテゴリの下の「AI生成」なら、その親のカテゴリも表示する。
開いている一覧をすべて既読にしたあとも、その一覧を開いている間は表示し、別の一覧を開いたときに表示しなくなる。

#### Scenario: 未読のない購読フィードを開く

- **WHEN** 設定を入れた状態で、未読が0のカテゴリCの下の、未読が0の購読フィードBの一覧を開く
- **THEN** 左のペインにカテゴリCと購読フィードBが表示される

#### Scenario: 別の一覧へ移る

- **WHEN** 未読が0の購読フィードBを開いている状態から、別の購読フィードAの一覧を開く
- **THEN** 購読フィードBは左のペインに表示されなくなる

### Requirement: 件数を読み込むまでの表示

未読の件数をまだ読み込んでいない間、左のペインは、未読のない項目を隠す設定が入っていても、どの項目も隠してはならない（MUST NOT）。

#### Scenario: 件数の読み込みを待つ

- **WHEN** 設定を入れた状態で画面を開き、未読の件数の応答がまだ届いていない
- **THEN** 左のペインには、すべてのカテゴリと購読フィードが表示される
