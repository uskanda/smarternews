# Spec Delta

## MODIFIED Requirements

### Requirement: キーボードでの項目の移動

`Shift+J` または `Shift+K` が押されたとき、画面は、左のペインに表示している記事の一覧の項目を上から順に見て、いまの項目の次または前の項目を開かなければならない（MUST）。
折りたたんだカテゴリの下の項目は表示していないため、たどる対象に入らない。
未読のない項目を隠す設定で隠した項目も、表示していないため、たどる対象に入らない。
「設定」と「実行履歴」は記事の一覧ではないため、たどる対象に入らない。

#### Scenario: 次のカテゴリへ移る

- **WHEN** カテゴリAとカテゴリBが並び、どちらにも購読フィードがない状態で、カテゴリAの一覧で `Shift+J` を押す
- **THEN** カテゴリBの一覧が開く

#### Scenario: カテゴリの下の項目へ移る

- **WHEN** 購読フィードを持つカテゴリAを開いて、`Shift+J` を押す
- **THEN** カテゴリAの下の「AI生成」の一覧が開く

#### Scenario: 折りたたんだカテゴリを飛ばす

- **WHEN** 購読フィードを持つカテゴリAを折りたたみ、その下にカテゴリBが並ぶ状態で、カテゴリAの一覧で `Shift+J` を押す
- **THEN** カテゴリBの一覧が開く

#### Scenario: 隠した項目を飛ばす

- **WHEN** 未読のない項目を隠す設定を入れ、未読のある購読フィードA、未読が0の購読フィードB、未読のある購読フィードCが並ぶ状態で、購読フィードAの一覧で `Shift+J` を押す
- **THEN** 購読フィードCの一覧が開く

#### Scenario: 前の項目へ戻る

- **WHEN** 左のペインの「スター」の一覧で `Shift+K` を押す
- **THEN** その上の「すべて」の一覧が開く
