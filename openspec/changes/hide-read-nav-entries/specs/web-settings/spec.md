# Spec Delta

## MODIFIED Requirements

### Requirement: 「この端末の設定」の区画

設定の画面は、「この端末の設定」の区画に、配色の選択の操作と、スクロールで既読にする設定の切り替えと、未読のない項目を隠す設定の切り替えを表示しなければならない（MUST）。
配色の選択の操作は、この区画の外には表示しない。
この区画は、ここの設定がこのブラウザーだけに保存され、サーバーには送られないことを伝える。

#### Scenario: 設定の画面を開く

- **WHEN** 設定の画面を開く
- **THEN** 設定の画面の「この端末の設定」の区画に、配色の選択の操作と、スクロールで既読にする設定の切り替えと、未読のない項目を隠す設定の切り替えが表示され、このブラウザーだけに保存することが書かれている

#### Scenario: 別のブラウザーで開く

- **WHEN** ブラウザーAで切り替えを入れてから、ブラウザーBで設定の画面を開く
- **THEN** ブラウザーBの切り替えは切れた状態で表示される

## ADDED Requirements

### Requirement: 未読のない項目を隠す設定の切り替え

利用者が未読のない項目を隠す設定の切り替えを入れたとき、画面は、保存の操作を待たずに、左のペインで未読のない項目を隠し始めなければならない（MUST）。
切り替えは、開いている項目と取得に問題のある購読フィードは隠さないこと、Shift+JとShift+Kも隠した項目を通らないことを伝える。
切り替えは、このブラウザーだけに保存し、サーバーには送らない。

#### Scenario: 切り替えを入れる

- **WHEN** 設定の画面で切り替えを入れる
- **THEN** サーバーへ何も送らずに切り替えが入った状態になり、再読み込みのあとも入ったままになる

#### Scenario: 選んでいないとき

- **WHEN** 切り替えを1度も選んでいないブラウザーで設定の画面を開く
- **THEN** 切り替えは切れた状態で表示される
