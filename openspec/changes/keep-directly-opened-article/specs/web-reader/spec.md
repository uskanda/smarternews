# Spec Delta

## MODIFIED Requirements

### Requirement: 読んだ記事の一覧への残留

未読の一覧で記事が既読になったとき、画面は、利用者が別の項目へ移るか更新を選ぶまで、その行を一覧から消してはならない（MUST NOT）。

#### Scenario: 読んだ記事に戻る

- **WHEN** 未読の一覧で1件目を開き、続けて2件目を開く
- **THEN** 1件目は既読の見た目で一覧に残り、選び直すと本文を読める

#### Scenario: 未読の記事を直接開く

- **WHEN** 未読の記事を新しいタブで直接開き、記事が一覧より先に届いて既読になる
- **THEN** 一覧が届いたあと、その記事の行は既読の見た目で一覧に残り、`j` と `k` はその行から前後の行へ移る
