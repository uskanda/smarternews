# Spec Delta

## ADDED Requirements

### Requirement: ダイアログを開いている間のキー操作の無効化

ダイアログを開いている間、画面は、1文字のキーによる記事と項目の操作を受け付けてはならない（MUST NOT）。
対象は、狭い画面の左のペインを除く、すべてのダイアログである。左のペインを除くのは、その中のキーで項目を移るからである。ダイアログの中のTab、Enter、Space、Escapeは、ダイアログの中の操作に使う。

#### Scenario: ダイアログのボタンにフォーカスがある

- **WHEN** 購読フィードの追加のダイアログで、閉じるボタンにフォーカスを置いて `j` を押す
- **THEN** 選んでいる記事は変わらず、ダイアログは開いたままである

#### Scenario: 確認のダイアログ

- **WHEN** 登録の解除の確認のダイアログを開いた状態で `s` を押す
- **THEN** 背後で選んでいる記事のスターは切り替わらない

#### Scenario: 隠すフィルターを作るダイアログ

- **WHEN** 隠すフィルターを作るダイアログで、ボタンにフォーカスを置いて `j` を押す
- **THEN** 選んでいる記事は変わらず、ダイアログは開いたままである
