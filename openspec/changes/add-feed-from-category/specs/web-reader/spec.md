# Spec Delta

## ADDED Requirements

### Requirement: カテゴリの一覧の追加の操作

ニュースのカテゴリの記事の一覧を表示している間、画面は、一覧の上部に「購読フィードを追加」の操作を表示しなければならない（MUST）。
イベントのカテゴリの一覧と、カテゴリの「AI生成」の一覧には表示しない。カテゴリ以外の一覧のうち、表示するのは「購読フィード」と「未分類」の一覧だけで、その初期のカテゴリは「なし（未分類）」とする（変更`add-feed-from-feed-lists`）。

#### Scenario: ニュースのカテゴリの一覧

- **WHEN** ニュースのカテゴリAの記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードを追加」が表示される

#### Scenario: 操作を出さない一覧

- **WHEN** イベントのカテゴリの一覧、カテゴリAの「AI生成」の一覧、または「未読」の一覧を開く
- **THEN** 一覧の上部に「購読フィードを追加」は表示されない

### Requirement: カテゴリの一覧からの追加のダイアログ

利用者が一覧の上部の「購読フィードを追加」を選んだとき、画面は、記事の一覧を表示したまま、購読フィードの追加のダイアログを開かなければならない（MUST）。
ダイアログは、設定の画面の購読フィードの追加と同じ入力と振る舞いを持つ。URLの入力、カテゴリの選択、自動の要約、翻訳、全文の取得の切り替えと説明、複数のフィードからの選択、Webページの購読である。
ダイアログのカテゴリは、開いていたカテゴリを選んだ状態にする。開いた直後のフォーカスは、URLの入力欄に置く。

#### Scenario: カテゴリを選んだ状態で開く

- **WHEN** カテゴリAの記事の一覧で「購読フィードを追加」を選ぶ
- **THEN** 記事の一覧の上にダイアログが開き、カテゴリにカテゴリAが選ばれ、URLの入力欄にフォーカスがある

#### Scenario: フィードを2つ指定するページ

- **WHEN** ダイアログで、フィードを2つ指定するページのURLを入力して追加する
- **THEN** ダイアログは2つのフィードのタイトルとURLを表示し、利用者が選んだ1つだけが登録される

#### Scenario: フィードのないページ

- **WHEN** ダイアログで、フィードの指定を持たないページのURLを入力して追加する
- **THEN** ダイアログは、フィードが見つからなかったことと、そのページをWebページの購読フィードとして購読する操作を表示する

### Requirement: ダイアログからの追加の完了

ダイアログで購読フィードを登録できたとき、画面は、ダイアログを閉じ、その購読フィードを左のペインの選んだカテゴリの下に表示しなければならない（MUST）。
画面は、追加したことを知らせ、フォーカスを「購読フィードを追加」の操作に戻す。記事の一覧は、開いていたカテゴリのまま変えない。

#### Scenario: フィードのURLを入力して追加する

- **WHEN** カテゴリAの一覧から開いたダイアログに、フィードのURLを入力して追加する
- **THEN** ダイアログが閉じ、左のペインのカテゴリAの下にそのフィードのタイトルが加わり、カテゴリAの記事の一覧が表示されたままである

#### Scenario: カテゴリを選び直して追加する

- **WHEN** カテゴリAの一覧から開いたダイアログで、カテゴリをBに選び直して追加する
- **THEN** 購読フィードは左のペインのカテゴリBの下に加わり、カテゴリAの記事の一覧が表示されたままである

### Requirement: ダイアログの取りやめ

利用者がダイアログを閉じる操作またはEscapeのキーを選んだとき、画面は、購読フィードを登録せずにダイアログを閉じなければならない（MUST）。
次に開いたダイアログは、入力していない状態から始まる。

#### Scenario: 入力の途中で閉じる

- **WHEN** ダイアログにURLを入力し、追加を選ばずにEscapeを押す
- **THEN** ダイアログが閉じ、購読フィードは増えず、フォーカスは「購読フィードを追加」の操作にある

#### Scenario: 閉じたあとに開き直す

- **WHEN** URLを入力してダイアログを閉じ、もう一度「購読フィードを追加」を選ぶ
- **THEN** URLの入力欄は空で、カテゴリには開いているカテゴリが選ばれている

### Requirement: 登録に失敗したときのダイアログ

ダイアログで購読フィードを登録できなかったとき、画面は、ダイアログを開いたまま、入力を残して理由を表示しなければならない（MUST）。
理由の文言は、設定の画面の追加と同じにする。

#### Scenario: 登録済みのフィード

- **WHEN** ダイアログに、すでに購読しているフィードのURLを入力して追加する
- **THEN** ダイアログは開いたままで、入力したURLが残り、すでに購読していることが表示される

### Requirement: 購読フィードの一覧の設定の操作

購読フィードの記事の一覧を表示している間、画面は、一覧の上部に「購読フィードの設定」の操作を表示しなければならない（MUST）。
カテゴリの一覧と、購読フィード以外の一覧には表示しない。

#### Scenario: 購読フィードの一覧

- **WHEN** 購読フィードXの記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードの設定」が表示される

#### Scenario: カテゴリの一覧

- **WHEN** カテゴリAの記事の一覧を開く
- **THEN** 一覧の上部に「購読フィードの設定」は表示されない

### Requirement: 購読フィードの設定のダイアログ

利用者が一覧の上部の「購読フィードの設定」を選んだとき、画面は、記事の一覧を表示したまま、その購読フィードの設定のダイアログを開かなければならない（MUST）。
ダイアログは、自動の要約、翻訳、全文の取得の3つの切り替えを、その購読フィードのいまの値で表示する。
それぞれの切り替えのそばには、設定の画面の編集と同じ説明を表示する。

#### Scenario: いまの値で開く

- **WHEN** 翻訳だけを入れている購読フィードXの一覧で「購読フィードの設定」を選ぶ
- **THEN** ダイアログが開き、翻訳の切り替えだけが入っていて、3つの切り替えのそばにそれぞれの説明が表示される

#### Scenario: Webページの購読フィード

- **WHEN** Webページの購読フィードの一覧で「購読フィードの設定」を選ぶ
- **THEN** 全文の取得の切り替えのそばに、ページから得るのはタイトル、リンク、日時だけであることが表示される

### Requirement: 購読フィードの設定の保存

利用者がダイアログで保存を選んだとき、画面は、3つの切り替えの値をその購読フィードに保存し、ダイアログを閉じなければならない（MUST）。
画面は、保存したことを知らせ、フォーカスを「購読フィードの設定」の操作に戻す。
名前、カテゴリ、取得周期、一時停止、Webページのセレクターは変えない。保存した切り替えが対象にする記事は、設定の画面の編集で保存したときと同じである。

#### Scenario: 要約を入れて保存する

- **WHEN** 購読フィードXのダイアログで、自動で要約する切り替えを入れて保存する
- **THEN** ダイアログが閉じ、設定の画面の購読フィードの一覧で、購読フィードXに自動で要約する印が表示される

#### Scenario: ほかの設定を保つ

- **WHEN** 取得周期を120分にした購読フィードXのダイアログで、翻訳の切り替えを入れて保存する
- **THEN** 購読フィードXの取得周期は120分のままで、名前とカテゴリも変わらない

### Requirement: 購読フィードの設定の取りやめ

利用者が保存を選ばずにダイアログを閉じたとき、画面は、購読フィードの設定を変えてはならない（MUST NOT）。

#### Scenario: 切り替えてから閉じる

- **WHEN** 購読フィードXのダイアログで翻訳の切り替えを入れ、保存を選ばずにEscapeを押す
- **THEN** ダイアログが閉じ、購読フィードXの翻訳は切れたままである

### Requirement: 購読フィードの設定の保存の失敗

ダイアログで保存できなかったとき、画面は、ダイアログを開いたまま、切り替えた値を残して理由を表示しなければならない（MUST）。

#### Scenario: 購読フィードが削除されていた

- **WHEN** ほかの画面で削除された購読フィードXのダイアログで、保存を選ぶ
- **THEN** ダイアログは開いたままで、保存できなかった理由が表示される
