# Spec Delta

## MODIFIED Requirements

### Requirement: スターのある配信記事の保護

サーバーは、スターのある配信記事と、注釈のある配信記事を、フィルターによって隠してはならない（MUST NOT）。
注釈をすべて消した配信記事と、スターを外した配信記事は、フィルターに合えば再び隠す。

#### Scenario: スターを付けたあとに隠すフィルターを足す

- **WHEN** タイトルに「特売」を含む配信記事にスターを付けたあと、タイトルに「特売」を含むという隠すフィルターを登録する
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: 残すフィルターに合わないスターのある記事

- **WHEN** 購読フィードAに残すフィルターがある状態で、そのフィルターに合わないAの配信記事にスターを付ける
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: ハイライトを付けたあとに隠すフィルターを足す

- **WHEN** タイトルに「特売」を含む配信記事にハイライトを付けたあと、タイトルに「特売」を含むという隠すフィルターを登録する
- **THEN** その配信記事は記事の一覧に含まれる

#### Scenario: 隠した配信記事の一覧から開いて注釈を付ける

- **WHEN** 隠すフィルターの隠した配信記事の一覧から配信記事を開き、記事全体へのメモを保存する
- **THEN** その配信記事は記事の一覧に含まれ、そのフィルターの隠している件数から外れる

#### Scenario: 最後の注釈を消す

- **WHEN** 隠すフィルターに合い、スターがなく、ハイライトが1つだけある配信記事で、そのハイライトを消す
- **THEN** その配信記事は記事の一覧に含まれなくなる

### Requirement: 隠している件数の提供

フィルターの一覧の要求を受けたとき、サーバーは、フィルターごとに、隠している配信記事の件数を返さなければならない（MUST）。
隠すフィルターの件数は、範囲に入り、そのフィルターに合う配信記事の件数である。残すフィルターの件数は、範囲に入り、その範囲の有効な残すフィルターのどれにも合わない配信記事の件数である。
どちらも、スターのある配信記事と、注釈のある配信記事を数えない。ほかのフィルターでも隠れる配信記事は、それぞれのフィルターで数える。無効のフィルターの件数は0である。

#### Scenario: フィルターごとの件数

- **WHEN** 隠すフィルターAが配信記事を4件、隠すフィルターBが0件隠している状態で一覧を要求する
- **THEN** Aに件数4、Bに件数0が返る

#### Scenario: 2つのフィルターに合う記事

- **WHEN** 隠すフィルターAとBの両方に合う配信記事が1件だけある状態で一覧を要求する
- **THEN** AとBのどちらにも件数1が返る

#### Scenario: 注釈のある記事を数えない

- **WHEN** 隠すフィルターAに合う配信記事が3件あり、うち1件にハイライトがある状態で一覧を要求する
- **THEN** Aに件数2が返る
