# Spec Delta

## MODIFIED Requirements

### Requirement: 記事の保存期間

スターと注釈のどちらもない生成記事の最終更新から180日が過ぎたとき、サーバーはその生成記事を削除しなければならない（MUST）。

#### Scenario: 古い記事

- **WHEN** スターと注釈のどちらもない生成記事の最終更新から181日が過ぎる
- **THEN** その生成記事は、記事の一覧とRSSのどちらにも現れない

## ADDED Requirements

### Requirement: 注釈のある記事の保持

注釈のある記事について、サーバーは保存期間による削除をしてはならない（MUST NOT）。
生成記事と配信記事のどちらにも適用する。注釈は、ハイライトと記事全体へのメモのどちらでもよい。

#### Scenario: ハイライトを付けた古い生成記事

- **WHEN** スターがなく、ハイライトのある生成記事の最終更新から1年が過ぎる
- **THEN** その生成記事は読み出せる

#### Scenario: 記事全体へのメモだけを書いた古い配信記事

- **WHEN** スターがなく、記事全体へのメモだけのある配信記事の並びの時刻から1年が過ぎる
- **THEN** その配信記事は読み出せる

### Requirement: 注釈をすべて消した記事の保存期間

記事の最後の注釈が削除されたとき、サーバーは、その記事を保存期間による削除の対象に戻さなければならない（MUST）。
スターのある記事は、スターのある記事の保持に従って残す。

#### Scenario: 注釈を消した古い生成記事

- **WHEN** スターがなく、最終更新から200日が過ぎた生成記事の、ただ1つのハイライトを削除する
- **THEN** 次の保存期間の削除で、その生成記事は削除される

#### Scenario: スターのある記事の注釈を消す

- **WHEN** スターがあり、最終更新から200日が過ぎた生成記事の、ただ1つのハイライトを削除する
- **THEN** その生成記事は保存期間による削除のあとも読み出せる
