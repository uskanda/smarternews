# Spec Delta

## MODIFIED Requirements

### Requirement: 照合する欄

サーバーは、記事の次の欄を検索語と照合しなければならない（MUST）。
照合するのは、タイトル、訳したタイトル、要約、本文、読み手への影響、イベントの会場、ハイライトした文字列、注釈のメモである。
生成記事の本文は記事の本文を指し、配信記事の本文はMarkdownに変換した内容を指す。配信記事の要約は、自動の要約で作った要約を指す。
注釈のメモは、ハイライトへのメモと記事全体へのメモの両方を指す。ハイライトした文字列は、本文に見つからなくなったものも照合する。

#### Scenario: 本文にだけ含む

- **WHEN** 本文にだけ「量子」を含む配信記事がある状態で、「量子」を検索する
- **THEN** その配信記事が結果に含まれる

#### Scenario: 訳したタイトルにだけ含む

- **WHEN** 原文のタイトルが英語で、訳したタイトルにだけ「決算」を含む配信記事がある状態で、「決算」を検索する
- **THEN** その配信記事が結果に含まれる

#### Scenario: 読み手への影響にだけ含む

- **WHEN** 読み手への影響にだけ「金利」を含む生成記事がある状態で、「金利」を検索する
- **THEN** その生成記事が結果に含まれる

#### Scenario: イベントの会場にだけ含む

- **WHEN** 会場にだけ「公会堂」を含むイベントの記事がある状態で、「公会堂」を検索する
- **THEN** そのイベントの記事が結果に含まれる

#### Scenario: ハイライトへのメモにだけ含む

- **WHEN** ハイライトへのメモにだけ「比較」を含む生成記事がある状態で、「比較」を検索する
- **THEN** その生成記事が結果に含まれる

#### Scenario: 記事全体へのメモにだけ含む

- **WHEN** 記事全体へのメモにだけ「来月」を含む配信記事がある状態で、「来月」を検索する
- **THEN** その配信記事が結果に含まれる

#### Scenario: 本文から消えたハイライト

- **WHEN** 配信記事で「電池」を含むただ1つの文にハイライトを付けたあと、書き換えでその文が本文から消え、ほかの欄に「電池」がない状態で、「電池」を検索する
- **THEN** その配信記事が結果に含まれる

#### Scenario: 本文の語とメモの語

- **WHEN** 本文に「電池」を含み、ハイライトへのメモに「工場」を含む記事がある状態で、`電池 工場` を検索する
- **THEN** その記事が結果に含まれる

### Requirement: 隠した配信記事の除外

隠すフィルターまたは残すフィルターで隠している配信記事について、サーバーは、検索の結果に含めてはならない（MUST NOT）。
スターのある配信記事と、注釈のある配信記事は、記事の一覧と同じく隠さない。

#### Scenario: フィルターで隠した記事

- **WHEN** 隠すフィルター「特売」で隠れている配信記事の本文に「電池」がある状態で、「電池」を検索する
- **THEN** その配信記事は結果に含まれない

#### Scenario: スターのある配信記事

- **WHEN** タイトルに「特売」と「電池」を含み、スターのある配信記事がある状態で、隠すフィルター「特売」を登録してから「電池」を検索する
- **THEN** その配信記事が結果に含まれる

#### Scenario: 注釈のある配信記事

- **WHEN** タイトルに「特売」と「電池」を含み、スターがなく、ハイライトのある配信記事がある状態で、隠すフィルター「特売」を登録してから「電池」を検索する
- **THEN** その配信記事が結果に含まれる

### Requirement: 一致した箇所の抜粋

検索の結果の記事について、サーバーは、要約、本文、読み手への影響、イベントの会場のいずれかに検索語が含まれるとき、最初に見つかった箇所の前後を抜粋として返さなければならない（MUST）。
これらの欄に語がなく、注釈のメモに語が含まれるときは、最初に見つかったメモの箇所の前後を抜粋として返す。そのときは、抜粋をメモから作ったことを示す値も返す。
抜粋はMarkdownの記法とリンク先を含まない文字列にする。タイトル、訳したタイトル、ハイライトした文字列にしか語が含まれないとき、抜粋は値なしにする。

#### Scenario: 本文の途中にある語

- **WHEN** 本文の2000文字目のあたりにだけ「電池」を含む配信記事がある状態で、「電池」を検索する
- **THEN** その記事の抜粋は「電池」とその前後の文字を含み、本文の先頭からは始まらない

#### Scenario: タイトルにだけある語

- **WHEN** タイトルにだけ「電池」を含む記事がある状態で、「電池」を検索する
- **THEN** その記事の抜粋は値なしである

#### Scenario: メモにだけある語

- **WHEN** ハイライトへのメモにだけ「比較」を含む生成記事がある状態で、「比較」を検索する
- **THEN** その記事の抜粋は、メモの「比較」とその前後の文字を含み、メモから作った抜粋であることが示される

#### Scenario: 本文とメモの両方にある語

- **WHEN** 本文と記事全体へのメモの両方に「電池」を含む記事がある状態で、「電池」を検索する
- **THEN** その記事の抜粋は本文から作られ、メモから作った抜粋であることは示されない

#### Scenario: 本文から消えたハイライトにだけある語

- **WHEN** 本文の「電池」を含む1文にメモのないハイライトを付けたあと、書き換えでその文が本文から消え、ほかの欄に「電池」がない状態で、「電池」を検索する
- **THEN** その記事は結果に含まれ、抜粋は値なしである

## ADDED Requirements

### Requirement: 注釈の変更の即時の反映

注釈が保存、変更、または削除されたとき、サーバーは、その時点の注釈の内容を、次の検索から照合に使わなければならない（MUST）。

#### Scenario: メモを書いたあと

- **WHEN** 記事全体へのメモに「比較」と書いたあと、「比較」を検索する
- **THEN** その記事が結果に含まれる

#### Scenario: メモを書き直したあと

- **WHEN** ハイライトへのメモを「比較」から「確認」に書き直したあと、「比較」を検索する
- **THEN** ほかの欄に「比較」を含まないとき、その記事は結果に含まれない

#### Scenario: ハイライトを消したあと

- **WHEN** 本文にない語「試作」をメモに書いたハイライトを消したあと、「試作」を検索する
- **THEN** その記事は結果に含まれない
