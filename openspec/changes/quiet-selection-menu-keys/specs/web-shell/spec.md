# Spec Delta

## MODIFIED Requirements

### Requirement: メニューを開いている間のキー操作の無効化

左のペインの項目のメニューか、本文で選んだ文字列のメニューを開いている間、画面は1文字のキーによる記事と項目の操作を受け付けてはならない（MUST NOT）。
メニューの中の矢印キー、Enter、Escapeは、メニューの操作に使う。

#### Scenario: メニューを開いて次の記事のキーを押す

- **WHEN** 購読フィードの項目のメニューを開いた状態で `j` を押す
- **THEN** 選んでいる記事は変わらず、メニューは開いたままである

#### Scenario: 選んだ文字列のメニューを開いて次の記事のキーを押す

- **WHEN** 配信記事の本文の文字を選び、右クリックでメニューを開いた状態で `j` を押す
- **THEN** 選んでいる記事は変わらず、メニューは開いたままである
