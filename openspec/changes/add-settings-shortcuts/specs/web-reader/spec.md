# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードの設定のダイアログからほかの設定への移動

利用者が購読フィードの設定のダイアログで「ほかの設定」を選んだとき、画面は、購読フィードの設定の画面へ移り、その購読フィードの行の編集を開いた状態にしなければならない（MUST）。
ダイアログで切り替えて保存していない値は保存しない。編集の欄は、保存してある値から始まる。

#### Scenario: ほかの設定へ移る

- **WHEN** 購読フィードAの記事の一覧で「フィードの設定」を開き、「ほかの設定」を選ぶ
- **THEN** ダイアログが閉じ、購読フィードの設定の画面が表示され、購読フィードAの行の編集が開き、名前の入力欄にフォーカスがある

#### Scenario: 保存していない切り替え

- **WHEN** ダイアログで翻訳を入れてから、保存を選ばずに「ほかの設定」を選ぶ
- **THEN** 購読フィードAの翻訳は切れたままで、開いた編集の欄の翻訳も切れている
