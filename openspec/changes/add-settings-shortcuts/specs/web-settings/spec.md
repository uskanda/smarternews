# Spec Delta

## ADDED Requirements

### Requirement: 購読フィードの一覧からの記事の一覧への移動

購読フィードの設定の画面は、一覧の各行に、その購読フィードの記事の一覧へ移るリンクを表示しなければならない（MUST）。
リンクの読み上げ用の名前は「〈購読フィードの名前〉の記事の一覧」とする。行の編集の欄を開いている間は、リンクを表示しない。

#### Scenario: 行から記事の一覧へ移る

- **WHEN** 購読フィードの設定の画面で、購読フィードAの行の「記事の一覧」を選ぶ
- **THEN** 購読フィードAの記事の一覧が表示される

#### Scenario: 編集の欄を開いている

- **WHEN** 購読フィードAの行の編集を開く
- **THEN** 購読フィードAの行に「記事の一覧」は表示されない

### Requirement: アドレスで指定した購読フィードの編集

購読フィードの設定の画面を `/settings/feeds#feed-<識別子>-edit` で開いたとき、画面は、その行の編集を開かなければならない（MUST）。
そのうえで、最初の入力欄にフォーカスを置き、行までスクロールする。
スクロールは、購読フィードの一覧を読み込んだあとに行う。指定した購読フィードがないときは、どの行の編集も開かない。
`-edit` のない `/settings/feeds#feed-<識別子>` では、編集は開かない。
取得の状態の表示（show-feed-fetch-state）のとおり、行までスクロールして行の名前にフォーカスを移す。

#### Scenario: 編集を指定せずに行を指定して開く

- **WHEN** 購読フィードBの行を、`-edit` を付けずに指定して購読フィードの設定の画面を開く
- **THEN** Bの行までスクロールし、Bの名前にフォーカスがあり、Bの行の編集は開かない

#### Scenario: 購読フィードを指定して開く

- **WHEN** 購読フィードAとBがある状態で、Bの行を指定して購読フィードの設定の画面を開く
- **THEN** Bの行の編集が開き、名前の入力欄にフォーカスがあり、Bの行までスクロールし、Aの行の編集は開かない

#### Scenario: ない購読フィードを指定して開く

- **WHEN** 存在しない購読フィードの行を指定して購読フィードの設定の画面を開く
- **THEN** どの行の編集も開かず、各行に「編集」が表示される

### Requirement: 設定の画面の区画へのリンク

設定の画面は、見出しの下に、9つの区画へのリンクを並べなければならない（MUST）。
区画は、カテゴリ、購読フィード、語の色付け、読み手情報、全体設定、この端末の設定、設定ファイル、プロバイダー、トークンである。
リンクは幅が足りなければ折り返し、画面をスクロールすると一緒に流れる。

#### Scenario: リンクの並び

- **WHEN** 設定の画面を開く
- **THEN** 見出しの下に、9つの区画へのリンクが上の順に並ぶ

#### Scenario: リンクで区画へ移る

- **WHEN** 区画のリンクの「トークン」を選ぶ
- **THEN** 画面は「トークン」の区画までスクロールする

### Requirement: アドレスで指定した区画への移動

アドレスで区画を指定して設定の画面を開いたとき、画面は、設定を読み込んだあとに、その区画までスクロールしなければならない（MUST）。
読み込みのあとに表示される区画（読み手情報、全体設定）も対象とする。

#### Scenario: 読み込みのあとに出る区画

- **WHEN** 読み手情報の区画を指定して設定の画面を開く
- **THEN** 設定を読み込んだあと、画面は読み手情報の区画までスクロールする

#### Scenario: プロバイダーの区画

- **WHEN** 月の予算の警告の「プロバイダーの設定」から設定の画面を開く
- **THEN** 画面はプロバイダーの区画までスクロールする

### Requirement: 設定の画面の主となる操作

設定の画面は、主となるボタンを表示してはならない（MUST NOT）。
カテゴリの追加、読み手情報の保存、全体設定の保存のボタンは、ほかのボタンと同じ見た目にする。

#### Scenario: 設定の画面のボタン

- **WHEN** 設定の画面を開き、設定を読み込み終える
- **THEN** どのボタンも主となるボタンの見た目ではない
